# スタディスポットMAP

無料で勉強できる場所（図書館・公民館・学習スペース・カフェ等）を地図上にピンで並べ、
**5軸の評価（100点満点・S〜Cランク）**、**設備の事実（電源・Wi-Fi・空調）**、
**時間帯ごとの空き状況**を共有するための Web アプリです。

`index.html` はビルド不要の単一HTML構成で、そのまま開いても GitHub Pages で公開しても動作します。

---

## 主な機能

- **全国47都道府県・707件の初期データ**（2026-11-22時点のDBと同期）
- **地域・現在地・キーワード検索**
  - 都道府県 › 市町村セレクタ（`?pref=...&city=...&spot=...` でURL共有可能）
  - **📍 現在地ボタン**で現在地周辺を「近い順」に表示・直線距離表示
  - 全国横断のインクリメンタル検索サジェスト
- **絞り込み＆並び替え**
  - ランク（S / A / B / C / 未評価 / Z=勉強できなかった報告あり）
  - 種別（データ上の `公民館`・`大学` 表記も含めて網羅）
  - チップ：🕐 いま空いてる／いま開いてる（祝日・休館日・深夜営業対応）／⚡ 電源／📶 Wi-Fi／静か／座席快適／集中ムード／息抜きしやすい／空調・空間／完全無料
  - 電源・Wi-Fiは「確認済みのみ／未確認も含める」の切り替えに対応
- **地図表示（OpenStreetMap / 国土地理院タイル + Leaflet / MarkerCluster）**
  - ピン色はランクに対応（S=金 / A=緑 / B=青 / C=灰 / 未=灰破線 / Z=黒赤枠）
  - 広域表示時は自動でクラスタリングして描画負荷を軽減
- **口コミ・ワンタップ設備報告・スポット追加**
  - 5軸採点＋訪問時間帯・混雑度＋「ここでは勉強できなかった」報告
  - 施設詳細から「電源・Wi-Fi・空調」の有無をワンタップで報告可能
  - スポット追加時に「地図クリック」「住所から位置取得（国土地理院API）」「現在地」に対応
  - 施設ごとのコメント欄（`/comments/comments.js`）

## 評価指標（5軸）

「ある／ない」の事実（電源・Wi-Fi・空調）と、体感・主観の5軸評価を分けて扱っています。

| 軸 | 重み | 見るところ |
|---|---|---|
| 静音性 | 25% | 会話・放送・生活音による中断の少なさ |
| 座席・姿勢の快適さ | 20% | 机の広さ、椅子の質、用途に応じた席の選択肢 |
| 周囲の集中度・ピア効果 | 20% | 周りの集中ムードに引っ張られる環境か |
| 空調・空間 | 20% | 温度管理、換気、採光、天井の高さや開放感 |
| 息抜きのしやすさ | 15% | 飲食可否や休憩スペース、気分転換のしやすさ |

各口コミで1〜5（具体的基準つき）をつけ、平均に重みを掛けて100点換算します。

| ランク | 点数 |
|---|---|
| S | 85〜100 |
| A | 72〜84 |
| B | 58〜71 |
| C | 〜57 |
| 未 | まだ評価なし |
| Z | ここでは勉強できなかった報告のみあり |

## データの保存先 — 共有DB / 端末内フォールバック

- **共有DB（Supabase）**: 全員が同じスポット・口コミ・設備情報を参照・投稿できます（`DB.fetchAll` により1,000件超でも全件ページング取得）。
- **端末内保存（localStorage）**: 共有DBに接続できない場合は同梱 `SEED` データを元にローカル保存へ自動フォールバックします。

```text
├── supabase-schema.sql   # 共有DBのテーブル定義・RLS・本番移行手順
└── README.md
```

## 本番運用に向けた課題（`supabase-schema.sql` 参照）

1. **RLS の引き締め** — 現在は匿名での更新・削除も通るプロトタイプ設定。`supabase-schema.sql` 末尾の「段階1・段階2」SQLに従って `DELETE` / `UPDATE` の権限制限、またはログイン必須化に切り替える必要があります。
2. **口コミ・設備データの拡充** — 707件のうち評価済みは一部に偏っているため、現地利用者のワンタップ設備報告・口コミを増やす導線と、10件未満の23府県（特に大都市圏）のデータ追加が今後の課題です。
3. **インデックス制御** — 現在はサイト全体の AdSense 審査経緯により `<meta name="robots" content="noindex,follow">` が設定されています。検索流入を狙うタイミングで解除・`sitemap.xml` 登録を検討してください。
