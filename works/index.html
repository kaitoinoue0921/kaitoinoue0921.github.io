スタディスポットMAP

無料で勉強できる場所を地図に並べて、S〜Cのランクと点数で共有するサイト。栃木県から始めています。図書館や公民館は「行ってみないと使えるか分からない」ので、行く前に分かるようにしたかった。

  • 静音性・電源・Wi-Fi・座席・人目・空調・アクセス・水の8軸で採点し、100点満点とS/A/B/Cランクに変換
  • 時間帯ごとの空き状況をヒートマップで表示。「いま空いてる」場所だけに絞り込める
  • 都道府県から市町村まで絞り込み。誰でもスポットと口コミを書き込める
  • Leaflet / OpenStreetMap
  • Google Maps API
  • Supabase
  • Vanilla JS
