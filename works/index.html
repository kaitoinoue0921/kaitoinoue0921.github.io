スタディスポットMAP

無料で勉強できる場所を地図に並べて、S〜Cのランクと点数で共有するサイト。栃木県から始めています。図書館や公民館は「行ってみないと使えるか分からない」ので、行く前に分かるようにしたかった。

  • 静音性・電源・Wi-Fi・座席・人目・空調・アクセス・水の8軸で採点し、100点満点とS/A/B/Cランクに変換
  • 時間帯ごとの空き状況をヒートマップで表示。「いま空いてる」場所だけに絞り込める
  • 都道府県から市町村まで絞り込み。誰でもスポットと口コミを書き込める
  • Leaflet / OpenStreetMap
  • Google Maps API
  • Supabase
  • Vanilla JS

Works · 04プロトタイプ公開中

東大理三 数学マップ

参考書を何冊も渡り歩くのが非効率だと思ったので、数学の全範囲を「これが分からないとこれが分からない」の依存関係で構造化しました。1つのノードを開けば、着眼点・手順・別解・東大での出方が全部そこにあります。何を、どの順で、なぜやるかを、感覚ではなくグラフで決めるためのものです。

  • 138ノードを依存グラフ化。分からない場所から前提を左に辿ると、原因のノードに必ず行き着く
  • 東大での必要度と「そこが止まると何ノードが解けなくなるか」から優先度を計算し、今日やる3つだけを出す
  • 記述の採点は現実的でないので、方針の選択・誤りの発見・値の一致の3形式で習得を判定する
  • 忘却曲線に沿ってパワーが下がる。単元ごとのモンスターが弱るので、放置した範囲が一目で分かる
  • 全ノードをObsidianのMarkdownとCanvasに書き出せる。グラフビューに構造がそのまま出る

まだ作りかけです。統合解説を書き終えたのは138ノード中6つで、合格可能性の数値も実データでの較正前。数字の絶対値ではなく、習得や放置で動く方向を見るものとして置いています。

  • Vanilla JS
  • PWA / Service Worker
  • JSON
  • GitHub Pages

まちのコエ

まちの困りごとを住民同士で共有し、賛同が集まったら行政提出用の提案書を自動で作る、非営利のシビックテック・プラットフォーム。手数料は取らず、運営費は寄付だけで賄う設計にしています。

  • 課題を地図とリストで可視化。賛同（1人1票）とコメントで議論を集約する
  • 賛同が50件に達すると、議論の要約を行政提出フォーマットに組んでPDF化する
  • 寄付額と運営費の内訳を毎月公開する透明性ダッシュボードつき

いまはデータを端末内に保存するだけのプロトタイプです。ログインと共有データベースはこれから。

Works · 06開発中

FocusRoom

勉強に集中するためのiOSアプリを作っています。スマホを触らせないアプリはOS標準のスクリーンタイムが最強なので、そこでは勝負していません。同じ部屋に入った人どうしが、お互いの状態を見ている、という一点に賭けています。

  • 部屋に入ると集中時間とコインが貯まる。ロックを外すと「解除中」として部屋の全員に流れる
  • 休憩（5・10・20分）は解除と明確に分けた。休憩中は誰にも流れず、責められない。隠れてサボる方に流れさせないため
  • ただし休憩中は集中時間もコインも増えないので、だらだら延ばす動機はない
  • ロックは必ず自分で外せる。外せない仕組みは、いざというときに危ないので作らない
  • Swift / SwiftUI
  • Supabase
  • iOS

まだ手元で動かしている段階で、配布はしていません。いまは休憩機能と配色を入れたところです。

Works · 07開発中

InkVault

Obsidianで医学知識をまとめていたのですが、画像を並べて比較できない・画像に直接書き込めないという不便さが解決できず、自分の使い方に合わせて作り直しました。文章はObsidianと同じく上から下へ書き、画像はWordのように自由に動かせて、その上からペンで直接書き込めます。

  • [[リンク]] で他のノートとつながる。存在しなければタップで新規作成される
  • 画像はドラッグで自由配置。「ペン」モードに切り替えると、文章や画像の上から直接手書きできる（Apple Pencil対応）
  • 画像内の文字をOCRで自動認識し、検索対象にする
  • 既存のObsidian vault（980ノート・画像447枚）をそのまま取り込み済み

まだ自分のMac上でローカルサーバーとして動かしているだけで、公開URLはありません。医学知識を毎日ここにまとめながら、使いながら直しています。

  • Vanilla JS
  • Node.js
  • tesseract.js（OCR）
  • SVG / PointerEvents

国試対策 ブルーノート

医師国家試験に向けた演習アプリ。Ankiの間隔反復を国試向けに厳格化し、復習期日を過ぎるとEXPが指数的に減衰してレベルダウンする仕組みにしました。解いた問題にはその場で自分の語呂合わせや理解を書き込め、公式解説はみんなで編集できるWikiにしています。

  • SM-2アルゴリズムで復習間隔を計算。評価4段階（Again/Hard/Good/Easy）で次の復習日を決める
  • 復習期日超過1日ごとにEXPが0.9倍される厳格な減衰式。放置すると容赦なくレベルダウンする
  • 出題基準（ブループリント）に紐づけ、必修85%・一般臨床75%を目標に到達度をレーダーチャートで可視化
  • 公式解説は全員で編集できるWiki、自分用の語呂合わせや病態生理メモは公開/非公開を選べる「My Note」として分離

まだモックデータで動く段階のプロトタイプです。Supabaseを繋いで、実際の過去問データと共有DBに置き換えていきます。

  • React / TypeScript
  • Tailwind CSS
  • Supabase
  • Recharts

Backlog · 09構想中

これから作りたいもの

まだ手をつけていない案です。作ると決めたものではなく、「これが要るのでは」と思って書き留めてあるものを、そのまま置いておきます。どれも、越えないといけない壁のほうを先に書いています。

  • 家庭教師を回すためのもの

    生徒・保護者・講師の三者で、日程と指導内容を同じ場所で見る。LINEで足りてしまうので、指導内容の透明化とドタキャンの扱いに絞らないと存在理由がない。

  • スマホを触らせないもの

    いまの FocusRoom がここに当たります。OS標準のスクリーンタイムが本命の競合なので、制限そのものではなく、解除の条件で差をつけるしかない。

  • 家族のためのもの

    毎日ひとつ、家族全員に同じ質問が届く、くらいまで具体化しないと続かない。「絆を深める」は目的であって機能ではないので、そこを設計に落とせるかどうか。

  • 結婚を考えているふたりのためのもの

    価値観のすり合わせと、式場・引っ越し・保険のタスク管理。結婚した瞬間に不要になる構造なので、月額課金は成立しない。

  • Webサイトをアプリにするもの

    URLを入れるだけでアプリにする。ただし「Webを表示するだけ」のアプリは審査で落ちるので、カメラや位置情報やオフラインを自動で足せるかが全部。

  • 原価が分かるもの

    検索した商品の原価の見当をつける。実際の原価は企業の機密なので出せるのは推計値だけで、その一線をどう明示するかが難しい。

  • 人と話すきっかけを作るもの

    初対面で何を話すかを渡す。誰がどの場面で使うのかを決めないと、UIが決まらないまま使われないものになる。
