必須

if の省略と倒置（Were / Had / Should）

着眼点if を省くと、were / had / should が文頭に出る。文頭が Were / Had / Should なら仮定法を疑う。

もとの形if省略
If I were you, …Were I you, …
If I had known, …Had I known, …
If it should rain, …Should it rain, …
例文
1
Had I known the truth, I would have told you.
真実を知っていたら、あなたに話していただろうに。
2
Were he younger, he could join the team.
彼がもっと若ければ、チームに入れるのに。
注意否定の倒置: Had I not known…（× Hadn't I known…）。not は主語の後ろ。一般動詞（If I knew → × Knew I）は倒置できない。
確認問題
1
書き換え。If I had had more time, I would have finished it. → ( ) I ( ) more time, I would have finished it.
答え
Had / had had。if 省略で Had を文頭に。

「仮定法」の項目

  1. 仮定法過去（現在の事実の反対）必須
  2. 仮定法過去完了（過去の事実の反対）必須
  3. 混合仮定法（過去の原因→現在の結果）必須
  4. if の省略と倒置（Were / Had / Should）必須
  5. I wish ＋ 仮定法必須
  6. as if / as though ＋ 仮定法必須
  7. It is (high/about) time ＋ 仮定法過去必須
  8. If S should / were to（未来の仮定）差がつく
  9. If only ～ / Without ～ / But for ～差がつく
  10. ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）差がつく
  11. 丁寧な依頼の仮定法（I wonder if you could ～）不要
