If S should / were to（未来の仮定）

着眼点should は「万一」、were to は「仮に〜としたら」（実現不可能・極端な仮定）。

If S should 原形, S will/would/命令文… 主節は現在形・命令文も可。
If S were to 原形, S would 原形.

例文
1
If you should see him, please give him this note.
万一彼に会ったら、このメモを渡してください。
2
If the sun were to disappear, all life on Earth would die.
仮に太陽が消えたら、地球上の全生物が死ぬだろう。
ポイントIf it should rain tomorrow, we will cancel the game. のように、主節に will を使えるのは should 型だけ。
確認問題
1
空所補充。If I ( ) to be born again, I would be a pianist.
答え
were。If S were to 原形。

「仮定法」の項目

  1. 仮定法過去（現在の事実の反対）必須
  2. 仮定法過去完了（過去の事実の反対）必須
  3. 混合仮定法（過去の原因→現在の結果）必須
  4. if の省略と倒置（Were / Had / Should）必須
  5. I wish ＋ 仮定法必須
  6. as if / as though ＋ 仮定法必須
  7. It is (high/about) time ＋ 仮定法過去必須
  8. If S should / were to（未来の仮定）差がつく
  9. If only ～ / Without ～ / But for ～差がつく
  10. ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）差がつく
  11. 丁寧な依頼の仮定法（I wonder if you could ～）不要
