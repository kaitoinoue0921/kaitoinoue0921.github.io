必須

動名詞を使う慣用表現

着眼点そのまま覚えて使う決まり文句。

表現意味
It is no use doing〜しても無駄だ
There is no doing〜することはできない
cannot help doing〜せざるを得ない
feel like doing〜したい気がする
be worth doing〜する価値がある
be busy doing〜するのに忙しい
spend 時間 doing〜して時間を過ごす
have difficulty (in) doing〜するのに苦労する
go doing〜しに行く（go shopping）
on doing〜するとすぐに
例文
1
It is no use crying over spilt milk.
こぼれたミルクを嘆いても無駄だ（覆水盆に返らず）。
2
This museum is worth visiting.
この博物館は訪れる価値がある。
3
On arriving at the station, he called her.
駅に着くとすぐに、彼は彼女に電話した。
注意be worth doing の doing は目的語の働きなので、worth visiting it ではなく worth visiting（it を重ねない）。
確認問題
1
空所補充。 I couldn't help ( ) (laugh) at his joke.
答え
laughing（cannot help doing）

「動名詞」の項目

  1. 動名詞の働き（S・O・C・前置詞の目的語）必須
  2. 動名詞の意味上の主語・否定・完了形必須
  3. 動名詞だけを目的語に取る動詞必須
  4. 意味が変わる動詞（remember / forget / try / stop など）必須
  5. どちらを取ってもほぼ同じ意味の動詞差がつく
  6. need / want ＋ doing（受動の意味）差がつく
  7. 前置詞の to ＋動名詞必須
  8. 動名詞を使う慣用表現必須
  9. 前置詞 on / in ＋動名詞の使い分けと細かい形不要
