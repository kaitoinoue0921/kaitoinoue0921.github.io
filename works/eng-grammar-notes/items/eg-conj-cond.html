必須

条件・譲歩の接続詞

着眼点if, unless, as long as, in case, though など。unless は if not だが、使える場面に制限がある。

表現意味
if / unlessもし〜なら／〜でない限り
as long as / so long as〜する限り（条件）
as far as〜する範囲では（範囲・限度）
provided (that) / supposing (that)もし〜ならば
though / although / even if / even though〜だけれども／たとえ〜でも／実際〜なのに
while / whereas〜だけれど（対比）／〜なのに対して
例文
1
You can't pass unless you study.
勉強しない限り合格できない。
2
As long as you stay here, you'll be safe.
ここにいる限り、安全だ。
3
Although it was raining, we went out.
雨が降っていたが、私たちは出かけた。
注意although の節の中に but は重ねない（誤：Although … but …）。 as far as I know（私の知る限り）と as long as（〜の間・条件）を混同しない。 even if は仮定、even though は事実。
確認問題
1
書き換え。 If you don't hurry, you'll be late. → ( ) you hurry, you'll be late.
答え

「接続詞」の項目

  1. 等位接続詞と従位接続詞必須
  2. 時を表す接続詞と時制（未来の代用）必須
  3. 理由・結果・目的の接続詞必須
  4. 条件・譲歩の接続詞必須
  5. that 節（名詞節・同格・形容詞の後）必須
  6. if と whether の判別必須
  7. as の多義（時・理由・様態・比例・譲歩）必須
  8. 相関接続詞（not only … but also など）必須
  9. so … that / such … that 構文必須
  10. その他の重要接続詞（whereas, lest, so long as, no sooner）差がつく
  11. lest ～ should / for fear (that)不要
