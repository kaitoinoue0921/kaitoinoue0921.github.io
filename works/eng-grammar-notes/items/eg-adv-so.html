so / too / very / enough / quite の使い分け

着眼点程度を表す副詞は、後ろに続く形で決まる。

型意味
so ＋形/副 ＋ that ～とても～なので…
too ＋形/副 ＋ to do～すぎて…できない
形/副 ＋ enough to do…するのに十分～
very ＋ 形/副とても（原級を強める）
much ＋ 比較級ずっと～（比較級を強める）
例文
1
It was so cold that we stayed home.
とても寒かったので、私たちは家にいた。
2
He is too tired to go out.
彼は疲れすぎて外出できない。
注意very は比較級に付けない（×very better → much better）。

「形容詞・副詞」の項目

  1. 限定用法と叙述用法必須
  2. 意味で使い分ける形容詞必須
  3. 形容詞が複数並ぶときの語順差がつく
  4. 名詞を後ろから修飾する形容詞差がつく
  5. many / much / a lot of / few / little必須
  6. number / amount / large / small差がつく
  7. enough の位置差がつく
  8. 副詞の位置（頻度・程度の副詞）必須
  9. 紛らわしい副詞（形容詞と同形・-ly で意味が変わる語）必須
  10. so / too / very / enough / quite の使い分け差がつく
  11. also / too / either / as well の位置と否定文不要
