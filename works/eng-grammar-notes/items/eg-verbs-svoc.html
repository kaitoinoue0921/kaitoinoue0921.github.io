必須

SVOC（第5文型）の主な動詞

着眼点O と C の間に「O＝C」「OがCする」の関係がある。

型動詞意味
V O 名詞/形容詞make / keep / leave / find / call / name / considerOをCにする/しておく
V O to 原形want / ask / tell / allow / enable / expect / advise / forceOが〜するのを望む/頼む/…
V O 原形（使役・知覚）make / let / have / see / hear / feelOが〜するようにさせる/〜するのを見る
例文
1
The news made her happy.
その知らせを聞いて彼女は幸せになった。
2
The teacher asked us to be quiet.
先生は私たちに静かにするよう求めた。
3
I found the book difficult.
その本は難しいと思った。
注意suggest / insist / demand などは V O to 原形 を取れない。that節（that S (should) 原形）を使う。
確認問題
1
誤りを訂正せよ。I want him come with us.
答え
come → to come。want O to 原形。

「動詞の語法」の項目

  1. SVOO（第4文型）と SVO＋前置詞（第3文型）の書き換え必須
  2. SVOC（第5文型）の主な動詞必須
  3. 使役動詞 make / let / have / get必須
  4. 知覚動詞 see / hear / feel / notice ＋ 原形・現在分詞・過去分詞必須
  5. 他動詞と自動詞の混同必須
  6. lie / lay、rise / raise、sit / seat などの活用必須
  7. to不定詞だけ / 動名詞だけを目的語に取る動詞必須
  8. どちらも取るが意味が変わる動詞（remember / forget / try / stop / regret）必須
  9. say / tell / speak / talk と、紛らわしい動詞の使い分け差がつく
  10. 複雑な語法（hold O C 型の希少動詞・動詞の細かな補語形）不要
