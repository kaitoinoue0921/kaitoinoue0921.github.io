等位接続詞と従位接続詞

着眼点等位接続詞は対等につなぎ（and, but, or, so, for）、従位接続詞は主節に従う節を作る。

種類代表例
等位and / but / or / so / for / yetHe studied hard, so he passed.
従位（名詞節）that / if / whetherI think that he is right.
従位（副詞節）when / because / if / although などIf it rains, we'll stay home.
命令文＋and / orHurry up, and you will catch the bus. / or you will miss it.〜しなさい、そうすれば／さもないと
例文
1
Study hard, or you will fail the exam.
一生懸命勉強しなさい、さもないと試験に落ちるよ。
2
He was tired, for he had worked all night.
彼は疲れていた。一晩中働いたからだ。
注意for は理由を後から付け足す等位接続詞で、文頭には置けず、コンマの後に使う。
確認問題
1
書き換え。 If you leave now, you will catch the train. → Leave now, ( ) you will catch the train.

「接続詞」の項目

  1. 等位接続詞と従位接続詞必須
  2. 時を表す接続詞と時制（未来の代用）必須
  3. 理由・結果・目的の接続詞必須
  4. 条件・譲歩の接続詞必須
  5. that 節（名詞節・同格・形容詞の後）必須
  6. if と whether の判別必須
  7. as の多義（時・理由・様態・比例・譲歩）必須
  8. 相関接続詞（not only … but also など）必須
  9. so … that / such … that 構文必須
  10. その他の重要接続詞（whereas, lest, so long as, no sooner）差がつく
  11. lest ～ should / for fear (that)不要
