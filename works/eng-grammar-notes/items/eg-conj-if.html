if と whether の判別

着眼点名詞節の if は「〜かどうか」、副詞節の if は「もし〜なら」。whether は名詞節・副詞節で使える。

名詞節（〜かどうか）副詞節
if動詞の目的語のみ：I don't know if he'll come.もし〜なら（条件）→ will を使わない
whether主語・補語・目的語・前置詞の目的語：Whether he comes is unknown.〜であろうとなかろうと（Whether you like it or not）
例文
1
I wonder if she will come.
彼女が来るかどうか疑問だ。
2
Whether he will agree is another matter.
彼が賛成するかどうかは別問題だ。
3
If it rains tomorrow, we'll stay home.
明日雨が降ったら、家にいる。
ポイント見分けのコツ：「〜かどうか」と訳して通る名詞節の if は will を使え、条件の if は現在形になる。
注意主語位置・前置詞の後・to 不定詞の前（whether to go）は whether のみ。if は使えない。
確認問題
1
空所補充。 It depends on ( ) he will help us.
答え
whether（前置詞の目的語は whether）
2
誤りを正せ。 If it will be sunny tomorrow, we will go hiking.
答え
If it is sunny（条件の副詞節は現在形）

「接続詞」の項目

  1. 等位接続詞と従位接続詞必須
  2. 時を表す接続詞と時制（未来の代用）必須
  3. 理由・結果・目的の接続詞必須
  4. 条件・譲歩の接続詞必須
  5. that 節（名詞節・同格・形容詞の後）必須
  6. if と whether の判別必須
  7. as の多義（時・理由・様態・比例・譲歩）必須
  8. 相関接続詞（not only … but also など）必須
  9. so … that / such … that 構文必須
  10. その他の重要接続詞（whereas, lest, so long as, no sooner）差がつく
  11. lest ～ should / for fear (that)不要
