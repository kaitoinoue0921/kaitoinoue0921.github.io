必須

It is (high/about) time ＋ 仮定法過去

着眼点「もう〜してもよい時間だ」。節の中は過去形。

It is time (that) S 過去形. / It is time for S to 原形. high / about を入れて強められる。

例文
1
It is high time you went to bed.
もうとっくに寝る時間だよ。
2
It is about time we started the meeting.
そろそろ会議を始める時間だ。
確認問題
1
空所補充。It is time you ( ) your homework.（do）
答え
did。It is time の後ろは仮定法過去。

「仮定法」の項目

  1. 仮定法過去（現在の事実の反対）必須
  2. 仮定法過去完了（過去の事実の反対）必須
  3. 混合仮定法（過去の原因→現在の結果）必須
  4. if の省略と倒置（Were / Had / Should）必須
  5. I wish ＋ 仮定法必須
  6. as if / as though ＋ 仮定法必須
  7. It is (high/about) time ＋ 仮定法過去必須
  8. If S should / were to（未来の仮定）差がつく
  9. If only ～ / Without ～ / But for ～差がつく
  10. ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）差がつく
  11. 丁寧な依頼の仮定法（I wonder if you could ～）不要
