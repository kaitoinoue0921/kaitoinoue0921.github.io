丁寧な依頼の仮定法（I wonder if you could ～）

着眼点過去形にして「控えめ・丁寧」にする用法。

例文
1
I was wondering if you could lend me your pen.
ペンをお借りできないかと思っているのですが。
ポイント読めば分かるので優先度は低い。会話文・英作文で使うなら Would you ～? / Could you ～? で十分。
ノートで開いて「理解した」をつける →
← 前の項目ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）次の項目 →部分否定と全否定

「仮定法」の項目

  1. 仮定法過去（現在の事実の反対）必須
  2. 仮定法過去完了（過去の事実の反対）必須
  3. 混合仮定法（過去の原因→現在の結果）必須
  4. if の省略と倒置（Were / Had / Should）必須
  5. I wish ＋ 仮定法必須
  6. as if / as though ＋ 仮定法必須
  7. It is (high/about) time ＋ 仮定法過去必須
  8. If S should / were to（未来の仮定）差がつく
  9. If only ～ / Without ～ / But for ～差がつく
  10. ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）差がつく
  11. 丁寧な依頼の仮定法（I wonder if you could ～）不要
