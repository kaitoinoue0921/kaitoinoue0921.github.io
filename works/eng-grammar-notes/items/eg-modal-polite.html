着眼点Could you ～? / Would you ～? / Would you mind ～ing? / Do you mind if I ～? の答え方。

表現承諾断り
Could you ～?Sure. / Certainly.I'm afraid I can't.
Would you mind ～ing?Not at all.I'm sorry, but ～.
Do you mind if I ～?No, go ahead.Actually, I'd rather you didn't.
例文
1
Do you mind if I sit here?
ここに座ってもよろしいですか。
2
Would you mind turning down the music?
音楽の音量を下げていただけませんか。

「助動詞」の項目

  1. can / could / be able to必須
  2. may / might必須
  3. must / have to / must not / don't have to必須
  4. should / ought to / had better必須
  5. will / would / shall の用法必須
  6. 推量の強さ（must / should / may / cannot）必須
  7. 助動詞＋have p.p.（過去への推量・後悔）必須
  8. used to / would / be used to の区別必須
  9. 丁寧な依頼・許可と応答差がつく
  10. 提案・要求・命令の後ろの should（原形）差がつく
  11. 感情・判断を表す should差がつく
  12. 助動詞を含む慣用表現（would rather / cannot help など）不要
