差がつく

need / want ＋ doing（受動の意味）

着眼点物が主語のとき need doing ＝ need to be p.p.。

The car needs washing. = The car needs to be washed.
主語の側から見て「〜される必要がある」。deserve, require も同じ型。

例文
1
This room needs cleaning.
この部屋は掃除が必要だ。
注意人が主語のとき I need to clean. は「私が掃除する必要がある」で、意味が変わる。
確認問題
1
書き換え。 The roof needs to be repaired. → The roof needs ( ).
答え
repairing

「動名詞」の項目

  1. 動名詞の働き（S・O・C・前置詞の目的語）必須
  2. 動名詞の意味上の主語・否定・完了形必須
  3. 動名詞だけを目的語に取る動詞必須
  4. 意味が変わる動詞（remember / forget / try / stop など）必須
  5. どちらを取ってもほぼ同じ意味の動詞差がつく
  6. need / want ＋ doing（受動の意味）差がつく
  7. 前置詞の to ＋動名詞必須
  8. 動名詞を使う慣用表現必須
  9. 前置詞 on / in ＋動名詞の使い分けと細かい形不要
