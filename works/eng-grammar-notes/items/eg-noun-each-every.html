必須

each / every / all / both / either / neither

着眼点「単数扱いか複数扱いか」「2つか3つ以上か」を区別する。

語意味扱い・形
eachそれぞれ（個別）each＋単数名詞 / each of＋複数（単数動詞）
everyすべての（全体）every＋単数名詞（単数扱い）、ofは続けない
allすべてall＋複数名詞（複数扱い）/ all of the ～
both両方both＋複数名詞（複数扱い）
eitherどちらか一方either of＋複数 / either＋単数名詞
neitherどちらも～ないneither of＋複数 / neither＋単数名詞
例文
1
Every student has a locker.
どの生徒もロッカーを持っている。
2
Each of the girls has her own room.
少女たちはそれぞれ自分の部屋を持っている。
3
Neither of the answers is correct.
どちらの答えも正しくない。
注意×every of the students。all / both は主語の直後に置く用法もある（They both like it.）。

「名詞・冠詞・代名詞」の項目

  1. 可算名詞と不可算名詞必須
  2. 意味で可算・不可算が変わる名詞差がつく
  3. 複数形・所有格の注意点必須
  4. 不定冠詞 a / an の用法必須
  5. 定冠詞 the の用法必須
  6. 無冠詞になる場合・慣用表現必須
  7. 再帰代名詞（-self）必須
  8. it の用法と one / that / those必須
  9. one / another / the other / others の整理必須
  10. some と any必須
  11. each / every / all / both / either / neither必須
  12. 部分否定と全体否定差がつく
  13. 集合名詞の単数・複数扱い不要
