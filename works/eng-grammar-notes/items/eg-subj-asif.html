必須

as if / as though ＋ 仮定法

着眼点「まるで〜であるかのように」。主節と同じ時点なら過去形、それより前なら had＋過去分詞。

例文
1
He talks as if he knew everything.
彼はまるですべてを知っているかのように話す。
2
She looked as if she had seen a ghost.
彼女はまるで幽霊を見たかのような顔をしていた。
注意事実の可能性がある場合は直説法もある（It looks as if it is going to rain.）。「実際には違う」と話者が考えるときに仮定法。
確認問題
1
空所補充。He behaves as if he ( ) the boss.（be）
答え
were。現実と違う（実はボスではない）ことを表す。

「仮定法」の項目

  1. 仮定法過去（現在の事実の反対）必須
  2. 仮定法過去完了（過去の事実の反対）必須
  3. 混合仮定法（過去の原因→現在の結果）必須
  4. if の省略と倒置（Were / Had / Should）必須
  5. I wish ＋ 仮定法必須
  6. as if / as though ＋ 仮定法必須
  7. It is (high/about) time ＋ 仮定法過去必須
  8. If S should / were to（未来の仮定）差がつく
  9. If only ～ / Without ～ / But for ～差がつく
  10. ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）差がつく
  11. 丁寧な依頼の仮定法（I wonder if you could ～）不要
