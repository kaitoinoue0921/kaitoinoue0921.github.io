必須

that 節（名詞節・同格・形容詞の後）

着眼点that ＝「〜ということ」。主語・目的語・補語・同格になる。目的語の that は省略可。

働き例
主語That he is honest is clear. / It is clear that he is honest.
目的語（省略可）I know (that) she is a nurse.
補語The problem is that we have no money.
同格the fact that he lied / the news that she won
形容詞の後I'm glad that you came. / I'm sure that he'll win.
例文
1
The fact that she was late surprised nobody.
彼女が遅れたという事実は、誰も驚かせなかった。
2
I'm afraid that I can't help you.
残念ながらお手伝いできません。
ポイント同格の that ＝後ろが完全な文。関係代名詞 that は欠けがある文。the news that he heard（欠け＝関係詞）と the news that he died（完全＝同格）を比べる。
注意that 節を取れない名詞・動詞に注意：discuss や mention は that 節を直接取れる。ただし「同格の that」を作る名詞は fact, idea, news, belief, hope, rumor, evidence など限られる。
確認問題
1
空所補充。 There is no evidence ( ) he did it. / The evidence ( ) he showed was weak.
答え
that（同格）/ that または which（目的格の関係詞。showed の目的語が欠けている）

「接続詞」の項目

  1. 等位接続詞と従位接続詞必須
  2. 時を表す接続詞と時制（未来の代用）必須
  3. 理由・結果・目的の接続詞必須
  4. 条件・譲歩の接続詞必須
  5. that 節（名詞節・同格・形容詞の後）必須
  6. if と whether の判別必須
  7. as の多義（時・理由・様態・比例・譲歩）必須
  8. 相関接続詞（not only … but also など）必須
  9. so … that / such … that 構文必須
  10. その他の重要接続詞（whereas, lest, so long as, no sooner）差がつく
  11. lest ～ should / for fear (that)不要
