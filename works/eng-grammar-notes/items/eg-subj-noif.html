ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）

着眼点「〜でなければ」と訳せる otherwise、「〜なら」を含む主語・to不定詞・with に注意。

例文
1
I was busy; otherwise I would have gone with you.
忙しかった。そうでなければ一緒に行っただろう。
2
A wise man would not say such a thing.
賢い人ならそんなことは言わないだろう。
3
To hear him speak, you would take him for a native speaker.
彼が話すのを聞けば、母語話者だと思うだろう。
注意would / could が主節にあるのに if が見当たらないときは、主語や副詞句に条件が隠れている。
確認問題
1
空所補充。Take a taxi; ( ) you will be late.
答え
otherwise。「そうしなければ」。直説法なので will。

「仮定法」の項目

  1. 仮定法過去（現在の事実の反対）必須
  2. 仮定法過去完了（過去の事実の反対）必須
  3. 混合仮定法（過去の原因→現在の結果）必須
  4. if の省略と倒置（Were / Had / Should）必須
  5. I wish ＋ 仮定法必須
  6. as if / as though ＋ 仮定法必須
  7. It is (high/about) time ＋ 仮定法過去必須
  8. If S should / were to（未来の仮定）差がつく
  9. If only ～ / Without ～ / But for ～差がつく
  10. ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）差がつく
  11. 丁寧な依頼の仮定法（I wonder if you could ～）不要
