必須

混合仮定法（過去の原因→現在の結果）

着眼点if節は過去完了、主節は would＋原形。「あのとき〜していたら、今ごろ…だろう」。

If S had 過去分詞, S would/could 原形（＋now など）.
逆に、現在の状態が過去の結果に影響する型もある（If I were rich, I would have bought it.）。

例文
1
If I had taken his advice, I would be happier now.
彼の忠告を聞いていたら、今はもっと幸せだろうに。
2
If she had left earlier, she would be here by now.
彼女がもっと早く出ていたら、今ごろはここにいるだろうに。
注意now / today / still など「今」を示す語が主節にあれば混合を疑う。
確認問題
1
空所補充。If I ( ) harder then, I ( ) a better job now.（work / have）
答え
had worked / would have。if節は過去、主節は現在。

「仮定法」の項目

  1. 仮定法過去（現在の事実の反対）必須
  2. 仮定法過去完了（過去の事実の反対）必須
  3. 混合仮定法（過去の原因→現在の結果）必須
  4. if の省略と倒置（Were / Had / Should）必須
  5. I wish ＋ 仮定法必須
  6. as if / as though ＋ 仮定法必須
  7. It is (high/about) time ＋ 仮定法過去必須
  8. If S should / were to（未来の仮定）差がつく
  9. If only ～ / Without ～ / But for ～差がつく
  10. ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）差がつく
  11. 丁寧な依頼の仮定法（I wonder if you could ～）不要
