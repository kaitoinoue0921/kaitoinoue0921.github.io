分詞の限定用法（名詞の修飾）

着眼点分詞が1語なら名詞の前、語句を伴うなら名詞の後ろ。

前置修飾：a running boy / a closed door
後置修飾：the boy running in the park / the door closed by the wind

後置の分詞は関係代名詞節（who is running / which was closed）の省略とみなせる。

例文
1
The girl talking with Tom is my sister.
トムと話している女の子は私の姉（妹）だ。
2
This is a picture painted by my grandfather.
これは私の祖父が描いた絵だ。
注意文頭の The boy running … is … では、running … が the boy を修飾し、動詞は is。分詞を述語と取り違えない。
確認問題
1
空所補充。 The language ( ) in Brazil is Portuguese. (speak)
答え
spoken（language は speak される側）

「分詞」の項目

  1. 現在分詞と過去分詞の見分け必須
  2. 分詞の限定用法（名詞の修飾）必須
  3. 叙述用法（補語になる分詞：SVC・SVOC）必須
  4. 感情を表す動詞の分詞（interesting / interested）必須
  5. with ＋O＋分詞・形容詞・前置詞句（付帯状況）必須
  6. 分詞を使う熟語・形容詞化した分詞差がつく
  7. 時間・お金を使う表現＋分詞（spend / busy / find）差がつく
  8. 完了を表す過去分詞（fallen / retired など）不要
