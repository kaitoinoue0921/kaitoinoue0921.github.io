If only ～ / Without ～ / But for ～

着眼点If only ＝ I wish の強調。Without / But for ＝ If it were not for / If it had not been for。

表現意味
If only S 過去形〜でさえあればなあ
If it were not for ～ ＝ Without ～ ＝ But for ～（今）〜がなければ
If it had not been for ～ ＝ Without ～ ＝ But for ～（過去に）〜がなかったら
例文
1
If only I had more time!
もっと時間があればなあ。
2
But for your help, I would have failed.
あなたの助けがなければ、私は失敗していただろう。
3
If it were not for water, we could not live.
水がなければ、私たちは生きられないだろう。
確認問題
1
書き換え。If it had not been for his advice, I would have lost. → ( ) his advice, I would have lost.
答え
Without / But for。過去の仮定なので would have lost と対応。

「仮定法」の項目

  1. 仮定法過去（現在の事実の反対）必須
  2. 仮定法過去完了（過去の事実の反対）必須
  3. 混合仮定法（過去の原因→現在の結果）必須
  4. if の省略と倒置（Were / Had / Should）必須
  5. I wish ＋ 仮定法必須
  6. as if / as though ＋ 仮定法必須
  7. It is (high/about) time ＋ 仮定法過去必須
  8. If S should / were to（未来の仮定）差がつく
  9. If only ～ / Without ～ / But for ～差がつく
  10. ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）差がつく
  11. 丁寧な依頼の仮定法（I wonder if you could ～）不要
