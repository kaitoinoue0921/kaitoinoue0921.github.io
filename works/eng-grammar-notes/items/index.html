英文法ノート 項目一覧（全196項目）

高校英文法を、用法の表・例文・確認問題でまとめた持ち運び用ノート。ネット不要・この1ファイルだけで開ける。 各項目を1ページずつ読めます。必須・差がつく・不要の3段階の線引きつき。

基本

🧱 文型と品詞

  1. 5文型の全体像必須
  2. 自動詞と他動詞必須
  3. 混同しやすい自動詞・他動詞のペア差がつく
  4. 第2文型 SVC を作る動詞必須
  5. 第4文型 SVOO と第3文型への書き換え必須
  6. 第5文型 SVOC の見抜き方必須
  7. 形式目的語 it を使った SVOC差がつく
  8. 品詞の働きと文の要素必須
  9. 句と節（名詞・形容詞・副詞のかたまり）必須
  10. There is 構文と存在・形式主語差がつく
  11. 第3文型の特殊型と同族目的語不要

🔤 名詞・冠詞・代名詞

  1. 可算名詞と不可算名詞必須
  2. 意味で可算・不可算が変わる名詞差がつく
  3. 複数形・所有格の注意点必須
  4. 不定冠詞 a / an の用法必須
  5. 定冠詞 the の用法必須
  6. 無冠詞になる場合・慣用表現必須
  7. 再帰代名詞（-self）必須
  8. it の用法と one / that / those必須
  9. one / another / the other / others の整理必須
  10. some と any必須
  11. each / every / all / both / either / neither必須
  12. 部分否定と全体否定差がつく
  13. 集合名詞の単数・複数扱い不要

🎨 形容詞・副詞

  1. 限定用法と叙述用法必須
  2. 意味で使い分ける形容詞必須
  3. 形容詞が複数並ぶときの語順差がつく
  4. 名詞を後ろから修飾する形容詞差がつく
  5. many / much / a lot of / few / little必須
  6. number / amount / large / small差がつく
  7. enough の位置差がつく
  8. 副詞の位置（頻度・程度の副詞）必須
  9. 紛らわしい副詞（形容詞と同形・-ly で意味が変わる語）必須
  10. so / too / very / enough / quite の使い分け差がつく
  11. also / too / either / as well の位置と否定文不要

時制と助動詞

⏰ 時制

  1. 現在形の用法必須
  2. 過去形の用法と時の表現必須
  3. 不規則動詞の活用と過去形の混同必須
  4. 未来を表す形（will / be going to / 現在進行形）必須
  5. 時・条件の副詞節では未来を現在形で必須
  6. 進行形（現在・過去・未来）必須
  7. 進行形にしない状態動詞必須
  8. 状態動詞と動作動詞で意味が変わる語差がつく
  9. 時制の一致と例外差がつく
  10. 歴史的現在・be to 構文の未来不要

✅ 完了形

  1. 現在完了の基本（have p.p.）必須
  2. 現在完了の4用法の判別必須
  3. have been to / have gone to と継続の状態動詞必須
  4. 現在完了と過去形の使い分け必須
  5. 過去完了（had p.p.）必須
  6. 未来完了（will have p.p.）差がつく
  7. 現在完了進行形（have been doing）差がつく
  8. 過去完了進行形・未来完了進行形不要
  9. 完了形の書き換え（It is ～ since / 過去形と完了形）差がつく

🧭 助動詞

  1. can / could / be able to必須
  2. may / might必須
  3. must / have to / must not / don't have to必須
  4. should / ought to / had better必須
  5. will / would / shall の用法必須
  6. 推量の強さ（must / should / may / cannot）必須
  7. 助動詞＋have p.p.（過去への推量・後悔）必須
  8. used to / would / be used to の区別必須
  9. 丁寧な依頼・許可と応答差がつく
  10. 提案・要求・命令の後ろの should（原形）差がつく
  11. 感情・判断を表す should差がつく
  12. 助動詞を含む慣用表現（would rather / cannot help など）不要

🔁 受動態

  1. 受動態の形と作り方必須
  2. 時制・助動詞・進行形・完了形の受動態必須
  3. 否定文・疑問文の受動態必須
  4. 第4文型（SVOO）の受動態必須
  5. 第5文型（SVOC）の受動態必須
  6. 使役・知覚動詞の受動態必須
  7. 群動詞（句動詞）の受動態必須
  8. by 以外の前置詞を取る受動態差がつく
  9. 感情を表す分詞形容詞（-ing と -ed）差がつく
  10. "It is said that ～" 型の受動態差がつく
  11. get 受動態と状態を表す be p.p.差がつく
  12. 受動態にならない他動詞・能動の形で受動の意味不要

準動詞

➡️ 不定詞

  1. 名詞的用法（S・O・C になる）必須
  2. 形容詞的用法（名詞を後ろから修飾）必須
  3. 副詞的用法（目的・感情の原因・結果・判断の根拠）必須
  4. easy 型構文（目的語が主語になる）差がつく
  5. 不定詞の意味上の主語（for ～ / of ～）必須
  6. 完了不定詞（to have ＋過去分詞）必須
  7. 原形不定詞（使役・知覚動詞）必須
  8. too … to ～ / enough to ～ / so … as to ～必須
  9. be to 構文（予定・義務・可能・運命・意図）差がつく
  10. 独立不定詞・慣用表現差がつく
  11. 分離不定詞（to と原形の間に副詞）不要

🔁 動名詞

  1. 動名詞の働き（S・O・C・前置詞の目的語）必須
  2. 動名詞の意味上の主語・否定・完了形必須
  3. 動名詞だけを目的語に取る動詞必須
  4. 意味が変わる動詞（remember / forget / try / stop など）必須
  5. どちらを取ってもほぼ同じ意味の動詞差がつく
  6. need / want ＋ doing（受動の意味）差がつく
  7. 前置詞の to ＋動名詞必須
  8. 動名詞を使う慣用表現必須
  9. 前置詞 on / in ＋動名詞の使い分けと細かい形不要

🧩 分詞

  1. 現在分詞と過去分詞の見分け必須
  2. 分詞の限定用法（名詞の修飾）必須
  3. 叙述用法（補語になる分詞：SVC・SVOC）必須
  4. 感情を表す動詞の分詞（interesting / interested）必須
  5. with ＋O＋分詞・形容詞・前置詞句（付帯状況）必須
  6. 分詞を使う熟語・形容詞化した分詞差がつく
  7. 時間・お金を使う表現＋分詞（spend / busy / find）差がつく
  8. 完了を表す過去分詞（fallen / retired など）不要

✂️ 分詞構文

  1. 分詞構文の作り方（4ステップ）必須
  2. 分詞構文の5つの意味（時・理由・付帯状況・条件・譲歩）必須
  3. 分詞構文の位置と主語の一致必須
  4. 完了形の分詞構文（Having p.p.）必須
  5. 受動態の分詞構文（Being p.p. → p.p.）必須
  6. 独立分詞構文（主語が違うとき）差がつく
  7. 接続詞を残す分詞構文・there を使う形差がつく
  8. 慣用的な分詞構文（独立分詞の熟語）必須
  9. 接続詞化した分詞（provided, supposing, given）差がつく
  10. 形容詞・名詞が前に出る分詞構文（Being を省いた形）不要

節をつなぐ

🔗 関係詞

  1. 関係代名詞の格と先行詞必須
  2. 関係代名詞の省略と that を使う場合必須
  3. 前置詞＋関係代名詞必須
  4. 制限用法と非制限用法（コンマ付き）必須
  5. 関係代名詞 what（先行詞を含む）必須
  6. 関係副詞（where / when / why / how）必須
  7. 関係代名詞と関係副詞の判別必須
  8. 複合関係詞（-ever）差がつく
  9. 関係詞節の中の挿入（I think / he says）と連鎖差がつく
  10. 擬似関係代名詞（as / than / but）不要

🪢 接続詞

  1. 等位接続詞と従位接続詞必須
  2. 時を表す接続詞と時制（未来の代用）必須
  3. 理由・結果・目的の接続詞必須
  4. 条件・譲歩の接続詞必須
  5. that 節（名詞節・同格・形容詞の後）必須
  6. if と whether の判別必須
  7. as の多義（時・理由・様態・比例・譲歩）必須
  8. 相関接続詞（not only … but also など）必須
  9. so … that / such … that 構文必須
  10. その他の重要接続詞（whereas, lest, so long as, no sooner）差がつく
  11. lest ～ should / for fear (that)不要

比較・仮定・否定

⚖️ 比較

  1. 原級・比較級・最上級の基本形必須
  2. 比べるものをそろえる（that of / those of）必須
  3. 比較級・最上級の強め方必須
  4. 倍数表現必須
  5. the＋比較級 …, the＋比較級 ～（〜すればするほど…）必須
  6. no more than / no less than / not more than / not less than差がつく
  7. クジラの構文（A is no more B than C is D）差がつく
  8. much more / much less と least差がつく
  9. ラテン比較級（-or）と than の代わりの to差がつく
  10. 最上級を表す書き換え差がつく
  11. no sooner … than の細かな変形・more A than B の語順論不要

💭 仮定法

  1. 仮定法過去（現在の事実の反対）必須
  2. 仮定法過去完了（過去の事実の反対）必須
  3. 混合仮定法（過去の原因→現在の結果）必須
  4. if の省略と倒置（Were / Had / Should）必須
  5. I wish ＋ 仮定法必須
  6. as if / as though ＋ 仮定法必須
  7. It is (high/about) time ＋ 仮定法過去必須
  8. If S should / were to（未来の仮定）差がつく
  9. If only ～ / Without ～ / But for ～差がつく
  10. ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）差がつく
  11. 丁寧な依頼の仮定法（I wonder if you could ～）不要

🚫 否定・疑問・話法

  1. 部分否定と全否定必須
  2. 準否定語（hardly / scarcely / seldom / rarely / little / few）必須
  3. 否定の慣用表現差がつく
  4. 疑問文の種類（Yes/No・疑問詞・選択・否定疑問）必須
  5. 付加疑問必須
  6. 間接疑問必須
  7. 話法の転換（直接話法→間接話法）差がつく
  8. 描出話法・二重否定の細かな文語表現不要

🔀 倒置・強調・省略・挿入

  1. 否定語・否定の副詞句が文頭に出る倒置必須
  2. So ＋助動詞＋S / Neither ＋助動詞＋S必須
  3. 場所・補語の前置による倒置（Here comes / On the hill stood …）差がつく
  4. It is … that ～ の強調構文必須
  5. 疑問詞の強調（It is … that）と not until の強調差がつく
  6. 強調の do と強調語句必須
  7. 省略（共通語句・副詞節の S＋be・that・関係詞）必須
  8. 同格（A, B / of / that節）必須
  9. 挿入（カンマ・ダッシュ・挿入節）差がつく
  10. 文学的な倒置・語順の変形（as 譲歩倒置など）不要

語法

📍 前置詞

  1. 時を表す at / on / in必須
  2. by と until（till）必須
  3. for / during / while、within / in必須
  4. 場所を表す at / on / in、between / among、across / through など必須
  5. 群前置詞（2語以上で1つの前置詞の働き）必須
  6. 形容詞と前置詞の結びつき必須
  7. 動詞と前置詞の結びつき（A of B / A from B / A with B）差がつく
  8. 前置詞を含む重要熟語（on / in / at の慣用）差がつく
  9. 文語的な前置詞（amid / notwithstanding / hence など）不要

🔧 動詞の語法

  1. SVOO（第4文型）と SVO＋前置詞（第3文型）の書き換え必須
  2. SVOC（第5文型）の主な動詞必須
  3. 使役動詞 make / let / have / get必須
  4. 知覚動詞 see / hear / feel / notice ＋ 原形・現在分詞・過去分詞必須
  5. 他動詞と自動詞の混同必須
  6. lie / lay、rise / raise、sit / seat などの活用必須
  7. to不定詞だけ / 動名詞だけを目的語に取る動詞必須
  8. どちらも取るが意味が変わる動詞（remember / forget / try / stop / regret）必須
  9. say / tell / speak / talk と、紛らわしい動詞の使い分け差がつく
  10. 複雑な語法（hold O C 型の希少動詞・動詞の細かな補語形）不要
