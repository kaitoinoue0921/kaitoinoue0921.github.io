必須

used to / would / be used to の区別

着眼点見た目が似た3つの表現。

表現意味後ろの形
used to ＋原形以前は～だった／よく～したものだ（今は違う）原形（状態も動作もOK）
would ＋原形よく～したものだ（過去の習慣的動作）動作のみ。状態動詞は不可
be used to ＋名詞/doing～に慣れている名詞・動名詞
be used to ＋原形～するために使われる原形（受動態の used）
例文
1
There used to be a cinema near the station.
以前は駅の近くに映画館があった。（今はない）
2
He would often take me fishing.
彼はよく私を釣りに連れて行ってくれたものだ。
3
I am used to getting up early.
私は早起きに慣れている。
注意状態を表す used to（There used to be ～）は would に置き換えられない。

「助動詞」の項目

  1. can / could / be able to必須
  2. may / might必須
  3. must / have to / must not / don't have to必須
  4. should / ought to / had better必須
  5. will / would / shall の用法必須
  6. 推量の強さ（must / should / may / cannot）必須
  7. 助動詞＋have p.p.（過去への推量・後悔）必須
  8. used to / would / be used to の区別必須
  9. 丁寧な依頼・許可と応答差がつく
  10. 提案・要求・命令の後ろの should（原形）差がつく
  11. 感情・判断を表す should差がつく
  12. 助動詞を含む慣用表現（would rather / cannot help など）不要
