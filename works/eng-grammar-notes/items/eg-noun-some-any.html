必須

some と any

着眼点肯定文は some、否定文・疑問文・if節は any。ただし依頼・勧誘では some。

例文
1
I don't have any money with me.
私は今お金を持ち合わせていない。
2
Would you like some more coffee?
コーヒーをもう少しいかがですか。（勧誘は some）
3
You may take any book you like.
好きな本はどれでも取っていいよ。（肯定文の any＝どれでも）
注意肯定文で any ＋単数名詞は「どんな～でも」の意味。

「名詞・冠詞・代名詞」の項目

  1. 可算名詞と不可算名詞必須
  2. 意味で可算・不可算が変わる名詞差がつく
  3. 複数形・所有格の注意点必須
  4. 不定冠詞 a / an の用法必須
  5. 定冠詞 the の用法必須
  6. 無冠詞になる場合・慣用表現必須
  7. 再帰代名詞（-self）必須
  8. it の用法と one / that / those必須
  9. one / another / the other / others の整理必須
  10. some と any必須
  11. each / every / all / both / either / neither必須
  12. 部分否定と全体否定差がつく
  13. 集合名詞の単数・複数扱い不要
