差がつく

どちらを取ってもほぼ同じ意味の動詞

着眼点like, love, hate, begin, start, continue など。意味がほぼ変わらないが、ニュアンスの差を押さえる。

begin / start / continue / like / love / hate / prefer はどちらも可。

ただし：
・進行形のあとは to do：It is beginning to rain.（ing の連続を避ける）
・would like / would love / would hate は to do：I'd like to go.
・like doing は一般的な好み、like to do は具体的・その時の選択のニュアンス。

例文
1
I like swimming in the sea.
私は海で泳ぐのが好きだ。
2
I would like to swim in the sea today.
今日は海で泳ぎたい。
確認問題
1
正しい方を選べ。 It is starting (raining / to rain).
答え
to rain（進行形のあとは ing を重ねない）

「動名詞」の項目

  1. 動名詞の働き（S・O・C・前置詞の目的語）必須
  2. 動名詞の意味上の主語・否定・完了形必須
  3. 動名詞だけを目的語に取る動詞必須
  4. 意味が変わる動詞（remember / forget / try / stop など）必須
  5. どちらを取ってもほぼ同じ意味の動詞差がつく
  6. need / want ＋ doing（受動の意味）差がつく
  7. 前置詞の to ＋動名詞必須
  8. 動名詞を使う慣用表現必須
  9. 前置詞 on / in ＋動名詞の使い分けと細かい形不要
