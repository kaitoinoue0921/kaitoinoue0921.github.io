英文法ノートの着眼点まとめ（全196項目）

各項目の「着眼点」（問題文のどこを見て、どう解き始めるか）を、単元ごとに1ページへ並べました。項目名を押すと、その項目のページに進みます。必須・差がつく・不要の3段階つき。

基本

🧱 文型と品詞

  • 5文型の全体像必須

    文型は「動詞の後ろに何が来るか」で決まる。前置詞つきの語句（修飾語）は文型に数えない。

  • 自動詞と他動詞必須

    他動詞は直後に目的語を取る（前置詞不要）。自動詞は前置詞を介して名詞をつなぐ。

  • 混同しやすい自動詞・他動詞のペア差がつく

    形が似た動詞は、自動詞か他動詞かで使い分ける。活用も合わせて覚える。

  • 第2文型 SVC を作る動詞必須

    「be」以外にも、状態・変化・知覚を表す動詞がCを取る。後ろは形容詞（副詞ではない）。

  • 第4文型 SVOO と第3文型への書き換え必須

    前置詞が to か for かは動詞の性質で決まる。

  • 第5文型 SVOC の見抜き方必須

    O と C の間に「O は C だ／する」という主語述語の関係があるのが第5文型。第4文型との分かれ目はここ。

  • 形式目的語 it を使った SVOC差がつく

    make / think / find / consider ＋ it ＋ C ＋ to do / that節 の型。長い目的語を後ろに回す。

  • 品詞の働きと文の要素必須

    「何詞か」より「文中でどの要素になっているか」が大事。語尾（-ly, -tion, -ive など）が手がかり。

  • 句と節（名詞・形容詞・副詞のかたまり）必須

    文が長いとき、かたまりを括弧でくくって主節の S V O C を探す。

  • There is 構文と存在・形式主語差がつく

    真主語は be 動詞の後ろ。be 動詞は後ろの名詞に合わせる。

  • 第3文型の特殊型と同族目的語不要

    自動詞が同じ語源の名詞を目的語に取る形（live a happy life, die a natural death）。

🔤 名詞・冠詞・代名詞

  • 可算名詞と不可算名詞必須

    数えられない名詞に a / an や -s をつけない。数えるときは a piece of ～ などの単位を使う。

  • 意味で可算・不可算が変わる名詞差がつく

    抽象的な意味では不可算、具体的な「個・種類」を表すと可算になる。

  • 複数形・所有格の注意点必須

    不規則複数、常に複数の名詞、所有格の作り方を押さえる。

  • 不定冠詞 a / an の用法必須

    「初めて話題に出る」「どれでもいい1つ」「～につき」「ある～」。a / an は発音が母音で始まる語の前で an。

  • 定冠詞 the の用法必須

    「話し手・聞き手の間で特定できる」ときに使う。

  • 無冠詞になる場合・慣用表現必須

    役割・目的を表すときは冠詞を落とす。

  • 再帰代名詞（-self）必須

    主語と目的語が同じ人・ものを指すとき、または強調のとき。

  • it の用法と one / that / those必須

    it は「同じ物」、one は「同種の別の物」、that/those は「前の名詞の繰り返し（修飾語つき）」。

  • one / another / the other / others の整理必須

    「全部で何個あるか」と「特定できるか」で使い分ける。

  • some と any必須

    肯定文は some、否定文・疑問文・if節は any。ただし依頼・勧誘では some。

  • each / every / all / both / either / neither必須

    「単数扱いか複数扱いか」「2つか3つ以上か」を区別する。

  • 部分否定と全体否定差がつく

    not と all / every / both / always が結ぶと部分否定（全部が～というわけではない）。

  • 集合名詞の単数・複数扱い不要

    family, team, audience など集合名詞の単複扱い。

🎨 形容詞・副詞

  • 限定用法と叙述用法必須

    名詞の前に置く（限定）か、C になる（叙述）か。叙述にしか使えない語がある。

  • 意味で使い分ける形容詞必須

    日本語が似ていて、主語にできる語が違うペア。人を主語にできない形容詞が頻出。

  • 形容詞が複数並ぶときの語順差がつく

    名詞に近いほど、性質・材料・用途など「そのものの本質」を表す語が来る。

  • 名詞を後ろから修飾する形容詞差がつく

    -thing / -body / -one の後ろ、また -able / -ible が付いた形容詞が最上級などと一緒のとき後置される。

  • many / much / a lot of / few / little必須

    可算か不可算かで選ぶ。a が付くか付かないかで肯定・否定が変わる。

  • number / amount / large / small差がつく

    number・population・amount は「多い・少ない」を large / small で表す。many / much は使わない。

  • enough の位置差がつく

    enough は形容詞・副詞の後ろ、名詞の前後どちらも可。

  • 副詞の位置（頻度・程度の副詞）必須

    頻度の副詞（always, usually, often, sometimes, never, hardly）は、一般動詞の前・be動詞/助動詞の後ろ。

  • 紛らわしい副詞（形容詞と同形・-ly で意味が変わる語）必須

    -ly が付くと意味が変わる語が頻出。

  • so / too / very / enough / quite の使い分け差がつく

    程度を表す副詞は、後ろに続く形で決まる。

  • also / too / either / as well の位置と否定文不要

    「～も」の副詞は、肯定文＝too / also / as well、否定文＝either。

時制と助動詞

⏰ 時制

  • 現在形の用法必須

    現在形は「今この瞬間」ではなく「習慣・事実・不変の真理」を表す。

  • 過去形の用法と時の表現必須

    過去形は「現在とは切り離された過去の事実」。過去を表す明確な語句（yesterday, ago, last ～, in 2020, when ～）があれば過去形。

  • 不規則動詞の活用と過去形の混同必須

    原形・過去形・過去分詞の3段活用を暗記。形が似た語が出題されやすい。

  • 未来を表す形（will / be going to / 現在進行形）必須

    will＝その場の決心・単純な予測、be going to＝すでに決めていた予定・根拠のある予測、現在進行形＝手配済みの近い未来。

  • 時・条件の副詞節では未来を現在形で必須

    when / if / before / after / as soon as / until など「時」「条件」を表す副詞節の中では、未来のことも現在形（または現在完了）で書く。

  • 進行形（現在・過去・未来）必須

    進行形は「ある時点で動作が進行中」。一時的な状態も表す。

  • 進行形にしない状態動詞必須

    状態・認識・感情・所有を表す動詞は、ふつう進行形にしない。

  • 状態動詞と動作動詞で意味が変わる語差がつく

    同じ綴りでも、状態用法と動作用法で意味が違う。

  • 時制の一致と例外差がつく

    主節が過去形なら、従属節の時制もひとつ過去側にずらす。例外は不変の真理・現在も続く事実・歴史的事実。

  • 歴史的現在・be to 構文の未来不要

    過去の出来事を現在形で臨場感を出す用法、be to do（予定）。

✅ 完了形

  • 現在完了の基本（have p.p.）必須

    「過去の出来事が、今に影響・つながっている」ことを表す。過去を表す明確な語（yesterday, ago, when）とは使えない。

  • 現在完了の4用法の判別必須

    用法は意味と相性のいい副詞で判別する。

  • have been to / have gone to と継続の状態動詞必須

    「行ったことがある」と「行ってしまった」を区別する。継続は状態動詞で表す。

  • 現在完了と過去形の使い分け必須

    過去の時点が明示されるか、現在とのつながりがあるかで決める。

  • 過去完了（had p.p.）必須

    過去のある時点より前の出来事（大過去）を表す。完了・経験・継続・結果の4用法は現在完了と同じ。

  • 未来完了（will have p.p.）差がつく

    未来のある時点までに、完了・経験・継続していることを表す。

  • 現在完了進行形（have been doing）差がつく

    過去から今まで続いている動作を強調する。「ずっと～し続けている」。

  • 過去完了進行形・未来完了進行形不要

    had been doing（過去のある時点までの継続動作）、will have been doing。

  • 完了形の書き換え（It is ～ since / 過去形と完了形）差がつく

    「～して以来…年になる」は定番の書き換え。

🧭 助動詞

  • can / could / be able to必須

    can＝能力・可能・許可・可能性。過去の「～できた」は could か was able to。

  • may / might必須

    may＝許可・推量（～かもしれない）。might は may より可能性が低い、または控えめ。

  • must / have to / must not / don't have to必須

    must＝義務・強い推量。否定形で意味がずれる。

  • should / ought to / had better必須

    should＝当然・助言。had better は強い忠告（しないと困ったことになる）で、目上には使わない。

  • will / would / shall の用法必須

    will＝意志・予測・習性・依頼。would は丁寧・過去の習慣・仮定。Shall I / Shall we で申し出・提案。

  • 推量の強さ（must / should / may / cannot）必須

    同じ「～だろう」でも確信度が違う。

  • 助動詞＋have p.p.（過去への推量・後悔）必須

    「過去のことへの推量」と「実際にはしなかった・した」ことへの後悔。

  • used to / would / be used to の区別必須

    見た目が似た3つの表現。

  • 丁寧な依頼・許可と応答差がつく

    Could you ～? / Would you ～? / Would you mind ～ing? / Do you mind if I ～? の答え方。

  • 提案・要求・命令の後ろの should（原形）差がつく

    「要求・提案・主張・命令」を表す動詞・形容詞の後の that 節は、(should＋)原形を使う。

  • 感情・判断を表す should差がつく

    驚き・遺憾・当然の気持ちを表す形容詞・名詞の後ろの that 節に should。

  • 助動詞を含む慣用表現（would rather / cannot help など）不要

    would rather ＋原形（むしろ～したい）、cannot help ＋ ing（～せざるを得ない）、cannot ～ too ～（いくら～してもし過ぎることはない）。

🔁 受動態

  • 受動態の形と作り方必須

    能動態の O を主語にし、動詞を be ＋ 過去分詞に、S を by ～ にする。

  • 時制・助動詞・進行形・完了形の受動態必須

    be の部分を時制に合わせて変える。

  • 否定文・疑問文の受動態必須

    be 動詞の後ろに not、疑問文は be を前に出す。

  • 第4文型（SVOO）の受動態必須

    2つの O のどちらも主語にできる。物を主語にすると前置詞が残る場合がある。

  • 第5文型（SVOC）の受動態必須

    O を主語にし、C はそのまま残す。C が原形不定詞のときは to が付く。

  • 使役・知覚動詞の受動態必須

    原形不定詞を取る make / see / hear / watch / feel は、受動態で to を復活させる。let は受動態を作らず be allowed to を使う。

  • 群動詞（句動詞）の受動態必須

    動詞＋前置詞・副詞で1つの他動詞のように扱い、まとめて受動態にする。by を落とさず前置詞も残す。

  • by 以外の前置詞を取る受動態差がつく

    感情・状態を表す受動態は、by 以外の前置詞とセットで覚える。

  • 感情を表す分詞形容詞（-ing と -ed）差がつく

    感情を「与える」側は -ing、「感じる」側は -ed。

  • "It is said that ～" 型の受動態差がつく

    say / think / believe / report などの that 節を、It を主語にした形に直す。

  • get 受動態と状態を表す be p.p.差がつく

    "get ＋ p.p." は動作・変化、"be ＋ p.p." は動作にも状態にもなる。

  • 受動態にならない他動詞・能動の形で受動の意味不要

    have / resemble / lack / fit / become などの他動詞は受動態にしない。sell well のように能動で受動の意味になる動詞もある。

準動詞

➡️ 不定詞

  • 名詞的用法（S・O・C になる）必須

    「〜すること」と訳せ、文の主語・目的語・補語になる。形式主語 It … to ～ が最頻出。

  • 形容詞的用法（名詞を後ろから修飾）必須

    名詞のあとに to do が付き「〜するための／〜すべき」。修飾される名詞と to do の関係を3パターンで見抜く。

  • 副詞的用法（目的・感情の原因・結果・判断の根拠）必須

    動詞・形容詞を修飾する to do。訳し分けは「何を修飾するか」と前の語で決まる。

  • easy 型構文（目的語が主語になる）差がつく

    形容詞＋to do で、to do の目的語を主語にして書く型。to do のあとに目的語を重ねて置かない。

  • 不定詞の意味上の主語（for ～ / of ～）必須

    to do の動作をする人を示す。ふつう for ～、人の性質を表す形容詞のときだけ of ～。

  • 完了不定詞（to have ＋過去分詞）必須

    述語動詞より前の出来事を表す。「時のズレ」を読む。

  • 原形不定詞（使役・知覚動詞）必須

    make / let / have ＋O＋原形、see / hear / feel ＋O＋原形。toが消える。受動態では to が復活する。

  • too … to ～ / enough to ～ / so … as to ～必須

    程度を表す3つの型。書き換え問題の定番。

  • be to 構文（予定・義務・可能・運命・意図）差がつく

    be ＋ to do で5つの意味。文脈と主語・副詞で判別する。

  • 独立不定詞・慣用表現差がつく

    文全体を修飾する決まり文句と、to do を含む熟語を覚える。

  • 分離不定詞（to と原形の間に副詞）不要

    to ＋副詞＋原形（to carefully read）。

🔁 動名詞

  • 動名詞の働き（S・O・C・前置詞の目的語）必須

    「〜すること」。名詞と同じ位置に置け、前置詞の直後には動名詞しか置けない。

  • 動名詞の意味上の主語・否定・完了形必須

    動名詞の動作をする人は所有格（口語は目的格）、否定は直前に not、前の時は having ＋p.p.。

  • 動名詞だけを目的語に取る動詞必須

    「済んだこと・現実の行為」を嫌う、止める、避ける動詞。MEGAFEPS などの頭文字暗記が定番。

  • 意味が変わる動詞（remember / forget / try / stop など）必須

    動名詞は「過去・実際にした」、不定詞は「これから・まだ」。意味の違いが正誤問題に出る。

  • どちらを取ってもほぼ同じ意味の動詞差がつく

    like, love, hate, begin, start, continue など。意味がほぼ変わらないが、ニュアンスの差を押さえる。

  • need / want ＋ doing（受動の意味）差がつく

    物が主語のとき need doing ＝ need to be p.p.。

  • 前置詞の to ＋動名詞必須

    to の後ろが名詞扱いになる熟語。不定詞の to と見分けるのが勝負。

  • 動名詞を使う慣用表現必須

    そのまま覚えて使う決まり文句。

  • 前置詞 on / in ＋動名詞の使い分けと細かい形不要

    on doing（直後）と in doing（〜するとき・〜する際に）の差、by doing（手段）。

🧩 分詞

  • 現在分詞と過去分詞の見分け必須

    名詞との関係が「する（能動）」なら現在分詞、「される（受動）」なら過去分詞。進行・完了は別の用法。

  • 分詞の限定用法（名詞の修飾）必須

    分詞が1語なら名詞の前、語句を伴うなら名詞の後ろ。

  • 叙述用法（補語になる分詞：SVC・SVOC）必須

    S や O の状態を説明する分詞。知覚・使役・have 系の SVOC が頻出。

  • 感情を表す動詞の分詞（interesting / interested）必須

    感情を起こさせる側は現在分詞、感情を持つ側は過去分詞。主語が「人」か「物・事」かで判断する。

  • with ＋O＋分詞・形容詞・前置詞句（付帯状況）必須

    「〜しながら／〜した状態で」。O と後ろの語の関係で、現在分詞か過去分詞かを決める。

  • 分詞を使う熟語・形容詞化した分詞差がつく

    分詞が形容詞的に定着した表現と、よく出る熟語。

  • 時間・お金を使う表現＋分詞（spend / busy / find）差がつく

    spend 時間 doing、be busy doing、find O doing / p.p. など、分詞を補語にとる定番型。

  • 完了を表す過去分詞（fallen / retired など）不要

    自動詞の過去分詞が「完了」を表す特殊な形。

✂️ 分詞構文

  • 分詞構文の作り方（4ステップ）必須

    副詞節を、接続詞・主語を消して動詞を doing に変える。主節と主語が同じときが基本。

  • 分詞構文の5つの意味（時・理由・付帯状況・条件・譲歩）必須

    形は同じで、意味は文脈で判断する。読み取ったら、接続詞を補って訳す。

  • 分詞構文の位置と主語の一致必須

    文頭・文中・文末のどこにあっても、分詞の意味上の主語は主節の主語と同じが原則。

  • 完了形の分詞構文（Having p.p.）必須

    主節の動詞より前の出来事を表す。

  • 受動態の分詞構文（Being p.p. → p.p.）必須

    being は省略され、過去分詞から始まる形になることが多い。文頭の過去分詞を見たら分詞構文を疑う。

  • 独立分詞構文（主語が違うとき）差がつく

    分詞の意味上の主語を、分詞の前に置いて示す形。

  • 接続詞を残す分詞構文・there を使う形差がつく

    意味をはっきりさせるため接続詞を残すことがある。

  • 慣用的な分詞構文（独立分詞の熟語）必須

    主語が一般人（we, one）の決まり文句。主語の一致は問われない。

  • 接続詞化した分詞（provided, supposing, given）差がつく

    分詞が接続詞として働く。if の代わりの provided / providing が最頻出。

  • 形容詞・名詞が前に出る分詞構文（Being を省いた形）不要

    Being を省略して、形容詞・名詞・前置詞句から始まる文。

節をつなぐ

🔗 関係詞

  • 関係代名詞の格と先行詞必須

    先行詞（人／物）と、関係詞節の中での働き（主語／目的語／所有）で決まる。

  • 関係代名詞の省略と that を使う場合必須

    目的格は省略できる。主格は原則省略不可（ただし「主格＋be」は省略可で、後置分詞になる）。

  • 前置詞＋関係代名詞必須

    関係詞節の中で前置詞の目的語が欠けているとき、前置詞を関係詞の前に出せる。出すと whom / which のみで、省略不可。

  • 制限用法と非制限用法（コンマ付き）必須

    コンマのある関係詞は、先行詞に補足説明を加える。who / which は「接続詞＋代名詞」に言い換えられる。

  • 関係代名詞 what（先行詞を含む）必須

    what ＝ the thing(s) which。名詞節を作り、S・O・C になる。先行詞がなければ what。

  • 関係副詞（where / when / why / how）必須

    先行詞が場所・時・理由・方法で、関係詞節が完全文（欠けがない）のとき。

  • 関係代名詞と関係副詞の判別必須

    関係詞のあとの文が「欠けているか完全か」で決める。先行詞が place でも where とは限らない。

  • 複合関係詞（-ever）差がつく

    名詞節（〜するものは何でも）と譲歩の副詞節（たとえ〜でも）の2つの用法。

  • 関係詞節の中の挿入（I think / he says）と連鎖差がつく

    関係詞のすぐ後ろに I think などが入る形。挿入を飛ばして、格を判断する。

  • 擬似関係代名詞（as / than / but）不要

    such … as / the same … as / as … as のあとの as、than の関係詞用法。

🪢 接続詞

  • 等位接続詞と従位接続詞必須

    等位接続詞は対等につなぎ（and, but, or, so, for）、従位接続詞は主節に従う節を作る。

  • 時を表す接続詞と時制（未来の代用）必須

    時・条件の副詞節では未来のことも現在形で書く。名詞節では will を使える。

  • 理由・結果・目的の接続詞必須

    because, since, as の強さ、so that の2用法、now that、in case を区別する。

  • 条件・譲歩の接続詞必須

    if, unless, as long as, in case, though など。unless は if not だが、使える場面に制限がある。

  • that 節（名詞節・同格・形容詞の後）必須

    that ＝「〜ということ」。主語・目的語・補語・同格になる。目的語の that は省略可。

  • if と whether の判別必須

    名詞節の if は「〜かどうか」、副詞節の if は「もし〜なら」。whether は名詞節・副詞節で使える。

  • as の多義（時・理由・様態・比例・譲歩）必須

    as は文脈で訳が決まる。後ろの節との関係を見る。

  • 相関接続詞（not only … but also など）必須

    2つの語句をセットでつなぐ。動詞の一致は後ろの名詞に合わせる型に注意。

  • so … that / such … that 構文必須

    「とても〜なので…」の結果・程度。so は形容詞・副詞、such は名詞を含む。

  • その他の重要接続詞（whereas, lest, so long as, no sooner）差がつく

    対比・時間関係をつなぐ表現。倒置とセットで覚える。

  • lest ～ should / for fear (that)不要

    「〜しないように」の文語的表現。

比較・仮定・否定

⚖️ 比較

  • 原級・比較級・最上級の基本形必須

    「何と何を比べているか」を先に見る。比べる相手は形も種類もそろえる。

  • 比べるものをそろえる（that of / those of）必須

    than の後ろに来る名詞が、前の名詞と同じ種類かを確認する。

  • 比較級・最上級の強め方必須

    比較級は much / far / a lot / still / even、最上級は much / by far / the very。very は使えない。

  • 倍数表現必須

    「〜倍」は as … as の前に置く。語順は 倍数＋as＋原級＋as。

  • the＋比較級 …, the＋比較級 ～（〜すればするほど…）必須

    文頭の The が2つ並んだら、この構文。

  • no more than / no less than / not more than / not less than差がつく

    「no＝差がゼロ」と覚える。no は驚き・主観、not は客観的な上限・下限。

  • クジラの構文（A is no more B than C is D）差がつく

    「CがDでないのと同じくらい、AもBでない」。どちらも否定する。

  • much more / much less と least差がつく

    肯定文の後は much more（まして〜）、否定文の後は much less（〜はなおさら…ない）。

  • ラテン比較級（-or）と than の代わりの to差がつく

    superior / inferior / senior / junior / prefer は than でなく to。

  • 最上級を表す書き換え差がつく

    原級・比較級・否定語で「一番」を言い換える。入試の書き換え頻出パターン。

  • no sooner … than の細かな変形・more A than B の語順論不要

    特殊な語順や長い文語表現。

💭 仮定法

  • 仮定法過去（現在の事実の反対）必須

    動詞が過去形なのに「今」の話。時制を1つ過去にずらして「現実から遠い」ことを表す。

  • 仮定法過去完了（過去の事実の反対）必須

    if節は had＋過去分詞、主節は would have＋過去分詞。

  • 混合仮定法（過去の原因→現在の結果）必須

    if節は過去完了、主節は would＋原形。「あのとき〜していたら、今ごろ…だろう」。

  • if の省略と倒置（Were / Had / Should）必須

    if を省くと、were / had / should が文頭に出る。文頭が Were / Had / Should なら仮定法を疑う。

  • I wish ＋ 仮定法必須

    「〜ならいいのに」。wish の後ろの時制は、wish より1つ過去にずらす。

  • as if / as though ＋ 仮定法必須

    「まるで〜であるかのように」。主節と同じ時点なら過去形、それより前なら had＋過去分詞。

  • It is (high/about) time ＋ 仮定法過去必須

    「もう〜してもよい時間だ」。節の中は過去形。

  • If S should / were to（未来の仮定）差がつく

    should は「万一」、were to は「仮に〜としたら」（実現不可能・極端な仮定）。

  • If only ～ / Without ～ / But for ～差がつく

    If only ＝ I wish の強調。Without / But for ＝ If it were not for / If it had not been for。

  • ifを使わない仮定法（otherwise / 主語・不定詞に隠れる仮定）差がつく

    「〜でなければ」と訳せる otherwise、「〜なら」を含む主語・to不定詞・with に注意。

  • 丁寧な依頼の仮定法（I wonder if you could ～）不要

    過去形にして「控えめ・丁寧」にする用法。

🚫 否定・疑問・話法

  • 部分否定と全否定必須

    not と all / every / both / always などが一緒に来たら部分否定（すべてが〜というわけではない）。

  • 準否定語（hardly / scarcely / seldom / rarely / little / few）必須

    「ほとんど〜ない」。これ自体が否定語なので、さらに not は付けない。

  • 否定の慣用表現差がつく

    否定語を使った決まり文句。意味をひとまとまりで覚える。

  • 疑問文の種類（Yes/No・疑問詞・選択・否定疑問）必須

    答え方は日本語と逆になる。否定疑問は「Yes＝肯定の内容、No＝否定の内容」で、問いが否定でも変わらない。

  • 付加疑問必須

    肯定文→否定の付加、否定文→肯定の付加。主語は代名詞にする。

  • 間接疑問必須

    疑問文が別の文の中に入ると、語順は「疑問詞＋S＋V」（平常文の語順）になる。

  • 話法の転換（直接話法→間接話法）差がつく

    伝達動詞を整える→that節にする→人称・時制・時と場所の副詞を直す、の順に。

  • 描出話法・二重否定の細かな文語表現不要

    小説で見かける文体上の話法。

🔀 倒置・強調・省略・挿入

  • 否定語・否定の副詞句が文頭に出る倒置必須

    文頭の Never / Hardly / Not only / Little / Seldom の後ろは疑問文の語順（助動詞＋S＋V）。

  • So ＋助動詞＋S / Neither ＋助動詞＋S必須

    「〜もそうだ」。肯定には So、否定には Neither / Nor。助動詞は前の文の動詞に合わせる。

  • 場所・補語の前置による倒置（Here comes / On the hill stood …）差がつく

    副詞や補語が文頭に出ると、S V が V S になる。主語が代名詞のときは倒置しない。

  • It is … that ～ の強調構文必須

    強調したい語句を It is と that の間に入れる。It is と that を除いて文が成り立てば強調構文。

  • 疑問詞の強調（It is … that）と not until の強調差がつく

    疑問詞は強調構文で文頭に出す。not … until は It is not until … that ～ の型。

  • 強調の do と強調語句必須

    動詞を強めるときは do / does / did を動詞の前に入れる（動詞は原形に戻る）。

  • 省略（共通語句・副詞節の S＋be・that・関係詞）必須

    時・条件・譲歩の副詞節では、主節と主語が同じなら「S＋be」を省略できる。

  • 同格（A, B / of / that節）必須

    名詞のすぐ後ろで、その名詞を言い換える・説明する語句。カンマ・of・that に注目。

  • 挿入（カンマ・ダッシュ・挿入節）差がつく

    読むときは挿入部分を括弧に入れ、主語と述語をつなげて骨組みを見る。

  • 文学的な倒置・語順の変形（as 譲歩倒置など）不要

    「形容詞/名詞＋as＋S＋V」の譲歩倒置は長文で読めれば足りる。

語法

📍 前置詞

  • 時を表す at / on / in必須

    範囲の広さのイメージ。at は一点、on は特定の日、in は幅のある期間。

  • by と until（till）必須

    動作が「その時までに完了」なら by、「その時までずっと継続」なら until。

  • for / during / while、within / in必須

    for＋期間の長さ、during＋特定の期間を表す名詞。while は接続詞。

  • 場所を表す at / on / in、between / among、across / through など必須

    at＝点、on＝接触・面、in＝空間の中。between は2つ、among は3つ以上。

  • 群前置詞（2語以上で1つの前置詞の働き）必須

    意味を1つのかたまりで覚える。後ろには名詞（句）が来る。

  • 形容詞と前置詞の結びつき必須

    形容詞ごとに決まった前置詞を取る。句ごと覚える。

  • 動詞と前置詞の結びつき（A of B / A from B / A with B）差がつく

    「AにBを〜する」の型は、前置詞が意味を決める。

  • 前置詞を含む重要熟語（on / in / at の慣用）差がつく

    前置詞のイメージから意味が決まる句を、まとめて覚える。

  • 文語的な前置詞（amid / notwithstanding / hence など）不要

    文語表現で、出ても長文の中。

🔧 動詞の語法

  • SVOO（第4文型）と SVO＋前置詞（第3文型）の書き換え必須

    「人に物を」の動詞は、to を取るか for を取るかで分かれる。

  • SVOC（第5文型）の主な動詞必須

    O と C の間に「O＝C」「OがCする」の関係がある。

  • 使役動詞 make / let / have / get必須

    「〜させる」の4つ。原形を取るか、to＋原形か、過去分詞かで分ける。

  • 知覚動詞 see / hear / feel / notice ＋ 原形・現在分詞・過去分詞必須

    原形＝動作の全体、現在分詞＝動作の途中、過去分詞＝受け身。

  • 他動詞と自動詞の混同必須

    日本語の「〜に」「〜と」に引きずられて前置詞を付けない。他動詞は直後に目的語。

  • lie / lay、rise / raise、sit / seat などの活用必須

    自動詞（目的語なし）か他動詞（目的語あり）かを見て選ぶ。過去形が重なるものに注意。

  • to不定詞だけ / 動名詞だけを目的語に取る動詞必須

    「未来・これから」の意味ならto、「すでにしたこと・今していること」の意味なら動名詞。

  • どちらも取るが意味が変わる動詞（remember / forget / try / stop / regret）必須

    to不定詞＝これからのこと（未来）、動名詞＝すでにしたこと（過去）。

  • say / tell / speak / talk と、紛らわしい動詞の使い分け差がつく

    目的語に何を取るかで選ぶ。

  • 複雑な語法（hold O C 型の希少動詞・動詞の細かな補語形）不要

    一部の動詞だけに見られる補語の形。
