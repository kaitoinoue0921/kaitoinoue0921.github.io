必須

so … that / such … that 構文

着眼点「とても〜なので…」の結果・程度。so は形容詞・副詞、such は名詞を含む。

型例
so ＋形容詞・副詞 ＋ thatHe ran so fast that no one could catch him.
such ＋(a)＋(形)＋名詞 ＋ thatIt was such a hot day that we stayed inside.
so ＋形容詞＋a＋名詞It was so hot a day that …（文語）
so ～ that … not / too ～ toHe is too tired to walk. = He is so tired that he can't walk.
例文
1
She was so surprised that she couldn't speak.
彼女はとても驚いて、言葉が出なかった。
2
It was such a good book that I read it twice.
とてもいい本だったので、2回読んだ。
ポイントso / such の使い分け：後ろに名詞があるか。a good book なら such a good book、good だけなら so good。
注意so … that の that が省略されることもある（口語）。 so that（目的）とは別物：so that の直前に形容詞・副詞がない。
確認問題
1
空所補充。 This is ( ) difficult a problem that nobody can solve.
答え
so（so ＋形容詞＋a＋名詞。such a difficult problem と同じ）
2
空所補充。 It was ( ) a long speech ( ) everyone fell asleep.
答え
such / that

「接続詞」の項目

  1. 等位接続詞と従位接続詞必須
  2. 時を表す接続詞と時制（未来の代用）必須
  3. 理由・結果・目的の接続詞必須
  4. 条件・譲歩の接続詞必須
  5. that 節（名詞節・同格・形容詞の後）必須
  6. if と whether の判別必須
  7. as の多義（時・理由・様態・比例・譲歩）必須
  8. 相関接続詞（not only … but also など）必須
  9. so … that / such … that 構文必須
  10. その他の重要接続詞（whereas, lest, so long as, no sooner）差がつく
  11. lest ～ should / for fear (that)不要
