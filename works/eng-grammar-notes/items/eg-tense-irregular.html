不規則動詞の活用と過去形の混同

着眼点原形・過去形・過去分詞の3段活用を暗記。形が似た語が出題されやすい。

型活用
A-B-C（すべて違う）go-went-gone / see-saw-seen / take-took-taken / write-wrote-written / eat-ate-eaten / give-gave-given / begin-began-begun / drink-drank-drunk / fly-flew-flown / know-knew-known
A-B-Bbuy-bought-bought / bring-brought-brought / teach-taught-taught / leave-left-left / hold-held-held / find-found-found / lose-lost-lost / pay-paid-paid / sell-sold-sold
A-B-Acome-came-come / become-became-become / run-ran-run
A-A-Acut-cut-cut / put-put-put / read-read-read（発音注意）/ set-set-set / hit-hit-hit / let-let-let
例文
1
She wrote a letter and sent it yesterday.
彼女は昨日手紙を書いて送った。
注意read の過去形・過去分詞 read は /red/ と発音する。lie-lay-lain / lay-laid-laid は「自動詞・他動詞」の項を参照。

「時制」の項目

  1. 現在形の用法必須
  2. 過去形の用法と時の表現必須
  3. 不規則動詞の活用と過去形の混同必須
  4. 未来を表す形（will / be going to / 現在進行形）必須
  5. 時・条件の副詞節では未来を現在形で必須
  6. 進行形（現在・過去・未来）必須
  7. 進行形にしない状態動詞必須
  8. 状態動詞と動作動詞で意味が変わる語差がつく
  9. 時制の一致と例外差がつく
  10. 歴史的現在・be to 構文の未来不要
