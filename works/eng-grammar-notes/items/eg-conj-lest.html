lest ～ should / for fear (that)

着眼点「〜しないように」の文語的表現。

He ran fast lest he should miss the train.（= for fear that he might miss …）

例文
1
She spoke softly lest she should wake the baby.
彼女は赤ちゃんを起こさないように、そっと話した。
ポイント文語で、書くなら so as not to … / so that … not で足りる。難関大の語彙・文法で出ることはあるが、共通テスト〜MARCH・国公立では優先度が低い。

「接続詞」の項目

  1. 等位接続詞と従位接続詞必須
  2. 時を表す接続詞と時制（未来の代用）必須
  3. 理由・結果・目的の接続詞必須
  4. 条件・譲歩の接続詞必須
  5. that 節（名詞節・同格・形容詞の後）必須
  6. if と whether の判別必須
  7. as の多義（時・理由・様態・比例・譲歩）必須
  8. 相関接続詞（not only … but also など）必須
  9. so … that / such … that 構文必須
  10. その他の重要接続詞（whereas, lest, so long as, no sooner）差がつく
  11. lest ～ should / for fear (that)不要
