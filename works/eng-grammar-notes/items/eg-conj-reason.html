理由・結果・目的の接続詞

着眼点because, since, as の強さ、so that の2用法、now that、in case を区別する。

表現意味例
because理由（最も強い・新情報）He was absent because he was ill.
since / as〜なので（相手も知っている理由）Since you're here, help me.
now that今や〜なのでNow that you are a student, …
so that ～ can / will〜するために（目的）He left early so that he could catch the train.
so that ～（コンマ後）その結果〜（結果）It rained, so that the game was cancelled.
in case ～〜するといけないからTake an umbrella in case it rains.
例文
1
Now that the exam is over, I can relax.
試験が終わったので、くつろげる。
2
Speak slowly so that everyone can understand you.
みんなが理解できるように、ゆっくり話しなさい。
注意Why 疑問への答えや、強調構文（It is because …）は because のみ。so that の目的用法では助動詞（can / will / may）を伴う。
確認問題
1
空所補充。 Take a coat ( ) ( ) it gets cold.
答え
in case（寒くなるといけないから）

「接続詞」の項目

  1. 等位接続詞と従位接続詞必須
  2. 時を表す接続詞と時制（未来の代用）必須
  3. 理由・結果・目的の接続詞必須
  4. 条件・譲歩の接続詞必須
  5. that 節（名詞節・同格・形容詞の後）必須
  6. if と whether の判別必須
  7. as の多義（時・理由・様態・比例・譲歩）必須
  8. 相関接続詞（not only … but also など）必須
  9. so … that / such … that 構文必須
  10. その他の重要接続詞（whereas, lest, so long as, no sooner）差がつく
  11. lest ～ should / for fear (that)不要
