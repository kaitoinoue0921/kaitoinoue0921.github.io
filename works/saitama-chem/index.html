埼玉大 化学 攻略ノート

教育学部・理科専修の前期化学を、2017〜2025年度の18大問から分析
出題の全体像年度別一覧分野別の頻度対策電池・電気分解の過去問知識チェックリスト(生物・化学)

出題の全体像

埼玉大の化学は、各年度2大問です。18大問のうち理論化学が15本で、残りは無機・有機・高分子が1本ずつしかありません。つまり、有機を厚く対策するよりも、理論化学(気体・溶液、結晶・化学結合、化学平衡・反応速度)を固めるほうが点に直結します。

もうひとつの特徴は、1つの大問が小問の寄せ集めになっていることです。たとえば2018年の大問1は、分子の極性、銅と硝酸の反応、モル濃度、溶解度が1題に入っています。深い1分野より、広く浅くの基本事項を落とさないことが大切です。

分野の分類は、東進の過去問データベースにある解答画像を見て筆者が判定したものです。混合問題は主なものに寄せています。2026年度は東進に大問1の解答しか載っておらず、大問2が不明なため、下の分野別の集計(18大問)には含めていません。2026年の大問1は、溶液・酸塩基、周期律・結合、有機が小問で並ぶ寄せ集めで、これまでの傾向と同じ形でした。電池・電気分解は出ていません。

対策の優先順位

1. 気体・溶液(5本で最多)

蒸気圧、分圧、凝固点降下、モル濃度、溶解度。計算を落とさないことが最優先です。気体の状態方程式と混合気体の分圧は、燃焼などの反応計算と組み合わさって出ます。

2. 結晶・化学結合と原子構造(4本)

結晶格子の密度計算(単位格子中の原子数、アボガドロ定数)、イオン半径の大小、イオン化エネルギー、分子の極性。暗記と短い計算の組み合わせで、準備した分だけ点になります。

3. 化学平衡・反応速度(3本、直近2年は連続)

平衡定数、ルシャトリエの原理、速度式、活性化エネルギー。2024・2025年と続けて出ているので、直近の傾向としては要注意です。

4. 電池・電気分解と酸化還元

大問として出たのは2019・2020年の2回ですが、その後も酸化還元は形を変えて出ています。半反応式が書けて、電気量から物質量に直せれば、ほぼ取れる分野です。次の節の2題で練習できます。

5. 有機・無機・高分子

各1本ずつで、どれも標準的な反応式と構造式の問題でした。理論を固めたうえで、反応式を押さえる程度で十分です。

過去問: 電池・電気分解

9年間で電池・電気分解が大問になったのは2題だけです。電池の練習に向く素材として、2題を問題・解答・解説つきで載せます。問題文は過去問データベースから書き起こしたもので、図は省略しています。

問題A 2019年度 前期 大問2(鉛蓄電池)

鉛蓄電池は正極に酸化鉛(IV) PbO2、負極に鉛 Pb、電解液に希硫酸 H2SO4 を用いた電池である。その鉛蓄電池中の硫酸は質量パーセント濃度で30.0%、0.5 kg とする。必要ならば原子量として H = 1.0、O = 16.0、S = 32.1、Pb = 207.2、ファラデー定数 F = 9.65×104 C/mol を使用しなさい。計算問題に関しては有効数字2桁で答えなさい。

  1. 問1 放電時の正極と負極の反応を、電子 e− を含むイオン反応式で書きなさい。
  2. 問2 鉛蓄電池の放電時の全体の化学反応式を書きなさい。
  3. 問3 鉛蓄電池の放電を電流5Aの条件下で1930秒間行った。正極で増加した質量を求めなさい。また、その放電後の硫酸の質量パーセント濃度を求めなさい。
  4. 問4 「外部電源」「正極」「負極」という語を用いて、鉛蓄電池の充電方法を書きなさい。
解答と解説を見る

問1
正極: PbO2 + 4H+ + SO42− + 2e− → PbSO4 + 2H2O
負極: Pb + SO42− → PbSO4 + 2e−
どちらも電極の表面に PbSO4 が付きます。正極ではPbの酸化数が+4から+2に、負極では0から+2に変わります。

問2
Pb + PbO2 + 2H2SO4 → 2PbSO4 + 2H2O
問1の2式を足して e− を消せばよいです。

問3
流れた電気量は 5 × 1930 = 9650 C、電子の物質量は 9650 ÷ 9.65×104 = 0.10 mol です。
正極ではPbO2(式量239.2)がPbSO4(式量303.3)に変わり、電子2 molあたりSO2の分(64.1 g)だけ重くなります。0.10 molなら 64.1 × 0.10 ÷ 2 = 3.2 g の増加です。
硫酸は、全体の式から電子2 molでH2SO4が2 mol減り、水が2 mol増えます。電子0.10 molなら、H2SO4が0.10 mol(9.8 g)減り、水が0.10 mol(1.8 g)増えます。
最初の溶液は500 gで、H2SO4は 500 × 0.300 = 150 g です。放電後のH2SO4は約140.2 g、溶液は 500 − 9.8 + 1.8 = 492 g なので、濃度は 140.2 ÷ 492 ≒ 0.285 で約28%です。
答え: 正極は3.2 g増加、硫酸濃度は28%。

つまずきやすい点: 溶液の質量が「硫酸が減った分」だけでなく「水が増えた分」も入ることです。水の増加を忘れると 140.2 ÷ 490.2 ≒ 28.6% になり、29%と答えてしまいます。

問4
外部電源の正極を鉛蓄電池の正極に、外部電源の負極を鉛蓄電池の負極につなぎ、放電と逆向きに電流を流して電気分解を行います(模範解答は「外部電源と鉛蓄電池の正極どうし、負極どうしを接続して電気分解を行う」)。

問題B 2020年度 前期 大問1(電解質とNaCl水溶液の電気分解)

純水を用いてつくったグルコース、塩化ナトリウム、エタノール、塩酸の4種類の水溶液を用意した。その4種類の水溶液について、図1のような実験装置(豆電球、電源装置、電流計、2本の電極を水溶液に入れたもの)で電流が流れるかどうか調べた。ただし、電極自身は反応しないものとする。

  1. 問1 4種類の水溶液から、電流が流れたものを全て選びなさい。
  2. 問2 水溶液にする前に、結晶の塩化ナトリウムに電流が流れるかどうか調べたところ、電流は流れなかった。この結果と問1の結果を比較して、どんなことがわかるか書きなさい。
  3. 問3 この実験では、純水の代わりに水道水を用いてはいけない。その理由を説明しなさい。
  4. 問4 塩化ナトリウム水溶液の場合、実験中に図1の電極付近に変化が見られた。その変化を化学反応式で書きなさい。
  5. 問5 この実験装置を用いて、雨水を調べたところ、わずかに電流が流れた。その理由を説明しなさい。
解答と解説を見る

問1 塩化ナトリウム、塩酸。
水に溶けて電離する物質(電解質)の水溶液だけが電流を流します。NaCl → Na+ + Cl−、HCl → H+ + Cl−。グルコースとエタノールは電離しない非電解質です。

問2 結晶のままではイオンが動けないので電気を通さないが、水溶液にすると電離してイオンが自由に動けるようになり、電気を通すこと。

問3 水道水にはNa+、Ca2+、Mg2+、Cl−などのイオンが含まれているので、グルコースやエタノールの水溶液でも電流が流れてしまい、電解質かどうかを正しく判定できないから。

問4 電極自身は反応しないので、水溶液中の物質が反応します。
陽極: 2Cl− → Cl2 + 2e−
陰極: 2H2O + 2e− → H2 + 2OH−
全体にまとめると 2NaCl + 2H2O → Cl2 + H2 + 2NaOH です。問題が「化学反応式で」と言っているので、全体の式で答えるのが無難です。電子を含む2式のどちらかで答えても、実際の採点では認められる可能性が高いです。

問5 雨水には大気中の二酸化炭素が溶け込み、その一部が電離してイオンができているから(CO2 + H2O → H+ + HCO3−、pHは5.6程度で弱い酸性)。

問題Bは電池そのものではなく、電解質と電気分解の入り口の問題です。問題Aの前に基礎確認として使い、余裕があれば飛ばして構いません。
