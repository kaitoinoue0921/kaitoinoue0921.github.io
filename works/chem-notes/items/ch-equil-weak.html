必須

弱酸の電離平衡と pH

着眼点電離度 \alpha が小さい（1 - \alpha \fallingdotseq 1）とみなして、[\ce{H+}] = \sqrt{cK_a}。

K_a = \frac{[\ce{H+}][\ce{A-}]}{[\ce{HA}]} = \frac{c\alpha^2}{1 - \alpha} \fallingdotseq c\alpha^2\alpha = \sqrt{\frac{K_a}{c}},\qquad [\ce{H+}] = c\alpha = \sqrt{cK_a}
例題
1
0.10 mol/L の酢酸水溶液の pH と電離度を求めよ。K_a = 2.5\times10^{-5}\ \mathrm{mol/L}、\log_{10} 2 = 0.30。
解答
[\ce{H+}] = \sqrt{0.10 \times 2.5\times10^{-5}} = \sqrt{2.5\times10^{-6}} = \frac{1}{2}\sqrt{10}\times10^{-3} \mathrm{pH} = 3 - \log_{10}\sqrt{2.5} = 3 - \frac{1}{2}(1 - 2 \times 0.30) = 3 - 0.20 = 2.8 \alpha = [\ce{H+}]/c = 1.58\times10^{-3}/0.10 = 1.6\times10^{-2}
答え pH 2.8、電離度 1.6\times10^{-2}
確認問題
1
弱酸の濃度を 1/100 にすると、電離度は何倍か。
答え
10倍（\alpha = \sqrt{K_a/c}）
ポイント弱塩基（アンモニアなど）も同じ形: [\ce{OH-}] = \sqrt{cK_b} を出してから pOH → pH。
注意濃度が非常に薄いと \alpha が大きくなり、近似が使えない。\alpha が 0.05 程度を超えたら二次方程式で解く。

「反応速度と化学平衡」の項目

  1. 反応速度の表し方と変える要因必須
  2. 反応速度式の次数を実験データから決める差がつく
  3. 活性化エネルギーと触媒必須
  4. アレニウスの式不要
  5. 平衡定数（化学平衡の法則）必須
  6. 平衡定数から平衡時の量を求める必須
  7. 圧平衡定数 Kp差がつく
  8. ルシャトリエの原理（平衡の移動）必須
  9. 水のイオン積と pH・pOH必須
  10. 弱酸の電離平衡と pH必須
  11. 弱塩基（アンモニア）の電離平衡と pH必須
  12. 共役な酸と塩基の関係 KₐKb = Kw差がつく
  13. 2価の弱酸（炭酸）の段階的な電離差がつく
  14. 緩衝液の pH必須
  15. 緩衝液に強酸・強塩基を加えたときの pH差がつく
  16. 塩の加水分解と pH必須
  17. 弱酸を強塩基で滴定したときの各点の pH差がつく
  18. 指示薬の変色域と電離平衡不要
  19. 溶解度積と沈殿の判定必須
  20. 溶解度積から溶解度を求める差がつく
  21. 硫化水素の電離平衡と硫化物の沈殿不要
  22. ごく薄い酸の pH（水の電離を無視できないとき）不要
