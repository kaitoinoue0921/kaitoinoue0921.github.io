必須

溶解度積と沈殿の判定

着眼点混ぜた直後のイオン濃度の積が K_{sp} を超えたら沈殿が生じる。等量混合なら濃度は半分になる。

\ce{AgCl(s) <=> Ag+ + Cl-},\qquad K_{sp} = [\ce{Ag+}][\ce{Cl-}]
  • イオン濃度の積 > K_{sp} → 沈殿する。
  • イオン濃度の積 \le K_{sp} → 沈殿しない。
例題
1
2.0\times10^{-4}\ \mathrm{mol/L} の \ce{AgNO3} 水溶液と 2.0\times10^{-4}\ \mathrm{mol/L} の \ce{NaCl} 水溶液を等体積混合した。沈殿は生じるか。\ce{AgCl} の K_{sp} = 1.8\times10^{-10}\ \mathrm{mol^2/L^2}。
解答
混合直後 [\ce{Ag+}] = [\ce{Cl-}] = 1.0\times10^{-4}
積 = 1.0\times10^{-8} > 1.8\times10^{-10} 答え 沈殿が生じる
2
0.10 mol/L の \ce{NaCl} 水溶液に \ce{AgCl} は何 mol/L まで溶けるか。K_{sp} は上と同じ。
解答
溶ける量を s とすると [\ce{Cl-}] = 0.10 + s \fallingdotseq 0.10
s = 1.8\times10^{-10}/0.10 答え 1.8\times10^{-9}\ \mathrm{mol/L}（純水中の \sqrt{1.8\times10^{-10}} = 1.3\times10^{-5} よりずっと小さい＝共通イオン効果）
確認問題
1
共通イオン効果とは何か（一言で）。
答え
同じイオンを含む電解質を加えると、そのイオンが減る向きに平衡が移り、溶解度が小さくなること
注意\ce{Ag2CrO4} のような型では K_{sp} = [\ce{Ag+}]^2[\ce{CrO4^2-}] と係数が指数に入る。

「反応速度と化学平衡」の項目

  1. 反応速度の表し方と変える要因必須
  2. 反応速度式の次数を実験データから決める差がつく
  3. 活性化エネルギーと触媒必須
  4. アレニウスの式不要
  5. 平衡定数（化学平衡の法則）必須
  6. 平衡定数から平衡時の量を求める必須
  7. 圧平衡定数 Kp差がつく
  8. ルシャトリエの原理（平衡の移動）必須
  9. 水のイオン積と pH・pOH必須
  10. 弱酸の電離平衡と pH必須
  11. 弱塩基（アンモニア）の電離平衡と pH必須
  12. 共役な酸と塩基の関係 KₐKb = Kw差がつく
  13. 2価の弱酸（炭酸）の段階的な電離差がつく
  14. 緩衝液の pH必須
  15. 緩衝液に強酸・強塩基を加えたときの pH差がつく
  16. 塩の加水分解と pH必須
  17. 弱酸を強塩基で滴定したときの各点の pH差がつく
  18. 指示薬の変色域と電離平衡不要
  19. 溶解度積と沈殿の判定必須
  20. 溶解度積から溶解度を求める差がつく
  21. 硫化水素の電離平衡と硫化物の沈殿不要
  22. ごく薄い酸の pH（水の電離を無視できないとき）不要
