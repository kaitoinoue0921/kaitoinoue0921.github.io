共役な酸と塩基の関係 K_aK_b = K_w

着眼点弱酸 \ce{HA} の K_a と、その共役塩基 \ce{A-} の K_b を掛けると K_w。片方が分かればもう片方が出る。

K_a = \frac{[\ce{H+}][\ce{A-}]}{[\ce{HA}]},\qquad K_b = \frac{[\ce{HA}][\ce{OH-}]}{[\ce{A-}]}K_aK_b = [\ce{H+}][\ce{OH-}] = K_w

酸が弱い（K_a が小さい）ほど、共役塩基は強い（K_b が大きい）。

例題
1
酢酸の K_a = 2.0\times10^{-5}\ \mathrm{mol/L} のとき、酢酸イオンの K_b は。K_w = 1.0\times10^{-14}\ \mathrm{mol^2/L^2}。
解答
K_b = K_w / K_a = 1.0\times10^{-14} / 2.0\times10^{-5} 答え 5.0\times10^{-10}\ \mathrm{mol/L}
確認問題
1
アンモニアの K_b = 2.0\times10^{-5} のとき、アンモニウムイオンの K_a は（K_w = 1.0\times10^{-14}）。
答え
5.0\times10^{-10}\ \mathrm{mol/L}
ポイント次の「塩の加水分解」の加水分解定数 K_h は、この K_b（陽イオン側なら K_a）そのもの。

「反応速度と化学平衡」の項目

  1. 反応速度の表し方と変える要因必須
  2. 反応速度式の次数を実験データから決める差がつく
  3. 活性化エネルギーと触媒必須
  4. アレニウスの式不要
  5. 平衡定数（化学平衡の法則）必須
  6. 平衡定数から平衡時の量を求める必須
  7. 圧平衡定数 Kp差がつく
  8. ルシャトリエの原理（平衡の移動）必須
  9. 水のイオン積と pH・pOH必須
  10. 弱酸の電離平衡と pH必須
  11. 弱塩基（アンモニア）の電離平衡と pH必須
  12. 共役な酸と塩基の関係 KₐKb = Kw差がつく
  13. 2価の弱酸（炭酸）の段階的な電離差がつく
  14. 緩衝液の pH必須
  15. 緩衝液に強酸・強塩基を加えたときの pH差がつく
  16. 塩の加水分解と pH必須
  17. 弱酸を強塩基で滴定したときの各点の pH差がつく
  18. 指示薬の変色域と電離平衡不要
  19. 溶解度積と沈殿の判定必須
  20. 溶解度積から溶解度を求める差がつく
  21. 硫化水素の電離平衡と硫化物の沈殿不要
  22. ごく薄い酸の pH（水の電離を無視できないとき）不要
