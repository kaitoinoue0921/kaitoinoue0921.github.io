緩衝液に強酸・強塩基を加えたときの pH

着眼点加えた \ce{H+} はそのまま塩の陰イオンと反応して弱酸に変わる。物質量を足し引きしてから、緩衝液の式に入れ直す。

強酸 n mol を加えると

\ce{CH3COO- + H+ -> CH3COOH}

酢酸イオンが n mol 減り、酢酸が n mol 増える。強塩基なら逆。そのあと

[\ce{H+}] = K_a \times \frac{n_{\text{acid}}}{n_{\text{salt}}}
例題
1
酢酸 0.10 mol と酢酸ナトリウム 0.10 mol を含む水溶液 1.0 L に、塩化水素 0.020 mol を加えた。pH はいくつからいくつに変わるか。体積変化は無視。K_a = 2.0\times10^{-5}\ \mathrm{mol/L}、\log_{10} 2 = 0.30、\log_{10} 3 = 0.48。
解答
加える前: [\ce{H+}] = K_a = 2.0\times10^{-5}、\mathrm{pH} = 5 - 0.30 = 4.7
加えた後: 酢酸 0.12 mol、酢酸イオン 0.08 mol
[\ce{H+}] = 2.0\times10^{-5} \times \frac{0.12}{0.08} = 3.0\times10^{-5} \mathrm{pH} = 5 - 0.48 = 4.52
答え 4.7 から 4.5 に変わる（純水 1.0 L に同じ量を加えると pH 7 → 1.7）
確認問題
1
上の緩衝液に、塩化水素ではなく水酸化ナトリウム 0.020 mol を加えると、酢酸と酢酸イオンはそれぞれ何 mol になるか。
答え
酢酸 0.08 mol、酢酸イオン 0.12 mol（[\ce{H+}] は K_a の 2/3 倍になり pH は少し上がる）

「反応速度と化学平衡」の項目

  1. 反応速度の表し方と変える要因必須
  2. 反応速度式の次数を実験データから決める差がつく
  3. 活性化エネルギーと触媒必須
  4. アレニウスの式不要
  5. 平衡定数（化学平衡の法則）必須
  6. 平衡定数から平衡時の量を求める必須
  7. 圧平衡定数 Kp差がつく
  8. ルシャトリエの原理（平衡の移動）必須
  9. 水のイオン積と pH・pOH必須
  10. 弱酸の電離平衡と pH必須
  11. 弱塩基（アンモニア）の電離平衡と pH必須
  12. 共役な酸と塩基の関係 KₐKb = Kw差がつく
  13. 2価の弱酸（炭酸）の段階的な電離差がつく
  14. 緩衝液の pH必須
  15. 緩衝液に強酸・強塩基を加えたときの pH差がつく
  16. 塩の加水分解と pH必須
  17. 弱酸を強塩基で滴定したときの各点の pH差がつく
  18. 指示薬の変色域と電離平衡不要
  19. 溶解度積と沈殿の判定必須
  20. 溶解度積から溶解度を求める差がつく
  21. 硫化水素の電離平衡と硫化物の沈殿不要
  22. ごく薄い酸の pH（水の電離を無視できないとき）不要
