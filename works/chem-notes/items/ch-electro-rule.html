電極での生成物の決め方

着眼点陰極（電源の負極側）では還元、陽極（電源の正極側）では酸化。下の表を上から順に当てはめる。

極条件反応
陰極\ce{Ag+}、\ce{Cu^2+} がある\ce{Ag+ + e- -> Ag}、\ce{Cu^2+ + 2e- -> Cu}
陰極酸性（\ce{H+} が多い）\ce{2H+ + 2e- -> H2}
陰極イオン化傾向の大きい金属イオンだけ（\ce{Na+}、\ce{K+} など）\ce{2H2O + 2e- -> H2 + 2OH-}
陽極電極が \ce{Cu}、\ce{Ag} など（白金・金・炭素以外）電極が溶ける: \ce{Cu -> Cu^2+ + 2e-}
陽極\ce{Cl-}、\ce{I-} がある\ce{2Cl- -> Cl2 + 2e-}、\ce{2I- -> I2 + 2e-}
陽極塩基性（\ce{OH-} が多い）\ce{4OH- -> O2 + 2H2O + 4e-}
陽極\ce{SO4^2-}、\ce{NO3-} だけ\ce{2H2O -> O2 + 4H+ + 4e-}
例題
1
白金電極で硫酸ナトリウム水溶液を電気分解した。各極の反応は。
解答
陰極: \ce{Na+} は還元されないので \ce{2H2O + 2e- -> H2 + 2OH-}
陽極: \ce{SO4^2-} は酸化されないので \ce{2H2O -> O2 + 4H+ + 4e-}
結果として水の電気分解（\ce{H2} と \ce{O2} が体積比 2：1）。
確認問題
1
炭素電極で塩化銅(Ⅱ)水溶液を電気分解した。各極の生成物は。
答え
陰極 \ce{Cu}、陽極 \ce{Cl2}
ポイント陰極は「Cu・Ag なら金属、それ以外は水素」、陽極は「電極が溶けるか → ハロゲン → 酸素」。
注意陽極に銅を使うと、溶液に \ce{Cl-} があっても電極の銅が先に溶ける。電極の材質を最初に見る。

「電池と電気分解」の項目

  1. 電池のしくみ（負極・正極）必須
  2. ダニエル電池必須
  3. ボルタ電池差がつく
  4. 鉛蓄電池（量的関係）必須
  5. 燃料電池差がつく
  6. 実用電池の一覧差がつく
  7. 電極での生成物の決め方必須
  8. 代表的な電気分解の組み合わせ必須
  9. ファラデーの法則（電気量と生成量）必須
  10. 水酸化ナトリウムの製造（イオン交換膜法）必須
  11. 電解槽の直列・並列差がつく
  12. 銅の電解精錬・アルミニウムの溶融塩電解差がつく
  13. 標準電極電位と起電力の計算不要
