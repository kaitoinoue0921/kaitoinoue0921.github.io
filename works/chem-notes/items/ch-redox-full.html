必須

半反応式から反応式をつくる

着眼点電子の数をそろえて2式を足し、\ce{e-} を消す（イオン反応式）。化学反応式にするには、省いた対イオンを両辺に足す。

例題
1
硫酸酸性の過マンガン酸カリウム水溶液と過酸化水素水の反応を、イオン反応式と化学反応式で書け。
解答
\ce{MnO4- + 8H+ + 5e- -> Mn^2+ + 4H2O}（×2）
\ce{H2O2 -> O2 + 2H+ + 2e-}（×5）
足して \ce{e-} と \ce{H+} を整理:
\ce{2MnO4- + 6H+ + 5H2O2 -> 2Mn^2+ + 8H2O + 5O2}対イオン: \ce{2K+} と \ce{3SO4^2-} を両辺に加える
\ce{2KMnO4 + 3H2SO4 + 5H2O2 -> 2MnSO4 + K2SO4 + 8H2O + 5O2}（検算 O: 左 8+12+10=30、右 8+4+8+10=30）
確認問題
1
\ce{Fe^2+} と \ce{Cr2O7^2-}（酸性）のイオン反応式は。
答え
\ce{Cr2O7^2- + 14H+ + 6Fe^2+ -> 2Cr^3+ + 7H2O + 6Fe^3+}
ポイント\ce{H+} は硫酸から来たことにして \ce{SO4^2-} を足す。右辺では \ce{Mn^2+}, \ce{K+} と組ませて硫酸塩にする。
注意電子の数をそろえずに足すと、両辺の電荷が合わない。足したあとに電荷を必ず確認。

「酸化還元」の項目

  1. 酸化・還元の定義必須
  2. 酸化数の決め方と酸化還元の判定必須
  3. 酸化数が分数になる物質不要
  4. 代表的な酸化剤・還元剤の半反応式必須
  5. 半反応式のつくり方（4手順）必須
  6. 半反応式から反応式をつくる必須
  7. 酸化剤にも還元剤にもなる物質（H₂O₂・SO₂）差がつく
  8. 過マンガン酸カリウム滴定必須
  9. ヨウ素滴定差がつく
  10. COD（化学的酸素要求量）不要
  11. イオン化傾向と金属の反応性必須
  12. 金属と金属イオンの反応必須
  13. 電池のしくみ（ダニエル電池）差がつく
  14. 金属の製錬差がつく
