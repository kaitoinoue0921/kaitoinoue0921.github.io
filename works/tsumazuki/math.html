数学Ⅰ

🧮 数と式

  • 乗法公式と展開の工夫必須

    (a-b)^3 の符号は「+,-,+,-」と交互。-3a^2b と +3ab^2 を取り違えやすい。

  • たすき掛けの因数分解必須

    最後に展開して戻すまでが因数分解。符号ミスはここでしか見つからない。

  • 次数の最も低い文字で整理する差がつく

    答えを (a-b)(b-c)(c-a) の形にそろえるときの符号に注意。a-c=-(c-a)。

  • 分母の有理化必須

    分子にも同じものを掛け忘れない。最後に約分できるか確認する。

  • √(a²)=|a| と場合分け必須

    中身を2乗の形（(x-2)^2 など）に直してから |\ | を付ける。直さないまま外すミスが多い。

  • 二重根号を外す差がつく

    マイナスのときは大きい方を前に。\sqrt3-\sqrt5 と書くと負になり誤り。

  • 絶対値を含む方程式・不等式必須

    場合分けで出た解が、その場合の範囲に入っているかを必ず確認する。

  • 一次不等式と整数解必須

    端点 a=6 のように等号が入るかは、その値を実際に入れて数えて決める。

  • 対偶と背理法差がつく

    背理法は「結論を否定して矛盾を導く」。対偶と混同して、仮定まで否定しない。

📈 二次関数

  • 平方完成と頂点必須

    くくり出した係数を、引いた定数にも掛け忘れる（上の例1で 2\times(-4) を忘れる）ミスが最多。

  • 平行移動・対称移動差がつく

    平行移動は「x-p」でマイナス。右に2なら x\to x-2。

  • 軸が動くときの場合分け必須

    答えは「a の範囲ごとに」まとめて書く。範囲の書き漏れ（a=1 など）に注意。

  • 条件つき・置き換えの最大最小差がつく

    y=2-x から出る x の範囲（0\le x\le2）を落とすと最大値が出ない。

  • 二次不等式必須

    -1 を掛けたら不等号の向きを逆に。D\le0 のときは表で確認する（「解なし」と「すべての実数」を取り違えやすい）。

  • 「すべての x で成り立つ」条件必須

    「二次不等式」と書いていなければ x^2 の係数が0の場合も含める。

📐 図形と計量

  • 相互関係（1つ分かれば残りが出る）必須

    \sin\theta だけ与えられたときは鋭角・鈍角の2通りがありうる。条件文で範囲を必ず確認する。

  • 三角比を含む方程式・不等式必須

    置き換えたら範囲を書く。0^\circ\le\theta\le180^\circ では 0\le\sin\theta\le1、-1\le\cos\theta\le1。

  • sinθ+cosθ の値から式の値差がつく

    \sin\theta-\cos\theta は2乗から出すので、符号を別に決める理由を書く。

  • 余弦定理必須

    \cos A が負のとき（鈍角）、-2bc\cos A はプラスになる。符号ミスに注意。

  • 三角形が2つできる場合差がつく

    正弦定理で \sin C から角を出すと鈍角の解を落としやすい。両方が三角形になるか（角の和 <180^\circ）を確認する。

  • 三角形の形状決定差がつく

    答えは「どの辺が等しいか」「どの角が直角か」まで書く。

  • 円に内接する四角形差がつく

    角 A をはさむ2辺は AB,AD、角 C をはさむ2辺は CB,CD。組を間違えないよう図に書き込む。

📊 データの分析

  • 平均値・中央値・最頻値必須

    並べ替えずに真ん中を取るミスが一番多い。値を1つ加える・除く問題では個数（奇偶）が変わる点にも注意。

  • 四分位数と四分位範囲必須

    個数が奇数のとき中央値を前半・後半の両方に入れてしまうミスに注意（教科書の定義では入れない）。

  • 箱ひげ図の読み取り必須

    箱ひげ図から平均値は読めない。「箱の幅が広い＝人数が多い」も誤り（各区間はほぼ同じ人数）。

  • 外れ値の基準差がつく

    問題文に基準が書かれていればそれに従う（共通テストでは毎回明記される形が多いので、読み落とさない）。

  • 分散と標準偏差必須

    標準偏差を求めて終わりの問題で、分散のまま答えるミスに注意。単位も「元のデータと同じ」になるのは標準偏差。

  • 変量の変換 y=ax+b必須

    a が負のとき標準偏差を a s_x（負）にしてしまうミス。標準偏差は必ず |a| 倍。

  • 共分散と相関係数必須

    相関係数が -1\sim1 を超えたら計算ミス。共分散は負になり得るが、分散・標準偏差は負にならない。

  • 変換したときの共分散・相関係数差がつく

    共分散は ac 倍で変わるのに、相関係数は（符号以外）変わらない。混同しやすい。

  • 仮説検定の考え方差がつく

    「基準以上だった＝仮説が正しいと示された」と書くのは誤り。結論は「誤りとは言えない」。

数学A

🎲 場合の数と確率

  • 和の法則・積の法則必須

    「大小2個」とあれば区別あり。区別のないさいころでも、確率では区別して数える（後述）。

  • 順列 ₙPᵣ（隣接・非隣接・数字の並び）必須

    0を含む数字の問題で、先頭の0を除き忘れるミス。偶数の条件と0の条件が重なるので「一の位が0か否か」で場合分けする。

  • 組分け（区別あり／なし）差がつく

    「4人・4人・2人」なら割るのは 2!（同じ人数の組が2つ）。全部を 3! で割るミスに注意。

  • 円順列・じゅず順列差がつく

    1人固定したあとに「固定した人の位置」まで並べてしまうと n! になって誤り。

  • 重複順列と部屋分け（空き部屋なし）差がつく

    3^5-3\cdot2^5 で止めると、全員が1部屋に入る場合を引きすぎたまま。

  • 確率の定義と「区別して数える」必須

    「和が7になるのは(1,6),(2,5),(3,4)の3通り、全体21通り」のように区別せずに数えると、根元事象が同様に確からしくなく誤り。

  • 余事象・「少なくとも」・最大値の確率必須

    「最大値が5」を「少なくとも1つ5」とだけ考えて6を除き忘れるミス。

  • 独立試行・反復試行の確率必須

    優勝決定型で単純に {}_{5}\mathrm{C}_{3}p^3q^2 とすると、4試合目までに優勝が決まった後も試合を続けた場合を含んでしまう。

  • 条件付き確率と乗法定理必須

    P_A(B) と P_B(A) の取り違えが最頻出ミス。「〜であったとき」の〜が分母。

  • 2状態の推移 pₙ₊₁=apₙ+b必須

    初項を p_0 で考えるか p_1 で考えるかで指数が1ずれる。問題文の「最初」が何回目かを確認。

  • 3状態以上の推移（対称性で1本の漸化式に）差がつく

    「Aにいる → 次もA」の項を入れ忘れない（この例では0だが、とどまる確率がある問題では必要）。

🔢 整数の性質

  • 最大公約数・最小公倍数と ab=GL必須

    「互いに素」の条件を落として (a',b')=(2,6) を入れると、最大公約数が12になってしまう。

  • 1次不定方程式 ax+by=c必須

    一般解の x と y で k の係数の符号を逆にし忘れるミス。最後に k=1 を代入して元の式を満たすか確かめる。

  • 合同式で余りを計算する差がつく

    記述答案で合同式を使う場合、記号の意味を一言添えておくと安全（採点者に誤解されない）。

  • 積の形に直す (x-a)(y-b)=k必須

    負の約数の組を検討せずに捨てるのは減点対象。範囲から外れることを1行で書く。

  • n 進法（整数と小数）必須

    割り算の余りを上から読んでしまうミス（整数は下から、小数は上から）。

📐 図形の性質

  • 三角形の五心（重心・内心・外心・垂心）必須

    内心と外心の取り違えが多い。内心＝内接円＝角の二等分線、外心＝外接円＝垂直二等分線。

  • チェバの定理必須

    比を一周させる順番を崩すと逆数になる。紙の図に矢印で一周を書いてから式にする。

  • メネラウスの定理必須

    「どの三角形」と「どの直線」かを答案に明記する。三角形の選び方を間違えると比が1つ足りなくなる。

  • 円周角・円に内接する四角形必須

    「同じ弧」かどうかは、角の両端の2点が同じかで確かめる。弧の反対側の円周角は 180^\circ- になる。

  • 方べきの定理必須

    外部の点の場合、PB を「AB の長さ」と取り違えるミスが最多。必ず P から測る。

数学Ⅱ

🧮 式と証明

  • 二項定理と一般項必須

    (2x-1)^5 の 2 や -1 を一般項から外し忘れて {}_{5}\mathrm{C}_{2}=10 と答えるミスが最多。符号 (-1)^r も忘れない。

  • 整式の割り算 A=BQ+R必須

    x^3+1 を割るときなどに x^2,\ x の欄を空けずに詰めて書くと桁がずれる。

  • 剰余の定理必須

    x+2 で割るときに代入するのは x=-2。符号の取り違えに注意。

  • 恒等式の係数決定（係数比較・数値代入）必須

    数値代入法だけで終わると「必要条件」しか示していない。代入した値の個数が次数＋1以上でないときは逆の確認を書く。

  • 相加平均と相乗平均の関係必須

    例題2で各かっこに別々に使うと 2\sqrt{\dfrac{x}{y}}\cdot2\sqrt{\dfrac{4y}{x}}=8 となるが、等号条件 xy=1 と xy=4 が同時に成り立たないので誤り。まず展開。

🔢 複素数と方程式

  • 負の数の平方根必須

    \sqrt{-2}\sqrt{-8}=\sqrt{16}=4 は誤り（正しくは -4）。

  • 複素数の相等必須

    虚数には大小関係がない。2i>i のような比較はできない。

  • 解と係数の関係と対称式必須

    \alpha+\beta=-\dfrac{b}{a} のマイナスを落とすミスが多い。\alpha^2+\beta^2 が負になることもある（虚数解だから）。

📐 図形と方程式

  • 点と直線の距離必須

    y=2x+1 のまま a=2,\ b=1 としない。2x-y+1=0 に直して b=-1。

  • 円の方程式（標準形・一般形）必須

    平方完成した後、右辺に r^2>0 が残るか確認。\le 0 なら円を表さない。

  • 円の接線必須

    中心が原点でない円は公式が変わる: (x-a)^2+(y-b)^2=r^2 上の点 (x_1,y_1) での接線は (x_1-a)(x-a)+(y_1-b)(y-b)=r^2。

  • 軌跡の求め方必須

    答えは「方程式」ではなく「図形」で書く（中心・半径まで）。媒介変数に範囲があると軌跡も一部だけになる。

  • 不等式の表す領域必須

    境界を「含む／含まない」を必ず書き添える。

🌀 三角関数

  • 単位円による定義と値必須

    \cos^2\theta から \cos\theta を出すとき、象限で符号を決めるのを忘れない。

  • グラフ（周期・振幅・平行移動）差がつく

    2\theta-\dfrac{\pi}{3} を見て「\dfrac{\pi}{3} 移動」とするミスが多い。くくり出してから読む。

  • 三角関数の合成必須

    範囲を書かずに「最小値 -2」とするミスが多い。\theta+\alpha の範囲を単位円にかいて確認。

  • 三角方程式必須

    範囲が1周を超える（例題2は \dfrac{\pi}{3} から \dfrac{7}{3}\pi まで）と、2周目の解 \dfrac{13}{6}\pi を落としやすい。

  • 三角不等式必須

    0\le\theta<2\pi で下側の弧を答えるとき、\theta=0 をまたぐので2つの区間に分かれる。

  • 2次関数に帰着する最大最小必須

    最後に \theta の値まで答える問題が多い。t のままで止めない。

📐 指数・対数関数

  • 指数法則と累乗根必須

    \sqrt[n]{a^m} は a^{\frac{m}{n}}。分母と分子を逆にする誤りが多い。(a^r)^s と a^{r^s} も別物。

  • 累乗・累乗根の大小比較必須

    累乗して比べてよいのは全部正のときだけ。負の数が混じったら先に符号で分ける。

  • t=aˣ と置いて2次方程式・不等式に必須

    t>0 を書き忘れると、負の解 t から存在しない x を作ってしまう。

  • aˣ+a⁻ˣ を置き換える最大・最小差がつく

    t の範囲を t>0 としてしまうと、軸 t=1 で最小と誤る。必ず t\ge 2。

  • 対数の定義・性質・底の変換必須

    \log_a(M+N) は分解できない。(\log_a M)^2 と \log_a M^2 も別物。

  • 対数方程式・不等式（真数条件が先）必須

    真数条件を後回しにすると、まとめた後の式 (x-1)(x+2)>0 のようなゆるい条件で判断してしまい、余計な解が残る。

  • t=logₐ x と置く最大・最小差がつく

    \log_2 x^4 は 4\log_2 x、(\log_2 x)^4 ではない。答えは t でなく x で書く。

  • 桁数・最高位の数字・小数第何位必須

    負のとき「-14.313 だから14位」としがち。10^{-15}\le N<10^{-14} の形に直して判断する。

📉 微分法（数Ⅱ）

  • 導関数の公式と計算必須

    定数項の微分は 0。(x^3)'=3x^2 を 3x^3 と書く写し間違いが多い。

  • 微分係数の定義と極限の変形差がつく

    「定義に従って」と言われたら公式 (x^n)'=nx^{n-1} で答えると0点になりうる。極限の計算を書く。

  • 曲線外の点から引く接線（接点を t とおく）必須

    点が曲線上にあっても、その点以外で接する接線がありうる。「点 A を通る接線」と「点 A における接線」は別物。

  • 増減表の書き方と極値必須

    f'(a)=0 でも符号が変わらなければ極値ではない（例：f(x)=x^3 の x=0）。

  • 極値をもつ条件・極値から係数を決める必須

    「常に増加」は D\le0（D<0 ではない）。D=0 のとき f'(x)=0 になる点は1点だけで、増加は保たれる。

  • 極大値と極小値の差（3次関数の性質）差がつく

    記述式では公式だけ書かず、積分で示すか、直接 f(\alpha)-f(\beta) を計算する。

  • 置き換えて3次関数にする（三角関数・指数など）差がつく

    t の範囲を書かないと、端の値 t=-1 を見落とす。

  • 不等式の証明（差をとって最小値 ≧0）必須

    範囲が「x\ge0」なのに x<0 側の極値まで比べたり、逆に端 x=0 を見落としたりしない。

📏 積分法（数Ⅱ）

  • 不定積分（f'(x) から f(x) を求める）必須

    「C は積分定数」の一言を書く。\int x^2dx を \frac{x^3}{2} とする（割る数のずれ）ミスが多い。

  • 定積分の計算と偶関数・奇関数必須

    F(b)-F(a) の引き算でカッコを付け忘れ、符号を誤るのが最多のミス。下端の値は必ずカッコでくくる。

  • 絶対値のついた定積分必須

    \left|\int f(x)dx\right| と \int|f(x)|dx は別物。積分してから絶対値をとってはいけない。

  • 1/6公式（放物線と直線・放物線どうし）必須

    記述式では「\int_\alpha^\beta(x-\alpha)(x-\beta)dx=-\frac16(\beta-\alpha)^3 を用いて」と式の形を書いてから使う。答えだけ公式で出すと減点されうる。

  • 上端・下端が定数 → 定数 k とおく必須

    k を求めた後、f(x) に戻して答える（k の値で止めない）。

  • 上端が x → 微分する・x=a を代入する必須

    微分だけで終えると定数の情報が失われる。「微分」と「代入」はいつもセット。

  • 積分の中に x がある ∫₀ˣ(x-t)f(t)dt差がつく

    x を外に出さずに「f(x) を代入して (x-x)f(x)=0」とするのは誤り。

数学B

🔢 数列

  • 等比数列の一般項と和必須

    r が文字のまま和を求めるときに r=1 の場合を忘れるのが典型的な減点。

  • Σの公式と計算必須

    \sum_{k=1}^{n-1} のときは公式の n を n-1 に置き換える。\sum_{k=1}^n 3 は 3 ではなく 3n。

  • 分数の和は部分分数分解で消える（差の形）必須

    \frac{1}{(2k-1)(2k+1)} の分解で係数 \frac12 を忘れやすい。分けた後に通分して元に戻るか確認。

  • （等差）×（等比）の和は S-rS必須

    引き算の最後の項 -n\cdot2^n を落としやすい。ずらして縦にそろえて書く。

  • 階差数列・和 Sₙ から一般項必須

    \sum_{k=1}^{n-1} の上端は n-1。公式の n を n-1 にするのを忘れると1ずれる。

  • aₙ₊₁=paₙ+q（特性方程式）必須

    特性方程式は「変形のための計算メモ」。記述式では a_{n+1}-\alpha=p(a_n-\alpha) の変形の方を書く。

  • 分数型は逆数をとる差がつく

    逆数をとる前に a_n\ne0 を一言述べる。

  • 3項間漸化式 aₙ₊₂=paₙ₊₁+qaₙ必須

    ①②の右辺の初項は a_2-\alpha a_1（a_1 ではない）。ここで a_1 を使うミスが多い。

  • 数学的帰納法必須

    [II] で、示したい n=k+1 の式を最初から正しいものとして変形しない。仮定の式から出発する。

📊 統計的な推測

  • 確率分布と期待値 E(X)必須

    表を作らずに期待値を出そうとして、確率の合計が1にならないまま計算してしまうミスが多い。

  • 分散 V(X) と標準偏差 σ(X)必須

    \{E(X)\}^2 と E(X^2) の取り違え。分散が負になったら必ずどこかが間違っている。

  • aX+b の期待値・分散必須

    V(-2X)=-4V(X) や \sigma(-2X)=-2\sigma(X) と書くミス。分散・標準偏差は負にならない。

  • 和の期待値・独立な確率変数の分散差がつく

    V(X-Y)=V(X)-V(Y) は誤り。独立なら V(X-Y)=V(X)+V(Y)。

  • 正規分布と標準化（正規分布表の引き方）必須

    分散 \sigma^2 と標準偏差 \sigma の取り違え。N(50,\,100) なら割るのは10。

  • 二項分布の正規分布による近似必須

    高校の範囲では半整数補正（±0.5）はしないのが標準。問題文の指示に従う。

  • 標本平均の分布必須

    割るのは n ではなく \sqrt n。分散で考えるなら \dfrac{\sigma^2}{n}。

  • 母平均の推定（信頼度95%）差がつく

    「母平均が95%の確率でこの区間に入る」は厳密には不正確。「このやり方で作った区間の約95%が母平均を含む」という意味。記述で問われたら注意。

  • 仮説検定（二項分布の正規近似・両側検定）差がつく

    棄却されないとき「偏りがない（公平だ）と証明された」とは書かない。「偏りがあるとはいえない」と書く。

数学C

🧭 ベクトル

  • 内積の定義と成分表示・なす角必須

    |\vec a-\vec b| が与えられたら「2乗して展開」。|\vec a-\vec b|=|\vec a|-|\vec b| とはできない。

  • 三角形の面積必須

    3点 A, B, C の座標が与えられたら、まず \overrightarrow{\mathrm{AB}},\ \overrightarrow{\mathrm{AC}} を作ってから公式に入れる。

  • 内分点・外分点・重心必須

    内分の係数を逆にするミスが最多。「近い方の点ほど係数が大きい」で確認する。

  • 交点の位置ベクトル（2通りに表して係数比較）必須

    一次独立の断り書きを忘れると記述で減点されやすい。

  • ベクトル方程式（直線・円）差がつく

    |3\vec p-\cdots|=6 を3で割るとき、右辺も3で割るのを忘れない。

  • 空間ベクトルの成分・内積必須

    単位ベクトルは \pm の2つ。片方だけ答えるミスが多い。

  • 4点が同一平面上・直線と平面の交点差がつく

    係数の和を見るのは「L, M, N を基準に書き直した後」。\vec a,\vec b,\vec c の係数のまま和を1にしても意味がない。

🌀 複素数平面

  • 共役複素数と絶対値（|z|²=zz̄）必須

    |z|^2=z^2 ではない（z^2 は一般に複素数）。必ず z\overline z。

  • 極形式と積・商必須

    偏角は \tan だけで決めず、点がどの象限にあるかを図で確かめる。

  • n 乗根（zⁿ=α の解）必須

    k を 0 だけで止めて解を1つしか書かないミス。n 乗根は必ず n 個。

  • 3点の位置関係（(γ-α)/(β-α) を見る）差がつく

    分母と分子の順番に注意。\dfrac{\gamma-\alpha}{\beta-\alpha} の偏角は「ABからACへ」回る角。

  • w=f(z) による図形の移り方差がつく

    z\ne0 のような除外点があるときは、像からも対応する点を除く（上の例は z\to0 に対応する点がないので除外なし）。

🔭 平面上の曲線

  • 放物線 y²=4px（焦点・準線）必須

    y=ax^2 の形で与えられたら x^2=\frac1a y に直してから 4p=\frac1a。

  • 楕円 x²/a²+y²/b²=1必須

    双曲線と混ぜて c=\sqrt{a^2+b^2} にしてしまうミス。楕円は「引く」。

  • 平行移動と一般形からの標準形必須

    平方完成で引く定数に係数をかけ忘れる（4(x-2)^2 なら -4\cdot4=-16）。

  • 2次曲線の接線の公式差がつく

    接点が曲線上にあることを先に確かめる。曲線外の点から引く接線はこの公式を直接使えない（接点を (x_1,y_1) とおいて解く）。

  • 定義から2次曲線の方程式を作る差がつく

    楕円は b^2=a^2-c^2、双曲線は b^2=c^2-a^2。どちらも c は中心から焦点までの距離。

  • 媒介変数表示（円・楕円・双曲線）と消去必須

    \theta や t の範囲が制限されていると、曲線の一部だけになる。範囲があれば x,\ y の範囲も書く。

数学Ⅲ

🎯 極限

  • 不定形 ∞/∞・∞-∞ の崩し方必須

    「\infty-\infty=0」「\frac{\infty}{\infty}=1」としない。不定形は形を変えるまで値が決まらない。

  • rⁿ の極限と場合分け必須

    r=1 と r=-1 を場合分けから落としやすい。r=-1 は (-1)^n が振動するので別扱い。

  • はさみうちの原理必須

    答案には「はさみうちの原理より」と必ず書く。両端の極限が一致しないとはさめていない。

  • 漸化式で決まる数列の極限差がつく

    「極限を \alpha とおいて \alpha=p\alpha+q」だけでは、収束することを示していないので答案として不十分。

  • 無限等比級数必須

    初項 =0 の場合を忘れやすい（例2の x=0）。和の関数が不連続になる典型。

  • 部分和を求めてから極限（部分分数分解）必須

    逆は成り立たない：a_n\to0 でも収束するとは限らない（\sum\frac1n は発散）。

  • 関数の極限：0/0 と x→-∞必須

    x<0 で \sqrt{x^2}=x としてしまうミスが多い（正しくは -x）。置き換えればこのミスが消える。

  • 極限値から係数を決める差がつく

    「分子 \to0」は必要条件。その後に極限を計算して条件を満たすことを確認するまでが解答。

  • limₓ→₀(sin x)/x=1必須

    x\to\infty では使えない：\displaystyle\lim_{x\to\infty}\frac{\sin x}{x}=0（はさみうち）。x\to0 の形に直してから使う。

  • e に関する極限必須

    \left(1+\frac1n\right)^n\to1^\infty=1 としない。1^\infty も不定形。

  • 片側極限と「極限が存在しない」差がつく

    \frac{1}{x-1} の x\to1 を「\infty」と書くのは誤り。片側で符号が違うので、極限はない。

  • 関数の連続性差がつく

    |x|=1 のときは x^{2n}=1 なので、|x|<1・|x|>1 の式に入れず別に計算する。

  • 中間値の定理差がつく

    「連続」の一言を書き忘れない。解が「ちょうど1つ」なら、加えて単調性（微分）が必要。

📉 微分法（数学Ⅲ）

  • 合成関数・逆関数の微分必須

    \{(2x+1)^5\}'=5(2x+1)^4 と中身の微分 \times2 を忘れるのが最多ミス。正しくは 10(2x+1)^4。

  • 三角・指数・対数関数の導関数必須

    (\cos x)'=-\sin x の符号、(\log f(x))'=\dfrac{f'(x)}{f(x)} の分子 f' を落としやすい。

  • 対数微分法差がつく

    (x^x)'=x\cdot x^{x-1} は誤り。x^\alpha の公式は指数が定数のときだけ。

  • 媒介変数表示の微分必須

    第2次導関数を \dfrac{(dy/dt)'}{(dx/dt)'} としない。\frac{dy}{dx} を t で微分して、もう一度 \frac{dx}{dt} で割る。

  • 陰関数の微分（円・楕円・双曲線の接線）差がつく

    y=0 となる点（接線が縦）では y'=-\frac{x}{y} が使えない。別に扱う。

  • 接線・法線必須

    「点 (p,q) における接線」（接点）と「点 (p,q) を通る接線」（接点は未知）を読み分ける。

  • 増減と極値（増減表）必須

    f'(a)=0 でも符号が変わらなければ極値ではない（例：x^3 の x=0）。

  • 最大・最小（文章題を含む）必須

    開区間では端点で値をとらないので、「最大値なし」になることがある。端での極限も調べる。

  • 方程式の実数解の個数（定数分離）差がつく

    分離のとき x で割るなら x=0 を別に確かめる。グラフの端の極限（漸近線）を書かないと個数が数えられない。

  • 速度・加速度と近似式差がつく

    近似式の h は必ず弧度法。度のまま 1 を入れると桁違いになる。

🧮 積分法（数学Ⅲ）

  • 基本の不定積分必須

    \displaystyle\int\frac1x\,dx の絶対値を落とさない。\displaystyle\int x^{-1}dx=\frac{x^0}{0} とはしない。

  • f(ax+b) の積分必須

    中身が2次以上（e^{x^2} など）にはこの公式は使えない。

  • 置換積分（定積分は範囲も置き換える）必須

    置換したのに積分範囲を x のまま残す、dx を置き換え忘れる、の2つが定番のミス。

  • 分数関数の積分（割り算・部分分数）差がつく

    部分分数分解は、最後に通分して元に戻るか確かめる。

  • 定積分で表された関数必須

    \displaystyle\int_0^x(x-t)f(t)\,dt のように中に x があるときは、x\int_0^xf(t)\,dt-\int_0^xtf(t)\,dt と x を外に出してから微分する。

  • 区分求積法必須

    k が 1 から 2n まで動くなど、範囲が違えば積分区間も変わる（\frac kn は 0 から 2 → \int_0^2）。

  • 面積必須

    区間内で上下が入れ替わるなら分けて積分する。そのまま積分すると打ち消し合って小さく出る。

  • 体積（断面積・回転体）必須

    2曲線の間を回転させるときは \pi\int(f^2-g^2)\,dx。\pi\int(f-g)^2dx は誤り（ドーナツ状の断面）。

  • 媒介変数表示の曲線と面積差がつく

    t が増えると x が減る区間では、範囲の上下が逆になる。符号で面積が負になったら範囲を確認。

  • 曲線の長さ差がつく

    \sqrt{4\sin^2\frac t2}=2\left|\sin\frac t2\right|。範囲で符号を確認してから絶対値を外す。
