長文読解 標準

逆接の前後を言い換える

見分け方

however や but の前後に、よく似た内容の選択肢がある。

例題

I expected the online map to save time. However, many paths shown on it were closed. What did the writer find after using the map?

最初の一手を見る
  1. 逆接の前と後をそれぞれ一言で言い換える。
  2. 設問が聞く人物・時点・理由に合う側を本文で探す。
解答とつまずきやすい所

地図に載っている道のうち多くが通れなかったと分かった。前半の save time は使用前の予想で、使用後に分かった事実は however の後にある。

確認 本文と同じ語があるだけで選ぶと、使用前の予想と使用後の発見を取り違える。
