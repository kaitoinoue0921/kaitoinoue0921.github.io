数Ⅱ・微分と積分 基本

放物線と x 軸で囲まれる面積を求める

見分け方

交点で積分区間を決める。区間内では放物線が x 軸以上にある。

例題

放物線 y=4−x² と x 軸で囲まれる部分の面積を求めよ。

最初の一手を見る
  1. 4−x²=0 より、交点の x 座標は −2 と2。
  2. 区間内では 4−x²≧0。左右対称なので 0 から2までの積分を2倍できる。
解答とつまずきやすい所

面積は ∫₋₂²(4−x²)dx=2(8−8/3)=32/3。

確認 0から2までの積分は右半分の面積になる。
