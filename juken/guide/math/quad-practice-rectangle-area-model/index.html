数Ⅰ・二次関数 基本

周の長さから長方形の面積を式にする

見分け方

周の半分は異なる向きの2辺の和。片方を x とおけば、もう片方も x で表せる。

例題

周の長さが24 mの長方形を作る。短い方の辺の長さを x m として、面積を x の式で表せ。また、面積の最大値を求めよ。正方形も含める。

最初の一手を見る
  1. もう一方の辺は 12−x m。短い方を x としたので 0＜x≦6。
  2. 面積 x(12−x) を平方完成し、最大になる x を確かめる。
解答とつまずきやすい所

面積は x(12−x)=36−(x−6)² m²。0＜x≦6 の範囲で平方が0になる x=6 のとき最大で、最大値は36 m²。

確認 周の長さ24 mをそのまま2辺の和には使わない。
