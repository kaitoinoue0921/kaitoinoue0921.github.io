最初に折り返した地点を再び通る時刻と道のり

見分け方

まず速度の符号から折り返しを見つける。求める時刻では、速度ではなく位置が最初の折り返しと一致する。

例題

直線上を動く点の時刻 t 秒での位置を s(t)=t³−(9/2)t²+6t メートルとする。0≦t≦3 の間で、最初に折り返した地点をその後に再び通る時刻と、そこまでに動いた道のりを求めよ。

最初の一手を見る
  1. s′(t)=3(t−1)(t−2) の符号が t=1, 2 で変わる。最初に折り返すのは t=1 で、位置は 5/2。
  2. s(t)−5/2=(t−1)²(t−5/2) と因数分解し、t=1 より後の解を取る。
  3. 時刻0、1、2、5/2の位置から、向きが一定の各区間で動いた長さを足す。
解答とつまずきやすい所

最初の折り返しは t=1、位置は 5/2 m。その位置と一致する条件は s(t)−5/2=(t−1)²(t−5/2)=0 なので、再び通るのは t=5/2 秒。位置は順に 0、5/2、2、5/2 なので、道のりは 5/2+1/2+1/2=7/2 m。

確認 再び同じ場所を通っても、速度が0になるとは限らない。
