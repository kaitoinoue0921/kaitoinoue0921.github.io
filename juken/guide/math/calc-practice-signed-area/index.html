数Ⅱ・微分と積分 標準

x軸を横切る曲線の面積を求める

見分け方

曲線が x 軸の上下にまたがると、定積分では上下の面積に異なる符号が付く。交点で区切って足す。

例題

−1≦x≦1 において、曲線 y=x³−3x と x 軸の間にある部分の面積の合計を求めよ。

最初の一手を見る
  1. f(x)=x(x²−3) と因数分解し、−1≦x≦1 で x 軸と交わるのは x=0 だけだと分かる。
  2. 左半分では f(x) が正、右半分では負。右半分では −f(x) を積分する。奇関数なので左右の面積は等しい。
解答とつまずきやすい所

x²−3＜0 なので、曲線は左半分では x 軸の上、右半分では下。f(−x)=−f(x) より面積は右半分の2倍で、2∫₀¹(3x−x³)dx=2(3/2−1/4)=5/2。

確認 区間全体の定積分は0になるが、左右の面積はそれぞれ正。
