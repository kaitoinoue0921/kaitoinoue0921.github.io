数Ⅱ・微分と積分 融合

積分で決まる関数を微分して形を追う

見分け方

上端が x の積分で関数が定義され、その最大値や増減を聞かれる。

例題

0≦x≦2 で、F(x) を 0 から x までの 2−2t の定積分とする。F(x) の最大値は。

最初の一手を見る
  1. 微分して被積分関数を求め、その符号が変わる点を出す。
  2. 増減と両端を調べ、必要な点で元の積分を計算する。
解答とつまずきやすい所

F′(x)=2−2x。x=1 まで増加、その後減少する。F(1)=[2t−t²]₀¹=1 が最大。

確認 問われたのは F の最大値。F′ の最大値や、面積の絶対値の和ではない。
