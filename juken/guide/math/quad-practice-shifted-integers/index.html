数Ⅰ・二次関数 標準

平行移動した区間に入る整数を数える

見分け方

まず x−3/2 全体を一つの変数として不等式を解き、戻してから整数を拾う。

例題

f(x)=x²−x−6 とする。f(x−3/2)≦0 を満たす整数 x をすべて求めよ。

最初の一手を見る
  1. u=x−3/2 とおくと、f(u)≦0 は (u+2)(u−3)≦0 と書ける。
  2. −2≦u≦3 に u=x−3/2 を戻し、x の範囲に入る整数を列挙する。
解答とつまずきやすい所

−2≦x−3/2≦3 なので −1/2≦x≦9/2。条件を満たす整数は 0, 1, 2, 3, 4。

確認 左端 −1/2 より大きい最初の整数は0。右端 9/2 より小さい最後の整数は4。
