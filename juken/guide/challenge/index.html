平方完成と最大・最小

基本

関数 f(x)=−x²+4x の 0≦x≦3 における最大値と最小値を求めよ。また、それぞれを取る x の値を求めよ。

最初に何をする？

方針と理由を見る

平方完成し、軸と両端の位置を確かめる

区間内の軸で最大値を取り、軸から遠い端で最小値を取ります。

例題の解答と復習
標準

実数 a に対し、関数 f(x)=−x²+4x の a≦x≦a+2 における最小値を a で表せ。また、最小値を取る x をすべて求めよ。

最初に何をする？

方針と理由を見る

左右の端の値が等しくなる a を探す

下に開くので、最小になるのは軸から遠い方の端です。両端が軸から同じ距離にあるときに入れ替わります。

例題の解答と復習
融合

実数 a, t に対し、関数 f(x)=−x²+4x+t は a≦x≦a+2 で最大値4、最小値1を取る。この条件を満たす (a, t) をすべて求めよ。

最初に何をする？

方針と理由を見る

区間と軸の位置で分け、最大値と最小値の差を調べる

t を変えると両方の値が同じだけ動きます。差は変わらないので、先に差3を作れる区間を探せます。

例題の解答と復習

方程式を平方完成し、境目になる高さを求める

例題の解答と復習

二つの実数解を求め、それぞれが区間に入る条件を課す

二次不等式と整数解

基本

二次不等式 x²−x−6≦0 を解け。

最初に何をする？

方針と理由を見る

まず二つの因数が0になる点を求める

二つの根が符号の境目です。根の間と外で積の符号を見ます。

例題の解答と復習
標準

f(x)=x²−x−6 とする。f(x−3/2)≦0 を満たす整数 x をすべて求めよ。

最初に何をする？

方針と理由を見る

x−3/2 を一まとまりと見て解き、そのあと x の区間に戻す

二次不等式の解を −2≦x−3/2≦3 と表すと、元の x が取る範囲と整数解が分かります。

例題の解答と復習
融合

最初に何をする？

方針と理由を見る

それぞれを解いて共通区間を作る

両方を満たす整数だけを数えます。区間の端が整数を通過するときに個数が変わります。

長方形の面積と条件

基本

周の長さが24 mの長方形を作る。短い方の辺の長さを x m として、面積を x の式で表せ。また、面積の最大値を求めよ。正方形も含める。

最初に何をする？

方針と理由を見る

周の長さを2で割って、もう一方の辺を 12−x と表す

周には各辺が2本ずつ含まれます。2辺の和と面積の式を順に求めます。

例題の解答と復習
標準

周の長さが24 mの長方形を作る。短い方の辺を2 m以上とし、長い方の辺を短い方より4 m以上長くする。面積の最大値と、そのときの2辺の長さを求めよ。

最初に何をする？

方針と理由を見る

短い方の辺を x とおき、辺の差と最短の条件を x の不等式にする

辺の差は (12−x)−x です。差の条件から x の上限を求めます。

例題の解答と復習
融合

a≧0 とする。周の長さ24 m、短い方の辺が2 m以上で、長い方と短い方の辺の差が a m以上の長方形を作る。面積を35 m²以上にできる a の範囲と、そのときの短い方の辺の長さ x の範囲を a で表せ。正方形も含める。

最初に何をする？

方針と理由を見る

面積の不等式と辺の差の不等式を作り、x の範囲を重ねる

面積35 m²以上には x≧5 が必要です。辺の差で決まる x の上限がその下限に届くか確かめます。

球の取り出しと条件付き確率

基本

箱Aに赤球3個、白球2個が入っている。この箱から無作為に1個ずつ2回取り出し、取り出した球は戻さない。2個とも赤である確率を求めよ。

最初に何をする？

方針と理由を見る

初めに赤が出た場合の残りを数えてから掛ける

2個とも赤になる経路では、1回目で赤球が1個減ります。2回目は残った4個のうち赤2個です。

例題の解答と復習
標準

箱Aに赤球3個、白球2個が入っている。無作為に1個ずつ2回取り出し、取り出した球は戻さない。取り出した2個のうち少なくとも1個は赤だった。このとき、2個とも赤である確率を求めよ。

最初に何をする？

方針と理由を見る

2個とも白の確率を1から引き、分母を出す

先に分かっている条件は「少なくとも1個が赤」です。その条件に合う全経路の確率から、2個とも赤の割合を求めます。

例題の解答と復習
融合

箱Aには赤球3個と白球2個、箱Bには赤球1個と白球4個が入っている。二つの箱から1箱を等確率で選び、その箱から無作為に1個ずつ2回取り出す。取り出した球は戻さない。少なくとも1個が赤だと分かったとき、選んだ箱がAである確率を求めよ。

最初に何をする？

方針と理由を見る

箱ごとに条件を満たす経路の確率を出す

選んだ箱によって赤が出やすいかが変わります。箱の選択と観測結果がともに成立する確率を比べます。

例題の解答と復習

反復試行と打ち切り

基本

各回の成功確率が 1/3 で、各回の結果は互いに独立である。3回試行するとき、ちょうど2回成功する確率を求めよ。

最初に何をする？

方針と理由を見る

成功2回・失敗1回の並び方を数えてから確率を掛ける

成功する回の位置が違う3通りを数えます。独立なので、どの順番でも各回の確率を掛けられます。

例題の解答と復習
標準

各回の成功確率が 1/3 で、各回の結果は互いに独立である。4回試行するとき、少なくとも2回成功する確率を求めよ。

最初に何をする？

方針と理由を見る

成功0回と1回を数え、その和を1から引く

「少なくとも2回」の余事象は「0回または1回」です。ちょうど1回の並び方も数えます。

例題の解答と復習
融合

各回の成功確率は 1/3 で、各回の結果は互いに独立である。成功が2回に達した時点で終了し、達しない場合も4回で打ち切る。終了時に成功が2回に達していたと分かったとき、4回目で終了した確率を求めよ。

最初に何をする？

方針と理由を見る

4回までに成功が2回に達する経路を分母にする

観測された条件は「成功が2回に達した」です。その中で、2回目の成功がちょうど4回目の経路を分子にします。

例題の解答と復習

組合せと条件付き確率

基本

1から6までの整数が1枚ずつ書かれた6枚のカードから、同時に2枚を無作為に選ぶ。数の合計が4になる確率を求めよ。

最初に何をする？

方針と理由を見る

等確率な2枚組と、和が4になる2枚組を数える

等確率なのはカードの組です。和が同じになるカードの組の数は、和によって変わります。

例題の解答と復習
標準

1から6までの整数が1枚ずつ書かれた6枚のカードから、同時に3枚を無作為に選ぶ。数の合計が偶数になる確率を求めよ。

最初に何をする？

方針と理由を見る

選んだ奇数カードの枚数で場合分けする

奇数のカードは1枚加わるたびに和の偶奇を反転させます。奇数が0枚と2枚の場合を数えます。

例題の解答と復習
融合

1から6までの整数が1枚ずつ書かれた6枚のカードから、同時に3枚を無作為に選ぶ。3枚の数の合計が偶数だったと分かったので、その3枚から1枚を等確率で除く。残った2枚の数の合計が4となる確率を求めよ。

最初に何をする？

方針と理由を見る

和が偶数の3枚組と、そこから除く1枚を一組として数える

条件に合う3枚組は等確率で、そこからの3通りの除き方も等確率です。残りが {1, 3} の場合をこの単位で数えます。

期待値と選択

基本

公平なさいころを1回振る。出目が1、2、3なら0点、4、5なら2点、6なら10点を得る。得点の期待値を求めよ。

最初に何をする？

方針と理由を見る

得点ごとの確率を求め、得点を重み付きで平均する

得点の出やすさはそれぞれ違います。確率を掛けると、出目6通りでの平均と同じになります。

例題の解答と復習
標準

公平なさいころを振り、出目が1、2、3なら0点、4、5なら2点、6なら10点を得る。1回目の結果を見て、その得点を確定するか、さいころを1回だけ振り直すかを選べる。振り直すと2回目の得点だけが残り、各回の出目は独立である。期待値を最大にする選び方と、その期待値を求めよ。

最初に何をする？

方針と理由を見る

1回目の確定点と、振り直した場合の期待値を比べる

振り直す場合の期待値 7/3 点は2点より大きく、10点より小さいので、得点ごとに選びます。

例題の解答と復習
融合

公平なさいころを振り、出目が1、2、3なら0点、4、5なら2点、6なら10点を得る。1回目の結果を見て、その得点を確定するか、1回だけ振り直すかを選べる。振り直しでは1回目の得点が消え、最終得点は2回目の得点から c 点を引いた値になる。各回の出目は独立で c≧0 とする。期待値が3点以上になる選び方が存在する c の範囲を求めよ。

最初に何をする？

方針と理由を見る

振り直しの期待値を一回目の得点ごとに比べ、c で場合分けする

振り直すかどうかは最初の得点を見て決められます。費用が上がると振り直す結果が減るため、境目で区切ります。

接線と面積

基本

曲線 y=x³−3x 上の x=0 に対応する点での接線の方程式を求めよ。

最初に何をする？

方針と理由を見る

接点の座標と、その点での導関数の値を求める

接点の x 座標は指定されています。元の関数と導関数をそれぞれ x=0 で評価します。

例題の解答と復習
標準

−1≦x≦1 において、曲線 y=x³−3x と x 軸の間にある部分の面積の合計を求めよ。

最初に何をする？

方針と理由を見る

曲線と x 軸の交点を探し、曲線の上下を確かめる

上下で符号が変わるため、定積分を一度だけ行うと面積が打ち消し合います。交点で区切って、各部分の面積を足します。

例題の解答と復習
融合

a＞0 とする。曲線 y=x³−3x と、その曲線上の点 (a, a³−3a) における接線で囲まれる部分の面積を a で表せ。また、面積が 27/4 になるときの a を求めよ。

最初に何をする？

方針と理由を見る

接線を求め、曲線と接線の差から交点を出す

面積を囲むのは曲線と接線です。差が0になる点を求め、どちらが上かを判断して積分します。

速度と道のり

基本

直線上を動く点の時刻 t 秒での位置を s(t)=t³−(9/2)t²+6t メートルとする。t=3/2 における速度と速さを求めよ。

最初に何をする？

方針と理由を見る

位置を微分し、指定の時刻を代入する

求めるのは指定時刻での瞬間の速度です。位置の時間微分を使い、速さにはその絶対値を使います。

例題の解答と復習
標準

最初に何をする？

積分で定まる関数

基本

F(t)=∫₀ᵗ(x²−4x+3)dx とする。F′(t) と F(1) を求めよ。

最初に何をする？

方針と理由を見る

導関数は上端での被積分関数の値を使い、F(1) は定積分で求める

導関数と積分値は別の量です。微分には変化する上端、積分値には0から1までの区間を使います。

例題の解答と復習
標準

F(t)=∫₀ᵗ(x²−4x+3)dx とする。0≦t≦4 における F(t) の最大値と最小値を求め、それぞれを取る t の値をすべて挙げよ。

最初に何をする？

方針と理由を見る

F′(t) の符号で増減を調べ、端点も含めて F(t) の値を比べる

増減表が示す候補と、定義域の両端を調べます。この問題では端点でも最大値や最小値を取ります。

例題の解答と復習
融合

G(t)=∫ₜᵗ⁺²(x²−4x+3)dx とする。0≦t≦2 における G(t) の最小値と、その値を取る t を求めよ。また同じ区間で G(t)=0 となる t をすべて求めよ。

最初に何をする？

方針と理由を見る

上端までの積分と下端までの積分の差を書き、両方を微分する

上端が進むと右から積分が加わり、下端が進むと左の積分が取り除かれます。両端の値の差を使います。

水平線で分ける面積

基本

放物線 y=4−x² と x 軸で囲まれる部分の面積を求めよ。

最初に何をする？

方針と理由を見る

放物線と x 軸が交わる x を求める

面積を囲む左右の端は、放物線の高さが0になるところです。

例題の解答と復習
標準

放物線 y=4−x² と x 軸で囲まれる領域を水平線 y=3 で切る。y≧3 にある部分の面積と、元の領域全体に対する面積の割合を求めよ。

最初に何をする？

方針と理由を見る

放物線と水平線の交点を出し、二つの高さの差を積分する

水平線の分だけ下の領域を除きます。積分する高さは (4−x²)−3 です。

例題の解答と復習
融合

放物線 y=4−x² と x 軸で囲まれる領域を、水平線 y=h（0＜h＜4）で等しい面積に分けたい。h の値を求めよ。

最初に何をする？

方針と理由を見る

水平線との交点を h で表し、上側の面積を全体の半分とおく

水平線を上げると上側の領域は低くなると同時に狭くなります。交点を h で求めれば両方を積分に反映できます。
