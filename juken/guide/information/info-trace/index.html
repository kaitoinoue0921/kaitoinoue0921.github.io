情報Ⅰ・プログラミング 基本

繰り返しをトレース表で追う

見分け方

変数が繰り返しの中で更新され、処理後の値を聞かれる。

例題

s=0 から始める。i を1, 2, 3, 4の順に取り、i が偶数のときだけ s に i を加える。終了時の s は。

最初の一手を見る
  1. 周回ごとに、条件判定・更新後の値・出力を分けて書く。
  2. 更新の順番をコード上の順で追う。
解答とつまずきやすい所

s は順に 0, 2, 2, 6。条件を通るのは i=2 と i=4 なので、最後は6。

繰り返しごとの変数の値
i1234
更新後の s0226

確認 i が奇数の周回では s を0に戻さない。前の値を保つ。
