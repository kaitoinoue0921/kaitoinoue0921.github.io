【東大型】空間図形の最大最小

東大レイヤー ／ 出題テーマ ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

空間の最大最小は、ベクトルで立式し、変数を減らし、最後に微分または平方完成で処理する——という長い一本道を最後まで走り切る体力が問われる。途中で計算が汚くなって手が止まるのが典型的な失敗で、その原因はほぼ座標の取り方にある。対称性を活かした座標を選べば式は驚くほど簡単になり、選び損ねれば同じ問題が別物のように重くなる。だから書き始める前に、座標設定に30秒使う価値がある。

こんなときに使う

  • 空間内の2点間の距離の最小 → 両方をパラメータで表し、2変数関数にする
  • ねじれの位置にある2直線の最短距離 → 共通垂線、または2変数の平方完成
  • 点と平面の距離 → 公式、または垂線の足を内積で求める
  • 正四面体・立方体 → 対称性のよい座標を選ぶ（原点を重心に取ると式が簡単になる）
  • 1変数に落ちたら微分、2変数のままなら平方完成を2回

手順

  1. 1. 対称性が最も活きる座標を設定する（ここで難易度が半分になる）
  2. 2. 動く点をパラメータで表す（線分上なら s, t ∈ [0,1]）
  3. 3. 求めたい量を、そのパラメータの式で表す
  4. 4. 距離なら2乗のまま扱う（√ を残さない）
  5. 5. 2変数なら片方ずつ平方完成する。1変数に落ちるなら微分する
  6. 6. パラメータの動く範囲内に最小値があるか確認する

例題

1辺の長さが 1 の正四面体 ABCD において、点 P は辺 AB 上を、点 Q は辺 CD 上を動く。線分 PQ の長さの最小値を求めよ。
解答
  1. 【座標設定】立方体の頂点を使うと、正四面体の座標が驚くほど簡単になる。
  2. 　A(1, 1, 1)、B(1, −1, −1)、C(−1, 1, −1)、D(−1, −1, 1)
  3. 各辺の長さは、例えば AB = |(0, −2, −2)| = 2√2。つまりこれは1辺 2√2 の正四面体。
  4. 最後に 1/(2√2) 倍して、1辺 1 の場合に直す。
  6. 【点をパラメータで表す】
  7. P は辺 AB 上： P = A + s(B − A) = (1, 1 − 2s, 1 − 2s)　（0 ≦ s ≦ 1）
  8. Q は辺 CD 上： Q = C + t(D − C) = (−1, 1 − 2t, −1 + 2t)　（0 ≦ t ≦ 1）
  10. 【距離の2乗を計算する】√ を付けたまま扱わない。
  11. Q − P = (−2, (1 − 2t) − (1 − 2s), (−1 + 2t) − (1 − 2s))
  12. 　　　 = (−2, 2s − 2t, 2s + 2t − 2)
  14. |PQ|² = 4 + 4(s − t)² + 4(s + t − 1)²
  16. 【最小化する】
  17. 第2項と第3項はどちらも 0 以上なので、両方が同時に 0 にできれば最小。
  18. 　s − t = 0 かつ s + t − 1 = 0　⇔　s = t = 1/2
  19. これは 0 ≦ s, t ≦ 1 の範囲内にある。
  21. このとき |PQ|² = 4、つまり |PQ| = 2。
  23. 【1辺 1 に換算する】
  24. 1辺 2√2 のとき最小値 2 なので、1辺 1 のときは 2/(2√2) = 1/√2 = √2/2
  26. ∴ 最小値は √2/2
  28. 【確認】s = t = 1/2 は AB と CD の中点。正四面体では対辺の中点を結ぶ線分が
  29. 両方の辺に垂直（共通垂線）になるので、幾何的にも整合する。

別解・ほかの見方

  • 共通垂線を幾何的に求める（対称性から中点どうしを結ぶと分かれば計算不要）
  • ベクトルの内積で垂直条件を2本立てて連立する
  • 1変数に落として微分する（片方の点が固定されている場合）
  • 正四面体は立方体に埋め込むと座標が簡単になる（この問題の要点）
  • 距離ではなく距離の2乗を扱う（√ を最後まで残さない）

落とし穴

  • 座標の取り方が悪く、式が汚いまま突き進む（最大の失敗要因）
  • √ を付けたまま最小化しようとする
  • パラメータの範囲（0 ≦ s ≦ 1）を確認せず、範囲外の点で最小値を主張する
  • 2変数の平方完成で、片方を定数扱いしたまま結論を出す
  • 対称性に気づかず、力任せに計算する
  • 変数の取り方が悪く式が汚くなったまま突き進む

なぜ大事か

ベクトルで立式→1変数に落として微分、という長い一本道を最後まで走り切る体力

東大での出方

東大では、空間ベクトルと微分を組み合わせた最大最小が定期的に出る。計算量が多いので、途中で方針が正しいか不安になるが、座標設定が良ければ式は必ず整理される。式が汚いまま進んでいると感じたら、座標を取り直す判断も含めて訓練しておくこと。

確認問題

  • 1辺 1 の立方体 ABCD-EFGH で、辺 AB 上の点 P と辺 GH 上の点 Q について PQ の最小値を求めよ
  • 点 (1, 1, 1) と平面 x + y + z = 0 の距離を、公式と垂線の足の両方で求めよ
  • 正四面体の対辺の中点を結ぶ線分が、両方の辺に垂直であることを示せ

発展

動く点が3つ以上ある場合、または曲面上を動く場合。変数が増えるので、対称性で減らす技術がそのまま得点力になる。

前提になるノード

  • 垂線の足・点と平面の距離・射影
  • 最大最小（実用・図形量への応用）
  • 対称性を利用して場合を減らす
