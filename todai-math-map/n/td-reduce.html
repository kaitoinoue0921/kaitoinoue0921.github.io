未知を既知に帰着させる（言い換えの技術）

要点

東大は初見の設定を出してくる。しかしその中身は、ほぼ必ず既習の型である。だから問題文の言葉のまま処理しようとすると手が止まり、設定を剥がして『これは何の問題か』を見抜けば、すでに持っている道具で解ける。この翻訳作業こそが受験数学の最上位の技術であり、パターン暗記だけで来た人が最後に止まるのもここである。逆に言えば、翻訳の引き出しを増やすことが、そのまま得点力になる。

こんなときに使う

  • 見たことのない設定 → 装飾を剥がし、何を求めるのかだけを抜き出す
  • 『〜が存在する』→ 方程式の解の存在条件（判別式・値域）に翻訳
  • 『すべての〜で成り立つ』→ 最小値・最大値の問題に翻訳
  • 図形の条件 → 座標・ベクトル・複素数・面積のどれかに翻訳
  • 数えにくい → 1対1に対応する別のものを数える
  • 規則が見えない → n = 1, 2, 3 で実験する

手順

  1. 1. 問題文から装飾（物語・ゲーム・実験の設定）を全部剥がす
  2. 2. 何が変数で、何が定数で、何を求めるのかを書き出す
  3. 3. 条件をすべて数式にする
  4. 4. 『これは何の型か』を判定する（解の存在条件／最大最小／数え上げ／漸化式）
  5. 5. 既知の型に落ちたら、その型の手順で処理する
  6. 6. 落ちなければ、小さい場合を実験して構造を探す

例題

1辺の長さが 1 の正三角形 ABC の内部の点 P から、3辺に下ろした垂線の長さをそれぞれ p, q, r とする。p + q + r の値を求めよ。
解答
  1. 垂線の足の位置を求めようとすると、点 P の座標を置くことになり計算が重くなる。
  2. しかしこの問題は、幾何の問題ではなく面積の問題に翻訳できる。
  4. 【翻訳】点 P と各頂点を結ぶと、三角形 ABC は3つの三角形に分割される。
  5. 　△PBC、△PCA、△PAB
  6. この3つの面積の和が、元の三角形の面積に等しい。
  8. 各三角形について、底辺は正三角形の1辺（長さ 1）、高さがそれぞれ p, q, r。
  9. 　(1/2)·1·p + (1/2)·1·q + (1/2)·1·r = （正三角形 ABC の面積）
  11. 正三角形の面積は (√3/4)·1² = √3/4 なので
  12. 　(1/2)(p + q + r) = √3/4
  14. ∴ p + q + r = √3/2
  16. 【要点】P がどこにあっても値が変わらない（一定である）ことが結論。
  17. 座標を置いて計算しても出せるが、面積に翻訳すれば3行で終わる。
  18. 『長さの和』を『面積の和』に読み替えた、という一点がこの問題の全て。
  20. 検算：P が重心のとき、p = q = r = 内接円の半径 = √3/6。
  21. 3倍して √3/2 ○

別解・ほかの見方

  • 図形 → 座標（計算で押し切る）／ベクトル（内積で角と長さ）／複素数（回転が絡むとき）／面積・体積（和が一定のとき）
  • 数え上げ → 1対1対応（最短経路を『右と上の並べ方』に読み替える等）
  • 『存在する』→ 判別式、値域、中間値の定理
  • 『一定である』→ 具体的な位置で値を求めて予想し、一般に示す
  • 整数 → 合同式・因数分解・評価のどれかに翻訳

落とし穴

  • 問題文の言葉のまま処理しようとして、計算が膨張する
  • 設定に引きずられ、本質でない部分を丁寧に計算してしまう
  • 既知の型に落ちているのに気づかず、一から考え直す
  • 翻訳した先の条件が、元の条件と同値でない（必要条件だけになっている）
  • 実験を飛ばして、いきなり一般の議論を始める
  • 問題文の言葉のまま処理しようとする

なぜ大事か

東大は初見の設定を出すが、中身は必ず既習の型。設定を剥がして何の問題かを見抜く作業が本体

東大での出方

東大の問題は『初見の設定 × 既習の型』という設計で作られている。誘導が薄い年ほどこの力が要求され、逆に誘導が丁寧な年は、その誘導自体が翻訳の道筋を示している。過去問を解くときは、答えが合ったかよりも『何に翻訳したか』を記録していくと蓄積になる。

確認問題

  • 正四面体の内部の点から4つの面に下ろした垂線の長さの和は一定であることを示せ（体積で翻訳する）
  • n 個のさいころを同時に投げたとき、出た目の最大値が k である確率を求めよ（『最大値 ≦ k』から引く）
  • 整数 x, y が x² + y² = z² を満たすとき、x, y の少なくとも一方は偶数であることを示せ（mod で翻訳する）

発展

翻訳の候補が複数あるとき、どれが最も軽いかを事前に見積もる判断。座標・ベクトル・複素数のどれで書くかで計算量が数倍変わることがあり、書き始める前に30秒考える価値がある。
