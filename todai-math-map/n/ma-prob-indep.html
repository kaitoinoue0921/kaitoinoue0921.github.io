独立試行・反復試行

数学A ／ 確率 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

独立とは、一方の結果が他方の確率を変えないということであり、このとき確率は掛け算になる。反復試行の公式 C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ は暗記するものではなく、2つの部分の積として読むものである。C(n,k) は n 回のうちどの k 回で成功するかの選び方、pᵏ(1−p)ⁿ⁻ᵏ はその並び1つが起こる確率。この分解ができていれば、『初めて成功するのが k 回目』のように C がつかない類題にも自然に対応できる。

こんなときに使う

  • 『同じ試行を n 回繰り返す』→ 反復試行
  • 『ちょうど k 回起こる』→ C(n,k)·pᵏ·qⁿ⁻ᵏ
  • 『少なくとも1回』→ 余事象（1 −『1回も起こらない』）
  • 『初めて成功するのが k 回目』→ 前の k−1 回は失敗、k 回目に成功。C はつかない
  • 玉を戻すか戻さないか → 戻せば独立、戻さなければ独立でない（条件付き確率へ）

手順

  1. 1. 各回の試行が独立か確認する（前の結果が次の確率を変えないか）
  2. 2. 『どの回で起こるか』の場合の数を数える
  3. 3. その並び1つが起こる確率を計算する
  4. 4. 2 と 3 を掛ける
  5. 5. 『少なくとも』が出てきたら、余事象のほうが楽でないか必ず比べる

例題

1個のサイコロを4回投げる。(1) 1の目がちょうど1回出る確率 (2) 1の目が少なくとも1回出る確率 を求めよ。
解答
  1. 各回の試行は独立で、1の目が出る確率は毎回 1/6。
  3. (1) ちょうど1回
  4. 　どの回で出るかの選び方： C(4,1) = 4 通り
  5. 　その並び1つが起こる確率： (1/6)¹ · (5/6)³ = 125/1296
  6. 　よって 4 × 125/1296 = 500/1296 = 125/324
  8. (2) 少なくとも1回
  9. 　直接数えると『1回・2回・3回・4回』の4通りを足すことになる。
  10. 　余事象『1回も出ない』を使うほうが速い。
  11. 　1回も出ない確率 = (5/6)⁴ = 625/1296
  12. 　よって 1 − 625/1296 = 671/1296
  14. 検算：(1) の 125/324 = 500/1296 は (2) の 671/1296 より小さい。
  15. 『ちょうど1回』は『少なくとも1回』に含まれるので、大小関係は整合的 ○

別解・ほかの見方

  • 余事象を使う（『少なくとも』はほぼ常にこちらが速い）
  • 『初めて成功するのが k 回目』は (1−p)^(k−1)·p。どの回かは選ばないので C がつかない
  • 戻さない抽出（非復元）は独立でないので、条件付き確率の積で処理する
  • 成功回数の期待値だけなら、線形性から np と即座に出る（分布を求める必要がない）

落とし穴

  • 独立でないのに掛け算する（玉を戻さない場合が典型）
  • 『初めて〜』の問題に C をつけてしまう
  • 『少なくとも1回』を直接数えて場合分けが増える
  • (5/6)³ のような累乗の計算ミス。約分は最後にまとめて行う

なぜ大事か

二項分布型の確率計算の基本形

東大での出方

単独では易しいので、他の要素と組み合わせて出る。特に確率漸化式では、各ステップの遷移確率を求める部分がこの反復試行の考え方になっている。ここが不安定だと、状態設計が正しくても答えが合わない。

確認問題

  • コインを5回投げて、表がちょうど3回出る確率を求めよ
  • サイコロを投げ続けるとき、初めて1の目が出るのが3回目である確率を求めよ
  • サイコロを4回投げて、1の目が2回以上出る確率を求めよ（余事象を使う）

発展

反復試行の確率 C(n,k)pᵏqⁿ⁻ᵏ を k の関数と見て、最大になる k を求める問題。隣接する項の比を取って 1 との大小を調べる、という手法は数列の最大項の議論と共通している。
