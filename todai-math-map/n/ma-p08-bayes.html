確8 条件付き確率・原因の確率

数学A ／ 確率 ／ 東大での重要度 ★★★☆☆

アプリで開く →

要点

P(A|B) = P(A∩B)/P(B) は『B が起こった世界だけを全体と見直したときの A の割合』。原因の確率は、樹形図で結果 B に至る経路を全部書き、その確率の和を分母、そのうち原因 A を通る経路を分子にする。検査の陽性的中率のように、直感と大きくずれる答えが出るのが特徴。

こんなときに使う

  • 『〜であったとき』『〜と分かったとき』
  • 『取り出した玉が赤であった。それが袋 A からである確率』（原因の確率）
  • 検査の陽性・陰性、くじを引く順番の有利不利

手順

  1. 1. 原因（どの袋か・病気かどうか）→ 結果（色・陽性か）の順に樹形図を描く
  2. 2. 各経路の確率を掛け算で出す
  3. 3. 分母 P(B) = 結果 B に至る全経路の確率の和
  4. 4. 分子 P(A∩B) = そのうち原因 A を通る経路の確率
  5. 5. 割る。答えが原因の事前の確率と比べて妥当な向きに動いたか確かめる

例題

ある病気の有病率は 1% である。検査は、病気の人を 90% の確率で陽性と判定し、病気でない人を 5% の確率で誤って陽性と判定する。陽性と判定された人が実際に病気である確率を求めよ。
解答
  1. 病気かつ陽性：0.01 × 0.9 = 0.009
  2. 病気でなく陽性：0.99 × 0.05 = 0.0495
  3. P(陽性) = 0.009 + 0.0495 = 0.0585
  4. ∴ P(病気 | 陽性) = 0.009/0.0585 = 2/13（約 15%）
  5. 感度 90% でも的中率が低いのは、病気でない人が圧倒的に多く、偽陽性の経路が大きいから

別解・ほかの見方

  • くじ引きの順番：先に引いた人の結果が分からなければ、何番目に引いても当たる確率は同じ
  • 『3人の子のうち少なくとも1人は男子』と分かったときの全員男子の確率（1/7）
  • 条件付き確率を使った独立の判定：P(A|B) = P(A) なら独立

落とし穴

  • P(A|B) と P(B|A) を混同する
  • 分母に、結果 B に至る経路の一部しか入れない
  • 条件で全体を絞ったのに、分母を元の全体のまま計算する
  • P(A|B) と P(B|A) を取り違える（陽性のとき病気である確率と、病気のとき陽性である確率）

なぜ大事か

『〜であったとき、それが〇〇による確率』は、分母を『結果が起こる全経路の和』にするだけ

東大での出方

東大では条件付き確率単独より、確率漸化式の途中で『〜のとき次に〜』を書く形で使う。医学部では検査の的中率がそのまま出る。

確認問題

  • 袋A（赤2個・白1個）と袋B（赤1個・白2個）から1つを等確率で選び1個取り出したら赤だった。袋Aからである確率を求めよ（答：2/3）
  • 3人の子がいる家庭で、少なくとも1人が男子と分かっているとき、3人とも男子である確率を求めよ（答：1/7）

発展

P(A|B) = P(B|A)P(A)/P(B) はベイズの定理。分母を P(B) = Σ P(B|Aᵢ)P(Aᵢ) と展開した形が、樹形図の経路の和そのものになっている。
