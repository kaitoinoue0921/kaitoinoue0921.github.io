積18 ∫(x−t)f(t)dt は x を外に出してから微分

数学II ／ 微分積分 ／ 東大での重要度 ★★★★☆

アプリで開く →

要点

∫[a→x](x − t)f(t)dt では、x は積分の上端と被積分関数の両方に入っている。t で積分している間は x は定数なので、まず x∫[a→x]f(t)dt − ∫[a→x]t f(t)dt と分けて x を積分の外に出す。そのあとで積の微分と d/dx∫[a→x]g(t)dt = g(x)（積9）を使うと、d/dx∫[a→x](x − t)f(t)dt = ∫[a→x]f(t)dt となる。もう一度微分すれば f(x) が出る。x = a を代入すると積分が 0 になる条件も忘れずに使う。

こんなときに使う

  • ∫[0→x](x − t)f(t)dt = x⁴ のような、積分の中に x を含む等式
  • ∫[1→x](x − t)f(t)dt = x³ − 3x + a のように、定数 a も決める
  • F(x) = ∫[0→x](x − t)f(t)dt の増減や極値を調べる

手順

  1. 1. 被積分関数の x を外に出す：x∫f(t)dt − ∫t f(t)dt
  2. 2. 積の微分で x について微分し、∫[a→x]f(t)dt を得る
  3. 3. 必要ならもう1回微分して f(x) を出す
  4. 4. 元の式と1回微分した式に x = a を代入し、定数の条件を出す

例題

∫[0→x](x−t)f(t)dt=x⁴ を満たす f(x) を求めよ。
解答
  1. 左辺を x で1回微分すると ∫[0→x] f(t)dt、右辺は 4x³。
  2. もう1回微分して f(x)=12x²。
  3. （検算：∫[0→x](x−t)12t²dt=12(x⁴/3−x⁴/4)=x⁴）
  4. ∴ f(x)=12x²

別解・ほかの見方

  • ∫[0→x](x − t)²f(t)dt は x² − 2xt + t² と展開して x², x を外に出す。3回微分すると 2f(x)
  • ∫[0→1]|x − t|f(t)dt のように上端が定数なら、x は区間を分ける点になる（積17）
  • ∫[a→x](x − t)f(t)dt は f を2回積分したもの（コーシーの公式）なので、F″(x) = f(x)、F(a) = F′(a) = 0

落とし穴

  • x = a を代入して定数を決める条件を落とす
  • x を外に出さずに「f(x) を代入して (x−x)f(x)=0」とするのは誤り。
  • x を外に出さずに微分して、(x − x)f(x) = 0 だけを答える

なぜ大事か

積分の中にある x は t の積分では定数なので、外に出せば上端が x の積分の微分（積9）になる

東大での出方

東大・医学部では、関数方程式の条件として ∫(x − t)f(t)dt が出ることがある。外に出す一行を書けば、あとは微分の計算だけになる。

確認問題

  • ∫[0→x](x − t)f(t)dt = x³ + x² を満たす f(x) を求めよ。（答：f(x) = 6x + 2）

発展

F(x) = ∫[a→x](x − t)f(t)dt は F″ = f、F(a) = F′(a) = 0 を満たすただ1つの関数。テイラーの定理の剰余項の積分表示はこの形をしている。
