【東大型】立体の体積

東大レイヤー ／ 出題テーマ ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

東大の体積は毎年のように出る最大配点帯であり、勝負どころは3つに集約される。座標の取り方、断面の把握、そして場合分けである。特に『2つの立体の共通部分』は東大が繰り返し出す形で、これは断面同士の共通部分を取る2次元の問題に落ちる。立体を3次元のまま想像しようとすると必ず詰まるので、x = t で切った瞬間に2次元の問題になるという手続きを身体に入れておくこと。そして最も落としやすいのが場合分けで、t の範囲によって断面の形が変わる設定を、東大は意図的に作ってくる。

こんなときに使う

  • 『2つの立体の共通部分の体積』→ 断面同士の共通部分を取る
  • 球と円柱、円柱と円柱、球と円錐 → 断面はどちらも円か正方形。半径の大小で場合分けが生じる
  • 回転軸が座標軸でない → 座標を回転させてから通常の回転体に帰着させる
  • 『線分が通過する部分』→ 通過領域の3次元版。断面で通過領域を求める
  • 断面の形が t によって変わりそう → 変わる境目の t を先に求めておく

手順

  1. 1. 対称性が最も活きるように座標を設定する
  2. 2. 切る向きを決める（迷ったら2通り試し、断面が単純なほうを採る）
  3. 3. 平面 x = t で切り、断面を y-z 平面上の2次元の図として描く
  4. 4. 断面の形が変わる境目の t を求め、場合分けを確定させる
  5. 5. 各場合で断面積 S(t) を求める
  6. 6. 区間ごとに積分して足す
  7. 7. 検算：端で S(t) = 0 になるか、既知の立体の体積と比べて妥当か

例題

原点を中心とする半径 1 の球と、z 軸を軸とする半径 1/2 の円柱がある。球の内部にあり、かつ円柱の外部にある部分の立体の体積を求めよ。
解答
  1. z 軸に垂直な平面 z = t で切る。断面は2次元の図形になる。
  3. 【断面を求める】
  4. 球 x² + y² + z² ≦ 1 を z = t で切ると、x² + y² ≦ 1 − t²。
  5. 　→ 半径 √(1 − t²) の円（|t| ≦ 1 のとき）
  6. 円柱 x² + y² ≦ 1/4 を z = t で切ると、x² + y² ≦ 1/4。
  7. 　→ 半径 1/2 の円（t によらず一定）
  9. 求める立体の断面は「球の断面から円柱の断面を除いた部分」＝ 円環。
  11. 【場合分け】
  12. 球の断面の半径 √(1 − t²) と、円柱の半径 1/2 の大小で形が変わる。
  13. 　√(1 − t²) ≧ 1/2 　⇔ 　1 − t² ≧ 1/4 　⇔ 　t² ≦ 3/4 　⇔ 　|t| ≦ √3/2
  15. (i) |t| ≦ √3/2 のとき：円環になり、S(t) = π(1 − t²) − π/4
  16. (ii) √3/2 < |t| ≦ 1 のとき：球の断面が円柱の中に完全に入るので、除いた残りは空。S(t) = 0
  18. 【積分する】
  19. V = ∫[−√3/2 → √3/2] {π(1 − t²) − π/4} dt = π∫[−√3/2 → √3/2] (3/4 − t²) dt
  21. 偶関数なので 2 倍して 0 から積分できる。
  22. = 2π [ (3/4)t − t³/3 ]₀^(√3/2)
  23. = 2π { (3/4)(√3/2) − (1/3)(3√3/8) }
  24. = 2π { 3√3/8 − √3/8 }
  25. = 2π · (2√3/8) = 2π · √3/4
  27. ∴ V = (√3/2)π
  29. 検算：球全体の体積は 4π/3 ≒ 4.19。求めた値は (√3/2)π ≒ 2.72。
  30. 円柱に抜かれた分が約 1.47 で、球の3分の1程度。半径 1/2 の円柱が貫いていることを考えると妥当 ○
  32. 【落とし穴】(ii) の場合分けを忘れて積分区間を [−1, 1] のままにすると、
  33. S(t) が負になる領域まで足してしまい、答えが小さくなる。

別解・ほかの見方

  • 切る向きを変える（この問題では z 軸に垂直が最善だが、常にそうとは限らない）
  • 円柱の側から考え、球から円柱内部の体積を引く（バームクーヘン型の分割）
  • カヴァリエリの原理：断面積が等しい立体は体積も等しい。検算に使える
  • 回転体として処理できる部分と、できない部分を分ける
  • 斜めの回転軸は、複素数平面の回転を使って座標変換してから処理する

落とし穴

  • 断面の形が変わる場合分けを落とす（東大が最も狙ってくる箇所）
  • 立体を3次元で把握しようとして手が止まる
  • 断面が円だと決めつける（2円柱の共通部分の断面は正方形）
  • 積分区間を、立体が実際に存在する範囲ではなく、片方の立体の範囲で取る
  • 座標設定が対称性を無視しており、式が汚いまま突き進む
  • 立体を3次元で把握しようとして詰まる（断面の2次元問題に落とす）

なぜ大事か

毎年のように出る最大配点帯。切断面をどの向きで取るかの一択で難易度が変わる

東大での出方

東大理系で毎年のように出題される最重要テーマ。共通部分・通過領域・斜回転が三大パターンで、いずれも『断面を2次元で捉える』一点に帰着する。配点が大きいので、ここを確実に取れるかどうかが理三の合否に直結する。

確認問題

  • 2つの円柱 x² + y² ≦ 1 と x² + z² ≦ 1 の共通部分の体積を求めよ（断面が正方形になる）
  • 上の問題で、断面が正方形になる理由を x = t の代入から説明せよ
  • 半径 1 の球を、中心から距離 1/2 の平面で切ったときの小さい方の体積を求めよ

発展

線分や図形が動いて通過する部分の体積。断面を取ったうえで、その断面内での通過領域を求める必要があり、2次元の通過領域の技術と体積が合流する。東大の最難問はこの形で出る。

前提になるノード

  • 非回転体の体積（断面積を積分する）
  • 垂線の足・点と平面の距離・射影
  • 対称性を利用して場合を減らす
