⑲ 三角関数置換型 a(n+1)=2a(n)²−1

数学B ／ 漸化式 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

2cos²θ − 1 = cos 2θ なので、a(n) = cos θ(n) と置けば a(n+1) = 2a(n)² − 1 は θ(n+1) = 2θ(n)、つまり θ(n) = 2ⁿ⁻¹·θ(1) になる。非線形の漸化式が、角度の世界では単なる等比数列。半角 a(n+1) = √((1 + a(n))/2) なら θ が 1/2 ずつ、3倍角 4a³ − 3a なら3倍ずつ。どの公式の形かを見抜くのが全て。

こんなときに使う

  • 2a² − 1、4a³ − 3a、√((1 + a)/2)、2a/(1 − a²) などの形
  • |a(1)| ≦ 1 が条件にある → cos か sin で置ける
  • |a(1)| > 1 なら a = (t + 1/t)/2 と置く（双曲線版）
  • 2a/(1 − a²) → tan の倍角

手順

  1. 1. 漸化式がどの三角関数の公式（倍角・半角・3倍角・tan の倍角）と同じ形か見抜く
  2. 2. a(1) = cos θ（0 ≦ θ ≦ π）と θ を1つに決める
  3. 3. 帰納法で a(n) = cos(2ⁿ⁻¹θ) を示す（半角なら範囲の確認が必要）
  4. 4. 具体的な値・周期性・極限を答える

例題

a(1) = 1/2、a(n+1) = 2a(n)² − 1 のとき a(n) を求めよ。
解答
  1. a(1) = 1/2 = cos(π/3)
  2. a(n) = cos θ(n) とすると a(n+1) = 2cos²θ(n) − 1 = cos 2θ(n)
  3. よって a(n) = cos(2ⁿ⁻¹·π/3) と帰納法で示せる
  4. 2ⁿ⁻¹π/3 は n≧2 で 2π/3, 4π/3, 8π/3, … で、cos の値は常に −1/2
  5. ∴ a(1) = 1/2、a(n) = −1/2（n≧2）
  6. 検算：a(2) = 2·(1/4) − 1 = −1/2 ○、a(3) = 2·(1/4) − 1 = −1/2 ○

別解・ほかの見方

  • 半角型：a(1) = 0、a(n+1) = √((1 + a(n))/2) なら a(n) = cos(π/2ⁿ)。極限は1、さらに 4ⁿ(1 − a(n)) の極限なども問える
  • |a(1)| > 1：a(1) = (t + 1/t)/2 と置くと a(n) = (t^(2ⁿ⁻¹) + t^(−2ⁿ⁻¹))/2
  • tan 型：a(n+1) = 2a(n)/(1 − a(n)²) なら a(n) = tan(2ⁿ⁻¹θ)

落とし穴

  • |a(1)| > 1 なのに cos で置く
  • θ の範囲を決めずに置き、半角で符号（√ の正負）を取り違える
  • 『cos で置けば解ける』を証明せずに一般項を書く（帰納法で示す）
  • |a(1)| ≦ 1 でないと cos で置けない／θ の範囲を決めない

なぜ大事か

倍角・半角公式と同じ形の漸化式は、cos θ と置くと角度が等比（2倍ずつ）になる

東大での出方

東大は三角関数と漸化式の融合を好む。極限や整数性（cos の値が有理数になる条件）と絡めて出る。

確認問題

  • a(1) = 0、a(n+1) = √((1 + a(n))/2) の一般項を求めよ（答：cos(π/2ⁿ)）
  • a(1) = cos(2π/7)、a(n+1) = 2a(n)² − 1 のとき a(4) = a(1) となることを示せ（16π/7 = 2π + 2π/7）

発展

2x² − 1 はチェビシェフ多項式 T₂、4x³ − 3x は T₃。T_m(T_n(x)) = T_mn(x) という性質が、この型の漸化式がきれいに解ける理由。
