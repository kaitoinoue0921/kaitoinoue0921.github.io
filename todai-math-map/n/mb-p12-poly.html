⑫ nの多項式型 a(n+1)=p·a(n)+(An+B)

数学B ／ 漸化式 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

⑩で定数 α を引いたのと同じく、今度は『nの1次式 αn + β』を引いて等比にする。a(n+1) − {α(n+1) + β} = p{a(n) − (αn + β)} が元の式と一致するように α, β を決める。もう1つの道は、n をずらして引く（階差を取る）ことで An + B の n を消し、⑩の形にする方法。

こんなときに使う

  • a(n+1) = p·a(n) + (nの1次式)
  • p = 1 なら単なる階差型（③）なので、この型ではない
  • 非同次項が n² なら αn² + βn + γ を引く

手順

  1. 1. a(n+1) − {α(n+1) + β} = p{a(n) − (αn + β)} と置く
  2. 2. 展開して a(n+1) = p·a(n) + (p−1)αn + (p−1)β + α の形にし、元の式と係数比較する
  3. 3. α, β を決め、{a(n) − (αn + β)} が公比 p の等比数列であることを使う
  4. 4. a(n) を求め、n=2, 3 で検算する

例題

a(1) = 1、a(n+1) = 2a(n) + n の一般項を求めよ。
解答
  1. a(n+1) + α(n+1) + β = 2{a(n) + αn + β} と変形できるとする
  2. 展開すると a(n+1) = 2a(n) + αn + (β − α)
  3. 元の式と比べて α = 1、β − α = 0 より β = 1
  4. {a(n) + n + 1} は初項 3、公比 2 の等比数列なので a(n) + n + 1 = 3·2ⁿ⁻¹
  5. ∴ a(n) = 3·2ⁿ⁻¹ − n − 1
  6. 検算：a(2) = 2 + 1 = 3、6 − 3 = 3 ○。a(3) = 6 + 2 = 8、12 − 4 = 8 ○

別解・ほかの見方

  • 階差を取る：a(n+2) = 2a(n+1) + n + 1 から元の式を引くと b(n) = a(n+1) − a(n) について b(n+1) = 2b(n) + 1（⑩）。最後に③で戻す
  • 答えを C·2ⁿ + αn + β と決め打ちして係数を決める

落とし穴

  • a(n+1) 側に α(n+1) + β ではなく αn + β を書く（最頻出）
  • 符号の向き：a(n) + αn + β と置くか a(n) − (αn+β) と置くかで α の符号が変わることを混乱する
  • 階差を取る方法で、最後に③で戻すのを忘れて b(n) を答える
  • αn+β を引いた式の n+1 側を α(n+1)+β にし忘れる

なぜ大事か

非同次項がnの式のとき。a(n) − (αn+β) が等比になるよう係数比較するか、階差を取って⑩に落とす

東大での出方

単独では典型問題レベル。期待値や回数を数える漸化式で、非同次項に n が残ったときに使う。

確認問題

  • a(1) = 2、a(n+1) = 3a(n) − 2n + 1 の一般項を求めよ（答：a(n) = 3ⁿ⁻¹ + n）
  • 上の例題を階差を取る方法でも解け

発展

なぜ αn + β で足りるのか：等比部分を除いた『特殊解』は、非同次項と同じ次数の多項式で取れる（p ≠ 1 のとき）。p = 1 なら次数が1つ上がる（③と同じ）。
