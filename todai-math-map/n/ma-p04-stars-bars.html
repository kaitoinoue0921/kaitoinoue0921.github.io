確4 仕切り（重複組合せ）

数学A ／ 場合の数 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

x + y + z = n の非負整数解は、n 個の○と2本の仕切り｜を一列に並べる並べ方と1対1に対応する（仕切りで区切られた○の個数が x, y, z）。だから n+2C2 通り。1以上という条件があれば、先に1個ずつ配って x' = x − 1 などと置き換え、0以上の問題に戻してから数える。

こんなときに使う

  • x + y + z = n を満たす整数の組の個数
  • 区別しない玉（同じ種類の品物）を区別できる箱・人に分ける
  • 重複を許して k 個選ぶ組合せ（例：3種類の果物から合計10個買う）

手順

  1. 1. 変数の個数 k（箱の数）と合計 n（玉の数）を確認する
  2. 2. 下限があるなら先に配って、全部 0 以上の問題にする（x ≧ 1 なら x' = x − 1）
  3. 3. 0 以上の解の個数は n+k−1Ck−1（○ n 個と仕切り k−1 本の並べ方）
  4. 4. 上限がある場合は、上限を超えるものを余事象として引く（確2・確3）

例題

x + y + z = 10 を満たす (1) 0 以上の整数の組、(2) 正の整数の組、の個数を求めよ。
解答
  1. (1) ○10個と仕切り2本の並べ方なので 12C2 = 66 通り
  2. (2) x = x' + 1 などと置くと x' + y' + z' = 7（x', y', z' ≧ 0）
  3. ○7個と仕切り2本で 9C2 = 36 通り
  4. 別解：○10個の間の9か所から仕切りを入れる2か所を選ぶと考えても 9C2 = 36
  5. 検算：x + y + z = 3 の正の整数解は (1,1,1) だけで、2C2 = 1 と一致

別解・ほかの見方

  • 不等式 x + y + z ≦ 10 は、余り w を足して x + y + z + w = 10 にする（13C3 = 286）
  • x ≦ 5 のような上限は、x ≧ 6 の場合を数えて引く
  • サイコロ3個の目の組（順番を考えない）も重複組合せ：8C3 = 56 種類

落とし穴

  • 正の整数解と非負整数解を取り違える
  • 仕切りの本数を箱の数と同じにする（正しくは箱の数 − 1）
  • 区別できる玉なのに重複組合せを使う（区別できるなら各玉が k 通りで kⁿ）
  • 正の整数解なのに 0 を許す式（n+2C2）で数える

なぜ大事か

x+y+z=n の解の個数も、区別しない玉を箱に入れる方法も、○と｜の並べ方1つで数えられる

東大での出方

東大では単独で出ることは少ないが、確率の分子・分母を数える場面で使う。上限付きは確3 の包除と組み合わせて出る。

確認問題

  • 同じ種類のアメ7個を、3人に配る方法は何通りか（もらわない人がいてもよい）（答：36通り）
  • x + y + z ≦ 10 を満たす 0 以上の整数の組の個数を求めよ（答：286通り）
