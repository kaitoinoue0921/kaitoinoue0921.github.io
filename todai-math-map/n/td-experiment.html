実験する手癖（n=1,2,3 を書き出す）

要点

東大の問題は、方針が見えない状態から始まる。そして手を動かして規則を見つける以外に入口がない問題が、毎年のように出る。10分考えて紙が白いままなら、それは考えているのではなく実験を飛ばしている。小さい場合を書き出すことは泥臭い手段ではなく、正規の第一手である。実際、誘導の (1) は多くの場合この実験そのもので、出題者は『まず手を動かせ』と言っている。

こんなときに使う

  • n を含む一般の主張が問われている → n = 1, 2, 3 を実際に書く
  • 設定が複雑で全体像が見えない → 最小のケース（点2個、サイコロ1回、n=1）を作る
  • 漸化式が型に当てはまらない → 数列を4〜5項書き出す
  • 『〜であることを示せ』で構造が見えない → 具体例で構造を掴む
  • 図形問題 → 正確な図を描く。これも実験のうち
  • 誘導の (1) が『n = 1 のとき求めよ』→ そこに方針が埋まっている

手順

  1. 1. パラメータを最小にする（n = 1、点を2個、操作を1回）
  2. 2. 頭の中でやらず、実際に紙に書き出す
  3. 3. n = 2, 3 と増やし、何がどう変化するかを見る
  4. 4. 規則を予想する（数列なら一般項、確率なら状態の個数）
  5. 5. 予想を数学的帰納法か直接証明で示す
  6. 6. 予想が立たなければ n = 4, 5 まで伸ばす。たいていそこで見える

例題

a₁ = 1、a_(n+1) = a_n / (1 + a_n) で定まる数列 {a_n} の一般項を求めよ。
解答
  1. この漸化式は等比型でも特性方程式型でもなく、既知の型に当てはまらない。
  2. そこで実際に書き出す。
  4. a₁ = 1
  5. a₂ = 1 / (1 + 1) = 1/2
  6. a₃ = (1/2) / (1 + 1/2) = (1/2) / (3/2) = 1/3
  7. a₄ = (1/3) / (1 + 1/3) = (1/3) / (4/3) = 1/4
  9. 【予想】a_n = 1/n
  11. 【数学的帰納法で証明】
  12. n = 1 のとき a₁ = 1 = 1/1 で成立。
  13. n = k で a_k = 1/k と仮定すると
  14. 　a_(k+1) = (1/k) / (1 + 1/k) = (1/k) / ((k+1)/k) = 1/(k+1)
  15. よって n = k+1 でも成立。ゆえにすべての自然数 n で a_n = 1/n。
  17. 【別解：逆数を取る】
  18. 漸化式の両辺の逆数を取ると
  19. 　1/a_(n+1) = (1 + a_n)/a_n = 1/a_n + 1
  20. b_n = 1/a_n とおくと b_(n+1) = b_n + 1、b₁ = 1。つまり公差1の等差数列で b_n = n。
  21. ∴ a_n = 1/n
  23. 【要点】別解のほうが鮮やかだが、逆数を取るという発想は実験で 1, 1/2, 1/3, 1/4 という並びを
  24. 見たあとなら自然に出てくる。実験は答えを予想するだけでなく、方針そのものを教えてくれる。

別解・ほかの見方

  • 実験 → 予想 → 帰納法（最も汎用的な流れ）
  • 実験で置き換えのヒントを得る（逆数、対数、差を取る）
  • 確率なら n = 1, 2 の場合を樹形図で書き、状態の分類を発見する
  • 整数なら小さい値を代入し、mod をいくつに取るかの当たりをつける
  • 図形なら特殊な位置（正三角形、直角、中点）で試して予想を立てる

落とし穴

  • 実験を飛ばして一般の議論から入り、手が止まる（この項目の存在理由そのもの）
  • 頭の中だけで計算して、間違ったまま予想を立てる
  • n = 1, 2 だけで打ち切り、規則を見誤る（n = 3, 4 まで伸ばす）
  • 予想を書いただけで証明を書かない（実験は証明ではない）
  • 実験の計算ミスに気づかず、存在しない規則を追いかける
  • 考え込んで10分間紙が白いまま

なぜ大事か

東大の問題は方針が見えない状態から始まる。手を動かして規則を見つける以外に入口がない問題が毎年ある

東大での出方

東大は誘導の (1) を実験に充てることが多い。『n = 1 のときを求めよ』『具体的に書き出せ』という小問は、点を取らせるためではなく、(2) 以降の方針を発見させるために置かれている。逆に誘導がない年は、自分で実験を始められるかどうかが分かれ目になる。

確認問題

  • a₁ = 2、a_(n+1) = 2a_n/(a_n + 1) の一般項を、実験して予想し帰納法で示せ
  • 1 から n までの整数の3乗の和を n = 1, 2, 3, 4 で計算し、規則を予想せよ
  • サイコロを n 回投げて出た目の積が偶数になる確率を、n = 1, 2 で数えてから一般化せよ

発展

実験しても規則が見えない場合。見方を変える（差を取る、比を取る、階差の階差を見る、素因数分解する）と現れることがある。この『見方の引き出し』は経験の蓄積そのもの。
