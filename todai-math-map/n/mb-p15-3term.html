⑮ 隣接3項間 a(n+2)+p·a(n+1)+q·a(n)=0

数学B ／ 漸化式 ／ 東大での重要度 ★★★★☆

要点

x² + px + q = 0 の解を α, β とすると、a(n+2) − α·a(n+1) = β{a(n+1) − α·a(n)} と書ける（解と係数の関係）。つまり『a(n+1) − α·a(n)』は公比 β の等比数列で、α と β を入れ替えたものも成り立つ。2本の式を引けば a(n+1) が消えて a(n) が出る。重解（α = β）のときは1本しか作れないので、a(n+1) − α·a(n) = c·αⁿ⁻¹ を⑪（共鳴型）で解く。

こんなときに使う

  • a(n+2) が a(n+1) と a(n) の1次式で書かれている
  • フィボナッチ型の数え上げ（タイルの敷き詰め、階段の上り方）
  • 連立漸化式（⑯）を1本にまとめた結果

手順

  1. 1. 特性方程式 x² + px + q = 0 を解き α, β を得る
  2. 2. a(n+1) − α·a(n) = (a(2) − α·a(1))·βⁿ⁻¹ と a(n+1) − β·a(n) = (a(2) − β·a(1))·αⁿ⁻¹ を作る
  3. 3. α ≠ β なら2式を引いて a(n+1) を消し、(β − α)a(n) = … から a(n) を出す
  4. 4. α = β なら1本の式を αⁿ⁺¹ で割って等差数列（⑪の共鳴型）として解く
  5. 5. a(1), a(2), a(3) で検算する

例題

a(1) = 1、a(2) = 4、a(n+2) = 5a(n+1) − 6a(n) の一般項を求めよ。
解答
  1. x² − 5x + 6 = 0 より x = 2, 3
  2. a(n+1) − 2a(n) = (4 − 2)·3ⁿ⁻¹ = 2·3ⁿ⁻¹
  3. a(n+1) − 3a(n) = (4 − 3)·2ⁿ⁻¹ = 2ⁿ⁻¹
  4. 上から下を引くと a(n) = 2·3ⁿ⁻¹ − 2ⁿ⁻¹
  5. 検算：a(3) = 20 − 6 = 14、2·9 − 4 = 14 ○

別解・ほかの見方

  • 重解：a(n+2) = 4a(n+1) − 4a(n) なら a(n+1) − 2a(n) = (a(2) − 2a(1))·2ⁿ⁻¹ を 2ⁿ⁺¹ で割って等差数列にする。答えは (An + B)·2ⁿ の形
  • 答えを A·αⁿ + B·βⁿ と決め打ちし、a(1), a(2) で A, B を決める（記述では根拠が必要）
  • α, β が無理数（フィボナッチ）でも同じ手順。整数性を問われたら漸化式のまま帰納法で示す方が楽

落とし穴

  • 等比数列の初項を a(2) − α·a(1) ではなく a(1) にする
  • 引き算で (β − α) で割るのを忘れる
  • 重解で2本作れないことに気づかず止まる
  • 特性方程式を x² + px + q のつもりで x² − px − q の符号で立てる
  • 重解のときに同じやり方で2本作ろうとして詰まる／初項を a(2) − α·a(1) にし忘れる

なぜ大事か

特性方程式の2解 α, β で2本の等比型を作り、連立して a(n) を出す。重解は⑪の共鳴型になる

東大での出方

数え上げ（タイル、色塗り、文字列）を漸化式にすると3項間になることが多い。東大は立式させる側を問うので、ここは解けて当然の部分。

確認問題

  • a(1) = 1、a(2) = 1、a(n+2) = a(n+1) + 2a(n) の一般項を求めよ（答：{2ⁿ − (−1)ⁿ}/3）
  • a(1) = 1、a(2) = 4、a(n+2) = 4a(n+1) − 4a(n) の一般項を求めよ（答：a(n) = n·2ⁿ⁻¹）

発展

なぜ αⁿ, βⁿ が解になるのか：a(n) = xⁿ を代入すると x² + px + q = 0 が出る。線形漸化式の解は、この基本解の重ね合わせ（線形代数の固有ベクトル）。

  • ⑪ 指数型 a(n+1)=p·a(n)+rⁿ（rⁿ⁺¹で割る）
