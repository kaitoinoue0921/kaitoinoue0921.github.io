微18 微分可能性は左右の微分係数の一致

数学III ／ 微分法 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

f が x = a で微分可能とは、lim[h→0]{f(a + h) − f(a)}/h が有限な値に収束すること。これは h → +0 と h → −0 の極限（右微分係数・左微分係数）がともに存在して一致することと同じ。場合分けで定義された関数の継ぎ目や、|x|・√ を含む関数では、公式で微分した式に代入するのではなく、この定義で左右を別々に計算する。微分可能なら連続なので、継ぎ目では『値がつながる（連続）』と『傾きがつながる』の2条件が出る。

こんなときに使う

  • 『x = 0 で微分可能か調べよ』
  • x ≦ 1 と x > 1 で式が違う関数が『x = 1 で微分可能となる a, b』
  • |x|、x|x|、x² sin(1/x) のような関数の x = 0

手順

  1. 1. 継ぎ目 x = a で連続か（左右の極限と f(a) が一致するか）を確かめる
  2. 2. 右微分係数 lim[h→+0]{f(a + h) − f(a)}/h と左微分係数 lim[h→−0]{f(a + h) − f(a)}/h を定義で計算する
  3. 3. 両方が一致すれば微分可能で、その値が f′(a)
  4. 4. 係数を決める問題なら、連続の式と左右一致の式を連立する

例題

f(x) = x²（x ≦ 1）、f(x) = ax + b（x > 1）が x = 1 で微分可能となる a, b を求めよ。
解答
  1. 微分可能なら連続なので、x → 1 + 0 の極限 a + b が f(1) = 1 と一致する：a + b = 1。
  2. 左微分係数：lim[h→−0]{(1 + h)² − 1}/h = lim[h→−0](2 + h) = 2。
  3. 右微分係数：lim[h→+0]{a(1 + h) + b − 1}/h = lim[h→+0](a + b − 1 + ah)/h = a（a + b = 1 を使う）。
  4. 左右が一致するので a = 2、b = −1。
  5. ∴ a = 2, b = −1

別解・ほかの見方

  • |x| は x = 0 で右微分係数 1、左微分係数 −1 なので微分可能でない（連続ではある）
  • x|x| は x = 0 で微分可能で f′(0) = 0
  • x² sin(1/x)（x ≠ 0）、0（x = 0）は x = 0 で微分可能（f′(0) = 0）だが、f′ は x = 0 で連続でない

落とし穴

  • 連続でない継ぎ目で、両側の導関数の式の極限が一致するだけで微分可能とする
  • 連続の条件を書かずに、傾きの一致だけで係数を決める
  • 連続の条件を書かずに、両側の導関数の式が一致することだけで微分可能とする

なぜ大事か

継ぎ目や絶対値のある点では、公式ではなく定義で右と左の微分係数を別々に計算する

東大での出方

東大では関数方程式や、場合分けされた関数のなめらかな接続で出る。『微分可能 ⇒ 連続』を一行使って式を1本増やすのが定番。

確認問題

  • 定義に従って (√x)′ を求めよ（x>0）。（答：1/(2√x)）
  • f(x) が x=a で微分可能のとき、lim[h→0](f(a+3h)−f(a−h))/h を f′(a) で表せ。（答：4f′(a)）
  • f(x)=x|x| は x=0 で微分可能か。（答：可能。(f(h)−f(0))/h=(h|h|)/h=|h|→0 より f′(0)=0）

発展

至る所で連続なのに、どこでも微分可能でない関数（ワイエルシュトラス関数）もある。連続はグラフが切れないこと、微分可能は折れないことで、後者のほうが強い。
