⑩ 特性方程式型 a(n+1)=p·a(n)+q

数学B ／ 漸化式 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

a(n+1) = p·a(n) + q は、全項から定数 α を引いて b(n) = a(n) − α とすれば b(n+1) = p·b(n) の等比数列になる。α は『ずっとその値なら変化しない値（不動点）』で、α = pα + q を解けば出る。特性方程式は『どの定数を引けば等比になるか』を探す計算であって、答えそのものではない。

こんなときに使う

  • a(n+1) = p·a(n) + q（p ≠ 1、q ≠ 0）の形
  • 確率漸化式で p(n+1) = (1/2)(1 − p(n)) のような1本の式になった
  • ⑪⑬⑭などを変形した結果、この形になった

手順

  1. 1. α = pα + q を解く（α = q/(1−p)）
  2. 2. 元の式から α = pα + q を辺々引く：a(n+1) − α = p{a(n) − α}
  3. 3. {a(n) − α} は初項 a(1) − α、公比 p の等比数列
  4. 4. a(n) = α + (a(1) − α)pⁿ⁻¹
  5. 5. n=2 で検算する

例題

a(1) = 1、a(n+1) = 3a(n) + 2 の一般項を求めよ。
解答
  1. α = 3α + 2 より α = −1
  2. a(n+1) + 1 = 3{a(n) + 1}
  3. {a(n) + 1} は初項 2、公比 3 の等比数列なので a(n) + 1 = 2·3ⁿ⁻¹
  4. ∴ a(n) = 2·3ⁿ⁻¹ − 1
  5. 検算：a(2) = 3 + 2 = 5、2·3 − 1 = 5 ○

別解・ほかの見方

  • 階差を取る：a(n+2) − a(n+1) = p{a(n+1) − a(n)} で階差が等比、③で戻す（遠回りだが特性方程式を忘れても解ける）
  • |p| < 1 なら a(n) → α に収束（数III）。不動点が極限になる
  • p = 1 なら等差数列（特性方程式は解なし）

落とし穴

  • α を求めた時点で a(n) = α と答える
  • 初項を a(1) − α ではなく a(1) にする
  • 指数を pⁿ と pⁿ⁻¹ で取り違える（a(0) から始まる問題に注意）
  • α を一般項と取り違える／a(1) − α の初項を間違える

なぜ大事か

漸化式の最重要パターン。⑪⑫⑬⑭⑰と確率漸化式は最後にほぼ全部これに帰着する

東大での出方

確率漸化式の大部分がこの形に落ちる。東大では解けて当然で、ここで落とすと致命傷。

確認問題

  • a(1) = 2、a(n+1) = (1/2)a(n) + 3 の一般項と極限を求めよ（答：a(n) = 6 − 4(1/2)ⁿ⁻¹、極限6）
  • a(1) = 0、a(n+1) = −2a(n) + 3 の一般項を求めよ（答：1 − (−2)ⁿ⁻¹）

発展

α は『関数 y = px + q と y = x の交点』。グラフで a(n) が α に近づく・離れる様子を描く（くもの巣図）と、p の符号と大きさで振る舞いが分かる。
