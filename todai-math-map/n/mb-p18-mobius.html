⑱ 一次分数変換型 a(n+1)=(p·a(n)+q)/(r·a(n)+s)

数学B ／ 漸化式 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

分数型の不動点 x = (px + q)/(rx + s) の解を α, β とすると、a(n+1) − α と a(n+1) − β はどちらも (a(n) − α) や (a(n) − β) の定数倍を (r·a(n) + s) で割った形になる。比を取れば分母が消えて (a(n+1) − α)/(a(n+1) − β) = k·(a(n) − α)/(a(n) − β) の等比数列になる。重解なら 1/(a(n) − α) が等差数列。⑬は不動点が 0 の場合にあたる。

こんなときに使う

  • 分子にも分母にも a(n) の1次式がある分数型
  • 関数 f(x) = (px + q)/(rx + s) を n 回合成する問題
  • 連分数・ニュートン法の反復（√2 の近似など）

手順

  1. 1. 不動点 x = (px + q)/(rx + s) を解き α, β を得る
  2. 2. a(n+1) − α、a(n+1) − β をそれぞれ通分して計算する
  3. 3. 比を取り、b(n) = (a(n) − α)/(a(n) − β) が等比数列になることを示す
  4. 4. 重解なら b(n) = 1/(a(n) − α) が等差数列になる
  5. 5. b(n) を求めて a(n) について解く。a(n) ≠ β（分母 ≠ 0）は帰納法で示しておく

例題

a(1) = 2、a(n+1) = (4a(n) − 3)/a(n) の一般項を求めよ。
解答
  1. 不動点：x = (4x − 3)/x より x² − 4x + 3 = 0、x = 1, 3
  2. a(n+1) − 1 = 3(a(n) − 1)/a(n)、a(n+1) − 3 = (a(n) − 3)/a(n)
  3. （a(1) = 2 で、1 < a(n) < 3 なら a(n+1) = 4 − 3/a(n) も 1 < a(n+1) < 3。よって a(n) ≠ 0, 3）
  4. 比を取ると b(n) = (a(n) − 1)/(a(n) − 3) は公比 3、初項 (2 − 1)/(2 − 3) = −1 の等比数列：b(n) = −3ⁿ⁻¹
  5. a(n) − 1 = b(n)(a(n) − 3) より a(n) = (1 − 3b(n))/(1 − b(n)) = (3ⁿ + 1)/(3ⁿ⁻¹ + 1)
  6. 検算：a(2) = (8 − 3)/2 = 5/2、(9 + 1)/(3 + 1) = 5/2 ○。n→∞ で 3 に近づく

別解・ほかの見方

  • 重解の例：a(n+1) = (3a(n) − 1)/(a(n) + 1) は不動点 x = 1（重解）。1/(a(n) − 1) が公差 1/2 の等差数列
  • 行列 [[p, q], [r, s]] の n 乗と対応する（一次分数変換の合成＝行列の積）
  • a(n+1) = (a(n)² + 2)/(2a(n))（ニュートン法、√2 の近似）は2次分数だが、(a − √2)/(a + √2) が2乗ずつ変化する同じ発想で解ける

落とし穴

  • a(n) − α の計算で通分を誤る
  • 比 b(n) の初項を a(1) にしてしまう
  • a(n) ≠ β の確認を省く（b(n) が定義できない）
  • 重解なのに比を取ろうとして 0/0 になる
  • a(n) ≠ α, β や分母 ≠ 0 の確認／重解なのに比を取ろうとする

なぜ大事か

特性方程式（不動点）の2解 α, β で (a−α)/(a−β) が等比になる。重解なら 1/(a−α) が等差

東大での出方

関数の反復合成として出題され、極限まで問われることが多い。不動点の安定性（どちらに収束するか）の理解が問われる。

確認問題

  • a(1) = 2、a(n+1) = (3a(n) − 1)/(a(n) + 1) の一般項を求めよ（答：a(n) = (n + 3)/(n + 1)）
  • 例題で、a(1) を 1 と 3 以外のどんな正の値にしても a(n) → 3 となることを b(n) の式から説明せよ

発展

(a − α)/(a − β) が等比になる理由は、一次分数変換が α を 0 に、β を ∞ に移す座標で見ると単なる拡大 x → kx になるから（共役）。
