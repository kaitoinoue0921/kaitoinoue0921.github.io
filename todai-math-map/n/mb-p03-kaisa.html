③ 階差数列 a(n+1)−a(n)=f(n)

数学B ／ 数列 ／ 東大での重要度 ★★★☆☆

アプリで開く →

要点

階差数列は『差が分かっている数列は、差を足し上げれば戻せる』というだけの話。a(n) = a(1) + Σ[k=1〜n−1] f(k) の上端が n−1 になるのは、1番目からn番目まで行くのに差を n−1 回足すから。式の形ではなく、何回足したかで覚える。

こんなときに使う

  • a(n+1) − a(n) が n だけの式で与えられている → そのまま階差型
  • 数列を書き並べて、隣の差を取ると規則が見える → 階差数列を作る
  • 他の型の漸化式を割ったり置換したりした結果、b(n+1) = b(n) + (nの式) になった → ここに合流

手順

  1. 1. b(n) = a(n+1) − a(n) を求める（与えられていれば不要）
  2. 2. n≧2 のとき a(n) = a(1) + Σ[k=1〜n−1] b(k) を計算する
  3. 3. 得られた式に n=1 を代入し、a(1) と一致するか確認する
  4. 4. 一致すれば『n=1 でも成り立つ』と書いて1本にまとめる。一致しなければ分けて答える

例題

a(1) = 2、a(n+1) − a(n) = 2n + 1 で定まる数列の一般項を求めよ。
解答
  1. n≧2 のとき a(n) = 2 + Σ[k=1〜n−1] (2k + 1)
  2. Σ[k=1〜n−1] 2k = (n−1)n、Σ[k=1〜n−1] 1 = n−1
  3. よって a(n) = 2 + n(n−1) + (n−1) = n² + 1
  4. n=1 のとき 1² + 1 = 2 = a(1) なので n=1 でも成り立つ
  5. ∴ a(n) = n² + 1
  6. 検算：a(2) = 2 + 3 = 5 = 2² + 1 ○

別解・ほかの見方

  • 階差の階差（第2階差）が等差・定数なら、2回この操作をする。元の数列は n の3次式以下になる
  • a(n) が n の2次式と分かっているなら、a(n) = An² + Bn + C と置いて3項で係数を決めても同じ答えになる

落とし穴

  • Σの上端を n にしてしまう（1つずれる）
  • n≧2 の断りを書かない、n=1 の確認をしない
  • Σ[k=1〜n−1] k を n(n+1)/2 のまま使う（n を n−1 に置き換え忘れ）
  • Σの上端を n−1 にし忘れる／n≧2 で出した式を n=1 で確かめない

なぜ大事か

隣同士の差がnの式なら、和を取れば一般項になる。漸化式の多くは最後にこの形へ落ちる

東大での出方

単独で出ることはまずないが、⑪⑫や確率漸化式の最後の一手として毎年のように使う。ここで1つずれると全部失う。

確認問題

  • a(1)=1、a(n+1) − a(n) = 3ⁿ の一般項を求めよ（答：(3ⁿ − 1)/2）
  • 1, 2, 5, 10, 17, … の一般項を、階差を取って求めよ

発展

数列を書き並べて階差を2回取ると定数になる、というのは『一般項が2次式』と同値。この見方は数え上げの答えを予想するときにも使える。
