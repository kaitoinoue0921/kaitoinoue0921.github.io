⑤ Σの基本公式（k, k², k³, 等比）

数学B ／ 数列 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

Σk = n(n+1)/2、Σk² = n(n+1)(2n+1)/6、Σk³ = {n(n+1)/2}²、Σc = nc、Σr^(k−1) = (rⁿ − 1)/(r − 1)（r≠1）。これらは全部『(k+1)の何乗 − kの何乗』を足すと隣同士が消える、という同じ仕組みで出てくる。和の計算は『展開してこの部品に分解する』か『差の形にして消す（⑦⑧⑨）』かの二択。

こんなときに使う

  • Σの中身が k の多項式 → 展開して部品に分解
  • k(k+1)、k(k+1)(k+2) のような連続整数の積 → 展開せず差の形 k(k+1)(k+2) − (k−1)k(k+1) = 3k(k+1) を使うと速い
  • 等比の和で公比が文字 → r = 1 と r ≠ 1 で場合分け

手順

  1. 1. Σの中身を k の多項式に展開する
  2. 2. 定数・k・k²・k³ の項ごとに公式を当てる
  3. 3. 共通因数 n(n+1) などでくくってから整理する（展開しきると因数分解に戻すのが大変）
  4. 4. n=1 または n=2 を代入して、元の和と一致するか確かめる

例題

Σ[k=1〜n] k(k+1) を求めよ。
解答
  1. k(k+1) = k² + k なので、和は n(n+1)(2n+1)/6 + n(n+1)/2
  2. n(n+1)/6 でくくると n(n+1)/6 · {(2n+1) + 3} = n(n+1)(2n+4)/6
  3. ∴ n(n+1)(n+2)/3
  4. 別解：k(k+1)(k+2) − (k−1)k(k+1) = 3k(k+1) を k=1〜n で足すと右辺の和の3倍が n(n+1)(n+2) になる
  5. 検算：n=2 で 2 + 6 = 8、2·3·4/3 = 8 ○

別解・ほかの見方

  • Σ[k=1〜n] k(k+1)(k+2) = n(n+1)(n+2)(n+3)/4。連続整数の積の和は『1つ増やして個数で割る』
  • 下端が1でない和は Σ[k=m〜n] = Σ[k=1〜n] − Σ[k=1〜m−1]

落とし穴

  • Σ[k=1〜n] 3 = 3 としてしまう
  • Σ(k²) と (Σk)² を混同する
  • 等比の和で r = 1 の場合を書き忘れる
  • 全部展開してから因数分解できずに時間を失う
  • Σ[k=1〜n] c = c と書く（正しくは nc）／等比の和で r=1 の場合分けを落とす

なぜ大事か

すべての和の計算の部品。覚えるだけでなく『差の形』から作り直せると忘れても困らない

東大での出方

部品として毎年使う。格子点の数え上げ（Σk²）、確率の期待値、数IIIの区分求積の前段階など。

確認問題

  • Σ[k=1〜n] (2k − 1)² を求めよ（答：n(2n−1)(2n+1)/3）
  • Σk³ = (Σk)² を n=3 で確かめよ

発展

Σk² の公式を (k+1)³ − k³ = 3k² + 3k + 1 を足し合わせて自分で導けるか。試験中に公式を忘れても復元できる。
