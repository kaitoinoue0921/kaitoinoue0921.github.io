極7 微分係数の定義に読み替える

数学III ／ 極限 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

f′(a) = lim[h→0]{f(a + h) − f(a)}/h は、極限の計算の道具としても使える。分子が f(a + □) − f(a)、分母が同じ □ になるように係数を調整すれば、その部分は f′(a) に置き換わる。f が具体的な式でも、(x¹⁰ − 1)/(x − 1) のように展開が面倒な極限は『x¹⁰ の x = 1 での微分係数』と読めば一瞬で済む。f(a) が無い形は、f(a) を引いて足して2つに分ける。

こんなときに使う

  • f が抽象的な関数で、f′(a) が与えられている極限
  • (xⁿ − 1)/(x − 1)、(eˣ − 1)/x、(sin x − sin a)/(x − a) のように、関数値の差 ÷ 変数の差の形
  • f(a + 3h) − f(a − h) のように、2つの点がどちらも a からずれている

手順

  1. 1. 分子を f(a + □) − f(a) の形にする（f(a) が無ければ引いて足す）
  2. 2. 分母を同じ □ にそろえ、余った係数を前に出す
  3. 3. □ → 0 を確かめて f′(a) に置き換える
  4. 4. x → a の形なら {f(x) − f(a)}/(x − a) → f′(a) をそのまま使う

例題

定義に従って、f(x)=x² の導関数を求めよ。
解答
  1. lim[h→0]((x+h)²−x²)/h=lim[h→0](2xh+h²)/h=lim[h→0](2x+h)=2x
  2. ∴ f′(x)=2x

別解・ほかの見方

  • lim[x→1](x¹⁰ − 1)/(x − 1) は f(x) = x¹⁰ の f′(1) = 10
  • lim[x→a]{x f(a) − a f(x)}/(x − a) は x f(a) − a f(a) + a f(a) − a f(x) と分けて f(a) − a f′(a)
  • lim[n→∞] n{f(a + 1/n) − f(a)} は h = 1/n とおいて f′(a)

落とし穴

  • □ をそろえずに置き換えて係数を落とす
  • f(a − h) − f(a) を h で割って +f′(a) とする（分母は −h なので −f′(a)）
  • 「定義に従って」と言われたら公式 (xⁿ)′=nxⁿ⁻¹ で答えると0点になりうる。極限の計算を書く。
  • 分子と分母の『□』をそろえずに f′(a) と置き換える（f(a + 3h) − f(a) を h で割って f′(a) とする）

なぜ大事か

lim{f(a + □) − f(a)}/□ の形が見えれば、極限の計算をせずに f′(a) に置き換えられる

東大での出方

東大では関数方程式（f(x + y) = f(x) + f(y) など）から f′(x) を求める問題で、この読み替えが出発点になる。

確認問題

  • lim[h→0](f(a+3h)−f(a−h))/h を f′(a) で表せ。（答：4f′(a)）

発展

ロピタルの定理を使わずに済む 0/0 の多くは、実は微分係数の定義そのもの。sin x/x → 1 も『sin の x = 0 での微分係数が 1』と同じ内容だが、sin の微分公式の証明に sin x/x → 1 を使うので、こちらを定義で示すと循環論法になる。
