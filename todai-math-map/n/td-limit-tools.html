極限の3種の神器（はさみうち・区分求積・漸化式評価）

要点

既知の公式に当てはまらない極限の答案は、ほぼ全て「はさみうち」「区分求積」「漸化式評価（I_nとI_{n+1}の関係から評価する）」のどれかに帰着する。大切なのは3つの公式を覚えることではなく、目の前の式を見て『どれを最初に試すか』を1秒で判断する目利き力。この判断力そのものが、東大の評価問題（積分と不等式・数列の極限）で差がつく部分。

こんなときに使う

  • 不等式で上下から挟める形がすぐ作れる → はさみうち
  • Σと(1/n)がセットで、kがnと連動して動いている → 区分求積
  • I_n（積分やΣで定義された数列）について、I_{n+1}とI_nの大小関係や漸化式が作れる → 漸化式評価
  • 1つの型で行き詰まったら、別の型に切り替えて試す（3つとも独立に試す価値がある）

手順

  1. 1. 式の形を観察する：不等式が作れるか／Σ(1/n)f(k/n)の形に整形できるか／I_nの漸化式が作れるか
  2. 2. 該当する型で評価式・変形を作る
  3. 3. n→∞の極限を取り、両端（または評価した値）が一致することを確認する
  4. 4. 型が複数組み合わさる問題（区分求積で挟んではさみうち、など）もあることを意識する

例題

I_n = ∫[0→1] xⁿ/(1+x) dx とするとき、lim[n→∞] I_n を求めよ。
解答
  1. 0≦x≦1で0≦xⁿ/(1+x)≦xⁿなので、0≦I_n≦∫[0→1]xⁿdx=1/(n+1)。
  2. n→∞で1/(n+1)→0なので、はさみうちよりI_n→0。
  3. （この問題は漸化式でI_nとI_{n-1}の関係を作る解法もあるが、はさみうちが最速）

別解・ほかの見方

  • 区分求積とはさみうちの組み合わせ：区分求積で厳密値が出せない和は、積分で上下から挟んで評価する（m3-int-ineqの核心）
  • 漸化式評価：I_nの漸化式を作り、I_n>I_{n+1}（単調減少）と下限（I_n>0など）から収束を示す方法もある

落とし穴

  • 公式を1つ覚えただけで満足し、他の2つの型を試さずに『解けない』と判断してしまう
  • はさみうちで下からの評価（0以上など）を書き忘れ、上からの評価だけで済ませてしまう
  • 区分求積とみせかけて実際はΣの中にnが単独で残っている（区分求積が使えない）ことを見抜けない
  • 3つとも試さず、覚えている公式が使えないだけで『分からない』と諦める

なぜ大事か

『公式に当てはまらない極限』の答案はほぼ全てこの3つのどれかに帰着する。どれを最初に試すかの判断力が得点力そのもの

東大での出方

東大の数III最難問帯（数学の掌握が体系化したことで有名なテーマ）。単独でも出るが、たいていの年で「評価と極限の融合」（「【東大型】評価と極限の融合」）の中核として組み合わさって出る。

確認問題

  • J_n = ∫[0→1] xⁿ e⁻ˣ dx について、lim[n→∞] n·J_n を求めよ（漸化式または評価のどちらが使えるか考える）
  • lim[n→∞] (1/n)Σ[k=1→n] 1/√(1+(k/n)²) を求めよ（どの型か判断してから計算する）

発展

log を取ってから区分求積に持ち込む変形（積の極限）や、はさみうちの評価式を自分で微分を使って作る（既存の不等式が使えない場合）も、この3種の神器の応用形として押さえておく。
