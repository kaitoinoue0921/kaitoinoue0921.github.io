整9 無理数の証明（既約分数とおいて背理法）

数学A ／ 整数 ／ 東大での重要度 ★★★☆☆

アプリで開く →

要点

無理数であることは『有理数ではない』という否定なので、背理法で示す。有理数と仮定して p/q（p, q は互いに素な整数、q > 0）とおき、両辺を整数の式に直すと、素数の性質（整7）や偶奇で『p も q も同じ素数で割り切れる』などの矛盾が出る。log₂3 のような対数なら 3ⁿ = 2ᵐ になり、偶奇で矛盾する。無理数を含む等式 a + b√2 = 0 では、b ≠ 0 なら √2 = −a/b が有理数になるので b = 0、a = 0 と係数比較できる。

こんなときに使う

  • 『〜は無理数であることを示せ』
  • √2 + √3、log₂3、³√2 などが有理数でないこと
  • 有理数 a, b で a + b√2 = c + d√2 のような等式（係数比較）

手順

  1. 1. 有理数であると仮定し、p/q（互いに素、q > 0）とおく
  2. 2. 両辺を累乗するなどして、分母を払った整数の等式にする
  3. 3. 素数の性質（p | ab ⇒ p | a または p | b）や偶奇から、p も q も同じ素数で割り切れることを導く
  4. 4. 互いに素に矛盾する、と書いて終える
  5. 5. 和の形（√2 + √3）は、有理数 r とおいて2乗し、√6 が有理数になる形に帰着する

例題

√3 は無理数であることを示せ。
解答
  1. √3 が有理数であると仮定し、√3 = p/q（p, q は互いに素な正の整数）とおく
  2. 両辺を2乗して p² = 3q²
  3. 右辺は 3 の倍数なので 3 | p²。3 は素数なので 3 | p（整7）。p = 3k とおく
  4. 9k² = 3q² より q² = 3k²、同じく 3 | q
  5. p, q がともに 3 で割り切れ、互いに素であることに矛盾。∴ √3 は無理数

別解・ほかの見方

  • log₂3 = m/n（m, n は正の整数）とおくと 2ᵐ = 3ⁿ。左辺は偶数、右辺は奇数で矛盾
  • √2 + √3 = r（有理数）とおくと 5 + 2√6 = r² で √6 が有理数になり矛盾
  • ³√2 = p/q なら p³ = 2q³ から p は偶数、さらに q も偶数

落とし穴

  • 『互いに素』の条件を書かずに p/q とおく（矛盾の行き先がなくなる）
  • 3 | p² から 3 | p を言うときに理由（3 が素数）を書かない
  • 4 | p² から 4 | p のように、素数でない数で同じ推論をする
  • p/q を既約分数とおかずに進めて、矛盾が出なくなる

なぜ大事か

『有理数でない』は直接示せない。p/q とおいて整数の式に直し、矛盾を出す

東大での出方

単独より、大問の (1) で無理数性を示させ、(2) でそれを使う形が多い。証明の型が決まっているので、答案の書き方まで固定しておくと得点源になる。

確認問題

  • log₂3 が無理数であることを示せ（答：log₂3 = m/n とおくと 2ᵐ = 3ⁿ で、左辺は偶数、右辺は奇数になり矛盾）
  • √2 + √3 が無理数であることを示せ（答：有理数 r とおくと √6 = (r² − 5)/2 が有理数になる。√6 が無理数であることを √3 と同じ方法で示して矛盾）

発展

一般に、自然数 n が平方数でなければ √n は無理数。これは整10 の有理数解の定理を x² − n = 0 に使うとすぐ出る。
