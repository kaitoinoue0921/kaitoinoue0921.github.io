場合分けを漏らさない・同値性を保つ記述

東大レイヤー ／ メタ技能 ／ 東大での重要度 ★★★★★

要点

東大の採点は論理の飛躍に厳しく、答えが合っていても過程で落ちる。押さえるべきは2点しかない。場合分けが排反かつ網羅的であること、そして式変形が同値であることである。特に危ないのが、両辺を2乗する・両辺に文字を掛ける・分母を払うといった操作で、これらは同値ではない。必要条件だけで進んだのなら、最後に必ず十分性を確認する。この確認を書くかどうかが、そのまま点差になる。

こんなときに使う

  • 絶対値・平方根・対数が出てきた → 場合分けか条件（真数条件など）
  • 両辺を2乗した → 同値でない。符号の確認が必要
  • 両辺に文字を掛けた／割った → その文字が 0 の場合を分ける
  • 分母を払った → 分母 ≠ 0 を条件として残す
  • 『⇒』の向きにだけ進んだ → 逆が言えるか確認する
  • 図形で点の位置によって形が変わる → その境目で場合分け

手順

  1. 1. 場合分けの基準を明示する（『x < 0 のとき』のように見出しを立てる）
  2. 2. 排反か（重複していないか）を確認する
  3. 3. 網羅的か（漏れがないか）を確認する。境界値をどちらに入れたかも明示
  4. 4. 同値でない変形をしたら、その場に印をつけておく
  5. 5. 最後に十分性を確認する（求めた解を元の式に戻す）
  6. 6. 各場合の結論を統合して、最終的な答えを書く

例題

方程式 √(x + 2) = x を解け。
解答
  1. 【よくある答案】
  2. 両辺を2乗して x + 2 = x²
  3. x² − x − 2 = 0、(x − 2)(x + 1) = 0
  4. よって x = 2, −1　　← ここで終えると誤り
  6. 【なぜ誤りか】
  7. 「A = B」から「A² = B²」は言えるが、逆は言えない（A = −B でも A² = B² になる）。
  8. つまり2乗は同値変形ではなく、必要条件しか得られていない。
  9. 実際 x = −1 を元の式に代入すると √1 = 1 だが右辺は −1 で、成り立たない。
  11. 【正しい書き方その1：十分性を確認する】
  12. 2乗して得た候補 x = 2, −1 を元の式に代入して確かめる。
  13. 　x = 2 のとき √4 = 2 ○
  14. 　x = −1 のとき √1 = 1 ≠ −1 ✕
  15. ∴ x = 2
  17. 【正しい書き方その2：最初から同値変形にする】
  18. √(x+2) = x ⇔ x ≧ 0 かつ x + 2 = x²　（左辺は 0 以上なので右辺も 0 以上が必要）
  19. 　　　　　　⇔ x ≧ 0 かつ (x − 2)(x + 1) = 0
  20. 　　　　　　⇔ x = 2
  22. この書き方なら十分性の確認が要らない。東大の答案としてはこちらが望ましい。
  23. （真数条件 x + 2 ≧ 0 は x = x² − 2 ≧ 0 から自動的に従う）

別解・ほかの見方

  • 同値記号（⇔）で繋いで書く（最も安全。ただし本当に同値か毎回確認すること）
  • 必要条件で候補を絞り、最後に十分性を確認する（計算は軽いが確認を忘れやすい）
  • 場合分けを表にまとめる（3つ以上の条件が絡むとき）
  • 『少なくとも』『すべての』が出たら、∀ と ∃ を明示的に書き分ける

落とし穴

  • 2乗したあと十分性を確認しない（最頻出）
  • 場合分けの境界値をどちらに入れたか書かない
  • 『x ≠ 0 のとき』で割ったのに、x = 0 の場合を扱わない
  • 必要条件で出した答えを、そのまま最終解答にする
  • 場合分けの見出しを立てず、地の文に混ぜて書く（採点者が追えない）
  • 必要条件だけ出して十分性の確認を書かない

なぜ大事か

東大の採点は論理の飛躍に厳しい。合っている答えでも過程で落ちる

東大での出方

東大は同値性の意識を直接測ってくる。特に軌跡・領域・方程式の解の議論では、必要条件だけで進むと必ず余分な解が混じる設計になっている。答えが合っているのに点が来ないという経験の大半は、ここが原因。

確認問題

  • √(2x + 3) = x を解け（十分性の確認まで書くこと）
  • |x − 1| + |x − 3| = 4 を解け（場合分けの網羅性を意識すること）
  • 方程式 x + 1/x = a が実数解を持つ a の条件を、同値変形で求めよ

発展

同値でない変形を意図的に使い、あとで十分性を確認するほうが速い場面もある。どちらが速いかを判断できるようになると、時間の使い方が変わる。

前提になるノード

  • 必要条件・十分条件
  • 2次関数の最大最小（区間・軸の場合分け）
  • 絶対値付き積分・区間の分割

このノードを前提にするノード

  • 減点されない答案の書き方
  • 【東大型】関数の決定・不等式の成立条件
