確10 対称性で状態を減らす

数学A ／ 確率 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

確率漸化式で状態が4つも5つもあると連立が解けない。しかし出発点から見て対等な位置（正三角形の B と C、正四面体の B, C, D など）は、いつでも同じ確率になる。だから1つの未知数でまとめてよい。まとめてよい条件は『そこから先の遷移確率が全部同じ』こと。和が 1 になる関係も使えば、未知数はさらに1つ減る。

こんなときに使う

  • 正多角形・正多面体の頂点を動く点
  • 立方体の頂点や、出発点からの距離で区別できる位置
  • 状態が3つ以上あり、そのうちいくつかが出発点に対して対称

手順

  1. 1. 出発点を固定して、対等な位置（距離が同じ・役割が同じ）をグループにまとめる
  2. 2. 各グループにいる確率を未知数にする（グループ内の1点ではなく、グループ全体の確率にすると楽）
  3. 3. グループ間の遷移確率を書き、まとめてよいか（遷移が同じか）確かめる
  4. 4. 和 = 1 を使って未知数を減らし、漸化式を解く
  5. 5. n = 1, 2 で直接数えた値と照合する

例題

正四面体 ABCD の頂点上を点 P が動く。P は1秒ごとに、今いる頂点以外の3頂点のどれかへ確率 1/3 ずつ移る。最初 A にいるとき、n 秒後に A にいる確率 pₙ を求めよ。
解答
  1. B, C, D は A から見て対等なので、n 秒後に A 以外にいる確率 1 − pₙ を1つにまとめる
  2. A にいれば次は必ず A 以外。A 以外にいれば、次に A へ移る確率は 1/3
  3. ∴ pₙ₊₁ = (1/3)(1 − pₙ)、p₀ = 1
  4. 特性方程式 α = (1/3)(1 − α) より α = 1/4。pₙ − 1/4 = (−1/3)ⁿ(p₀ − 1/4)
  5. ∴ pₙ = 1/4 + (3/4)(−1/3)ⁿ
  6. 検算：p₁ = 1/4 − 1/4 = 0、p₂ = 1/4 + 1/12 = 1/3（Aを出て、どこからでも1/3で戻る）○

別解・ほかの見方

  • 立方体の頂点を隣へ動く：出発点からの距離 0, 1, 2, 3 の4状態にまとめる
  • 正方形の頂点を隣へ動く：偶数秒後は A と対角の C の2状態だけになる（偶奇分け）
  • 2人がそれぞれ動く問題は、2人の『距離』を状態にすると1つにまとまる

落とし穴

  • 遷移の違う位置をまとめる（例：立方体で距離1と距離2を同じ状態にする）
  • グループの確率と、グループ内の1点の確率を混同して係数を間違える
  • まとめたあと和が 1 になるかを確かめない
  • 見た目が対称なだけで、そこから先の動き方が違う状態までまとめてしまう

なぜ大事か

状態が多い確率漸化式も、対等な状態をまとめれば未知数が1〜2個に減る

東大での出方

東大の確率漸化式は状態が多く見える設定で出ることが多く、対称性でまとめられるかが分かれ目。状態を何にするかを答案の最初に宣言する。

確認問題

  • 正六角形 ABCDEF の頂点を、1秒ごとに隣の頂点へ確率 1/2 ずつ動く。A から出発して3秒後に D にいる確率を求めよ（答：1/4）
  • 正方形 ABCD の頂点を、1秒ごとに隣の頂点へ確率 1/2 ずつ動く。A から出発して n 秒後に A にいる確率を求めよ（答：n が偶数（n ≧ 2）で 1/2、奇数で 0）

発展

状態をまとめるのは『マルコフ連鎖の集約』と呼ばれる操作で、条件は『同じグループの各点から、他のグループへ移る確率が等しい』こと。見た目の対称性はこの条件を保証する手段の1つにすぎない。
