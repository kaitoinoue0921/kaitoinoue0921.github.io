漸化式の型別処理（等比型・特性方程式・分数型・連立）

数学B ／ 漸化式 ／ 東大での重要度 ★★★★★

要点

a_(n+1)=pa_n+qの特性方程式α=pα+qを解く理由は、この式を使うとa_(n+1)−α=p(a_n−α)と書き直せて、数列{a_n−α}が公比pの等比数列になるから。αは『動かない点』を表している。分数型で逆数を取る、積の形で対数を取る、といった変換もすべて『既知の型（等差・等比）に帰着させる』という同じ目的を持つ。

こんなときに使う

  • a_(n+1)=pa_n+qの形は特性方程式を解いて等比数列に帰着させる
  • 分数型（a_(n+1)=a_n/(pa_n+q)など）は逆数を取る
  • 積の形は対数を取って和の形に変える

手順

  1. 1. 型を判別する（等比、階差、分数、積など）
  2. 2. 特性方程式、逆数、対数など適切な変換を行う
  3. 3. 既知の型（等差・等比）に帰着させて一般項を求める

例題

a₁=1、a_(n+1)=2a_n+3の一般項を求めよ。
解答
  1. 特性方程式α=2α+3よりα=−3
  2. a_(n+1)+3=2(a_n+3)なので{a_n+3}は公比2の等比数列。
  3. a_n+3=(a_1+3)・2^(n−1)=4・2^(n−1)
  4. ∴ a_n=2^(n+1)−3

別解・ほかの見方

  • 連立漸化式は行列（または加減法）で対角化して解く

落とし穴

  • 特性方程式の解を求めた後、元の数列にどう適用するかの手順を誤る
  • 型に当てはめられない形で手が止まる（両辺を何かで割る・置換する発想）
