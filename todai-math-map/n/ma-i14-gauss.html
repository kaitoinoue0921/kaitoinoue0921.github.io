整14 ガウス記号（[x] = n ⇔ n ≦ x < n + 1）

数学A ／ 整数 ／ 東大での重要度 ★★★☆☆

要点

[x] は x を超えない最大の整数で、[x] = n（n は整数）は n ≦ x < n + 1 と同じこと。ガウス記号を含む方程式は、[x] = n とおいて x を n で表し、この不等式に代入すると n の範囲が出て、整数 n が有限個に決まる。和 Σ[k/m] は、[k/m] が同じ値をとる k をまとめて数える。[2x] = 2[x] や [x + y] = [x] + [y] は一般には成り立たない。

こんなときに使う

  • [x]、⌊x⌋、『x を超えない最大の整数』
  • [√n] = k となる n の個数、Σ[k/3] のような和
  • 『x − [x]』（小数部分）を含む式

手順

  1. 1. [x] = n（n は整数）とおき、n ≦ x < n + 1 を書く
  2. 2. 方程式から x を n で表す
  3. 3. 不等式に代入して n の範囲を出し、整数 n を決める
  4. 4. それぞれの n で x を出し、もとの式に代入して確かめる
  5. 5. 和なら、[・] の値が同じになる区間ごとにまとめて足す

例題

方程式 3[x] = 2x + 1 を解け。ただし [x] は x を超えない最大の整数とする。
解答
  1. [x] = n とおくと 3n = 2x + 1 より x = (3n − 1)/2
  2. n ≦ x < n + 1 に代入して n ≦ (3n − 1)/2 < n + 1
  3. 左の不等式から 2n ≦ 3n − 1 で n ≧ 1、右から 3n − 1 < 2n + 2 で n < 3
  4. ∴ n = 1, 2 で x = 1, 5/2
  5. 確認：[1] = 1 で 3 = 3、[5/2] = 2 で 6 = 6

別解・ほかの見方

  • [√n] = 3 ⇔ 3 ≦ √n < 4 ⇔ 9 ≦ n < 16 で 7 個
  • Σ_{k=1}^{30} [k/3]：値 m（1〜9）をとる k が3個ずつ、k = 30 で 10、合計 145
  • [x] ≦ x < [x] + 1 から、x − 1 < [x] ≦ x として評価に使う（極限のはさみうちで頻出）

落とし穴

  • [2x] = 2[x] とする（x = 0.5 で [1] = 1、2[0.5] = 0）
  • n の範囲を出したあと、もとの式に代入して確かめない
  • 負の x で [−1.5] = −1 とする（正しくは −2）
  • [x] を x と同じように式変形して、[2x] = 2[x] や [x + y] = [x] + [y] とする

なぜ大事か

[x] は不等式2本に直せば普通の不等式の問題になる。[x] を整数 n と置くのが出発点

東大での出方

東大では整数の個数を数える問題や、極限のはさみうちの評価 x − 1 < [x] ≦ x として出る。不等式に直す1行目さえ書ければ、あとは普通の計算。

確認問題

  • [√n] = 3 となる自然数 n は何個か（答：7個）
  • [x] = 2x − 3 を解け（答：x = 5/2, 3）

発展

ルジャンドルの公式（整8）の [n/p] + [n/p²] + … もガウス記号の和。『1〜n のうち p の倍数の個数 = [n/p]』が、ガウス記号がいちばんよく使われる場面。
