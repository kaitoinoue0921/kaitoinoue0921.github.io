対称性を利用して場合を減らす

東大レイヤー ／ メタ技能 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

「a ≦ b ≦ c としてよい」「原点を中心に取ってよい」——この一言で計算量が数分の一になる。東大の問題は、対称性を使うことを前提に難易度が設定されていることが多く、気づかずに全場合を計算すると時間内に終わらないよう作られている。ただし使えるのは対称性が実際に存在する場合だけで、根拠を書かずに「一般性を失わない」と宣言すると減点される。何を入れ替えても状況が変わらないのかを、書く前に一度確認する習慣をつけること。

こんなときに使う

  • 式が文字の入れ替えで変わらない（対称式）→ 大小関係を仮定してよい
  • 図形に対称軸や対称中心がある → 座標をそこに合わせて取る
  • 確率で複数の対象が対等 → 状態をまとめて数を減らせる
  • 積分区間が原点対称 → 偶関数・奇関数で処理できないか見る
  • 積分区間が [0, a] で被積分関数に a−x の構造がある → x → a−x の置換
  • 回転対称な図形 → 複素数平面で回転として書ける

手順

  1. 1. 何を入れ替えても状況が変わらないかを確認する
  2. 2. 『〜としてよい』と書く根拠（対称性の所在）を明示する
  3. 3. 仮定を置いて調べる場合を減らす
  4. 4. 計算を進める
  5. 5. 最後に仮定を外し、対称な場合をすべて書き出す
  6. 6. 図形なら、対称性が最も活きる座標の取り方を選ぶ

例題

定積分 ∫[0→π] x·sin x / (1 + cos²x) dx を求めよ。
解答
  1. そのまま部分積分すると計算が重い。積分区間 [0, π] の対称性に注目する。
  3. 求める値を I とおく。x → π − x と置換する（dx は符号が変わるが区間も入れ替わる）。
  4. sin(π − x) = sin x、cos(π − x) = −cos x なので cos²(π − x) = cos²x。
  5. つまり被積分関数のうち、x 以外の部分は置換で変わらない。
  7. I = ∫[0→π] (π − x)·sin x / (1 + cos²x) dx
  9. 元の式と足し合わせると x の項が消える。
  10. 2I = ∫[0→π] {x + (π − x)}·sin x / (1 + cos²x) dx = π ∫[0→π] sin x / (1 + cos²x) dx
  12. 残った積分は u = cos x と置換できる。du = −sin x dx、x: 0 → π のとき u: 1 → −1。
  13. ∫[0→π] sin x/(1 + cos²x) dx = ∫[−1→1] du/(1 + u²)
  15. さらに u = tanθ と置換すると du = dθ/cos²θ、1 + u² = 1/cos²θ、u: −1 → 1 で θ: −π/4 → π/4。
  16. = ∫[−π/4→π/4] dθ = π/2
  18. よって 2I = π × (π/2) = π²/2
  20. ∴ I = π²/4
  22. 【要点】x → π − x で被積分関数の『x 以外の部分』が不変であることを見抜くのが全て。
  23. この構造に気づけば3行、気づかなければ計算が終わらない。

別解・ほかの見方

  • 整数問題：対称式なら a ≦ b ≦ c と仮定し、最後に並べ替えを戻す
  • 図形：対称軸を座標軸に取る、対称中心を原点に取る
  • 確率：対等な対象をまとめて1つの状態にする（正四面体の頂点など）
  • 積分：偶関数・奇関数、x → a−x の置換、周期性の利用
  • 複素数平面：回転対称な配置は 1 の n 乗根で表す

落とし穴

  • 対称性が実際にはないのに『一般性を失わない』と書く
  • 根拠を書かずに仮定だけ置く（東大は根拠の明示を見ている）
  • 最後に仮定を外して並べ替えを書くのを忘れる
  • 等号成立の場合（a = b など）を重複して数える
  • 対称性に気づかず、力任せに計算して時間切れになる
  • 「一般性を失わない」と書ける条件を確認せずに使う

なぜ大事か

『a≦b≦c としてよい』『座標をこう取ってよい』の一言で計算量が1/6になる

東大での出方

単独のテーマではないが、整数・確率・図形・積分のすべてに顔を出す。特に東大の空間図形と積分では、対称性を使うことを前提に計算量が設定されていることが多い。使えば10分、使わなければ40分、という差が現実に生じる。

確認問題

  • ∫[0→π/2] sin x/(sin x + cos x) dx を、x → π/2 − x の置換で求めよ
  • ∫[−1→1] x³/(1 + x²) dx を、被積分関数の偶奇から即答せよ
  • a + b + c = 3 を満たす正の実数について abc の最大値を求めよ（対称性から a = b = c を予想し、証明する）

発展

対称性が『ほぼ』ある場合。完全に対称ではないが、片方を固定すればもう片方に対称性が現れる、という構造を見抜く。予選決勝法（一方を固定して最大最小を取る）はこの考え方の一種。
