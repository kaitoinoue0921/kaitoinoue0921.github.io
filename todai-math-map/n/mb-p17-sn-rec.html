⑰ 和S(n)と一般項の混在型

数学B ／ 漸化式 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

S(n) を含む関係式は、n を n+1 にずらした式と元の式を引くと S(n+1) − S(n) = a(n+1) で和が消える。あとは a だけの漸化式（⑩など）になる。ただし最初の a(1) は、元の式に n=1 を入れて S(1) = a(1) から別に求める。どの式がどの n で成り立つかを毎回書くのが減点を防ぐコツ。

こんなときに使う

  • S(n) = 2a(n) − n のように、和と一般項が1つの式に混在
  • a(n+1) = 2S(n) + 1 のように、和で次の項が決まる
  • 『初項から第n項までの和を S(n) とする』と前置きがある漸化式

手順

  1. 1. 元の式に n=1 を入れ、S(1) = a(1) から a(1) を求める
  2. 2. n を n+1 にずらした式を書く
  3. 3. 2式を引き、S(n+1) − S(n) = a(n+1) で S を消す
  4. 4. 得られた a の漸化式を解く（成り立つ n の範囲に注意）
  5. 5. S(2) などで検算する

例題

数列 {a(n)} の初項から第n項までの和 S(n) が S(n) = 2a(n) − n を満たす。一般項を求めよ。
解答
  1. n=1：a(1) = 2a(1) − 1 より a(1) = 1
  2. S(n+1) = 2a(n+1) − (n+1) と S(n) = 2a(n) − n を引く
  3. a(n+1) = 2a(n+1) − 2a(n) − 1 より a(n+1) = 2a(n) + 1
  4. α = −1 より a(n) + 1 = 2·2ⁿ⁻¹ = 2ⁿ
  5. ∴ a(n) = 2ⁿ − 1
  6. 検算：S(2) = 1 + 3 = 4、2a(2) − 2 = 4 ○

別解・ほかの見方

  • a(n+1) = 2S(n) + 1 型：ずらした a(n) = 2S(n−1) + 1（n≧2）と引いて a(n+1) − a(n) = 2a(n)。この式は n≧2 でしか成り立たないので a(2) を別に計算し、a(2) を初項にする
  • S(n) について解いた方が楽な場合もある：a(n) = S(n) − S(n−1) を代入して S の漸化式にする

落とし穴

  • a(1) を元の式から求めず、漸化式だけで止まる
  • ずらした式が n≧2 でしか成り立たないのに、a(1) から等比数列を始めてしまう
  • S(n+1) − S(n) を a(n) と書く（a(n+1) が正しい）
  • ずらした式が成り立つ n の範囲（n≧2）と、a(1) を別に求めることを忘れる

なぜ大事か

S(n) が入った式は、nをずらして引けば S が消えて普通の漸化式になる

東大での出方

単独での出題は少ないが、和の条件付き数列で論証の丁寧さが採点される。

確認問題

  • a(1) = 1、a(n+1) = 2S(n) + 1 の一般項を求めよ（答：a(n) = 3ⁿ⁻¹）
  • S(n) = n²·a(n)、a(1) = 1 のとき a(n) を求めよ（答：2/{n(n+1)}）

発展

S(n) = n²a(n) 型では a(n)/a(n−1) = (n−1)/(n+1) という積の形になり、掛け合わせると約分で消える（⑨と同じ望遠鏡）。
