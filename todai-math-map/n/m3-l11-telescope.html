極11 部分和を出してから極限（部分分数・望遠鏡和）

数学III ／ 極限 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

無限級数 Σaₙ の和は、部分和 Sₙ = a₁ + … + aₙ の n → ∞ の極限として定義される。等比級数（極10）以外では、まず Sₙ を n の式で表すのが先。分数の項は部分分数分解で aₖ = bₖ − bₖ₊₁ の形にすると、足したときに隣同士が消えて Sₙ = b₁ − bₙ₊₁ が残る（望遠鏡和）。逆に aₙ → 0 にならなければ級数は必ず発散する。

こんなときに使う

  • Σ1/(n(n + 1))、Σ1/((2n − 1)(2n + 1)) のような積の逆数の級数
  • Σ(√(n + 1) − √n) のように、すでに差の形の級数
  • 『この級数は収束するか』（まず aₙ → 0 かを見る）

手順

  1. 1. aₙ → 0 か確かめる（0 でなければ発散で終わり）
  2. 2. 部分分数分解などで aₖ = bₖ − bₖ₊₁（または bₖ − bₖ₊₂）の形にする
  3. 3. Σ[k=1..n] を書き並べて消し合い、Sₙ を求める
  4. 4. n → ∞ の極限をとる

例題

Σ[n=1..∞]1/(n(n+1)) を求めよ。
解答
  1. Sₙ=Σ[k=1..n](1/k−1/(k+1))=1−1/(n+1)→1
  2. ∴ 1

別解・ほかの見方

  • 2つ飛びで消える aₖ = bₖ − bₖ₊₂ は、最初の2つと最後の2つが残る
  • Σ1/(n(n + 1)(n + 2)) は (1/2){1/(n(n + 1)) − 1/((n + 1)(n + 2))}
  • Σ(√(n + 1) − √n) は Sₙ = √(n + 1) − 1 → ∞ で発散

落とし穴

  • 部分和を経ずに、無限個の項をそのまま消し合わせる（収束しない級数でも成り立つように見えてしまう）
  • 2つ飛びで消える形で、残る項を1つずつしか書かない
  • 逆は成り立たない：aₙ→0 でも収束するとは限らない（Σ1/n は発散）。
  • 項 aₙ → 0 だから級数は収束する、とする（Σ1/n は発散）

なぜ大事か

無限級数は部分和 Sₙ の極限なので、等比でなければ Sₙ を閉じた形にするのが先

東大での出方

東大では級数単独より、区分求積（極8）や漸化式の極限の途中で Sₙ を出す場面で出る。Sₙ を閉じた形にできるかが分かれ目。

確認問題

  • Σ[n=1..∞]1/((2n−1)(2n+1)) を求めよ。（答：1/2）
  • Σ[n=1..∞]n/(n+1) は収束するか。（答：発散（第 n 項 n/(n+1)→1≠0））

発展

Σ1/n² = π²/6（バーゼル問題）のように望遠鏡和にできない級数も、1/k² < 1/(k(k − 1)) = 1/(k − 1) − 1/k と望遠鏡和で上から押さえれば、収束すること（和は 2 未満）だけは示せる。
