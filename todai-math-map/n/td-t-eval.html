【東大型】評価と極限の融合

東大レイヤー ／ 出題テーマ ／ 東大での重要度 ★★★★★

要点

「(1) で不等式を示し、(2) でその不等式を使って極限を出す」——東大が最も好む構造である。ここで理解すべきは、(1) は独立した小問ではなく、(2) のために置かれているということ。だから (1) が解けたら必ず (2) で使う。逆に (2) で手が止まったら、まず (1) の結果を見返す。この誘導の読み方が身についているかどうかが、そのまま得点差になる。誘導を無視して (2) を正面から解こうとすると、まず解けないように設計されている。

こんなときに使う

  • 『(1) 不等式を示せ → (2) 極限を求めよ』の構成 → (1) をはさみうちに使う
  • I_n のように n が入った積分や数列 → 漸化式を作るか、評価して挟む
  • 直接計算できない量が出てくる → 挟む以外に道はない
  • (1) で作った漸化式が (2) の和や極限に繋がる
  • 『〜より小さいことを示せ』→ その評価が後で効く

手順

  1. 1. (1) の結論を正確に書き留める（これが後で使う道具）
  2. 2. (2) の対象が、その不等式の中央に来るように整理する
  3. 3. 両端の極限を計算する
  4. 4. 一致すればはさみうちの原理で確定（『はさみうちの原理より』と明記する）
  5. 5. 一致しなければ評価が甘い。より強い不等式を作り直す
  6. 6. 漸化式が与えられている場合は、それを繰り返し使って和や一般項に持ち込む

例題

I_n = ∫[0→1] xⁿ/(1 + x) dx （n = 0, 1, 2, …）とする。 (1) 0 < I_n ≦ 1/(n+1) を示せ。 (2) I_n + I_(n+1) = 1/(n+1) を示せ。 (3) lim[n→∞] { 1 − 1/2 + 1/3 − … + (−1)^(n−1)/n } を求めよ。
解答
  1. (1) 0 ≦ x ≦ 1 のとき 1 ≦ 1 + x ≦ 2 だから、xⁿ ≧ 0 より
  2. 　　0 ≦ xⁿ/(1 + x) ≦ xⁿ
  3. 　積分して 0 ≦ I_n ≦ ∫[0→1] xⁿ dx = 1/(n+1)。
  4. 　被積分関数は x > 0 で正なので I_n > 0。よって 0 < I_n ≦ 1/(n+1)。
  6. (2) I_n + I_(n+1) = ∫[0→1] (xⁿ + x^(n+1))/(1 + x) dx
  7. 　　　　　　　　 = ∫[0→1] xⁿ(1 + x)/(1 + x) dx
  8. 　　　　　　　　 = ∫[0→1] xⁿ dx = 1/(n+1)
  9. 　分子が分母で割り切れる、という一点だけの計算。
  11. (3) まず I₀ = ∫[0→1] dx/(1 + x) = [log(1 + x)]₀¹ = log 2。
  13. 　(2) の関係 I_(n+1) = 1/(n+1) − I_n を繰り返し使う。
  14. 　　I₁ = 1/1 − I₀ = 1 − log 2
  15. 　　I₂ = 1/2 − I₁ = log 2 − (1 − 1/2)
  16. 　　I₃ = 1/3 − I₂ = (1 − 1/2 + 1/3) − log 2
  18. 　ここで S_n = 1 − 1/2 + 1/3 − … + (−1)^(n−1)/n とおくと、上の形から
  19. 　　log 2 − S_n = (−1)ⁿ I_n
  20. 　が成り立つ（n についての帰納法で示せる）。
  22. 　(1) より 0 < I_n ≦ 1/(n+1) であり、1/(n+1) → 0。
  23. 　はさみうちの原理より I_n → 0。したがって |log 2 − S_n| = I_n → 0。
  25. 　∴ lim[n→∞] S_n = log 2
  27. 【誘導の構造】(1) は挟むための道具、(2) は和を作るための道具。
  28. どちらも (3) のために置かれており、単独では意味を持たない。
  29. 検算：S₁ = 1、S₂ = 0.5、S₃ ≒ 0.833、S₄ ≒ 0.583 … log 2 ≒ 0.693 の周りで振動しながら収束 ○

別解・ほかの見方

  • 漸化式を作ってから極限へ（部分積分で I_n と I_(n−2) を結ぶ）
  • 評価だけで極限を出す（漸化式を作らずに、上下から挟む）
  • 区分求積と組み合わせる（和の極限を積分に翻訳してから評価する）
  • 平均値の定理で不等式を作る
  • (1) の不等式が甘くて挟めないときは、被積分関数の評価を精密にし直す

落とし穴

  • (1) を独立した小問だと思い、(2)(3) で使わない（最大の失点原因）
  • はさみうちを使ったのに『はさみうちの原理より』と書かない
  • 下からの評価（0 < I_n）を書かず、上からだけで極限を主張する
  • 係数が 1 に近いことを理由に極限が 0 だと決めつける
  • n の偶奇で符号が変わる構造を見落とす
  • (1)を飛ばして(2)を解こうとする（誘導は使うために置かれている）

なぜ大事か

『(1)で不等式を示し (2)で極限を出す』という誘導の意味を読む。理三で差がつく最上位テーマ

東大での出方

理三で最も差がつく最上位テーマ。3段構成の誘導で出るのが典型で、(1) と (2) は易しく作られていることが多い。つまり (1)(2) を確実に取り、(3) に手を伸ばすのが正しい戦い方であり、完答できなくても部分点で大きく稼げる。

確認問題

  • J_n = ∫[0→1] xⁿ e^x dx について 0 < J_n < e/(n+1) を示し、極限を求めよ
  • 上の I_n について、n·I_n の極限を予想し、数値で確かめよ
  • I_n が単調減少であることを示せ

発展

極限が 0 になる速さ（オーダー）まで求めさせる問題。n·I_n や n²·I_n の極限を問う形で、より精密な評価が必要になる。ここまで来ると挟む不等式を自分で設計する力が問われる。

前提になるノード

  • 積分と不等式（面積比較・評価）
  • 定積分と漸化式（I_n を n で結ぶ）
  • 平均値の定理
  • 極限の3種の神器（はさみうち・区分求積・漸化式評価）
