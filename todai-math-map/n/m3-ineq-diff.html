微分を用いた不等式の証明

数学III ／ 微分法 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

不等式 f(x) ≧ g(x) を示す手順は決まっている。差 h(x) = f(x) − g(x) を作り、h の最小値が 0 以上であることを微分で示す。手順自体は単純だが、実力が出るのは h′(x) の符号がすぐに決まらない場面である。そこで止まらずに h″(x) へ進み、h′ の増減から h′ の符号を決め、それから h の増減を決める——この二段階、必要なら三段階の階段を昇れるかどうかで差がつく。そしてこの技術の本当の価値は、はさみうちの材料を自分で作れるようになることにある。数IIIの極限問題の多くは、実はこの力に支えられている。

こんなときに使う

  • 『〜を示せ』の形で不等式が与えられている
  • 相加相乗やコーシーでは処理できない（対数・指数・三角が混ざっている）
  • 極限を求めたいが直接計算できない → 挟むための不等式を自分で作る
  • h′(x) の符号が determined しない → ためらわず h″(x) を調べる
  • n を含む不等式 → 微分ではなく帰納法かもしれない、と一度疑う

手順

  1. 1. 差 h(x) =（左辺）−（右辺）を作る
  2. 2. 定義域を確認する（対数なら真数条件、分数なら分母 ≠ 0）
  3. 3. h′(x) を計算し、符号を調べる
  4. 4. 符号が決まらなければ h″(x) を調べ、h′ の増減を出す。h′ の値が分かる点（多くは端点）と組み合わせて h′ の符号を確定させる
  5. 5. h の増減表を書き、最小値または端点での値を求める
  6. 6. 最小値 ≧ 0 を示す。等号成立条件も必ず述べる

例題

x > 0 のとき、e^x > 1 + x + x²/2 が成り立つことを示せ。
解答
  1. h(x) = e^x − 1 − x − x²/2 とおく。示したいのは x > 0 で h(x) > 0。
  3. 【1回目の微分】
  4. h′(x) = e^x − 1 − x
  5. この符号は一目では決まらない。そこでもう一段進む。
  7. 【2回目の微分】
  8. h″(x) = e^x − 1
  9. x > 0 のとき e^x > 1 なので h″(x) > 0。
  10. よって h′(x) は x > 0 で単調増加。
  12. 【h′ の符号を確定させる】
  13. h′(0) = e⁰ − 1 − 0 = 0
  14. h′ は単調増加で h′(0) = 0 だから、x > 0 では h′(x) > 0。
  16. 【h の符号を確定させる】
  17. よって h は x > 0 で単調増加。
  18. h(0) = 1 − 1 − 0 − 0 = 0
  19. したがって x > 0 では h(x) > 0。
  21. ∴ x > 0 のとき e^x > 1 + x + x²/2　（証明終）
  23. 【構造】微分するたびに『0 での値が 0』という情報が使えて、符号が1段ずつ確定していく。
  24. この階段を降りていく形は、e^x の多項式による評価では常に現れる。
  25. 同じ手順で e^x > 1 + x + x²/2 + x³/6 も示せる。

別解・ほかの見方

  • 凹凸を使う：凸関数は接線の上側にあるので、接線の式との比較で不等式が出る
  • 平均値の定理を使う（区間の設定と c の存在範囲の明示が必要）
  • 相加相乗平均やコーシー・シュワルツで処理できないか先に検討する（使えれば微分より速い）
  • n を含む不等式は数学的帰納法。微分と併用することもある
  • 両辺の対数を取ってから微分する（積や累乗の形のとき）

落とし穴

  • 1回微分で符号が決まらないところで止まってしまう（この単元の最大の壁）
  • 定義域の端点での値を調べず、最小値の議論が完結しない
  • 等号成立条件を書かない
  • 『単調増加だから正』と書くだけで、起点の値（h(0) = 0 など）に触れない
  • 定義域を確認せず、対数の真数が負になる範囲まで議論してしまう
  • 1回微分で符号が決まらないときに2回微分へ進めない

なぜ大事か

差をとって微分し最小値を評価。はさみうちの材料を自分で作れるようになる

東大での出方

単独でも出るが、より多いのは極限問題の (1) として出る形。『(1) この不等式を示せ → (2) 極限を求めよ』という誘導では、(1) がはさみうちの材料そのものになっている。(1) を飛ばして (2) を解こうとすると、まず解けない設計になっている。

確認問題

  • x > 0 のとき log(1 + x) < x を示せ
  • x > 0 のとき x − x²/2 < log(1 + x) を示せ（2段階の微分が必要）
  • 上の2つを合わせて lim[x→0] log(1+x)/x を求めよ（はさみうちの材料として使う）

発展

3回以上微分が必要な不等式。また、示したい不等式が弱すぎて挟めないときに、より強い不等式を自分で立て直す判断。東大の最上位帯はここを要求してくる。
