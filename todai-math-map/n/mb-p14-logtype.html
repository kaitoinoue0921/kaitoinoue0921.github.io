⑭ 積・累乗型（対数をとる） a(n+1)=q·a(n)^p

数学B ／ 漸化式 ／ 東大での重要度 ★★★☆☆

要点

log は積を和に、累乗を係数に変える。a(n+1) = q·a(n)^p の両辺の対数を取ると log a(n+1) = p·log a(n) + log q で、b(n) = log a(n) は⑩そのもの。底は q や a(1) に合わせて選ぶと数がきれいになる。対数を取るには a(n) > 0 が必要なので、最初に帰納法で示す。

こんなときに使う

  • a(n+1) = q·a(n)^p、a(n+1)·a(n)^k = c などの積と累乗の漸化式
  • a(n+1) = √(a(n)·a(n−1)) のような積の平均 → 対数で3項間（⑮）
  • 答えが 2 の何乗の何乗、のように指数が爆発的に増える

手順

  1. 1. a(1) > 0 と帰納法で、すべての n で a(n) > 0 を示す
  2. 2. 底を決めて（q か a(1) の底に揃える）両辺の対数を取る
  3. 3. b(n) = log a(n) と置き、⑩で解く
  4. 4. a(n) = (底)^b(n) に戻す

例題

a(1) = 2、a(n+1) = 4a(n)² の一般項を求めよ。
解答
  1. a(1) > 0 で、a(n) > 0 なら a(n+1) > 0。よって常に a(n) > 0
  2. 底2の対数を取る：log₂ a(n+1) = 2 + 2log₂ a(n)
  3. b(n) = log₂ a(n) とおくと b(n+1) = 2b(n) + 2、b(1) = 1
  4. α = −2 より b(n) + 2 = 3·2ⁿ⁻¹
  5. ∴ a(n) = 2^(3·2ⁿ⁻¹ − 2)
  6. 検算：a(2) = 4·4 = 16 = 2⁴、3·2 − 2 = 4 ○

別解・ほかの見方

  • a(n+2) = a(n+1)²·a(n) なら対数で b(n+2) = 2b(n+1) + b(n)（⑮）
  • 答えの指数が整数かどうかを問う整数問題に化けることがある

落とし穴

  • a(n) > 0 を示さずに log を取る
  • log(4a(n)²) = 4 + 2log a(n) としてしまう（log 4 = 2 を忘れる）
  • 最後に指数に戻すときに底を間違える
  • a(n) > 0 を示さずに対数を取る／底を何にするかで計算量が変わる

なぜ大事か

掛け算と累乗の漸化式は、対数で足し算と掛け算の漸化式（⑩）になる

東大での出方

単独より、積の極限や整数の桁数問題の中で使う。

確認問題

  • a(1) = 3、a(n+1) = a(n)³ の一般項を求めよ（答：3^(3ⁿ⁻¹)）
  • a(1) = 10、a(n+1) = 10a(n)² の一般項を求めよ（答：10^(2ⁿ − 1)）

発展

p > 1 なら指数部が pⁿ で増える（二重指数）。ニュートン法の収束の速さ（誤差が2乗で減る）もこの構造。
