⑥ (等差)×(等比)の和：S−rS

数学B ／ 数列 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

S = Σ(等差)×(等比) に公比 r を掛けると、各項が1つ右にずれる。元の S から引くと、等差部分の『差（公差）』だけが残り、それは等比数列の和になる。つまり『rを掛けてずらす』は、等差部分に階差を取らせる操作。

こんなときに使う

  • Σ k·2ᵏ、Σ (2k−1)·3ᵏ⁻¹ のように、kの1次式と等比数列の積
  • 期待値の計算で k·pᵏ⁻¹ の和が出てきた
  • 数IIIで Σ k·xᵏ の極限を問われた

手順

  1. 1. S を項を並べて書く（最初の2〜3項と最後の項）
  2. 2. rS を、1つ右にずらして S の下に書く
  3. 3. S − rS を計算する：真ん中は公差×等比の和、両端に初項と −(最後の項×r) が残る
  4. 4. 等比の和を計算し、(1 − r) で割る
  5. 5. n=1, 2 で検算する

例題

S = Σ[k=1〜n] k·2ᵏ を求めよ。
解答
  1. S = 1·2 + 2·2² + 3·2³ + … + n·2ⁿ
  2. 2S = 1·2² + 2·2³ + … + (n−1)·2ⁿ + n·2ⁿ⁺¹
  3. S − 2S = 2 + 2² + 2³ + … + 2ⁿ − n·2ⁿ⁺¹
  4. −S = (2ⁿ⁺¹ − 2) − n·2ⁿ⁺¹
  5. ∴ S = (n − 1)·2ⁿ⁺¹ + 2
  6. 検算：n=2 で 2 + 8 = 10、1·8 + 2 = 10 ○

別解・ほかの見方

  • 微分を使う：Σ xᵏ = (xⁿ⁺¹ − x)/(x − 1) を x で微分して x を掛ける（数III）
  • k² · rᵏ の和は S − rS を2回行う
  • 答えを (An + B)·2ⁿ + C と置いて n=1,2,3 から係数を決める方法もある

落とし穴

  • rS の最後の項 n·2ⁿ⁺¹ を引き忘れる
  • S − rS の真ん中の等比数列の項数を数え間違える
  • r = 1 のときは単なる Σk になることを書かない（rが文字のとき）
  • 引いたあとの最後の項（−n·rⁿ⁺¹ など）を落とす／r=1 の場合分け

なぜ大事か

Σ k·rᵏ 型は公式がない。ずらして引くことで等比の和に変える、という手の動きが答え

東大での出方

期待値や確率漸化式の解の和で出てくる。数IIIの極限 Σ k·rᵏ（|r|<1）と組み合わさることもある。

確認問題

  • Σ[k=1〜n] k·3ᵏ⁻¹ を求めよ（答：{(2n−1)·3ⁿ + 1}/4）
  • Σ[k=1〜n] k/2ᵏ を求め、n→∞ で 2 に近づくことを確かめよ

発展

なぜ r を掛けるのか：Σ a(k)rᵏ で a(k) が d次多項式なら、(1−r)を掛けるたびに a の階差が取られ、d+1回で等比の和だけになる。
