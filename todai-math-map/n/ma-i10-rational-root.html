整10 有理数解の定理（定数項の約数／最高次の係数の約数）

数学A ／ 整数 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

整数係数の方程式 aₙxⁿ + … + a₀ = 0 が有理数解 p/q（互いに素）をもつなら、p は定数項 a₀ の約数、q は最高次の係数 aₙ の約数になる。代入して分母を払うと aₙpⁿ + … + a₀qⁿ = 0 で、a₀qⁿ 以外は p の倍数なので p | a₀qⁿ、q と p は互いに素なので p | a₀（q についても同様）。候補が有限個なので、全部代入すれば『有理数解をもたない』ことまで示せる。

こんなときに使う

  • 『x³ − 3x + 1 = 0 は有理数解をもたないことを示せ』
  • 3次以上の方程式を因数定理で解くとき、最初の1つの解を探す
  • cos 20° などが無理数であることを、満たす3次方程式から示す

手順

  1. 1. 方程式が整数係数であることを確かめる（分数係数なら分母を払う）
  2. 2. 定数項の約数 p と最高次の係数の正の約数 q を全部書き、候補 ±p/q を作る
  3. 3. 候補を代入する。0 になれば因数定理で因数分解へ
  4. 4. どれも 0 にならなければ『有理数解をもたない』
  5. 5. 証明問題では、p/q とおいて上の理由（p | a₀、q | aₙ）も書く

例題

方程式 x³ − 3x + 1 = 0 は有理数解をもたないことを示せ。
解答
  1. 有理数解 p/q（p, q は互いに素、q > 0）をもつと仮定する
  2. 代入して分母を払うと p³ − 3pq² + q³ = 0
  3. q³ = −p(p² − 3q²) より p | q³。p, q は互いに素なので p = ±1。同様に p³ = q(3pq − q²) より q | p³ で q = 1
  4. ∴ 有理数解の候補は ±1 だけ。x = 1 で 1 − 3 + 1 = −1、x = −1 で −1 + 3 + 1 = 3 で、どちらも 0 でない
  5. ∴ 有理数解をもたない

別解・ほかの見方

  • 3x³ + x² + x − 2 = 0 は候補 ±1, ±2, ±1/3, ±2/3 を試すと x = 2/3 が解
  • cos 20° は 4x³ − 3x = 1/2（3倍角の公式）、つまり 8x³ − 6x − 1 = 0 の解で、これが有理数解をもたないので無理数
  • 最高次の係数が 1 なら、有理数解は必ず整数になる

落とし穴

  • 候補を整数だけにする（最高次の係数が 1 でないとき）
  • 負の候補を忘れる
  • 分数係数のまま定理を使う
  • 候補を整数（定数項の約数）だけにして、分母に最高次の係数の約数がくる候補を落とす

なぜ大事か

整数係数の方程式の有理数解は、候補が有限個に決まる。代入すれば有無が分かる

東大での出方

東大では『cos(2π/7) は無理数か』のように、三角関数・複素数の値の無理数性を3次方程式に帰着させる形で出る。整9 の背理法とセットで覚える。

確認問題

  • 3x³ + x² + x − 2 = 0 の有理数解を求めよ（答：x = 2/3）
  • x³ + 2x² − 2 = 0 は有理数解をもたないことを示せ（答：候補は ±1, ±2。代入すると 1, −1, 14, −2 でどれも 0 でない）

発展

x² − n = 0 に使うと、有理数解は整数に限られる。だから √n が有理数なら n は平方数。整9 の √2 の証明がこの定理の特別な場合だと分かる。
