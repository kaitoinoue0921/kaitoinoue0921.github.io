実数・絶対値・平方根の扱い

数学I ／ 数と式 ／ 東大での重要度 ★★☆☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

絶対値の場合分けが雑になることは、全分野を通じて最も多い減点原因の一つ。|x|の定義（xが0以上ならx、負なら−x）に忠実に戻れば、どんなに複雑な式でも機械的に処理できる。√(x²)=|x|であってxではない、という一点を体に染み込ませておくことが、後の軌跡・不等式・数IIIの計算すべての土台になる。

こんなときに使う

  • √の中に文字の2乗があれば、絶対値をつけて外す（符号の場合分けを忘れない）
  • |x−a|<bの形は−b<x−a<bに直す（距離のイメージで理解する）
  • 絶対値を含む方程式・不等式は、中身の符号が変わる点で区間を分ける

手順

  1. 1. 絶対値の中身が0になる点を求める
  2. 2. その点で場合分けし、各区間で絶対値を外した式に直す
  3. 3. 各区間で計算し、最後に区間の条件と解を照合する

例題

|x−2|+|x+1|=5 を解け。
解答
  1. 場合分けの境目はx=2とx=−1。
  2. (i) x<−1: −(x−2)−(x+1)=5 → −2x+1=5 → x=−2（x<−1を満たす）
  3. (ii) −1≦x<2: (2−x)+(x+1)=3で5にならず解なし
  4. (iii) x≧2: (x−2)+(x+1)=5 → 2x−1=5 → x=3（x≧2を満たす）
  5. ∴ x=−2, 3

別解・ほかの見方

  • 図形的に『2点からの距離の和』とみなして考える方法もある（この問題なら2と−1からの距離の和が5）

落とし穴

  • 場合分けの境界をどちらの区間に含めるか書かない
  • √(x²)=xと誤って符号を落とす
  • 場合分けした各区間で、出た解がその区間の条件を満たすか確認しない
  • √(x^2)=|x| を書かずに符号ミス

なぜ大事か

絶対値の場合分けは全分野に出る。ここの雑さが減点の常連

東大での出方

単独出題は少ないが、積分区間の分割（絶対値付き積分）や軌跡の除外点の議論など、あらゆる場面で正確さが要求される基礎技術。

確認問題

  • |2x−1|≦3 を解け
  • |x|+|x−3|=3 を解け

発展

3つ以上の絶対値が入った式、または絶対値の中に絶対値がある入れ子の式の処理。
