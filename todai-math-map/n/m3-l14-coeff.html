極14 極限値から係数を決める（分母→0なら分子→0）

数学III ／ 極限 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

lim[x→a] g(x)/h(x) = c（有限）で h(x) → 0 なら、g(x) = {g(x)/h(x)}·h(x) → c·0 = 0 なので、分子 → 0 が必要になる。これで係数の関係式が1本出る。ただしこれは必要条件なので、その関係を代入して約分（因数分解・有理化）し、極限が本当に c になるかを計算して、残りの係数を決める。

こんなときに使う

  • 『lim[x→1](x² + ax + b)/(x − 1) = 3 となる a, b を求めよ』
  • 分母が 0 に近づき、分子に未知の係数がある極限
  • √ を含む分子で係数を決める問題（有理化が必要）

手順

  1. 1. 分母 → 0 を確かめる
  2. 2. 極限が有限なので分子 → 0 が必要、と書いて係数の関係式を出す
  3. 3. 関係式を代入して、分子を (x − a) × … の形にする（因数分解・有理化）
  4. 4. 約分して極限を計算し、与えられた値と等しいとおいて残りを決める
  5. 5. 求めた値で確かに条件を満たすことを書く（十分性）

例題

lim[x→1](x²+ax+b)/(x−1)=3 となる a,b を求めよ。
解答
  1. 分母 →0 なので分子 →0 が必要：1+a+b=0、b=−1−a。
  2. このとき分子 =x²+ax−1−a=(x−1)(x+1+a) なので
  3. lim[x→1](x+1+a)=2+a=3
  4. ∴ a=1, b=−2

別解・ほかの見方

  • x → ∞ で lim(√(x² + ax) − bx) = 1 のような形は、b = 1 が必要（b ≠ 1 なら発散）を先に出す
  • 分母 → 0 でも極限が ∞ でよい問題では、分子 → 0 は要らない（条件を読む）
  • lim[x→0](a + b cos x)/x² = 1 は a + b = 0 が必要、そのあと (1 − cos x)/x² → 1/2 を使う

落とし穴

  • 分子 → 0 を『十分条件』のように扱い、極限の計算を省く
  • 「分子 →0」は必要条件。その後に極限を計算して条件を満たすことを確認するまでが解答。
  • 分子 → 0 から係数を決めたあと、実際に極限を計算して条件を満たすか確かめない

なぜ大事か

分母 → 0 で極限が有限なら、分子 → 0 が必要。これで係数の関係が1本出る

東大での出方

東大で単独では出にくいが、整式の決定や関数の連続性・微分可能性の条件（x = a でつながる条件）として部品で出る。

確認問題

  • lim[x→2](a√(x+2)−4)/(x−2)=b となる a,b を求めよ。（答：a=2, b=1/2）

発展

『分母 → 0 なら分子 → 0』は、微分可能性の条件（f が x = a で微分可能なら連続）と同じ構造。lim{f(x) − f(a)}/(x − a) が有限なら f(x) − f(a) → 0。
