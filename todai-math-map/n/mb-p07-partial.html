⑦ 部分分数分解で隣同士を消す

数学B ／ 数列 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

1/{k(k+1)} = 1/k − 1/(k+1) のように『f(k) − f(k+1)』の形に書ければ、和は f(1) − f(n+1) だけが残る（望遠鏡和）。分母の因数が2つ離れていれば (1/2)(1/k − 1/(k+2)) となり、消え残りが前後に2個ずつ出る。残る項の数は『分母の因数の間隔』に等しい。

こんなときに使う

  • 分母が k の積に因数分解できる分数の和
  • 4k² − 1 = (2k−1)(2k+1) のように因数分解できる形が隠れている
  • 数IIIで Σ 1/{k(k+1)} の極限（無限級数）

手順

  1. 1. 分母を因数分解する
  2. 2. 1/{(k+a)(k+b)} = 1/(b−a) · {1/(k+a) − 1/(k+b)} に分ける（係数 1/(b−a) を忘れない）
  3. 3. k = 1, 2, 3 と最後の2〜3項を書き並べ、消える組を線で結ぶ
  4. 4. 残った項だけを集める
  5. 5. n=1 で検算する

例題

Σ[k=1〜n] 1/{k(k+2)} を求めよ。
解答
  1. 1/{k(k+2)} = (1/2){1/k − 1/(k+2)}
  2. 書き並べると (1/1 − 1/3) + (1/2 − 1/4) + (1/3 − 1/5) + … + (1/(n−1) − 1/(n+1)) + (1/n − 1/(n+2))
  3. 前から 1/1, 1/2、後ろから −1/(n+1), −1/(n+2) が残る
  4. ∴ (1/2){1 + 1/2 − 1/(n+1) − 1/(n+2)} = 3/4 − (2n+3)/{2(n+1)(n+2)}
  5. 検算：n=1 で 1/3。3/4 − 5/12 = 1/3 ○

別解・ほかの見方

  • 3因数 1/{k(k+1)(k+2)} = (1/2){1/(k(k+1)) − 1/((k+1)(k+2))}：両端の因数で差を作る
  • k/(k+1)! = 1/k! − 1/(k+1)! のように階乗でも差の形が作れる

落とし穴

  • 係数 1/2 を付け忘れる（最頻出）
  • 1つ飛ばしで消えるのに、残る項を1個ずつしか書かない
  • n が小さいときに書き並べで使った項が存在しない（n=1）ことに気づかず式が崩れる
  • 係数（1/2 など）を付け忘れる／1つ飛ばしで消えるとき残る項の数を間違える

なぜ大事か

分数の和を閉じた形にする唯一の手段。数IIIの無限級数の収束計算に直結する

東大での出方

数IIIの無限級数・区分求積の準備として頻出。東大では和を閉じた形にできるか判断させる場面で使う。

確認問題

  • Σ[k=1〜n] 1/(4k² − 1) を求めよ（答：n/(2n+1)）
  • Σ[k=1〜∞] 1/{k(k+1)(k+2)} を求めよ（答：1/4）

発展

差の形にできない和（Σ 1/k など）は閉じた形にならない。その場合は積分で評価する（数III：区分求積・積分と不等式）。
