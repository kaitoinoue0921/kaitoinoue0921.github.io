⑬ 分数型（逆数をとる） a(n+1)=a(n)/(p·a(n)+q)

数学B ／ 漸化式 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

a(n+1) = a(n)/(p·a(n) + q) の逆数を取ると 1/a(n+1) = p + q·(1/a(n))。b(n) = 1/a(n) と置けば⑩（q = 1 なら等差数列）。逆数を取る前に、すべての n で a(n) ≠ 0 であることを示す必要がある（帰納法か、正であることの確認）。これを書かないと減点される。

こんなときに使う

  • 分子が a(n) の定数倍だけ、分母が a(n) の1次式
  • a(n+1)·a(n) を含む式（例：a(n+1) − a(n) = −2a(n+1)a(n)）→ 両辺を a(n+1)a(n) で割ると逆数の差になる
  • 分子に定数項もある一般形 (p·a + q)/(r·a + s) なら⑱

手順

  1. 1. a(1) > 0 などから、帰納法ですべての n で a(n) > 0（≠ 0）を示す
  2. 2. 両辺の逆数を取る
  3. 3. b(n) = 1/a(n) と置いて⑩または等差数列として解く
  4. 4. a(n) = 1/b(n) に戻す

例題

a(1) = 1、a(n+1) = a(n)/(2a(n) + 1) の一般項を求めよ。
解答
  1. a(1) > 0 で、a(n) > 0 なら a(n+1) > 0。よってすべての n で a(n) > 0（特に ≠ 0）
  2. 逆数を取ると 1/a(n+1) = (2a(n) + 1)/a(n) = 2 + 1/a(n)
  3. b(n) = 1/a(n) は初項 1、公差 2 の等差数列なので b(n) = 2n − 1
  4. ∴ a(n) = 1/(2n − 1)
  5. 検算：a(2) = 1/3。1/(2·2 − 1) = 1/3 ○

別解・ほかの見方

  • a(n+1) = 2a(n)/(a(n) + 2) なら逆数で 1/a(n+1) = 1/2 + 1/a(n)（等差）
  • a(n+1) = a(n)/(a(n) + 3) なら 1/a(n+1) = 3·(1/a(n)) + 1 で⑩

落とし穴

  • a(n) ≠ 0 の証明を省く
  • 逆数を取るときに分母分子を逆にし忘れて 1/a(n+1) = a(n)/(…) と書く
  • 最後に逆数に戻し忘れて b(n) を答える
  • a(n) ≠ 0 の確認を書かない

なぜ大事か

分子が a(n) だけの分数型は、逆数で一気に⑩になる

東大での出方

単独で出ることは少ないが、関数の反復（f(f(…f(x))) ）や図形の繰り返しで出てくる分数型の前提。

確認問題

  • a(1) = 1、a(n+1) = a(n)/(a(n) + 3) の一般項を求めよ（答：a(n) = 2/(3ⁿ − 1)）
  • a(n+1) − a(n) = −a(n+1)a(n)、a(1)=1 のとき a(n) を求めよ（答：1/n）

発展

一般の一次分数変換 (pa+q)/(ra+s) で不動点が 0 の1つだけ…ではなく、0 が不動点のとき逆数で⑩に落ちる、と見ると⑱との関係が分かる。
