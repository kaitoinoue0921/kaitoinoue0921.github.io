【東大型】複素数平面と図形

東大レイヤー ／ 出題テーマ ／ 東大での重要度 ★★★★☆

アプリで開く →

要点

複素数平面の強みは、回転と拡大を掛け算1つで書けることに尽きる。ベクトルでも座標でも書ける問題を、複素数なら数行で処理できる場面があり、その見極めが得点差になる。特に、回転が絡む図形条件と、|z| や arg で書かれた軌跡は複素数平面の独壇場である。逆に、実部・虚部に分解して計算を始めると式が膨張するので、できるだけ z のまま、あるいは共役 z̄ を使って処理するのが原則になる。

こんなときに使う

  • 回転が出てくる → 掛け算 e^(iθ) で書く
  • 『点 α を中心に θ 回転』→ α + (z − α)e^(iθ)
  • |z − a| = |z − b| → 2点から等距離、つまり垂直二等分線
  • |z − a| = r → 中心 a、半径 r の円
  • |z − a| : |z − b| が一定 → アポロニウスの円
  • arg((z−a)/(z−b)) が一定 → 円弧（一定角）
  • 1 の n 乗根 → 正 n 角形。和は 0

手順

  1. 1. 図形の条件を、絶対値・偏角・共役のいずれかで書く
  2. 2. 実部と虚部に分けたくなっても、まず z のまま処理できないか考える
  3. 3. 軌跡なら、w = f(z) を z について解き直し（逆に解く）、z の条件に代入する
  4. 4. 得られた w の条件を図形として読む
  5. 5. 除外点を確認する（分母が 0 になる点、対応しない点）

例題

|z| = 1 かつ z ≠ 1 を満たす複素数 z に対し、w = (z + 1)/(z − 1) とおく。z が動くとき、w はどのような図形を描くか。
解答
  1. 実部・虚部に分けると計算が膨張する。w を z について解き直すのが定石。
  3. 【逆に解く】
  4. w(z − 1) = z + 1
  5. wz − w = z + 1
  6. z(w − 1) = w + 1
  7. w = 1 のときこの式は 0 = 2 となり不合理なので w ≠ 1。よって
  8. 　z = (w + 1)/(w − 1)
  10. 【条件 |z| = 1 に代入する】
  11. |(w + 1)/(w − 1)| = 1
  12. すなわち |w + 1| = |w − 1|
  14. 【図形として読む】
  15. これは『w が点 −1 と点 1 から等距離にある』という条件。
  16. つまり w は 2点 −1, 1 を結ぶ線分の垂直二等分線、すなわち虚軸上にある。
  18. 【逆に、虚軸上の点はすべて現れるか（十分性）】
  19. w = it（t は実数）とすると z = (it + 1)/(it − 1)。
  20. |z| = |it + 1| / |it − 1| = √(1 + t²) / √(1 + t²) = 1 となり条件を満たす。
  21. また z = 1 となるのは it + 1 = it − 1、すなわち 1 = −1 のときで、これは起こらない。
  22. よって z ≠ 1 も満たされる。
  24. ∴ w は虚軸全体を描く。
  26. 【要点】w を z で表したまま考えず、z を w で表し直して既知の条件に代入する。
  27. この『逆に解く』手順は、複素数平面の軌跡問題のほぼ全てで使える。

別解・ほかの見方

  • 実部・虚部に分ける（最後の手段。式が膨張しやすい）
  • 共役を使う：|z|² = z·z̄、実数条件は z = z̄、純虚数条件は z + z̄ = 0
  • 回転で書き直す：正三角形の条件は γ − α = (β − α)·e^(±iπ/3)
  • ベクトルや座標に翻訳する（回転がない問題なら、そのほうが速いこともある）
  • 1 の n 乗根の和が 0 であることを使う（正 n 角形の重心が原点）

落とし穴

  • 実部・虚部に分解して計算量が爆発する
  • 偏角の一般角（+2kπ）を落として、n 乗根の個数を数え違える
  • 軌跡を求めたあと、除外点や十分性の確認をしない
  • 回転の中心を原点に移してから戻す、という手順を飛ばす
  • |z| = 1 を z = 1 と読み違える
  • 実部虚部に分解して計算が膨張する

なぜ大事か

回転・軌跡・n乗根。ベクトルや座標より圧倒的に短く書ける場面を見抜く

東大での出方

東大では複素数平面が単独の大問になる年と、まったく出ない年がある。出るときは回転か軌跡のどちらかで、いずれも『複素数のまま処理できるか』が問われる。ベクトルや座標でも解けるが計算量が数倍になる、という設計になっていることが多い。

確認問題

  • 点 1 + i を、点 2 を中心に π/2 だけ回転させた点を求めよ
  • |z − 1| = 2|z + 1| を満たす z の軌跡を求めよ（アポロニウスの円）
  • z⁵ = 1 の解をすべて求め、その和が 0 になることを確かめよ

発展

回転と拡大を組み合わせた変換（1次分数変換）が、円を円または直線に写すという性質。高校範囲では一般論は扱わないが、個別の問題で『円が直線に写った』という現象に出会ったときに驚かなくなる。
