微9 接線の本数は接点 t の方程式の実数解の個数

数学II ／ 微分積分 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

曲線 y = f(x) 上にない点 (p, q) を通る接線は、接点を (t, f(t)) とおいた接線 y = f′(t)(x − t) + f(t) が (p, q) を通る条件 q = f′(t)(p − t) + f(t) を、t の方程式とみて解く。3次関数では接点が違えば接線も違うので、接線の本数 = この t の方程式の異なる実数解の個数になる。本数を問う問題は、t の3次方程式の解の個数（微4・微17）に帰着する。4次関数では2点で接する接線があり、接点の数と接線の本数がずれることがある。

こんなときに使う

  • 『点 A から曲線に引いた接線の方程式』
  • 『点 (p, q) から引ける接線の本数』
  • 『接線が3本引ける点の範囲を図示せよ』

手順

  1. 1. 接点を (t, f(t)) とおき、接線 y = f′(t)(x − t) + f(t) を書く
  2. 2. 通る点 (p, q) を代入して t の方程式にする
  3. 3. 方程式を解いて t を戻し、接線を答える
  4. 4. 本数を問うなら、t の方程式の異なる実数解の個数を数える（定数分離か極値の符号）
  5. 5. 3次関数では『接点が異なれば接線も異なる』と一言書く

例題

点 (1,−3) から放物線 y=x² に引いた接線の方程式を求めよ。
解答
  1. 接点を (t,t²) とすると接線は y=2t(x−t)+t²=2tx−t²。
  2. (1,−3) を通るので −3=2t−t²、t²−2t−3=0、(t−3)(t+1)=0。
  3. t=3 のとき y=6x−9、t=−1 のとき y=−2x−1。
  4. ∴ y=6x−9, y=−2x−1

別解・ほかの見方

  • 曲線上の点を通る接線も、その点で接する1本だけとは限らない（y = x³ の (1, 1) を通る接線は t = 1, −1/2 の2本）
  • 接線が3本引ける点 (p, q) の領域は、t の3次方程式の (極大値)×(極小値) < 0 を p, q の不等式に直す（微17）
  • 放物線 y = x² では、外の点 (p, q) から2本引ける条件は q < p²

落とし穴

  • 通る点を接点と思い、f′(p) を傾きにする
  • 4次関数などで、接点の個数をそのまま接線の本数とする
  • 点が曲線上にあっても、その点以外で接する接線がありうる。「点 A を通る接線」と「点 A における接線」は別物。
  • 通る点を接点と思い込み、その点での微分係数を傾きにする

なぜ大事か

接点を t とおけば、『点を通る接線』の問題は t の方程式の解の問題になる

東大での出方

東大・京大で『接線が3本引ける点の範囲を図示せよ』は定番。t の3次方程式が異なる3実解をもつ条件 ⇔ 極大値×極小値 < 0 に持ち込む。

確認問題

  • 点 (0,2) から曲線 y=x³−x に引いた接線の方程式を求めよ。（答：y=2x+2）

発展

3次関数では、変曲点での接線と曲線で平面が分けられ、どの部分にある点かで引ける接線の本数が1本・2本・3本と決まる。
