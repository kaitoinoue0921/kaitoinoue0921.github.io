微7 凸性で不等式（グラフは接線より上・弦より下）

数学III ／ 微分法 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

f″(x) > 0（下に凸）の区間では、グラフはどの点での接線よりも上にあり、2点を結ぶ弦（割線）よりも下にある。だから f(x) ≧ f(a) + f′(a)(x − a)（接線の不等式）と、端の2点を結ぶ直線との不等式が、差をとって何度も微分しなくても見通せる。eˣ ≧ 1 + x、log x ≦ x − 1、sin x ≦ x（x ≧ 0）はすべて接線の不等式。上に凸（f″ < 0）なら向きが逆になる。記述式では、差をとった関数を微分して一度示すか、凸であることを根拠として明記する。

こんなときに使う

  • eˣ ≧ 1 + x、log x ≦ x − 1 のような、接線との比較
  • {f(a) + f(b)}/2 と f((a + b)/2) の大小
  • sin x ≧ (2/π)x（0 ≦ x ≦ π/2）のような、弦との比較

手順

  1. 1. f″ の符号を調べ、凸の向きを決める
  2. 2. 接線と比べるなら接点 a を決め、y = f(a) + f′(a)(x − a) を書く
  3. 3. 弦と比べるなら両端の2点を結ぶ直線を書く
  4. 4. 下に凸なら『グラフ ≧ 接線』『グラフ ≦ 弦』、上に凸なら逆
  5. 5. 等号が成り立つ点（接点・両端）を書く

例題

0 ≦ x ≦ π/2 のとき sin x ≧ (2/π)x を示せ。
解答
  1. f(x) = sin x は 0 < x < π/2 で f″(x) = −sin x < 0 なので上に凸。
  2. 上に凸なグラフは、両端 (0, 0)、(π/2, 1) を結ぶ弦 y = (2/π)x より上にある。
  3. よって 0 ≦ x ≦ π/2 で sin x ≧ (2/π)x。等号は x = 0, π/2。
  4. （差で書くなら g(x) = sin x − (2/π)x とおくと g″(x) < 0、g(0) = g(π/2) = 0 なので g は区間で 0 以上）

別解・ほかの見方

  • log x ≦ x − 1 は、上に凸な y = log x と x = 1 での接線 y = x − 1 の比較
  • (eᵃ + eᵇ)/2 ≧ e^((a + b)/2) は、下に凸な eˣ の弦の中点がグラフより上にあること
  • 3点以上ではイェンゼンの不等式 f((x₁ + … + xₙ)/n) ≦ {f(x₁) + … + f(xₙ)}/n（下に凸）

落とし穴

  • 上に凸なのに『接線より上』とする（上に凸は接線より下、弦より上）
  • f″ の符号を調べた区間と、示したい不等式の区間がずれている
  • 上に凸と下に凸を取り違え、不等号の向きを逆にする

なぜ大事か

f″ の符号だけで、グラフと接線・弦の上下が決まり、不等式の見当がつく

東大での出方

東大では積分の評価や極限のはさみうちで、eˣ ≧ 1 + x や sin x ≧ (2/π)x を部品として使う。グラフで見当をつけ、証明は差の微分で書くのが安全。

発展

弦の不等式を n 点に広げたのがイェンゼンの不等式。相加平均 ≧ 相乗平均も、上に凸な log x にイェンゼンを使うと出る。
