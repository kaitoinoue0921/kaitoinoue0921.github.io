解の配置問題

数学I ／ 2次関数 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

2次方程式の解の配置（特定の区間に解があるか）を決めるには、判別式・軸の位置・区間の端点での関数の値、という3つの情報が必要で、どれか1つでも欠けると誤った結論に至る。この3点セットは、東大が繰り返し出す『方程式の実数解の個数』問題の最も基本的な型であり、ここでの精度が数III の定数分離の議論にそのまま接続する。

こんなときに使う

  • 『区間内に解を持つ』『異なる2つの正の解を持つ』という条件は判別式・軸・端点の3点セットで攻める
  • 端点の値の符号だけで済ませようとしたら、軸の確認を忘れていないか疑う

手順

  1. 1. 判別式で実数解の存在を確認する
  2. 2. 軸の位置が求める区間内にあるか確認する
  3. 3. 区間の端点でのf(x)の値の符号を確認する
  4. 4. 3つの条件をすべて満たすかで範囲を決める

例題

x²−2ax+a+2=0が異なる2つの正の解を持つようなaの範囲を求めよ。
解答
  1. f(x)=x²−2ax+a+2とする。
  2. (i) D/4=a²−a−2>0 → (a−2)(a+1)>0 → a<−1またはa>2
  3. (ii) 軸 x=a>0
  4. (iii) f(0)=a+2>0 → a>−2
  5. 3つの共通範囲：a>2（(i)のa>2かつ(ii)a>0かつ(iii)a>−2）

別解・ほかの見方

  • 解と係数の関係（両解の和・積の符号）で攻める方法もある：和2a>0かつ積a+2>0かつD>0

落とし穴

  • 端点の値だけ確認して軸の条件を落とす（放物線が区間の外側で2回交わる場合を見逃す）
  • 3つの条件のうち1つでも忘れると誤った範囲になる
  • 端点の値の符号だけで済ませて軸条件を落とす

なぜ大事か

判別式・軸・端点の値の3点セット。方程式の解の個数問題の原型

東大での出方

方程式の実数解の個数を問う問題の基本形。数IIIでは定数分離とグラフの交点を数える方法に発展する。

確認問題

  • x²−2ax+a²−1=0が−1と1の間に異なる2つの解を持つaの範囲を求めよ
