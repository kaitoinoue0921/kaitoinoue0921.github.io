【東大型】関数の決定・不等式の成立条件

東大レイヤー ／ 出題テーマ ／ 東大での重要度 ★★★★☆

要点

『すべての x で成り立つ』と『ある x で成り立つ』は、まったく違う条件である。前者（∀）は最小値・最大値の問題に翻訳され、後者（∃）は解の存在条件に翻訳される。この翻訳ができれば、条件つきの不等式は関数の値域を調べる標準問題に落ちる。東大はこの読み分けを、文章の中に紛れ込ませる形で問うてくる。だから問題文を読んだら、まず ∀ か ∃ かを確定させてから式を書き始めること。

こんなときに使う

  • 『すべての x に対して f(x) ≧ 0』→ f の最小値 ≧ 0
  • 『ある x に対して f(x) ≧ 0』→ f の最大値 ≧ 0
  • 『すべての x で f(x) ≧ g(x)』→ 差 h = f − g の最小値 ≧ 0
  • 定数 a が分離できる → a ≧（何かの最大値）または a ≦（何かの最小値）
  • 変数が2つある → 片方を固定して、もう片方で処理する（予選決勝法）
  • 『成り立つような a の最小値』→ 分離した関数の最大値がそのまま答え

手順

  1. 1. ∀ か ∃ かを確定させる（ここを間違えると全部無駄になる）
  2. 2. 定数を分離できるか試す（a ≧ g(x) の形にする）
  3. 3. 分離できたら、g の最大値または最小値を求める
  4. 4. 分離できなければ、差を取って微分する
  5. 5. 定義域の端での挙動（極限）を必ず調べる
  6. 6. 等号が成立する点を確認する

例題

すべての x > 0 に対して log x ≦ ax が成り立つような正の定数 a の最小値を求めよ。
解答
  1. 【∀ であることを確認】『すべての x > 0 に対して』なので ∀ の問題。
  2. したがって最大値・最小値の問題に翻訳できる。
  4. 【定数を分離する】x > 0 なので両辺を x で割ってよい。
  5. 　log x ≦ ax　⇔　(log x)/x ≦ a
  6. これがすべての x > 0 で成り立つ条件は
  7. 　a ≧ （関数 f(x) = (log x)/x の最大値）
  9. 【f の最大値を求める】
  10. f(x) = (log x)/x　（x > 0）
  11. f′(x) = { (1/x)·x − (log x)·1 } / x² = (1 − log x)/x²
  13. f′(x) = 0 　⇔ 　log x = 1 　⇔ 　x = e
  14. 　0 < x < e のとき log x < 1 なので f′ > 0（増加）
  15. 　x > e のとき log x > 1 なので f′ < 0（減少）
  17. よって x = e で最大となり、最大値は f(e) = (log e)/e = 1/e。
  19. 【端の挙動も確認しておく】
  20. x → +0 のとき log x → −∞ なので f(x) → −∞。
  21. x → ∞ のとき f(x) → 0（分母のほうが速く増える）。
  22. したがって x = e での値が全体の最大値で間違いない。
  24. 【結論】a ≧ 1/e が条件。
  26. ∴ a の最小値は 1/e
  28. 【確認】a = 1/e のとき、x = e で log e = 1、ax = e/e = 1 となり等号が成立する。
  29. つまり y = x/e は曲線 y = log x の接線になっている。図で見ると納得しやすい。

別解・ほかの見方

  • ∃ の場合：『ある x で f(x) ≧ 0』は f の最大値 ≧ 0
  • 定数分離できないときは、差を取って微分する
  • 変数が2つあるときは予選決勝法（片方を固定 → もう片方を動かす）
  • 接線条件として幾何的に解く（この問題は『y = ax が y = log x の接線になる a』と同じ）
  • グラフを描いて視覚的に確認する（東大は図的な理解を要求してくる）

落とし穴

  • ∀ と ∃ を取り違える（答えが正反対になる）
  • 定数分離するとき、割る量の符号を確認しない
  • 定義域の端での極限を調べず、最大値の存在を見誤る
  • 等号成立を確認しない（『最小値』を聞かれているのに到達可能か不明のまま）
  • 2変数のとき、片方を固定した段階の結論をそのまま最終解答にする
  • ∀と∃の翻訳を取り違える

なぜ大事か

『すべてのxで成り立つ』『あるxで成り立つ』の違いを最小値・最大値に翻訳する

東大での出方

東大は ∀ と ∃ の読み分けを、問題文の日本語に埋め込んで問う。『任意の』『常に』は ∀、『存在する』『少なくとも1つ』は ∃。数III の関数と組み合わせると難易度が上がるが、翻訳さえできれば増減表を書く標準問題になる。

確認問題

  • すべての実数 x に対して x² + 2ax + 3a > 0 が成り立つ a の範囲を求めよ
  • すべての x > 0 に対して eˣ ≧ ax が成り立つ a の最大値を求めよ
  • 『ある x > 0 で log x ≧ ax』となる a の範囲を求め、∀ の場合と比べよ

発展

条件が2重になっている場合（『すべての x に対して、ある y が存在して〜』）。∀∃ の順序が入れ替わると意味が変わるので、どちらが外側かを厳密に読む必要がある。

前提になるノード

  • 微分を用いた不等式の証明
  • 定積分で表された関数・パラメータ入り積分の最小化
  • 場合分けを漏らさない・同値性を保つ記述
