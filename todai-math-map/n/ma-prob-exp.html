期待値

数学A ／ 確率 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

期待値の最大の武器は線形性である。E[X + Y] = E[X] + E[Y] は、X と Y が独立でなくても常に成り立つ。この事実を知っているかどうかで、解ける問題の範囲が大きく変わる。複雑な量を『起これば1、起こらなければ0』という小さな変数の和に分解し、各々の期待値（＝その事象が起こる確率）を足すだけでよい。全体の分布を求める必要がまったくない。東大では、まともに分布を求めると手に負えないが線形性を使えば数行で終わる、という形で出題される。

こんなときに使う

  • 『平均していくつか』『期待値を求めよ』
  • 分布を求めるのが大変そうだ、と感じた瞬間 → 線形性で分解する
  • 『〜の個数の期待値』→ 各要素に『含まれるなら1』の変数を割り当てて和にする
  • 反復試行の成功回数の期待値 → 線形性から即座に np
  • 分解できないときだけ、定義通り Σ(値 × 確率) を計算する

手順

  1. 1. 求めたい量が『何かの個数』や『合計』なら、小さな部分に分解できないか考える
  2. 2. 各部分について、起これば 1・起こらなければ 0 をとる変数を置く
  3. 3. その変数の期待値を求める（＝その事象が起こる確率そのもの）
  4. 4. 全部足す（独立でなくてよい。ここが線形性の強さ）
  5. 5. 分解できないなら、定義通り Σ(値 × 確率) を計算する

例題

1 から n までの番号がついた n 枚のカードを無作為に1列に並べる。左から k 番目に番号 k のカードが来ることを『的中』と呼ぶとき、的中する枚数の期待値を求めよ。
解答
  1. 的中枚数の分布そのものを求めようとすると、完全順列（1枚も的中しない場合の数）が必要になり、
  2. 包除原理を使う重い計算になる。しかし期待値だけなら線形性で一瞬で出る。
  4. 各 k (= 1, 2, …, n) に対して、変数 Xₖ を次のように定める。
  5. 　Xₖ = 1（k 番目に番号 k が来る）、Xₖ = 0（来ない）
  7. 求める的中枚数は X = X₁ + X₂ + … + Xₙ。
  9. 番号 k のカードが k 番目に来る確率は、どの位置も等確率だから 1/n。
  10. よって E[Xₖ] = 1 × (1/n) + 0 × (1 − 1/n) = 1/n
  12. 線形性より
  13. 　E[X] = E[X₁] + … + E[Xₙ] = n × (1/n) = 1
  15. ∴ 的中枚数の期待値は、n によらず 1
  17. 【ここが要点】X₁, …, Xₙ は互いに独立ではない（1枚が的中すると他の確率が変わる）。
  18. それでも線形性は成り立つので、独立性を気にせず足してよい。
  20. 検算：n = 2 のとき、並べ方は (1,2) と (2,1) の2通り。的中枚数は 2 と 0。
  21. 期待値は (2 + 0)/2 = 1 ○

別解・ほかの見方

  • 定義通り Σ(値 × 確率) を計算する（分解できないときの基本形）
  • 反復試行の成功回数は np（各回に 0/1 の変数を置いて足すだけ）
  • 状態ごとの期待値を未知数にして、期待値の漸化式を立てる（『平均何回で終わるか』型）
  • 最大値・最小値の期待値は分解できないので、P(X ≧ k) を使うか定義通り計算する

落とし穴

  • 『独立でないから線形性は使えない』と誤解する（和については常に使える）
  • 積の期待値を期待値の積にしてしまう（これは独立なときしか成り立たない）
  • 期待値が実際に取りうる値である必要はないことに戸惑う（サイコロの目の期待値は 3.5）
  • 分布を律儀に求めようとして、計算量に潰される
  • 独立でないのに線形性が使えないと思い込む（実は常に使える）

なぜ大事か

線形性を使えば場合分けを回避できる。差がつく道具

東大での出方

単独でも出題されるが、線形性を使えば一瞬・使えなければ手に負えない、という形で差をつけてくる。カードの並べ替え、玉の取り出し、格子上の移動など、設定を変えて繰り返し現れる。

確認問題

  • サイコロを3回投げたとき、出た目の和の期待値を求めよ
  • 5人が自分の帽子を持ち寄り、無作為に1つずつ取るとき、自分の帽子を取る人数の期待値を求めよ
  • 2個のサイコロを投げたとき、出た目の最大値の期待値を求めよ（これは分解できないので定義通り計算する）

発展

期待値の漸化式。『ある状態から終了までに平均何回かかるか』を状態ごとに未知数として立て、連立方程式を解く。確率漸化式と同じ状態設計の技術がそのまま使える。
