極4 漸化式の極限（|aₙ₊₁−α|≦r|aₙ−α| で 0 に挟む）

数学III ／ 極限 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

aₙ₊₁ = f(aₙ) で決まる数列の極限は、まず α = f(α) を解いて候補を出す。ただしこれは『収束するなら α』という必要条件にすぎない。一般項が出る型（aₙ₊₁ = paₙ + q）なら aₙ − α を等比数列にして直接極限をとる。一般項が出ないときは |aₙ₊₁ − α| ≦ r|aₙ − α|（0 < r < 1 の定数）を示し、繰り返して |aₙ − α| ≦ rⁿ⁻¹|a₁ − α| → 0 と、はさみうち（極3）に持ち込む。

こんなときに使う

  • aₙ₊₁ = √(aₙ + 2) のように一般項が求まらない漸化式で lim aₙ を問う
  • 『|aₙ₊₁ − α| ≦ r|aₙ − α| を示せ』という誘導
  • aₙ₊₁ = f(aₙ) で f が α の近くで傾きが 1 より小さい

手順

  1. 1. α = f(α) を解いて極限の候補 α を出す
  2. 2. aₙ₊₁ − α = f(aₙ) − f(α) を、aₙ − α を因数にもつ形に変形する（有理化・通分）
  3. 3. 残りの因数の絶対値を、aₙ の範囲（帰納法で示す）を使って r（< 1）以下に評価する
  4. 4. 繰り返して |aₙ − α| ≦ rⁿ⁻¹|a₁ − α| とする
  5. 5. rⁿ⁻¹ → 0 なので、はさみうちの原理より aₙ → α

例題

a₁=1, aₙ₊₁=(1/2)aₙ+3 のとき lim[n→∞]aₙ を求めよ。
解答
  1. α=(1/2)α+3 より α=6。
  2. aₙ₊₁−6=(1/2)(aₙ−6)
  3. aₙ−6=(1−6)(1/2)ⁿ⁻¹=−5(1/2)ⁿ⁻¹→0
  4. ∴ 6

別解・ほかの見方

  • aₙ₊₁ = paₙ + q（|p| < 1）は aₙ − α = (a₁ − α)pⁿ⁻¹ と一般項が出るので直接
  • f が微分できれば、平均値の定理で f(aₙ) − f(α) = f′(c)(aₙ − α) とし、|f′| ≦ r を示す
  • 単調で有界な数列は収束する（はさみうちでなく単調性で示す型。誘導があるときだけ使う）

落とし穴

  • 評価に使う aₙ の範囲（aₙ > 0 など）を示さずに分母を評価する
  • r を n に依存する量のままにする（r は n によらない 1 未満の定数でなければならない）
  • 「極限を α とおいて α=pα+q」だけでは、収束することを示していないので答案として不十分。
  • α = f(α) を解いて『極限は α』と書くだけで、収束することを示していない

なぜ大事か

一般項が出ない漸化式でも、極限の候補 α との差が毎回 r 倍以下に縮むことを示せば収束が言える

東大での出方

東大・医学部では誘導つきで頻出。『|aₙ₊₁ − α| ≦ (1/2)|aₙ − α| を示せ』の誘導が出たら、この手順のどこを聞かれているかを確かめる。数列㉙と同じ型。

確認問題

  • a₁=1, aₙ₊₁=√(aₙ+2) のとき、|aₙ₊₁−2|≦(1/2)|aₙ−2| を示し、lim[n→∞]aₙ を求めよ。（答：2）

発展

平均値の定理で |f′(x)| ≦ r < 1 を示す方法は、縮小写像の不動点定理の最も簡単な形。ニュートン法の収束の議論もこの延長にある。
