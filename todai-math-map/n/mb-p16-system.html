⑯ 連立漸化式（和と差・消去）

数学B ／ 漸化式 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

a(n+1) = p·a(n) + q·b(n)、b(n+1) = r·a(n) + s·b(n) は、a(n) + k·b(n) が等比数列になるような k を探すのが基本（固有ベクトル探し）。係数が対称なら k = ±1（和と差）でうまくいく。見つからない・面倒なときは、1本目から b(n) = … を作って2本目に代入し、a だけの3項間漸化式（⑮）にする。この消去法はどんな係数でも必ず通る。

こんなときに使う

  • 2つ以上の数列が互いに入り組んだ漸化式
  • 確率漸化式で状態が2〜3個（和が1になる条件で1つ消せないか先に考える）
  • 係数が対称（p = s、q = r）→ 和と差

手順

  1. 1. 和が一定などの保存量（確率なら a + b + c = 1）がないか確認し、あれば1つ消す
  2. 2. 係数が対称なら、和と差を取って2本の等比数列にする
  3. 3. 対称でなければ a(n+1) + k·b(n+1) = t{a(n) + k·b(n)} として k, t を決める（k が2つ出る）
  4. 4. または消去法：1本目を b(n) について解き、2本目に代入して⑮に帰着
  5. 5. a(n), b(n) を求め、n=2 で検算する

例題

a(1) = 1、b(1) = 0、a(n+1) = 2a(n) + b(n)、b(n+1) = a(n) + 2b(n) の一般項を求めよ。
解答
  1. 足すと a(n+1) + b(n+1) = 3{a(n) + b(n)}、初項 1 なので a(n) + b(n) = 3ⁿ⁻¹
  2. 引くと a(n+1) − b(n+1) = a(n) − b(n)、初項 1 なので a(n) − b(n) = 1
  3. ∴ a(n) = (3ⁿ⁻¹ + 1)/2、b(n) = (3ⁿ⁻¹ − 1)/2
  4. 検算：a(2) = 2、b(2) = 1。(3 + 1)/2 = 2、(3 − 1)/2 = 1 ○

別解・ほかの見方

  • 消去法：b(n) = a(n+1) − 2a(n) を2本目に代入すると a(n+2) − 4a(n+1) + 3a(n) = 0（⑮）。特性方程式の解 1, 3 が和・差の公比と一致する
  • 行列で書くと固有値が公比、固有ベクトルが k。数Cの行列（旧課程）やベクトルの知識があると見通しが立つ
  • 3状態以上の確率漸化式は、対称性で状態をまとめて2状態に減らせないか先に考える

落とし穴

  • 係数が対称でないのに和と差を取ってしまい、等比にならず止まる
  • 消去法で b(n+1) を作るときに添字を1ずらし忘れる
  • 確率の和が1の条件を使わずに3本の連立を解こうとする
  • 係数が対称でないのに単純な和・差で等比になると思い込む

なぜ大事か

確率漸化式で状態が2つ以上あると必ずこの形。足し引きか、1本消して3項間に落とす

東大での出方

東大の確率漸化式の主戦場。状態が2〜3個の連立になり、それを解けるかが問われる。

確認問題

  • a(1) = 1、b(1) = 1、a(n+1) = 3a(n) + b(n)、b(n+1) = 2a(n) + 2b(n) を解け（k = 1/2 で公比4、k = −1 で公比1。答：a(n) = b(n) = 4ⁿ⁻¹）
  • 上の連立を消去法で3項間にして解き、k を使う方法と一致するか確かめよ

発展

a + k·b が等比になる k を探すことは、行列の固有ベクトルを探すことと同じ。2つの k が実数で出ない（固有値が複素数）とき、数列は回転しながら変化する（三角関数で書ける）。
