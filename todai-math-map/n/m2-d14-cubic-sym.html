微14 3次関数の極値の差は (β−α)³、グラフは変曲点で点対称

数学II ／ 微分積分 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

3次関数 f(x)（x³ の係数 a）が x = α, β（α < β）で極値をとるとき、f′(x) = 3a(x − α)(x − β) なので f(α) − f(β) = −∫[α→β]f′(x)dx = (a/2)(β − α)³。α, β を具体的に出さなくても、解と係数の関係で β − α が分かれば差が出る。また3次関数のグラフは変曲点 x = (α + β)/2 に関して点対称で、極大点と極小点の中点が変曲点になる。だから極値の和は 2f((α + β)/2)。記述式では公式だけで済ませず、積分か直接の計算を一行書く。

こんなときに使う

  • 『極大値と極小値の差が 4 となる a』
  • 『極大値と極小値の和』
  • 極値をとる x が √ を含んで、直接代入すると計算が重い

手順

  1. 1. f′(x) = 3a(x − α)(x − β) と書き、α + β、αβ を解と係数の関係で出す
  2. 2. (β − α)² = (α + β)² − 4αβ から β − α を出す
  3. 3. 極値の差 = (|a|/2)(β − α)³
  4. 4. 和を問われたら、対称性から 2f((α + β)/2)

例題

f(x)=x³−3x²−9x+2 の極大値と極小値の差を、公式で求めよ。
解答
  1. f′(x)=3(x+1)(x−3) より α=−1, β=3。
  2. 差は 1/2·4³=32。
  3. （検算：7−(−25)=32）答 32

別解・ほかの見方

  • 極値の和は点対称性から 2f(−b/(3a))（f(x) = ax³ + bx² + …）
  • 接点 t での接線と3次曲線のもう1つの交点は、解と係数の関係で x = −b/a − 2t
  • 極値をとる x の差は、f′(x) = 0 の判別式 D から β − α = √D/|3a|（D は f′ の判別式）

落とし穴

  • a < 0 のとき (a/2)(β − α)³ が負になるのを、そのまま差とする（差は (|a|/2)(β − α)³）
  • 極値をもつ条件（f′ = 0 の判別式 > 0）を確かめずに公式を使う
  • 記述式では公式だけ書かず、積分で示すか、直接 f(α)−f(β) を計算する。
  • a < 0 のときに符号を落とし、極値の差を負で答える

なぜ大事か

f′(x) = 3a(x − α)(x − β) と書けば、α, β を出さずに極値の差が (β − α)³ で決まる

東大での出方

東大では3次関数の対称性を使うと計算が半分になる問題が多い。平行移動で変曲点を原点にする見方と合わせて使う。

確認問題

  • f(x)=x³−3ax² (a>0) の極大値と極小値の差が 4 のとき、a を求めよ。（答：a=1 （検算：f(0)=0, f(2)=8−12=−4、差 4））

発展

3次関数を変曲点が原点に来るように平行移動すると y = ax³ + px の奇関数になる。点対称性はここから一目で分かる。
