整3 1文字の2次方程式とみて判別式で絞る

数学A ／ 整数 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

x² + xy + y² = 7 のような2次の式は、積の形（整1）にしにくい。そこで x の2次方程式とみると、x が実数であるためには判別式 D ≧ 0 が要り、これが y の範囲を有限個に閉じ込める。さらに x が整数（有理数）であるためには D が平方数でなければならない。範囲で絞る（整2）の中で、大小の仮定が置けないときに使う型。

こんなときに使う

  • 2次の項に xy を含む不定方程式（x² + xy + y² = c など）
  • x², y² の係数がどちらも正で、左辺が楕円のように『有界』になりそうな式
  • 積の形にしようとして定数項が合わないとき

手順

  1. 1. 次数の低い文字、または係数の簡単な文字（x）について整理する
  2. 2. x の2次方程式の判別式 D を y の式で書く
  3. 3. D ≧ 0 から y の範囲を出す（有限個になる）
  4. 4. その範囲の y それぞれで D が平方数かを調べる
  5. 5. 平方数のときだけ解の公式で x を出し、整数か確かめる

例題

x² + xy + y² = 7 を満たす整数の組 (x, y) をすべて求めよ。
解答
  1. x について整理すると x² + yx + (y² − 7) = 0
  2. 判別式 D = y² − 4(y² − 7) = 28 − 3y² ≧ 0 より y² ≦ 28/3、∴ y = 0, ±1, ±2, ±3
  3. D は y = 0 で 28、±1 で 25、±2 で 16、±3 で 1。平方数になるのは y = ±1, ±2, ±3
  4. x = (−y ± √D)/2 より、y = 1 で x = 2, −3、y = 2 で x = 1, −3、y = 3 で x = −1, −2
  5. y が負のときは (x, y) → (−x, −y) の対称性で、y = −1 で x = 3, −2、y = −2 で x = 3, −1、y = −3 で x = 1, 2
  6. ∴ (x, y) = (2, 1), (−3, 1), (1, 2), (−3, 2), (−1, 3), (−2, 3), (3, −1), (−2, −1), (3, −2), (−1, −2), (1, −3), (2, −3) の12組

別解・ほかの見方

  • x² + 2y² = c のように xy がない形でも、y² ≦ c/2 で同じく有限化できる
  • 左辺が x² − y² のように不定符号なら判別式では有界にならない。積の形（整1）に戻る
  • パラメータ付きの2次方程式が整数解をもつ条件では、解と係数の関係で和・積を整数として扱う

落とし穴

  • D ≧ 0 だけで y を決めて、D が平方数でない y でも解があるとしてしまう
  • y が負の場合を忘れる
  • √D が整数でも、−y ± √D が偶数でないと x は整数にならない（係数が1以外のとき）
  • 判別式 ≧ 0 で範囲を絞ったあと、判別式が平方数になる条件を確かめずに解を出す

なぜ大事か

2次の不定方程式は、1文字について解けば『実数解をもつ』条件だけで範囲が有限になる

東大での出方

東大整数で、積の形にも大小の仮定にもならない2次式が出たときの第3の手。判別式で有限化するのは評価（整2）の一種と考えると整理しやすい。

確認問題

  • x² + xy + y² = 1 を満たす整数の組は何組か（答：6組）
  • 2x² + 2xy + y² = 5 を満たす整数の組は何組か（答：8組）

発展

x² + xy + y² は複素数 ω（1の虚立方根）を使うと |x − yω|² と書ける。整数解の個数が6の倍数になるのはこの対称性のため。
