不等式の表す領域・線形計画

数学II ／ 図形と方程式 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

領域の問題は「図示」→「kを動かして最大最小」の2段構え。最大値は多くの場合、領域の頂点か境界との接点に現れる。

こんなときに使う

  • 『領域Dにおける ax + by の最大値』→ 直線 ax+by=k を平行移動する
  • 『x² + y² の最大』→ 原点中心の円の半径を動かす
  • 『y/x の最大』→ 原点を通る直線の傾きと読む
  • 『(x-a)² + (y-b)² の最大』→ 点 (a,b) を中心とする円
  • 境界が曲線 → 接する場合を必ず調べる（頂点だけでは足りない）
  • 領域が非有界 → 最大値や最小値が存在しない可能性を疑う

手順

  1. 1. 領域を図示する。境界を含むか（実線/破線）を明示する
  2. 2. 最大化したい量を k と置き、k を含む図形を書く
  3. 3. その図形を動かし、領域と共有点を持つ k の範囲を調べる
  4. 4. 候補は領域の頂点と、境界への接点
  5. 5. 接する場合は判別式、または点と直線の距離で条件を出す
  6. 6. 境界を含まない場合、その値が最大値として『取れるか』を確認する

例題

領域 D: x ≧ 0, y ≧ 0, x + 2y ≦ 8, 2x + y ≦ 10 において、x + y の最大値を求めよ。
解答
  1. まず領域の頂点を求める。
  2. ・原点 (0, 0)
  3. ・x軸との交点：2x + y = 10 で y = 0 → (5, 0)（x + 2y ≦ 8 も満たす：5 ≦ 8 ○）
  4. ・y軸との交点：x + 2y = 8 で x = 0 → (0, 4)（2x + y ≦ 10 も満たす：4 ≦ 10 ○）
  5. ・2直線の交点：x + 2y = 8 と 2x + y = 10 を連立
  6. 　　x + 2y = 8 を2倍して 2x + 4y = 16、これから 2x + y = 10 を引いて 3y = 6、y = 2
  7. 　　x = 8 - 4 = 4　∴ (4, 2)
  9. 領域 D は (0,0), (5,0), (4,2), (0,4) を頂点とする四角形（境界を含む）。
  11. x + y = k とおくと、これは傾き -1 の直線。k を大きくすると直線は右上へ平行移動する。
  12. 領域と共有点を持つ最大の k は、直線が領域から離れる直前の位置、すなわちどれかの頂点を通るとき。
  14. 各頂点での x + y の値：
  15. 　(0,0) → 0　　(5,0) → 5　　(4,2) → 6　　(0,4) → 4
  17. ∴ 最大値は 6（点 (4, 2) のとき）
  19. 検算：(4,2) は x+2y = 4+4 = 8 ○、2x+y = 8+2 = 10 ○ で、2本の境界の交点上にある。
  20. 傾き -1 の直線が、傾き -1/2 と傾き -2 の2直線に挟まれた角の頂点で最大になるのは整合的。

別解・ほかの見方

  • 境界が曲線のときは接線条件（判別式 = 0 または点と直線の距離 = 半径）を使う
  • 分数式 (y - b)/(x - a) は、定点 (a, b) を通る直線の傾きと読む
  • 予選決勝法：一方の変数を固定して最大値を求め、そのあとで固定した変数を動かす
  • 通過領域の問題と表裏の関係にある。逆像法で得た不等式は、そのまま領域の条件として使える

落とし穴

  • 境界を含む/含まないの処理を落とし、最大値が存在しないのに答えてしまう
  • 頂点だけ調べて、曲線境界への接点を見落とす
  • 領域が非有界なのに最大値を求めようとする
  • 図を描かずに式だけで処理し、どこで最大になるかを見誤る
  • k の範囲を求めたあと、その k が実際に達成可能かを確認しない
  • 境界を含む/含まないの処理

なぜ大事か

「領域上での最大最小」は東大の頻出テーマ

東大での出方

単独より融合で出る。数IIIの関数の値域と組み合わせたり、通過領域を求めさせたうえでその領域上の最大最小を問うたりする形が多い。線形計画法そのものを問う出題は少なく、『k を動かす』という考え方が使えるかを見ている。

確認問題

  • 上の領域 D において 2x + 3y の最大値を求めよ（最大を与える頂点が変わることを確認する）
  • x² + y² ≦ 1 において x + y の最大値を求めよ（接線条件を使う）
  • x ≧ 0, y ≧ 0, x + y ≦ 1 において y/(x+2) の最大値を求めよ
