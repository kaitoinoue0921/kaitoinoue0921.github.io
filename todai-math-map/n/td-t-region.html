【東大型】通過領域・存在条件

東大レイヤー ／ 出題テーマ ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

通過領域は『∃t の条件に翻訳する』問題として説明されることが多いが、東大が本当に問うているのはその一段手前にある。∀（すべての t で）と ∃（ある t が存在して）を読み分ける力、そしてどちらの変数を先に固定するかを設計する力である。同じ問題でも、点 (x, y) を固定して t の存在条件を見る（逆像法）か、t を固定して x ごとの y の範囲を求めてから合併する（順像法）かで、難易度が何倍も変わる。方針の選択そのものが得点差になる、数少ないテーマの一つ。

こんなときに使う

  • パラメータが2次以下で範囲が実数全体 → 逆像法（判別式）が最速
  • パラメータに範囲がついている → 逆像法だが、解の配置の問題になる
  • パラメータが三角関数や指数の中にあって整理しにくい → 順像法が有利
  • パラメータが2つ → 1つずつ処理する。どちらを先に動かすかで難易度が変わる
  • 『すべての t で成り立つ』→ ∀。最小値・最大値の問題に翻訳する
  • 『ある t が存在して』『通過する』→ ∃。解の存在条件に翻訳する

手順

  1. 1. ∀ か ∃ かを最初に確定する（ここを誤ると以降の作業がすべて無駄になる）
  2. 2. ∃ の場合：点を (X, Y) と固定し、t についての方程式と見て解の存在条件を求める
  3. 3. あるいは：t を固定して x ごとの y の範囲を出し、t を動かして合併する
  4. 4. t に範囲があれば、解の配置（軸の位置・端点の値）で処理する
  5. 5. 得られた条件を図示し、境界を含むかを判定する
  6. 6. 検算：領域内の点を1つ取り、対応する t を実際に求めて確認する

例題

実数 t が全実数を動くとき、放物線 y = x² - 2tx + 2t² が通過する領域を図示せよ。
解答
  1. 【逆像法】点 (X, Y) が通過領域に属する条件は、Y = X² - 2tX + 2t² を満たす実数 t が存在すること。
  2. t について整理すると　2t² - 2Xt + (X² - Y) = 0
  3. これを t の2次方程式と見る（X, Y は定数）。実数解 t が存在する条件は判別式 ≧ 0。
  4. D/4 = X² - 2(X² - Y) = -X² + 2Y ≧ 0
  5. ∴ Y ≧ X²/2
  7. 求める領域は、放物線 y = x²/2 とその上側（境界を含む）。
  9. 【順像法（別解）】x を固定し、y = 2t² - 2xt + x² を t の関数と見る。
  10. = 2(t - x/2)² + x²/2　より、t が全実数を動くとき y の最小値は x²/2（t = x/2 のとき）。
  11. y はいくらでも大きくなれるので、y ≧ x²/2。同じ答えが出る。
  13. 検算：t = 0 のとき放物線は y = x²。点 (1, 1) は Y ≧ X²/2 すなわち 1 ≧ 1/2 を満たす ○
  14. 境界上の点 (2, 2) については、t = 1 のとき y = 4 - 4 + 2 = 2 ○（t = X/2 = 1 で境界に達する）

別解・ほかの見方

  • 逆像法：点を固定してパラメータの存在条件に落とす。パラメータが低次のとき最速
  • 順像法：パラメータを固定して値域を求め、合併する。パラメータに範囲があるとき、または式が整理しにくいとき有利
  • 上の問題のように両方で解けることは多い。試験場では計算が軽い方を選び、時間が許せばもう一方で検算する
  • 包絡線として捉える（高校範囲外だが、答えの検算に使える。接線族なら包絡線が境界になる）

落とし穴

  • ∀ と ∃ を取り違える（答えが正反対になる。下の確認問題で必ず体感しておくこと）
  • パラメータの範囲の制約を落とし、余分な領域まで塗る
  • 逆像法で判別式だけ見て、解が許された範囲にあるかの確認（解の配置）を飛ばす
  • 境界を含むかどうかの判定を書かない
  • 動点と固定点を同じ文字で書く
  • パラメータの範囲制約を落とし、余分な領域まで塗る

なぜ大事か

『あるtが存在してこの式を満たす点の集合』への読み替え。逆像法（yを固定してxの存在条件）が主武器

東大での出方

東大の最重要テーマの一つ。数IIIの関数と組み合わせて『曲線群の通過領域』として出し、そのうえで領域の面積を計算させる2段構成が定番。誘導が薄く、逆像法と順像法のどちらを選ぶかから任される年もある。

確認問題

  • t が 0 ≦ t ≦ 1 を動くとき、直線 y = 2tx - t² の通過領域を求めよ（範囲がつくと解の配置が必要になることを体感する）
  • 『すべての実数 t に対して y ≧ 2tx - t² が成り立つような点 (x, y)』の範囲を求めよ。∃版（y ≦ x²）と答えがどう違うか確認せよ
  • t が実数全体を動くとき、円 (x - t)² + y² = 1 の通過領域を求めよ

発展

パラメータが2つ (s, t) ある場合。片方を固定してもう片方で処理し、最後に固定した方を動かす。処理の順序を変えると難易度が大きく変わるので、両方の順序を試してから書き始める。
