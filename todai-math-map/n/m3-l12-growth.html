極12 指数と多項式・対数の強さ比べ

数学III ／ 極限 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

x → ∞ のとき、eˣ はどんな累乗 xⁿ より速く大きくなり、xⁿ（n > 0）はどんな log x より速く大きくなる。だから xⁿ/eˣ → 0、log x/x → 0。x → +0 の x log x は x = 1/t とおけば −log t/t となり、x → ∞ の形に戻る。結論は覚えてよいが、記述式で『示せ』と言われたら、微分で √x > log x のような不等式を作って、はさみうち（極3）で示す。

こんなときに使う

  • xⁿe⁻ˣ、log x/x、x log x（x → +0）、xˣ（x → +0）
  • グラフを描くときの端の極限（微3）
  • 『lim log x/x = 0 を示せ』という小問

手順

  1. 1. 分子と分母のどちらが強いかを見る（指数 > 累乗 > 対数）
  2. 2. 結論が使えるなら、弱い方 ÷ 強い方 → 0 として計算する
  3. 3. x → +0 なら x = 1/t、√x なら t = √x のように置き換えて基本形に直す
  4. 4. 証明が要るときは、微分で不等式（例：x > 0 で eˣ > x²/2、√x > log x）を作り、はさみうち

例題

lim[x→∞](log x)/√x を求めよ。
解答
  1. t=√x とおくと log x=2 log t、t→∞。
  2. (log x)/√x=(2 log t)/t→0
  3. ∴ 0

別解・ほかの見方

  • xˣ（x → +0）は log をとって x log x → 0 なので xˣ → 1
  • n/2ⁿ → 0 は二項定理 2ⁿ ≧ n(n − 1)/2 で示せる（数列版）
  • (log x)ᵏ/x → 0 も t = log x とおくと tᵏ/eᵗ → 0

落とし穴

  • ∞/∞ を 1 とする
  • x → +0 の x log x を『0 × (−∞) = 0』と理由なしに書く
  • 記述式では (log x)/x→0 そのものを示させることがある。x>0 で √x>log x を微分で示し（√x−log x は x=4 で最小値 2−log4>0）、x>1 で 0<(log x)/x<1/√x からはさみうち。
  • 記述式で xⁿ/eˣ → 0 や log x/x → 0 を証明なしに使う（示せと言われたら微分で不等式を作る）

なぜ大事か

x → ∞ では『指数 ≫ 累乗 ≫ 対数』の順に強く、弱い方 ÷ 強い方 → 0 で極限が決まる

東大での出方

東大では微分のグラフ問題の端の極限や、積分の評価の最後で使う。『x > 0 で eˣ > 1 + x + x²/2』を自分で示してから使う流れが定番。

確認問題

  • lim[x→+0]x log x を求めよ。（答：0）
  • lim[x→∞]x³e⁻ˣ を求めよ（答：0（x³/eˣ で指数関数が分母））

発展

強さの順は、微分の速さで見ると分かりやすい。(eˣ)′ = eˣ は自分と同じ速さで増え、(xⁿ)′ = nxⁿ⁻¹ は次数が1つ下がり、(log x)′ = 1/x は 0 に近づく。
