微10 共通接線・2曲線が接する（接点の値と傾きが一致）

数学II ／ 微分積分 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

2曲線 y = f(x), y = g(x) についての『接する』には2通りある。(A) 2曲線が x = t で接する（同じ点で共通の接線をもつ）なら、f(t) = g(t) かつ f′(t) = g′(t) の2式。(B) 別々の点で接する共通接線なら、y = f(x) の点 s での接線と y = g(x) の点 t での接線が同じ直線、つまり傾きと切片が一致する2式を s, t について解く。一方が放物線なら、もう一方の接線を放物線の式と連立して判別式 = 0 にするほうが早い。どちらの状況かを問題文から読むのが最初の分かれ目。

こんなときに使う

  • 『2つの放物線の共通接線を求めよ』
  • 『曲線 y = ax² と y = log x が接するような a』
  • 『2曲線が共有点をもち、その点で共通の接線をもつ』

手順

  1. 1. 同じ点で接するのか、別々の点で接する共通接線かを読み分ける
  2. 2. 同じ点なら、接点の x 座標を t とおいて f(t) = g(t)、f′(t) = g′(t) を連立する
  3. 3. 別々なら、片方の接点 s での接線を書き、もう片方とも接する条件（傾きと切片の一致、放物線なら判別式 = 0）を立てる
  4. 4. 求めた接点と接線を答える

例題

2つの放物線 y=x² と y=x²−4x+8 の共通接線の方程式を求めよ。
解答
  1. y=x² 上の点 (s,s²) での接線は y=2sx−s²。
  2. これが y=x²−4x+8 に接する：x²−4x+8=2sx−s²、すなわち x²−(2s+4)x+s²+8=0 が重解。
  3. D/4=(s+2)²−(s²+8)=4s−4=0
  4. より s=1。
  5. ∴ y=2x−1（y=x²−4x+8 とは x=3 で接する）

別解・ほかの見方

  • y = ax² と y = log x が接するのは 2at = 1/t かつ at² = log t より t = √e、a = 1/(2e)
  • 円と放物線の共通接線は、放物線の接線と円の中心との距離 = 半径を使う
  • y = eˣ と y = log x のように逆関数どうしは y = x に関して対称なので、共通接線も対称に組で出る

落とし穴

  • 同じ点で接する問題で、傾きの一致 f′(t) = g′(t) だけを使って値の一致を落とす
  • 判別式で求めたとき、もう一方の曲線との接点の座標を書き忘れる
  • 同じ点で接する条件と、別々の点で接する共通接線の条件を混同する

なぜ大事か

『同じ点で接する』なら値と傾きの2式、『別々の点で接する共通接線』なら2つの接線が同じ直線、と立て方が決まっている

東大での出方

数Ⅲの指数・対数関数との『接する』条件は東大・医学部頻出。f = g、f′ = g′ の2式から、文字定数と接点を同時に出す。

発展

2曲線が x = t で接することは、f(x) − g(x) が x = t で重解をもつことと同じ。多項式なら f(x) − g(x) が (x − t)² で割り切れる。
