数え上げの原則（和の法則・積の法則・辞書式）

数学A ／ 場合の数 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

数え上げで最初にすべきことは、公式を選ぶことではなく数える枠組みを決めることである。原理は2つしかない。排反な場合に分けて足す（和の法則）と、独立な選択を順に掛ける（積の法則）。順列も組合せも、この2つの帰結にすぎない。東大の確率で分母が作れない人は、この枠組みを持たずにいきなり C や P を使っている。数が小さければ辞書式に全部書き出す、という手が結局いちばん確実で、実験としても機能する。

こんなときに使う

  • 場合分けできる → 和の法則（ただし互いに排反であることを確認する）
  • 段階に分けられる → 積の法則（各段階の選択肢数が、前の選択に依存しないことを確認する）
  • 制約のある位置がある（先頭が0でない、一の位が奇数など）→ 制約のある場所から先に決める
  • 数が小さい → 辞書式に全部書き出す。実験にもなる
  • 『〜でない』が多い → 余事象
  • 直接数えにくい → 1対1に対応する別のものを数える

手順

  1. 1. 何を1つと数えるのかを決める（区別する／しないをここで確定させる）
  2. 2. 段階に分けられるか、場合分けが必要かを判断する
  3. 3. 積の法則を使うときは、各段階の選択肢数が前の選択に依らないか確認する
  4. 4. 依存するなら、制約の強い段階を先に持ってくる
  5. 5. 和の法則を使うときは、場合が互いに排反か確認する
  6. 6. n を小さくして書き出し、答えと一致するか検算する

例題

1, 2, 3, 4, 5 の5個の数字から異なる3個を選んで3桁の整数を作る。奇数は何個できるか。
解答
  1. 一の位が奇数であることが条件なので、制約の強い一の位から先に決める。
  3. 一の位：1, 3, 5 のいずれかで 3 通り
  4. 百の位：残り4個から選んで 4 通り
  5. 十の位：残り3個から選んで 3 通り
  7. 積の法則より 3 × 4 × 3 = 36 個
  9. 【なぜ一の位を先に決めるか】
  10. 百の位から決めると、それが奇数か偶数かによって一の位の選択肢数が変わってしまい、
  11. 積の法則がそのまま使えなくなる。制約のある場所を先に固定するのが原則。
  13. 検算：3桁の整数は全部で 5×4×3 = 60 個。
  14. 偶数は一の位が 2, 4 の 2 通りなので 2×4×3 = 24 個。36 + 24 = 60 ○

別解・ほかの見方

  • 余事象で数える（偶数を数えて全体から引く）
  • 1対1対応をつけて、数えやすい別のものに置き換える
  • 小さい場合を全部書き出して規則を見つけ、一般化する（東大では実験そのものが誘導になっていることが多い）
  • 樹形図を描く。場合分けの構造が視覚化され、漏れに気づきやすい

落とし穴

  • 制約のある位置を後回しにして、選択肢数が前の選択に依存してしまう（最頻出）
  • 和の法則で排反性を確認せず、重複して数える
  • 区別する／しないを決めないまま数え始める
  • 0 を含む問題で、先頭に 0 が来る場合を除き忘れる
  • いきなりC・Pに飛びついて数え落とす

なぜ大事か

公式より先に「重複なく漏れなく数える枠組み」を持てるかどうか。東大の確率はここで決まる

東大での出方

単独で問われることはないが、確率の分母を作る作業として毎回必要になる。東大の確率が難しいのは確率の理論ではなく、この数え上げの設計が複雑だから。誘導の (1) で小さい場合を数えさせるのは、ここで枠組みを作らせるため。

確認問題

  • 0, 1, 2, 3, 4 から異なる3個を選んで3桁の整数を作るとき、何個できるか（先頭に0が来ない）
  • 上の問題で偶数は何個か（一の位が0のときとそうでないときで場合分けが必要）
  • 3桁の整数のうち、各位の数字がすべて異なるものは何個か

発展

数えにくいものを、1対1対応で数えやすいものに翻訳する技術。最短経路の総数を『右と上の並べ方』に読み替えるのがその典型で、東大の格子点問題にも直結する。
