条件付き確率・原因の確率

数学A ／ 確率 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

条件付き確率 P(B|A) = P(A∩B)/P(A) が意味しているのは、全体を A に縮めてから、その中で B の占める割合を測るということである。分母が全体から A に変わる、ただそれだけの操作にすぎない。難しく感じる原因はほぼ一つで、問題文のどちらが条件でどちらが結果かを取り違えることにある。『〜であったとき』と書かれているほうが条件、つまり分母になる。この読み取りさえ正確なら、あとは割り算である。

こんなときに使う

  • 『〜であったとき、〜である確率』→ 前者が条件（分母）
  • 『〜と分かった。では〜だった確率は』→ 原因の確率。全確率の公式で分母を作る
  • 玉を戻さずに続けて取り出す → 条件付き確率の積で処理する
  • 状態を分けて考える必要がある → 確率漸化式への入口
  • 検査の陽性・不良品の混入など、原因を逆算する設定 → ベイズ型

手順

  1. 1. どちらが条件（分母）かを問題文から確定させる
  2. 2. P(A∩B) と P(A) をそれぞれ求める
  3. 3. P(B|A) = P(A∩B) / P(A) で割る
  4. 4. 原因を逆算する型では、全確率の公式 P(A) = ΣP(Aかつ各原因) で分母を作る
  5. 5. 検算：条件付き確率も 0 以上 1 以下に収まるか確認する

例題

袋に赤玉3個、白玉2個が入っている。玉を1個ずつ2回続けて取り出す（取り出した玉は戻さない）。2回目が赤であったとき、1回目も赤であった確率を求めよ。
解答
  1. 事象を A：2回目が赤、B：1回目が赤 とおく。求めるのは P(B|A)。
  3. 【分子 P(A∩B)：1回目も2回目も赤】
  4. 　(3/5) × (2/4) = 6/20 = 3/10
  6. 【分母 P(A)：2回目が赤】
  7. 　1回目が赤のとき： (3/5)×(2/4) = 3/10
  8. 　1回目が白のとき： (2/5)×(3/4) = 6/20 = 3/10
  9. 　これらは排反なので P(A) = 3/10 + 3/10 = 6/10 = 3/5
  11. 【割る】
  12. 　P(B|A) = (3/10) ÷ (3/5) = (3/10) × (5/3) = 1/2
  14. ∴ 1/2
  16. 検算：P(A) = 3/5 は『1回目が赤である確率』と同じ値になっている。
  17. 何回目に取り出しても赤である確率は変わらない（対称性）ので、これは正しい。

別解・ほかの見方

  • 樹形図を描き、条件に当てはまる枝の確率の比を取る（視覚的で間違えにくい）
  • 全確率の公式で分母を作る（原因が3つ以上あるときはこれが必須）
  • ベイズの定理は公式として覚える必要はない。定義から2行で導ける
  • 対称性を使う（上の問題では『2回目が赤』の確率が1回目と等しいことがすぐ分かる）

落とし穴

  • 条件と結果を取り違え、分母を間違える（この単元の失点のほぼ全て）
  • 非復元抽出なのに独立として掛け算する
  • 分母を全体のままにしてしまい、条件で絞るのを忘れる
  • P(A∩B) と P(B|A) を混同する
  • 分母にどの事象を置くかを取り違える

なぜ大事か

状態を分けて考える発想の入口。漸化式の立式に直結する

東大での出方

条件付き確率が単独で大問になることは少ないが、確率漸化式の立式は実質的にこの計算になっている。『n回後に状態Xにいるとき、次に状態Yへ移る確率』はまさに条件付き確率であり、ここが曖昧だと遷移図が書けない。

確認問題

  • 2個のサイコロを投げ、出た目の和が偶数であったとき、両方とも偶数である確率を求めよ
  • 上の袋の問題で、1回目が赤であったとき2回目も赤である確率を求めよ（答えを見比べると面白い）
  • 袋Aには赤2白1、袋Bには赤1白3が入っている。袋を等確率で選んで1個取り出したら赤だった。袋Aを選んでいた確率を求めよ

発展

3つ以上の原因がある場合の逆算。全確率の公式で分母を作る手順が本質的に効いてくる。医療検査の偽陽性の議論（有病率が低いと陽性でも実際に病気である確率は低い）は、この計算の最も有名な応用。
