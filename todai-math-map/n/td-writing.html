減点されない答案の書き方

東大レイヤー ／ メタ技能 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

同じ実力でも、答案の書き方だけで15〜25点は変わる。採点者は読み手であり、書いた本人の頭の中は見えない。だから必要なのは、宣言・根拠・結論の3つを揃えることに尽きる。文字を置いたら『〜とおく』と宣言し、使った定理には名前を書き、最後に『∴』で結論を明示する。計算だけが並んでいる答案は、たとえ正しくても何を求めているのかが伝わらず、部分点を拾えない。

こんなときに使う

  • 文字を新しく置いた → 『〜とおく』と宣言する
  • 座標を設定した → どこを原点に取ったかを明示する
  • 図形問題 → 図を描く（採点者に状況が伝わる）
  • 定理を使った → 名前を書く（はさみうちの原理、平均値の定理、中間値の定理）
  • 場合分けした → 見出しを立てる
  • 答えが出た → 『∴』で結論を書く
  • 完答できなかった → 方針だけでも書く（部分点になる）

手順

  1. 1. 問題文の条件を自分の記号に翻訳し、置いた文字をすべて宣言する
  2. 2. 図が描けるなら描く。座標設定の根拠（対称性など）も一言添える
  3. 3. 方針を最初に1行書く（『〜を示すため、差を取って微分する』）
  4. 4. 場合分けは見出しを立て、各場合の結論を書く
  5. 5. 使った定理の名前を明記する
  6. 6. 最後に『∴』で結論を書く。単位や範囲も忘れずに

例題

同じ内容を、伝わらない答案と伝わる答案で書き比べてみる。題材は「x > 0 で x > log(1+x) を示せ」。
解答
  1. 【伝わらない答案】
  2. 　f' = 1 − 1/(1+x) = x/(1+x) > 0
  3. 　f(0) = 0
  4. 　よって成り立つ
  6. → f が何なのか宣言されていない。x > 0 という条件をどこで使ったかも不明。
  7. 　計算は合っているが、読み手には論理が追えない。
  9. 【伝わる答案】
  10. 　f(x) = x − log(1 + x) とおく。定義域は x > −1 であり、以下 x ≧ 0 で考える。
  11. 　示したいのは x > 0 で f(x) > 0 である。
  13. 　f′(x) = 1 − 1/(1 + x) = x/(1 + x)
  14. 　x > 0 のとき分子・分母ともに正なので f′(x) > 0。
  15. 　よって f は x ≧ 0 で単調増加。
  17. 　また f(0) = 0 − log 1 = 0。
  18. 　単調増加で f(0) = 0 だから、x > 0 では f(x) > 0。
  20. 　∴ x > 0 のとき x > log(1 + x)　（証明終）
  22. 【違い】
  23. ・f を宣言した（何を調べているかが分かる）
  24. ・定義域を書いた
  25. ・示したいことを最初に述べた
  26. ・単調増加と f(0) = 0 を結びつけた（ここが論理の要）
  27. ・∴ で結論を明示した
  29. 内容は同じでも、後者は途中で計算を間違えても部分点が来る。前者は来ない。

別解・ほかの見方

  • 方針を冒頭に1行書く（採点者が読む姿勢を作れる）
  • 図・表・増減表を使う（言葉より速く正確に伝わる）
  • 完答できない場合、『ここまでは示せた』と書いて区切る
  • 計算が長くなる部分は、結果だけ書いて別枠で計算する（本筋が読みやすくなる）

落とし穴

  • 文字を宣言せずに使う
  • 定義域・条件を書かない
  • 定理名を書かず『よって』で済ませる
  • 結論を書かずに計算で終わる
  • 解けなかった問題を白紙で出す（方針だけでも部分点の可能性がある）
  • 字が読めない、消しゴムの跡で判別できない
  • 計算だけが並び、何を求めているかが読み手に伝わらない

なぜ大事か

同じ実力で15〜25点変わる領域。図・宣言（〜とおく）・結論の明示の3点

東大での出方

東大の採点基準は非公表だが、開示得点と自己採点のずれの多くはここに由来する。特に論証問題では、結論が合っていることより過程が通っていることが重視される。過去問を解いたら、答え合わせだけでなく『この答案は他人が読めるか』を必ず点検すること。

確認問題

  • 自分の答案を1週間後に読み返し、宣言・根拠・結論が揃っているか確認せよ
  • 上の証明を、定義域と定理名を入れて自分で書き直せ
  • 完答できなかった過去問について、部分点が来る形で書き直してみよ

発展

採点者の立場で自分の答案を読む訓練。可能なら他人に読んでもらい、どこで詰まったかを聞く。これが最も効率のよい改善方法になる。
