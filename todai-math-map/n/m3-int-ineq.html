積分と不等式（面積比較・評価）

数学III ／ 積分法 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

求まらない量を、求まる量で挟む。これが理三で最も差がつく技術である。積分の値が初等関数で書けなくても、被積分関数の大小を評価すれば、面積の大小として不等式が作れる。特に重要なのが和と積分の比較で、Σ 1/k と log n の関係はその代表例になる。階段状の和と滑らかな曲線の下の面積を比べる、という図が頭にあるかどうかで見通しが変わる。ただし論証としては、被積分関数の単調性を先に示すことが必須で、これを抜かすと面積の大小を主張する根拠がなくなる。

こんなときに使う

  • 『〜を示せ』の対象に、直接計算できない積分や和が含まれている
  • Σ と ∫ が同じ問題に現れる → 面積比較を疑う
  • log n が評価の対象 → 1/x の積分と調和級数の比較
  • はさみうちの材料が要る → 積分で作れないか考える
  • 『(1) 不等式を示せ → (2) 極限を求めよ』の誘導 → (1) が挟む道具
  • 被積分関数が単調 → 区間の両端の値で挟める

手順

  1. 1. 被積分関数 f の単調性を調べる（微分するか、明らかなら理由を一言）
  2. 2. 区間 [k, k+1] 上で、f が減少なら f(k+1) ≦ f(x) ≦ f(k)
  3. 3. 各辺を [k, k+1] で積分する（幅が1なので、両端の値がそのまま不等式になる）
  4. 4. k について足し合わせ、Σ と ∫ の大小関係を作る
  5. 5. 求めたい量がその不等式の中央に来るよう整理する
  6. 6. 両端の極限を計算し、一致すればはさみうちで確定する

例題

n を 2 以上の整数とするとき、次を示せ。 　　1/2 + 1/3 + … + 1/n < log n < 1 + 1/2 + … + 1/(n−1)
解答
  1. f(x) = 1/x は x > 0 で単調減少（f′(x) = −1/x² < 0）。
  3. 【区間ごとの評価】
  4. k ≦ x ≦ k+1 のとき、単調減少性より 1/(k+1) ≦ 1/x ≦ 1/k（等号は端点のみ）。
  6. 各辺を x について k から k+1 まで積分する。区間の幅が 1 なので
  7. 　1/(k+1) < ∫[k→k+1] dx/x < 1/k
  8. （f は定数でないので、狭義の不等号になる）
  10. 【足し合わせる】
  11. k = 1, 2, …, n−1 について足すと、中央の積分は繋がって ∫[1→n] dx/x = log n。
  13. 左辺の和： 1/2 + 1/3 + … + 1/n
  14. 右辺の和： 1 + 1/2 + … + 1/(n−1)
  16. ∴ 1/2 + 1/3 + … + 1/n < log n < 1 + 1/2 + … + 1/(n−1)　（証明終）
  18. 【この不等式が効く場面】
  19. 右側から Σ[k=1..n] 1/k > log n が言えるので、n → ∞ で調和級数が発散することが従う。
  20. また両側から、Σ[k=1..n] 1/k と log n の差が有界であることも分かる。
  22. 検算：n = 2 のとき 1/2 < log 2 < 1。log 2 ≒ 0.693 なので成立 ○

別解・ほかの見方

  • 向きを逆にする：積分を和で評価する（数値積分の誤差評価と同じ発想）
  • 台形で近似すると、長方形より精密な評価が得られる
  • 被積分関数が単調でないときは、増減表を書いて区間を分ける
  • 積分区間を平行移動・対称移動して、既知の積分に帰着させる
  • 定積分と漸化式（I_n を I_(n−2) で表す）と組み合わせて、極限のオーダーを出す

落とし穴

  • 単調性を示さずに面積の大小を主張する（論証として成立しない）
  • 区間の取り方（k から k+1 か、k−1 から k か）を誤り、和の範囲がずれる
  • 等号の有無を検討せず、狭義／広義を取り違える
  • 和の項数と積分区間の対応がずれる（n−1 項なのか n 項なのか）
  • 評価が甘くて両端の極限が一致せず、挟めないまま進む
  • 被積分関数の単調性を示さずに面積の大小を主張する

なぜ大事か

log n と調和級数の比較など。数IIIの最高難度帯で、理三の合否はここに出る

東大での出方

理三の合否がここに出る、最上位帯のテーマ。単独で出るというより、(1) で不等式を作らせ、(2) でその不等式を使って極限や評価を求めさせる形で出る。誘導の意図を読めるかどうかが問われており、(1) を独立した小問だと思って解くと (2) で行き詰まる。

確認問題

  • 上の不等式を使って、Σ[k=1..n] 1/k が n → ∞ で発散することを示せ
  • 0 < ∫[0→1] xⁿ/(1+x) dx < 1/(n+1) を示し、n → ∞ の極限を求めよ
  • Σ[k=1..n] 1/√k と 2√n の大小を、同じ方法で比較せよ

発展

和と積分の差そのものを評価する（オイラー・マスケローニ定数に繋がる話）。高校範囲では定数の存在までは示せないが、差が単調で有界であることは示せる。東大の最難問はこの一歩手前まで踏み込んでくる。
