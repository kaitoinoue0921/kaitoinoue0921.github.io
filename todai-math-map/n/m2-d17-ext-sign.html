微17 定数分離できないときは極大値×極小値の符号

数学II ／ 微分積分 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

x³ の係数が正の3次方程式 f(x) = 0 の異なる実数解の個数は、グラフと x 軸の交点の数。極値をもたなければ1個。極値をもつときは、(極大値)×(極小値) < 0 なら3個、= 0 なら2個（重解あり）、> 0 なら1個。文字 a が x と掛かっていて定数分離（微4）できないとき、または分離するとグラフが描きにくいときにこちらを使う。極値は f′(x) = 0 の解 α, β を代入して出すが、f(x) を f′(x) で割った余りに代入すると計算が軽い。

こんなときに使う

  • x³ − 3ax + 2 = 0 のように、文字が x と掛かっている3次方程式
  • 『異なる3つの実数解』『ちょうど2つの実数解』
  • 接線が3本引ける条件（微9）で出てくる t の3次方程式

手順

  1. 1. f′(x) = 0 が異なる2実解をもつ条件（微15）を書く
  2. 2. 極値 f(α)、f(β) を出す（割り算の余りを使うと楽）
  3. 3. 3個 ⇔ f(α)f(β) < 0、2個 ⇔ f(α)f(β) = 0、1個 ⇔ f(α)f(β) > 0
  4. 4. 極値をもたない場合も1個として合わせて答える

例題

a を実数とする。x³−3ax+2=0 が異なる3つの実数解をもつ a の範囲を求めよ。
解答
  1. f(x)=x³−3ax+2、f′(x)=3(x²−a)。
  2. 極値をもつには a>0 が必要。このとき x=±√a で極値。
  3. f(−√a)=2a√a+2>0（極大）、f(√a)=2−2a√a（極小）。
  4. 極小値 <0 が条件：a√a>1 より a>1。
  5. ∴ a>1

別解・ほかの見方

  • f(α)f(β) を α + β、αβ の対称式で表して計算する
  • 正の解の個数を問うときは、f(0) の符号と極値をとる x の位置も見る
  • 微9 の『接線が3本引ける点』は、この条件を通る点の座標 p, q の不等式にしたもの

落とし穴

  • 極値をもつ条件（a > 0 など）を書き忘れる
  • 重解をもつ2個の場合を3個に含める
  • 極値をもつ条件（a > 0 など）を書かずに、極値の符号だけで答える

なぜ大事か

3次方程式の実数解の個数は、極大値と極小値が x 軸をはさむかどうかで決まる

東大での出方

文字定数入りの3次方程式は東大の定番。微9 の接線の本数と組み合わせて出ることが多い。

発展

x³ + px + q = 0 では f(α)f(β) = (4p³ + 27q²)/27 となり、3次方程式の判別式 −(4p³ + 27q²) と符号が逆になる。
