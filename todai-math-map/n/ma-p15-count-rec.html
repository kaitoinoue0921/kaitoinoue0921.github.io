確15 状況から漸化式を立てて数える（最後の1手）

数学A ／ 場合の数 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

n 段の階段の上り方、n 個の並べ方などを直接数えられないとき、最後の1手（最後に何段上ったか、最後の文字が何か）で場合分けする。場合ごとに『残り』は同じ種類のもっと小さい問題になるので、aₙ = aₙ₋₁ + aₙ₋₂ のような漸化式が立つ。あとは初めの数項を数え、漸化式を順に計算するか一般項を求める。

こんなときに使う

  • n が文字で、n 個（n 段・長さ n）のものの並べ方・敷き詰め方
  • 『1が隣り合わない』『同じ文字が3つ続かない』などの並びの制約
  • 具体的な n で答えさせているが、直接数えるには大きすぎる（n = 10 など）

手順

  1. 1. 最後（または最初）の1手で、排反かつ網羅的に場合分けする
  2. 2. 各場合で、残りが元の問題の何番目（aₙ₋₁, aₙ₋₂, …）になるか見る
  3. 3. 漸化式を立て、初めの数項を直接数える
  4. 4. 求める n まで順に計算するか、数列の型（⑮ 3項間など）で一般項を出す
  5. 5. 小さい n で書き出した数と照合する

例題

階段を1回に1段または2段上る。10段の階段を上りきる方法は何通りか。
解答
  1. n 段の上り方を aₙ とする。最後の1回が1段なら残り n − 1 段、2段なら残り n − 2 段
  2. ∴ aₙ = aₙ₋₁ + aₙ₋₂（n ≧ 3）、a₁ = 1、a₂ = 2
  3. a₃ = 3, a₄ = 5, a₅ = 8, a₆ = 13, a₇ = 21, a₈ = 34, a₉ = 55, a₁₀ = 89
  4. ∴ 89 通り
  5. 検算：a₃ = 3 は（1,1,1）（1,2）（2,1）で一致

別解・ほかの見方

  • 長さ n の 0, 1 の列で1が隣り合わないもの：最後が0か『01』かで分けて bₙ = bₙ₋₁ + bₙ₋₂
  • 2 × n のマスを 1 × 2 のドミノで敷き詰める：左端が縦1枚か横2枚かで分けて同じ漸化式
  • 制約が複雑なら『最後が0で終わる個数』『1で終わる個数』を別々の数列にして連立する（数列⑯）

落とし穴

  • 最後の1手の場合分けが重なる（同じ並びを2回数える）
  • 初めの項 a₁, a₂ を数え間違える
  • 漸化式の成り立つ n の範囲を確かめない
  • 最後の1手の場合分けに漏れや重なりがあり、漸化式がずれる

なぜ大事か

n が文字の場合の数は、最後（または最初）の1手で場合分けすると、もっと小さい n の個数で書ける

東大での出方

東大では確率漸化式の場合の数版として出る。確9・確10 と同じく『何で場合分けするか』が勝負で、数えたあとの計算は数列の型に帰着する。

確認問題

  • 長さ5の 0, 1 の列で、1が隣り合わないものは何通りか（答：13通り）
  • 2 × 5 のマスを 1 × 2 のドミノで敷き詰める方法は何通りか（答：8通り）

発展

aₙ = aₙ₋₁ + aₙ₋₂ の一般項はフィボナッチ数の式（黄金比 (1 + √5)/2 の累乗）になる。答えの形が分かると、n が大きいときの増え方（約 1.618 倍ずつ）の見当がつく。

前提になるノード

  • 数え上げの原則（和の法則・積の法則・辞書式）
  • ⑮ 隣接3項間 a(n+2)+p·a(n+1)+q·a(n)=0

「場合の数」のノード

  • 数え上げの原則（和の法則・積の法則・辞書式）
  • 順列・組合せ
  • 同じものを含む順列・円順列・じゅず順列
  • 組分け・重複組合せ（仕切り）
  • 包除原理・余事象で数える
