確11 期待値の線形性（各対象の確率の和）

数学A ／ 確率 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

X = X₁ + X₂ + … + Xₙ なら E(X) = E(X₁) + … + E(Xₙ)。これは Xᵢ が独立でなくても成り立つ。個数を数える X は、『i 番目の対象が条件を満たせば 1、そうでなければ 0』という Xᵢ の和に分けられ、E(Xᵢ) = P(i 番目が条件を満たす)。だから期待値は確率の和になる。

こんなときに使う

  • 『〜の個数の期待値』『出ない目の種類の数の期待値』
  • 分布 P(X = k) を全部求めるのが大変そう
  • 対象が対称で、どの対象も同じ確率で条件を満たす

手順

  1. 1. 数えたい個数 X を、対象ごとの 0/1 の変数 Xᵢ の和に分ける
  2. 2. E(Xᵢ) = P(i 番目の対象が条件を満たす) を求める
  3. 3. E(X) = Σ P(i 番目が条件を満たす)。対称なら (対象の数) × (1つの確率)
  4. 4. 小さい場合で分布から直接計算して照合する

例題

さいころを6回投げるとき、一度も出ない目の種類の数を X とする。X の期待値を求めよ。
解答
  1. 目 i（i = 1〜6）について、i が一度も出なければ Xᵢ = 1、出れば Xᵢ = 0 とする
  2. X = X₁ + X₂ + … + X₆
  3. E(Xᵢ) = P(i が一度も出ない) = (5/6)⁶
  4. ∴ E(X) = 6 × (5/6)⁶ = 15625/7776（約 2.01）
  5. X の分布（X = 0, 1, …, 5 の確率）は包除原理が必要で重いが、期待値はこの1行で済む

別解・ほかの見方

  • n 人のプレゼント交換（ランダムな配り方）で自分のものを受け取る人数の期待値は、n に関係なく 1
  • 硬貨を n 回投げて『表の次も表』となる箇所の個数の期待値は (n − 1)/4
  • ランダムな順列の『山』（左右より大きい項）の個数なども、位置ごとの確率の和

落とし穴

  • Xᵢ が独立でないと線形性が使えないと誤解する（分散は独立性が要るが、期待値は要らない）
  • Xᵢ の分け方が X とずれる（同じものを2回数える）
  • E(XY) = E(X)E(Y) を独立でないのに使う
  • 独立でないから足せないと思い込み、分布を全部求めに行く

なぜ大事か

『〜の個数の期待値』は分布を求めなくても、各対象が条件を満たす確率を足すだけで出る

東大での出方

東大では期待値を問う問題が増えている。分布を出させる小問のあとに期待値を聞く場合も、線形性で検算できる。

確認問題

  • 硬貨を10回投げて、i 回目と i+1 回目がどちらも表となる i の個数の期待値を求めよ（答：9/4）
  • 1〜5 を並べたランダムな順列で、i 番目が i になっている i の個数の期待値を求めよ（答：1）

発展

分散は V(X) = Σ V(Xᵢ) + 2Σ Cov(Xᵢ, Xⱼ) で、共分散が残る。期待値だけが独立性なしで足せることを、この式との違いで覚えておく。
