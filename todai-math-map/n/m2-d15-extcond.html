微15 極値をもつ条件は f′=0 が異なる2実解

数学II ／ 微分積分 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

3次関数 f(x) が極値をもつのは、f′(x) = 0 が異なる2つの実数解をもち、その前後で f′ の符号が変わるとき。2次方程式 f′(x) = 0 の判別式で言えば D > 0。逆に D ≦ 0 なら f′(x) の符号は変わらず（x³ の係数が正なら f′(x) ≧ 0）、極値をもたない。D = 0 で f′ = 0 になる点が1つあっても増加は保たれる。『x = a で極値をとる』から係数を決めるときは、f′(a) = 0 が必要条件にすぎないので、求めた係数で f′ の符号が変わるか確かめる。

こんなときに使う

  • 『極値をもつような a の範囲』
  • 『常に増加（単調増加）となる a の範囲』
  • 『x = 1 で極小値 −2 をとるような a, b』

手順

  1. 1. f′(x) を出す
  2. 2. 極値をもつ ⇔ f′(x) = 0 の判別式 D > 0、極値をもたない ⇔ D ≦ 0
  3. 3. x = a で極値なら f′(a) = 0 と値の条件で係数を出す（必要条件）
  4. 4. 求めた係数で増減表を書き、確かに極大・極小か確かめる（十分性）

例題

f(x)=x³+ax²+bx+1 が x=1 で極小値 −2 をとるとき、a,b を求めよ。
解答
  1. f′(x)=3x²+2ax+b。
  2. 必要条件：f′(1)=3+2a+b=0、f(1)=2+a+b=−2。
  3. 辺々引いて 1+a=2 より a=1、b=−5。
  4. 十分性：f′(x)=3x²+2x−5=(3x+5)(x−1)。x=1 の前後で−から＋に変わるので確かに極小で、f(1)=1+1−5+1=−2。
  5. ∴ a=1, b=−5

別解・ほかの見方

  • 『極大値と極小値をともに正の x でとる』は、f′(x) = 0 の2解の配置（2次方程式の解の配置）
  • eˣ などを含む関数では、f′ の符号を決める因数だけ取り出して同じことを考える
  • 『x > 0 の範囲で極値をもつ』は、f′(x) = 0 が x > 0 に符号の変わる解をもつ条件

落とし穴

  • 常に増加の条件を D < 0 にする
  • f′(a) = 0 だけで『x = a で極値』と決め、十分性を確かめない
  • 「常に増加」は D≦0（D<0 ではない）。D=0 のとき f′(x)=0 になる点は1点だけで、増加は保たれる。
  • 『常に増加』の条件を D < 0 とし、D = 0 の場合を落とす

なぜ大事か

3次関数が極値をもつかどうかは、2次方程式 f′(x) = 0 の判別式だけで決まる

東大での出方

単独より、他の問題の前提（極値をもつ範囲で考える）として必ず出てくる。微17・微9 の最初の一行になる。

確認問題

  • f(x)=x³+ax²+ax が常に増加するような a の範囲を求めよ。（答：0≦ a≦3）
  • f(x)=x³+ax²+3x が極値をもつ a の範囲 を求めよ（答：D/4=a²−9>0 より a<−3, 3<a）

発展

4次以上では、f′ = 0 の解の重なり方で決まる。奇数重の解では符号が変わって極値、偶数重では変わらず極値にならない。
