⑨ 対数の和は log の差に分解して消す

数学B ／ 数列 ／ 東大での重要度 ★★☆☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

Σ log a(k) = log(a(1)a(2)…a(n)) なので、対数の和は『積の計算』と同じ。真数が (k+1)/k のような比なら、積は分母分子が隣同士で約分されて端だけ残る。log の差に分ける方法と、積にして約分する方法は同じことを言っている。

こんなときに使う

  • Σ log((k+1)/k)、Σ log(1 + 1/k) のように真数が隣同士の比
  • Σ log(1 − 1/k²) → (k−1)(k+1)/k² に因数分解すると比の積になる
  • 積 Π(1 − 1/k²) を求めよ → log を取らずにそのまま約分してもよい

手順

  1. 1. 真数を比の形 (k+1)/k、(k−1)/k などに因数分解する
  2. 2. log(k+1) − log k のように差に分ける（または積のまま書き並べる）
  3. 3. 書き並べて消える組を確認し、端に残る項だけ集める
  4. 4. 1つの log にまとめて答える

例題

Σ[k=2〜n] log(1 − 1/k²) を求めよ（n≧2）。
解答
  1. 1 − 1/k² = (k−1)(k+1)/k² = {(k−1)/k}·{(k+1)/k}
  2. Σ[k=2〜n] log((k−1)/k) = log(1/2 · 2/3 · … · (n−1)/n) = log(1/n)
  3. Σ[k=2〜n] log((k+1)/k) = log(3/2 · 4/3 · … · (n+1)/n) = log((n+1)/2)
  4. 合わせて log((n+1)/(2n))
  5. 検算：n=2 で log(3/4)。1 − 1/4 = 3/4 ○

別解・ほかの見方

  • n→∞ で log(1/2) に収束する（数III）
  • 積 Π[k=2〜n] (1 − 1/k²) = (n+1)/(2n) の形でも同じ。log なしの積で出題されることも多い

落とし穴

  • log(1 − 1/k²) を log 1 − log(1/k²) と分解する（log の差は真数の商にしか分けられない）
  • 下端が k=2 なのに端の項を k=1 から数える
  • log((k+1)/k) の分解の向き／1 − 1/k² を因数分解せずに止まる

なぜ大事か

log の和は真数の積。積が望遠鏡的に約分できる形を見抜く

東大での出方

単独での出題は少ない。積の極限や確率の積（n回連続で〜しない確率）を約分する場面で使う。

確認問題

  • Σ[k=1〜n] log₂((k+1)/k) を求めよ（答：log₂(n+1)）
  • Π[k=1〜n] (1 + 1/k) を求めよ（答：n+1）

発展

Σ log(1 + 1/k) = log(n+1) → ∞ から、Σ 1/k が発散することも示せる（log(1+x) < x を使う）。
