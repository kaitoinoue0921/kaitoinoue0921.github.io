積6 キングプロパティ（x を a+b−x に置換して足す）

数学III ／ 積分法 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

∫[a→b]f(x)dx = ∫[a→b]f(a + b − x)dx は、x = a + b − t と置換すると区間が入れ替わり dx = −dt の符号で元に戻ることから出る（「積7 偶関数・奇関数・周期で区間を整理」）。これを使う型では、求めたい積分 I を置換した形でも書き、2つを足す。2I = ∫[a→b]{f(x) + f(a + b − x)}dx の被積分関数が定数や簡単な式になるのが狙い。区間 0〜π/2 なら sin と cos が入れ替わり、0〜π なら x が π − x になって x の係数を外に出せる。分母が sin x + cos x、xⁿ + (a − x)ⁿ のような、入れ替えても同じ形のものが目印。

こんなときに使う

  • ∫[0→π/2]sin x/(sin x + cos x)dx のように、分母が sin と cos について対称
  • ∫[0→π]x f(sin x)dx のように、x と sin x（または cos x）の積で区間が 0〜π
  • ∫[0→a]f(x)/{f(x) + f(a − x)}dx の形、log(1 + tan x) の 0〜π/4

手順

  1. 1. 求める積分を I とおく
  2. 2. x = a + b − t と置換し、I を別の形で書く（区間と dx の符号を両方入れる）
  3. 3. 元の I と足して 2I を出す。被積分関数が簡単になることを確かめる
  4. 4. 2I を計算して 2 で割る
  5. 5. 0〜π の x f(sin x) 型は、x を π − x にすると I = π∫f(sin x)dx − I

例題

I = ∫[0→π/2] sin x/(sin x + cos x) dx を求めよ。
解答
  1. x = π/2 − t とおくと、sin x = cos t、cos x = sin t、dx = −dt、x: 0→π/2 のとき t: π/2→0。
  2. I = ∫[π/2→0] cos t/(cos t + sin t)·(−dt) = ∫[0→π/2] cos x/(sin x + cos x) dx。
  3. 元の I と足すと 2I = ∫[0→π/2] (sin x + cos x)/(sin x + cos x) dx = ∫[0→π/2] 1 dx = π/2。
  4. ∴ I = π/4

別解・ほかの見方

  • ∫[0→π] x sin x/(1 + cos²x) dx は x = π − t で I = π∫[0→π]sin x/(1 + cos²x)dx − I。後ろは cos x = u で π/2 になり、I = π²/4
  • ∫[0→π/4] log(1 + tan x) dx は x = π/4 − t で 1 + tan x が 2/(1 + tan t) になり、I = (π/8)log 2
  • ∫[0→a] f(x)/{f(x) + f(a − x)} dx は、足すと被積分関数が 1 になって a/2

落とし穴

  • 置換で区間を入れ替えたあと dx = −dt の符号を落とし、I = −I のような式になる
  • 0〜π の型で sin(π − x) = sin x だが cos(π − x) = −cos x なのを取り違える
  • 置換した積分を足すところまで行かず、元の積分と置換後の積分が等しいことだけで止まる

なぜ大事か

直接は積分できない式でも、x → a + b − x で別の形が出て、足すと被積分関数が簡単になる

東大での出方

東大・医学部では、直接やると重い定積分を誘導なしで出すことがある。分母や区間の対称性を見て、まず a + b − x を試すのが定石。

確認問題

  • ∫[0→π/2] cos x/(sin x + cos x) dx を求めよ。（答：π/4）
  • ∫[0→π] x sin x/(1 + cos²x) dx を求めよ。（答：π²/4）
  • ∫[0→π/4] log(1 + tan x) dx を求めよ。（答：(π/8)log 2）

発展

置換 x → a + b − x は区間の中点に関する折り返し。被積分関数をこの折り返しで偶の部分と奇の部分に分けると、奇の部分は積分が 0 になり偶の部分だけが残る。積7 の偶関数・奇関数を中点のまわりで見たものと同じ。
