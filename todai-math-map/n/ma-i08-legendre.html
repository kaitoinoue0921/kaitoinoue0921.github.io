整8 素因数の個数（n! のルジャンドル・約数の個数と和）

数学A ／ 整数 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

1 から n までの各数に含まれる素因数 p の個数を合計すると、n! に含まれる p の個数になる。p の倍数は少なくとも1個、p² の倍数はもう1個、p³ の倍数はさらにもう1個…と含むので、[n/p] + [n/p²] + [n/p³] + … と数えればよい（ルジャンドルの公式）。末尾の0の個数は 10 = 2 × 5 の個数で、5 の方が少ないので 5 の個数で決まる。N = pᵃqᵇ… の約数の個数は (a + 1)(b + 1)…、約数の和は (1 + p + … + pᵃ)(1 + q + … + qᵇ)…。

こんなときに使う

  • 『n! は 2 で何回割り切れるか』『末尾に 0 はいくつ並ぶか』
  • 二項係数 nCr が p で割り切れるかどうか（n!, r!, (n − r)! の p の個数の差）
  • 約数の個数・約数の和を求める問題

手順

  1. 1. 調べる素数 p を決める（末尾の0なら 5）
  2. 2. [n/p], [n/p²], [n/p³], … を p^k > n になるまで計算する
  3. 3. 全部足す
  4. 4. 二項係数なら、分子と分母それぞれの個数を引く

例題

100! を計算すると、末尾に 0 はいくつ並ぶか。
解答
  1. 末尾の 0 の個数は、100! に含まれる 10 = 2 × 5 の個数
  2. 2 の個数は [100/2] + [100/4] + … = 50 + 25 + 12 + 6 + 3 + 1 = 97 個で、5 より多い
  3. 5 の個数は [100/5] + [100/25] = 20 + 4 = 24 個（125 > 100 なので終わり）
  4. ∴ 末尾に 0 は 24 個並ぶ
  5. 25, 50, 75, 100 は 5 を2個ずつ含むので、[100/25] の分を足す

別解・ほかの見方

  • nCr が p で割り切れない条件：n! の p の個数 = r! と (n − r)! の p の個数の和
  • 2ⁿ 以下の数の中で、(2ⁿ)! に含まれる 2 の個数は 2ⁿ − 1
  • 72 = 2³·3² の約数の和は (1 + 2 + 4 + 8)(1 + 3 + 9) = 195

落とし穴

  • [n/p] だけで止める（p² 以上の倍数を数え落とす）
  • 末尾の 0 を 2 の個数で数える
  • [n/p²] を [n/p]/p と小数のまま計算してずれる（ガウス記号は1回ずつ取る）
  • n! に含まれる 5 の個数を [n/5] だけにして、25 の倍数が2個ずつ含む分を落とす

なぜ大事か

n! に p が何個含まれるかは、p の倍数・p² の倍数…を数えて足すだけで出る

東大での出方

東大では二項係数の整除性（nCr が素数で割り切れるか）の道具として出る。式を立てたら小さい n で直接確かめると安全。

確認問題

  • 50! は 2 で最大何回割り切れるか（答：47回）
  • 1000! の末尾に 0 はいくつ並ぶか（答：249個）

発展

n! に含まれる p の個数は (n − (n を p 進法で表した各桁の和))/(p − 1) とも書ける。整15 の n進法とつながる。
