⑪ 指数型 a(n+1)=p·a(n)+rⁿ（rⁿ⁺¹で割る）

数学B ／ 漸化式 ／ 東大での重要度 ★★★★☆

要点

rⁿ がじゃまなら、両辺を rⁿ⁺¹ で割って b(n) = a(n)/rⁿ と置くと b(n+1) = (p/r)b(n) + 1/r となり⑩に落ちる。pⁿ⁺¹ で割れば c(n+1) = c(n) + (r/p)ⁿ/p となり③（階差型）に落ちる。どちらで割っても解けるが、p = r のときは割ると b(n+1) = b(n) + 1/r の等差数列になり、答えに n·rⁿ が現れる（共鳴型）。

こんなときに使う

  • a(n+1) = p·a(n) + (定数)·rⁿ
  • p と r が等しい → 共鳴型。答えは n·pⁿ の形になると予想できる
  • 3項間漸化式で重解（⑮）を処理した後の a(n+1) − α·a(n) = c·αⁿ もこの形

手順

  1. 1. 両辺を rⁿ⁺¹（または pⁿ⁺¹）で割る
  2. 2. b(n) = a(n)/rⁿ と置き、b の漸化式に書き直す
  3. 3. p ≠ r なら⑩、p = r なら等差数列、pⁿ⁺¹ で割ったなら③で解く
  4. 4. a(n) = rⁿ·b(n) に戻す
  5. 5. a(2) で検算する

例題

a(1) = 1、a(n+1) = 2a(n) + 3ⁿ の一般項を求めよ。
解答
  1. 両辺を 3ⁿ⁺¹ で割る：a(n+1)/3ⁿ⁺¹ = (2/3)·a(n)/3ⁿ + 1/3
  2. b(n) = a(n)/3ⁿ とおくと b(n+1) = (2/3)b(n) + 1/3、b(1) = 1/3
  3. α = 1 なので b(n+1) − 1 = (2/3)(b(n) − 1)
  4. b(n) − 1 = (1/3 − 1)(2/3)ⁿ⁻¹ = −(2/3)ⁿ
  5. ∴ a(n) = 3ⁿ·b(n) = 3ⁿ − 2ⁿ
  6. 検算：a(2) = 2 + 3 = 5、9 − 4 = 5 ○
  7. 共鳴型の例：a(1) = 1、a(n+1) = 2a(n) + 2ⁿ なら 2ⁿ⁺¹ で割って b(n+1) = b(n) + 1/2、b(1) = 1/2 より b(n) = n/2、a(n) = n·2ⁿ⁻¹

別解・ほかの見方

  • 2ⁿ⁺¹ で割って階差型にする：c(n) = a(n)/2ⁿ、c(n+1) − c(n) = (1/2)(3/2)ⁿ、③で戻す
  • a(n) = A·3ⁿ + B·2ⁿ と形を決め打ちして係数を合わせる（解の形が分かっているときの検算にもなる）

落とし穴

  • rⁿ で割って rⁿ⁺¹ で割ったつもりになり、係数が1つずれる
  • 共鳴型（p = r）で特性方程式を立てて α が出ない、と止まる
  • b(1) = a(1)/r の計算で r と r² を取り違える
  • p = r のとき特性方程式型に持ち込もうとして詰まる／割る指数を1ずらす

なぜ大事か

非同次項が指数のとき、割って⑩か③に落とす。p = r の共鳴型で答えに n が掛かる

東大での出方

確率漸化式で (1/2)ⁿ のような項が残るときによく出る。共鳴型は東大好みの『形が崩れる場合』。

確認問題

  • a(1) = 3、a(n+1) = 3a(n) + 3ⁿ⁺¹ の一般項を求めよ（答：a(n) = n·3ⁿ）
  • a(1) = 1、a(n+1) = 2a(n) + 3ⁿ を 2ⁿ⁺¹ で割る方法でも解き、同じ答えになるか確かめよ

発展

一般に a(n+1) = p·a(n) + f(n) の解は『等比部分 C·pⁿ』＋『f(n) と同じ形の特殊解』。f が rⁿ なら A·rⁿ、ただし r = p なら n·pⁿ に格上げ。微分方程式と同じ構造。

前提になるノード

  • ⑩ 特性方程式型 a(n+1)=p·a(n)+q
  • ③ 階差数列 a(n+1)−a(n)=f(n)

このノードを前提にするノード
