非回転体の体積（断面積を積分する）

数学III ／ 積分の応用 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

立体の体積を求める作業は、立体そのものを3次元で把握する作業ではない。軸を1本決め、その軸に垂直な平面 x = t で切ったときの断面積 S(t) を求め、∫S(t)dt を計算する——ただそれだけの手続きである。だから難しさは積分ではなく、『t を固定したときに断面がどんな図形になるか』を求める2次元の問題を解けるかどうかに集約される。立体が頭の中で見えないまま止まってしまう人は、3次元で見ようとしているのであって、断面という2次元の問題に落とす手続きを踏んでいない。

こんなときに使う

  • 回転体ではない立体の体積 → 断面積を積分する以外の道はない
  • 『2つの立体の共通部分』→ 断面同士の共通部分を取る（2次元の問題になる）
  • 軸の選び方が自由なとき → 断面が最も単純になる向きを選ぶ（対称性のある向き）
  • 断面が t の範囲によって形を変えそう → 場合分けを最初に見積もる
  • 空間の点の条件が不等式で与えられている → x = t を代入して y, z の条件にする

手順

  1. 1. 座標軸を設定する。対称性が最も活きる取り方を選ぶ（ここで難易度が半分になる）
  2. 2. 積分する軸を決め、その軸に垂直な平面 x = t で切る
  3. 3. t を定数として扱い、断面が y-z 平面上のどんな図形かを求める（これは2次元の問題）
  4. 4. 断面積 S(t) を t の式で表す
  5. 5. t の動く範囲で断面の形が変わるなら場合分けし、各区間で S(t) を求める
  6. 6. V = ∫ S(t) dt を計算する
  7. 7. 検算：t の端で S(t) が 0 または既知の値になるか、体積のオーダーが直感と合うか

例題

底面が半径1の円である円柱を、底面の直径を含み底面と 45° をなす平面で切る。このとき小さい方の立体の体積を求めよ。
解答
  1. 底面の円の中心を原点、切断に使う直径を x 軸に取る。底面は x² + y² ≦ 1、高さ方向を z とする。
  2. 立体は、底面の半円 (y ≧ 0 の側) の上にあり、平面 z = y·tan45° = y の下にある部分。
  3. x = t (-1 ≦ t ≦ 1) で切る。断面は y-z 平面上で、0 ≦ y ≦ √(1 - t²)、0 ≦ z ≦ y の領域。
  4. これは直角をはさむ2辺が √(1 - t²) の直角三角形。
  5. S(t) = (1/2)·√(1 - t²)·√(1 - t²) = (1 - t²)/2
  6. V = ∫[-1→1] (1 - t²)/2 dt = (1/2)[t - t³/3]₋₁¹ = (1/2)·(2 - 2/3) = (1/2)·(4/3) = 2/3
  7. ∴ 2/3
  8. 検算：t = ±1 で S = 0 ○（円の端では断面が潰れる）。t = 0 で S = 1/2（斜辺が45°の直角三角形）○。

別解・ほかの見方

  • 軸の取り方を変える：同じ立体でも切る向きで計算量が数倍変わる。迷ったら2通り試して軽い方を採る
  • 共通部分の体積：立体A ∩ 立体B の断面は (Aの断面) ∩ (Bの断面)。2次元の共通部分を求める問題に落ちる
  • 回転体でも断面積で処理できる：回転体の公式 πr² は、断面が円である場合の特殊例にすぎない
  • 斜回転体：回転軸が座標軸でないときは、座標を回転させてから通常の回転体に帰着する（複素数平面の回転が使える）
  • カヴァリエリの原理：断面積が等しい立体は体積も等しい。答えの検算や、難しい立体を易しい立体に置き換えるのに使える

落とし穴

  • 3次元の形を頭で把握しようとして手が止まる（断面という2次元問題に落とす手続きを踏む）
  • 断面の形が t の範囲で変わるのに、1つの式で押し通す（東大はここを狙って出す）
  • 断面積を求める際に、断面が回転体の一部だと思い込んで円だと決めつける
  • 座標設定が対称性を無視しており、式が汚くなったまま突き進む
  • 積分区間を立体の存在範囲ではなく、なんとなくの範囲で取る
  • 断面の形状をtの範囲で場合分けせず一つの式で通そうとする

なぜ大事か

「x=t で切った断面を求める」。東大の空間問題の標準解法にして最難関。ここを完成させると理三の得点が安定する

東大での出方

東大理系で毎年のように出題される最大配点帯のテーマ。特に『2つの立体（円柱・球・正四面体など）の共通部分』の形が頻出。切る向きの選択と、断面の場合分けの2点が採点上の分岐になる。

確認問題

  • 半径1の2つの円柱 x² + y² ≦ 1 と x² + z² ≦ 1 の共通部分の体積を求めよ（断面は正方形になる）
  • 上の問題で、断面が正方形になる理由を、x = t を代入して説明せよ

発展

回転体と非回転体の融合。領域を回転させた立体を、さらに別の平面で切る問題。断面を求める段階で回転を考える必要があり、最難問クラスになる。
