定積分と漸化式（I_n を n で結ぶ）

数学III ／ 積分法 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

I_n = ∫ (n を含む式) の形の定積分は、直接計算しようとしても n が一般のままでは原始関数が書けない。そこで部分積分を1回だけ行い、I_n を I_{n-1} や I_{n-2} で表す関係式（漸化式）を作る。個別の値を求めるのではなく、値どうしの関係を作ってから初期値で下ろす、という発想の転換がこの単元の全てである。さらに東大はここで止めず、作った漸化式から不等式評価や極限へ繋げてくる。

こんなときに使う

  • 積分の中に自然数 n が指数として入っている（sinⁿx, xⁿeˣ, (log x)ⁿ など）→ 漸化式を作る
  • 『I_n を I_{n-2} で表せ』という誘導がある → 部分積分ほぼ確定
  • (1) で漸化式を作らせ (2) で極限 → 最後ははさみうち
  • n乗の積分で n が偶数か奇数かで答えが変わりそう → 2つ飛びの漸化式（I_n と I_{n-2}）

手順

  1. 1. I_n を定義通りに書き、部分積分の形に分ける（何を微分側・積分側に置くかを決める）
  2. 2. 一度部分積分し、出てきた積分を I_{n-1} または I_{n-2} の形に整理する
  3. 3. 整理の途中で sin²x = 1 - cos²x などを使い、同じ I_n が右辺に現れたら移項してまとめる
  4. 4. 初期値 I_0, I_1 を直接計算する
  5. 5. 漸化式を繰り返し適用して一般項を出す（n の偶奇で分かれることが多い）
  6. 6. 極限が問われていれば、0 ≦ I_n ≦ (評価しやすい式) を作ってはさみうち

例題

I_n = ∫[0→π/2] sinⁿx dx (n は 0 以上の整数) について、I_n を I_{n-2} で表し、lim[n→∞] I_n を求めよ。
解答
  1. n ≧ 2 とする。sinⁿx = sinⁿ⁻¹x · sinx と分け、sinx を積分側に取る。
  2. I_n = [-sinⁿ⁻¹x · cosx]₀^(π/2) + ∫[0→π/2] (n-1)sinⁿ⁻²x · cos²x dx
  3. 第1項は x = π/2 で cos = 0、x = 0 で sinⁿ⁻¹ = 0 (n ≧ 2) より 0。
  4. cos²x = 1 - sin²x を代入すると
  5. I_n = (n-1)∫[0→π/2] sinⁿ⁻²x dx - (n-1)∫[0→π/2] sinⁿx dx = (n-1)I_{n-2} - (n-1)I_n
  6. 移項して n·I_n = (n-1)I_{n-2}、すなわち I_n = ((n-1)/n) I_{n-2}
  7. 初期値は I_0 = π/2、I_1 = 1。
  8. 極限について：0 ≦ x ≦ π/2 で 0 ≦ sinx ≦ 1 だから sinⁿ⁺¹x ≦ sinⁿx、よって I_n は単調減少で I_n > 0。
  9. 漸化式より I_n = ((n-1)/n)I_{n-2} で、係数 (n-1)/n < 1 が掛かり続ける。
  10. n·I_n·I_{n-1} = (n-1)I_{n-2}·I_{n-1} より数列 n·I_n·I_{n-1} は一定で、I_1·I_0·1 = π/2。
  11. よって I_n·I_{n-1} = π/(2n) → 0。I_n は単調減少で正だから I_n² ≦ I_n·I_{n-1} = π/(2n) → 0。
  12. ∴ lim[n→∞] I_n = 0

別解・ほかの見方

  • 部分積分を2回使って元の I_n に戻し、移項して解く型（eˣsinx の積分など）
  • 積分の中身を評価してから積分する（漸化式を作らずに、はさみうちだけで極限を出す）
  • 置換で別の漸化式に化ける場合がある。x → π/2 - x の置換で cosⁿx の積分と等しいことが分かる
  • (log x)ⁿ 型は log を微分側に置くのが定石。xⁿeˣ 型は xⁿ を微分側に置く

落とし穴

  • 部分積分で微分側・積分側の選択を誤り、次数が下がらない
  • 漸化式は作れたが、初期値 I_0 と I_1 の両方を出さない（偶奇で必要）
  • 極限で『(n-1)/n < 1 だから 0 に収束する』と書いてしまう（1に近づく係数を無限回掛けても 0 とは限らないので、評価が必要）
  • はさみうちの下側 0 ≦ I_n を書かない
  • 移項が必要な形で、右辺に出た I_n を見落として計算を続ける
  • 漸化式は作れても最後の極限評価（はさみうち）に繋げられない

なぜ大事か

東大の頻出構造。部分積分でI_nとI_{n-2}を結び、極限や不等式へ繋ぐ

東大での出方

東大が構造的に好むテーマ。(1) 漸化式を作らせ、(2) 不等式を示させ、(3) その不等式で極限を出す、という3段の誘導で出る。誘導を使わずに解こうとすると詰まるように設計されているので、前問の結果を必ず使う。

確認問題

  • J_n = ∫[0→1] xⁿeˣ dx について J_n を J_{n-1} で表し、lim[n→∞] J_n を求めよ
  • K_n = ∫[1→e] (log x)ⁿ dx について漸化式を作れ

発展

漸化式から一般項を出さずに、不等式評価だけで極限の速さ（何のオーダーで 0 に近づくか）を求める問題。理三の最上位帯。
