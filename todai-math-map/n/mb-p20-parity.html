⑳ 偶奇分け（(−1)ⁿ型・2つ飛び）

数学B ／ 漸化式 ／ 東大での重要度 ★★★☆☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

a(n+1) + a(n) = f(n) のような式は、n を1つずらして引くと a(n+2) − a(n) = f(n+1) − f(n) となり『2つ飛びの階差数列』になる。奇数番目 a(1), a(3), … と偶数番目 a(2), a(4), … は別々の数列として解き、最後に (−1)ⁿ を使って1本にまとめる。(−1)ⁿ が入った式も、偶奇で場合分ければ (−1)ⁿ が ±1 の定数になる。

こんなときに使う

  • (−1)ⁿ が式に入っている
  • a(n+1) + a(n) = …、a(n+1)·a(n) = … のように隣同士の和や積
  • a(n+2) と a(n) だけの関係（1つ飛び）
  • 数列を書き並べると、偶数番目と奇数番目で別々の規則がある

手順

  1. 1. a(n+1) + a(n) 型なら n をずらして引き、a(n+2) と a(n) の関係にする
  2. 2. 奇数番目 n = 2m − 1 と偶数番目 n = 2m に分け、それぞれの初項から解く
  3. 3. 偶数番目の初項 a(2) は元の式から計算する
  4. 4. m を n に戻し（m = (n+1)/2 または n/2）、必要なら (−1)ⁿ で1本にまとめる
  5. 5. n = 1, 2, 3 で検算する

例題

a(1) = 1、a(n+1) + a(n) = 2n の一般項を求めよ。
解答
  1. n をずらした a(n+2) + a(n+1) = 2(n+1) から元の式を引くと a(n+2) − a(n) = 2
  2. a(2) = 2·1 − a(1) = 1
  3. 奇数番目：a(1) = 1 から2ずつ増えるので a(2m−1) = 2m − 1。つまり n が奇数なら a(n) = n
  4. 偶数番目：a(2) = 1 から2ずつ増えるので a(2m) = 2m − 1。つまり n が偶数なら a(n) = n − 1
  5. まとめると a(n) = n − (1 + (−1)ⁿ)/2
  6. 検算：a(2) + a(1) = 1 + 1 = 2 ○、a(3) + a(2) = 3 + 1 = 4 ○

別解・ほかの見方

  • a(n+1) = a(n) + (−1)ⁿ·n のような階差型は、Σ(−1)ᵏk を偶奇で分けて計算する
  • a(n+1) + a(n) = f(n) を (−1)ⁿ⁺¹ を掛けて c(n) = (−1)ⁿa(n) とおくと階差型にもできる
  • a(n+1)·a(n) = cⁿ 型は対数を取るか、割って a(n+2)/a(n) = c にする

落とし穴

  • 偶数番目の初項 a(2) を求め忘れる
  • a(2m) を求めた後に m = n/2 に戻し忘れる
  • (1 + (−1)ⁿ)/2 と (1 − (−1)ⁿ)/2 の取り違え（n=1 で確かめる）
  • 偶数番目と奇数番目で初項を取り違える／最後に1本にまとめるときの式

なぜ大事か

(−1)ⁿ や a(n+1)+a(n) の形は、nの偶奇で別々の数列に分けると単純になる

東大での出方

単独での難度は低いが、確率漸化式で偶数回と奇数回で状態が入れ替わる設定や、周期2の振動で使う。

確認問題

  • a(1) = 1、a(n+1) = −a(n) + 3 の一般項を偶奇で求めよ（答：奇数で1、偶数で2）
  • Σ[k=1〜n] (−1)ᵏk を n の偶奇で求めよ（答：偶数なら n/2、奇数なら −(n+1)/2）

発展

(1 + (−1)ⁿ)/2 は『偶数なら1、奇数なら0』を返す関数。場合分けの答えを1本の式に書く道具として覚えておく。
