微5 文字定数入りの最大最小（極値の位置と区間で場合分け）

数学III ／ 微分法 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

区間での f(x) の最大最小は、極値と端の値を比べて決まる。f に文字 a が入ると極値をとる x の位置が a で動くので、『極値をとる x が区間の中か外か』で場合を分ける。2次関数の軸と区間の場合分け（「2次関数の最大最小（区間・軸の場合分け）」）と同じ考え方で、最小を問うなら極小点の位置、最大を問うなら極大点の位置と端の値の比較が分かれ目になる。極値と端の値が等しくなる a が、さらに場合の境目になることがある。

こんなときに使う

  • 『0 ≦ x ≦ 1 における f(x) = x³ − 3a²x の最小値を a で表せ』
  • 区間そのものが a ≦ x ≦ a + 1 のように動く
  • 最大値を a の関数 M(a) とみて、さらにその最小値を問う

手順

  1. 1. f′(x) を出し、極値をとる x を a で表す
  2. 2. その x が区間の左・中・右のどこにあるかで場合を分ける
  3. 3. 各場合で増減表を書き、最大・最小の候補（端と極値）を比べる
  4. 4. 極値と端の値が等しくなる a があれば、そこでも場合を分ける
  5. 5. 場合ごとにまとめて答え、境目で値がつながるか確かめる

例題

a > 0 とする。0 ≦ x ≦ 1 における f(x) = x³ − 3a²x の最小値を a で表せ。
解答
  1. f′(x) = 3x² − 3a² = 3(x + a)(x − a)。x ≧ 0 では x = a で極小。
  2. 0 < a < 1 のとき：x = a が区間の中にあり、0 ≦ x ≦ a で減少、a ≦ x ≦ 1 で増加。最小値は f(a) = −2a³。
  3. a ≧ 1 のとき：0 ≦ x ≦ 1 で f′(x) ≦ 0 なので減少。最小値は f(1) = 1 − 3a²。
  4. （a = 1 で −2a³ = 1 − 3a² = −2 となり、境目で値がつながる）
  5. ∴ 0 < a < 1 のとき −2a³、a ≧ 1 のとき 1 − 3a²

別解・ほかの見方

  • 同じ f の最大値は f(0) = 0 と f(1) = 1 − 3a² の比較になり、a = 1/√3 が境目（0 < a < 1/√3 で 1 − 3a²、a ≧ 1/√3 で 0）
  • 区間が a ≦ x ≦ a + 1 のように動くときは、極値をとる x を固定して区間を動かす図を描く
  • 数Ⅲの関数でも同じ。f(x) = x − a log x（1 ≦ x ≦ e）の極小点 x = a の位置で分ける

落とし穴

  • 極値をとる x が区間外なのに、その極値を答えに使う
  • 場合分けの境目（a = 1 など）をどちらの場合にも入れ忘れる
  • 極値をとる x が区間の外にあるのに、その極値を最小値として答える

なぜ大事か

文字が入ると極値をとる x が動くので、それが区間の中か外かで最大・最小の候補が変わる

東大での出方

東大・医学部で『最小値を a で表し、そのグラフを描け』型は頻出。場合分けの境目で両側の式の値が一致するかで検算できる。

発展

最小値 m(a) は a の連続関数になる。境目で両側の式の値が一致しなければ、どこかで計算を誤っている。
