軌跡（動点の条件を式にする）

数学II ／ 図形と方程式 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

軌跡は方程式を出す問題ではなく、点の集合を過不足なく決める問題。図のように、動点Qの軌跡から中点Pの軌跡を求める典型例では、消去後に残る存在条件（実数条件・退化点）を書き忘れないこと。

こんなときに使う

  • 『点Pが〜を満たしながら動くとき、Pの軌跡を求めよ』→ 定石の手順に乗せる
  • 『〜の中点』『〜を m:n に内分する点』→ 元の点を文字で置いて、その条件を使う
  • 媒介変数が入っている → 消去したうえで、その変数の存在条件を残す
  • 『2点からの距離の比が一定』→ アポロニウスの円
  • 条件に『垂直』『距離』が出る → ベクトルや距離の式で書ける

手順

  1. 1. 軌跡上の点を (x, y) と置く（動点と定点で文字を必ず分ける）
  2. 2. 条件に出てくる他の動点を s, t などで置く
  3. 3. 与えられた条件をすべて式に翻訳する
  4. 4. s, t を消去して x, y の関係式を作る
  5. 5. 消去した文字が実数として存在する条件を、x, y の条件として残す
  6. 6. 除外点を調べる（分母が0、2点が一致する、図形が退化する場合）
  7. 7. 十分性を確認する（求めた図形上の点がすべて条件を満たすか）

例題

円 x² + y² = 4 上を点Qが動くとき、定点 A(6, 0) と Q を結ぶ線分 AQ を 1:2 に内分する点Pの軌跡を求めよ。
解答
  1. Q の座標を (s, t) とおくと、Q は円上にあるので s² + t² = 4 …①
  3. P は線分 AQ を 1:2 に内分するので、内分点の公式より
  4. P = ( (2·6 + 1·s)/3 , (2·0 + 1·t)/3 ) = ( (12 + s)/3 , t/3 )
  6. P の座標を (x, y) とおくと
  7. x = (12 + s)/3 　より　 s = 3x - 12
  8. y = t/3 　　　　より　 t = 3y
  10. これを①に代入して
  11. (3x - 12)² + (3y)² = 4
  12. 9(x - 4)² + 9y² = 4
  13. (x - 4)² + y² = 4/9
  15. ∴ 中心 (4, 0)、半径 2/3 の円
  17. 【十分性】逆に、この円上の任意の点 (x, y) に対して s = 3x-12, t = 3y と定めれば
  18. ①を満たす点 Q が存在し、P はその内分点になる。よって除外点はない。
  20. 検算：Q が (2, 0) のとき P = ((12+2)/3, 0) = (14/3, 0)。
  21. 中心 (4,0) からの距離は |14/3 - 4| = 2/3 ○

別解・ほかの見方

  • 媒介変数表示のまま処理する：円上の点を Q(2cosθ, 2sinθ) と置き、θ を消去する
  • 図形的に見る：この問題は A を中心とする相似変換（比 1/3）なので、円が円に写ることが即座に分かる。半径も 2×(1/3)=2/3 と暗算できる
  • ベクトルで処理する：OP = (2/3)OA + (1/3)OQ
  • 複素数平面で処理する。回転が絡む条件のときは、これが圧倒的に短い

落とし穴

  • 消去して方程式が出た時点で終わりにし、実数条件や除外点を落とす（最頻出の失点）
  • 動点 (x, y) と、条件に出てくる別の点を同じ文字で書いて論理が壊れる
  • 十分性（逆の確認）を書かない
  • 分母を払うときに、分母が 0 になる場合を落とす
  • 『軌跡は円』と答えて、中心と半径を書かない
  • 消去して終わりにし、除外点・存在条件を落とす

なぜ大事か

「パラメータを消去し、同時に実数条件を残す」という東大頻出の操作の原型

東大での出方

軌跡が単独で大問になることは少なく、通過領域や面積計算の前段として出る。軌跡を求めさせたあとに、その曲線で囲まれた図形の面積を出させる、あるいは軌跡の存在範囲を問う構成が定番。つまりここでの除外点の扱いが、後半の答えに直結する。

確認問題

  • 放物線 y = x² 上の2点 A(a, a²), B(b, b²) が ab = -1 を満たしながら動くとき、線分ABの中点の軌跡を求めよ
  • 上の問題で、a, b が実数として存在する条件が中点の軌跡にどんな制約を与えるか確かめよ
  • 2点 A(-1,0), B(2,0) からの距離の比が 1:2 である点の軌跡を求めよ

発展

軌跡が『求めた方程式の一部だけ』になる場合。存在条件によって範囲が制限されるケースを意識すると、通過領域の問題に自然に接続する。
