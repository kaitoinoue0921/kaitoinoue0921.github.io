区分求積法

数学III ／ 積分法 ／ 東大での重要度 ★★★★★

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

区分求積法は『和の極限を積分に翻訳する辞書』である。n個の項の和を、幅 1/n の長方形 n 個の面積の和と見れば、n→∞ で曲線の下の面積、すなわち定積分になる。使えるようになる鍵は公式の暗記ではなく、与えられた和を (1/n)·Σ f(k/n) の形に整形する手の動きにある。1/n を括り出せるかどうか、それだけを見ればよい。

こんなときに使う

  • Σ と lim が同時に出てくる → まず区分求積を疑う
  • 和の中に k/n の形が見える、または作れる → 確定
  • 分母が n の1次で、Σ の項数も n → 1/n を括り出せる形
  • Σ の中身が n だけの式で k がない → 区分求積ではない（単なる和の公式）
  • はさみうちで処理しようとして評価がうまく作れない → 区分求積で厳密値が出ないか見る

手順

  1. 1. 和の形を Σ[k=1..n] の形に統一する
  2. 2. 全体から 1/n を括り出す
  3. 3. 残りが k/n だけの式 f(k/n) になっているか確認する（なっていなければ変形する）
  4. 4. lim (1/n)Σ[k=1..n] f(k/n) = ∫[0→1] f(x) dx と書き換える
  5. 5. k の動く範囲と積分区間の対応を確認する（k=1..n なら [0,1]、k=1..2n なら [0,2] など）
  6. 6. 定積分を計算する

例題

lim[n→∞] Σ[k=1..n] n/(n² + k²) を求めよ。
解答
  1. 分母分子を n² で割る：n/(n² + k²) = (1/n) · 1/(1 + (k/n)²)。
  2. よって与式 = lim[n→∞] (1/n) Σ[k=1..n] 1/(1 + (k/n)²)。
  3. f(x) = 1/(1 + x²) とすると、これは f の [0,1] 上の区分求積の形。
  4. = ∫[0→1] dx/(1 + x²)
  5. x = tanθ と置換すると dx = dθ/cos²θ、1 + x² = 1/cos²θ、x: 0→1 のとき θ: 0→π/4。
  6. = ∫[0→π/4] dθ = π/4
  7. ∴ π/4
  8. 検算：各項は正で、n=1 のとき 1/2、項数が増えても和は π/4 ≒ 0.785 に近づく。数値的にも整合する。

別解・ほかの見方

  • はさみうち：区分求積で厳密値が出ない場合、単調性を使って積分で上下から挟む（∫ ≦ Σ ≦ ∫ の形）
  • 積分区間を [0,1] 以外に取る：k が 1 から 2n まで動くなら [0,2]
  • log を取ってから区分求積：積の形の極限（例：(n!/nⁿ)^(1/n)）は log で和に変えると使える。東大の頻出変形
  • 逆向きの利用：積分の値を近似する不等式を作るために、和と積分の大小を比較する

落とし穴

  • 1/n を括り出す整形ができず手が止まる（この単元の失敗はほぼ全てこれ）
  • k の範囲と積分区間の対応を間違える（k=0 から始まるか k=1 からかで区間の端がずれるが、極限では一致することの確認）
  • Σ の中に n が k と独立に残っているのに区分求積を適用してしまう
  • 積の形の極限に log を取らずに直接適用しようとする
  • 1/n を括り出す形に整理できない／k/n の範囲と積分区間の対応ミス

なぜ大事か

Σの極限を積分に翻訳する。東大は「和の極限」を積分で解かせるのが好き

東大での出方

『和の極限』を求めさせる形で頻出。単独では易しいため、不等式評価（はさみうち）と組み合わせて難度を上げてくるのが東大の通例。(1)で不等式を示させ、(2)でその不等式を使って極限を出す誘導が典型。

確認問題

  • lim[n→∞] (1/n) Σ[k=1..n] √(k/n) を求めよ
  • lim[n→∞] (n!/nⁿ)^(1/n) を求めよ（log を取る）

発展

和と積分の大小比較による評価（Σ 1/k と log n の比較）。調和級数の発散速度を押さえると、上位の極限問題が処理できるようになる。
