確3 包除原理（AもBもすべて〜）

数学A ／ 場合の数 ／ 東大での重要度 ★★★★☆

アプリで開く →
進み具合を記録できるアプリ版です（ノード単位の直リンクはありません）

要点

『AもBも起こる』の余事象は『Aが起こらない、またはBが起こらない』で、これは2つの事象の和集合。和集合の大きさは |X∪Y| = |X| + |Y| − |X∩Y| と、重なりを1回引いて直す。3つなら |X∪Y∪Z| = Σ|X| − Σ|X∩Y| + |X∩Y∩Z|。『全部の種類が出る』『空の箱がない』はこの形に必ずなる。

こんなときに使う

  • 『1の目と6の目の両方が出る』『すべての目が出る』
  • 『どの部屋も空でない』『全員に1つ以上配る』（全射の個数）
  • 『2でも3でも5でも割り切れない数』の個数

手順

  1. 1. 求める事象の余事象を『X₁ または X₂ または …』の形に書く（Xᵢ = i 番目の条件が満たされない）
  2. 2. |Xᵢ|、|Xᵢ∩Xⱼ|、… をそれぞれ求める。対称なら1つ求めて個数倍
  3. 3. 包除原理で和集合の大きさを出す（奇数個の共通部分は＋、偶数個は−）
  4. 4. 全体から引く
  5. 5. 小さい値（n = 2 など）で直接数えて確かめる

例題

さいころを3回投げる。1の目と6の目がどちらも少なくとも1回出る確率を求めよ。
解答
  1. X = 『1が出ない』、Y = 『6が出ない』とすると、求める事象の余事象は X∪Y
  2. P(X) = P(Y) = (5/6)³ = 125/216、P(X∩Y) = (4/6)³ = 64/216
  3. P(X∪Y) = 125/216 + 125/216 − 64/216 = 186/216
  4. ∴ 1 − 186/216 = 30/216 = 5/36
  5. 検算：1, 6, もう1つの目 の並べ方を直接数えると、もう1つが 2〜5 なら 4 × 3! = 24、1 か 6 なら 2 × 3 = 6、計 30 通りで一致

別解・ほかの見方

  • n 人を3つの部屋に空き部屋なく入れる：3ⁿ − 3·2ⁿ + 3
  • 1〜N のうち 2, 3, 5 のどれでも割り切れない数：N − (N/2 + N/3 + N/5) + (N/6 + N/10 + N/15) − N/30（ガウス記号付き）
  • 完全順列（誰も自分のプレゼントを受け取らない）も包除原理で出せる

落とし穴

  • 2重に引いた X∩Y を足し戻さない
  • 3つ以上の場合に符号を間違える（3つの共通部分は＋）
  • X を『1が出る』と取り、余事象との対応がずれる
  • 余事象を引くだけで、2重に引いた部分を足し戻さない

なぜ大事か

『1も6も出る』『どの部屋も空でない』は余事象が2つ以上重なる。重なりを足し引きで直す

東大での出方

東大では『すべての〜が出る確率』『どれも空でない』が繰り返し出る。2つまでの包除は暗算レベルにしておく。

確認問題

  • 4人を3つの部屋に空き部屋がないように入れる方法は何通りか（答：36通り）
  • 1〜100 のうち、2, 3, 5 のいずれでも割り切れない数の個数を求めよ（答：26個）

発展

n 人を k 部屋に空き部屋なく入れる数は Σ(−1)ʲ kCj (k − j)ⁿ。これを k! で割ると、区別しない k 組に分ける数（第2種スターリング数）になり、確14 の組分けとつながる。
