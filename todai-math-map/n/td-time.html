150分の運用（大問の選択と撤退の判断）

東大レイヤー ／ メタ技能 ／ 東大での重要度 ★★★★★

要点

東大理系数学は6問150分。ここで理解しておくべきなのは、全問完答は必要ないということである。理三でも4完＋部分点で十分に戦える。したがって本番で問われるのは解く力だけではなく、どれを解きどれを捨てるかの判断でもある。最も多い失敗は、1問に40分を溶かして他が白紙になることで、これは実力の問題ではなく運用の失敗である。時間配分は知識ではなく訓練なので、9月以降に必ず実戦形式で練習しておくこと。

こんなときに使う

  • 開始直後 → まず全6問に目を通す。いきなり第1問から解き始めない
  • 25分経って方針が立たない → 一旦離れる（後で戻る）
  • 完答できそうにない → (1) だけでも解いて部分点を取る
  • 残り15分 → 新しい問題に手を出さず、見直しと書き足しに使う
  • 計算が異常に汚い → 方針が違う可能性を疑う

手順

  1. 1. 0〜5分：全6問を読み、A（すぐ解ける）B（時間をかければ解ける）C（手が出ない）に分類する
  2. 2. 5〜100分：A から順に処理する。1問あたり25分で打ち切り、次へ移る
  3. 3. 100〜135分：残した問題に戻る。または部分点の書き足しに回る
  4. 4. 135〜150分：計算の見直しと、答案の体裁の点検
  5. 5. C に分類した問題も、(1) だけは必ず手をつける

例題

本番の時間配分を、A2問・B2問・C2問と見積もった場合で組み立ててみる。
解答
  1. 【0〜5分】全問を読む
  2. 　第1問 A（確率・見覚えのある型）
  3. 　第2問 C（見たことのない設定）
  4. 　第3問 B（体積・計算が重そう）
  5. 　第4問 A（微分・標準）
  6. 　第5問 B（整数・方針は立ちそう）
  7. 　第6問 C（複素数・条件が複雑）
  9. 【5〜50分】A の2問を確実に取る（1問20分強）
  10. 　ここで確実に2完。焦らず、検算までやる。
  12. 【50〜100分】B の2問に取り組む（1問25分）
  13. 　完答できれば4完。片方が途中で止まっても、そこまでの過程は書き切る。
  15. 【100〜135分】C の2問の (1) に手をつける
  16. 　完答は狙わない。(1) が取れれば十分。手が出なければ、B の見直しに回る。
  18. 【135〜150分】全体の見直し
  19. 　『とおく』の宣言、場合分けの網羅、結論の明示を確認する。
  20. 　計算ミスは別の方法で検算する（同じ計算を繰り返さない）。
  22. 【この配分の考え方】
  23. ・4完＋部分点で理三の水準に届く。6完は狙わない。
  24. ・最も避けたいのは、C に40分かけて A の見直しができないこと。
  25. ・25分で撤退するルールを、模試で必ず一度は試しておくこと。
  26. 　本番で初めてやろうとしても、心理的にできない。

別解・ほかの見方

  • 得意分野から始めて勢いをつける（心理的な効果を重視する場合）
  • 全問の (1) を先に片付けてから (2) 以降に戻る（部分点最大化に振る戦略）
  • 難問を最初に読んでおき、他を解きながら頭の片隅で考えさせる
  • 分野で決め打ちしない（『確率は得意』という思い込みで難問に突っ込まない）

落とし穴

  • 1問に固執して時間を溶かす（最も多い失敗）
  • 試験中に時計を見ない
  • 解けそうにないからと白紙で出す（方針だけでも部分点になり得る）
  • 見直しの時間を確保しない
  • 難易度の見積もりを最初にせず、第1問から順に解く
  • 1問に40分溶かして他が白紙になる

なぜ大事か

6問150分。全問完答は不要。解ける4問を確実に取り切る配分の設計

東大での出方

本番そのもの。過去問演習では答えが合ったかだけでなく、各問に何分かけたかを必ず記録すること。時間の使い方は記録しない限り改善しない。

確認問題

  • 過去問1年分を150分の通しで解き、各問にかけた時間を記録せよ
  • 『25分で撤退』を実際にやってみて、心理的な抵抗の大きさを確認せよ
  • 自分の答案を、方針・計算・記述のどこで失点したかに分類せよ

発展

分野ごとの得点期待値を自分で把握しておくこと。過去問での分野別正答率を記録すると、本番でのA/B/Cの見積もり精度が上がる。見積もりが当たるようになると、運用は一気に安定する。
