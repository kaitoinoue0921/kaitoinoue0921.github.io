Why · 01

なぜ寄付を受け取ることにしたか

広告は入れていませんし、有料の機能もありません。それでもサーバー代と API の利用料は毎月かかっていて、いまは自分の生活費から出しています。

金額そのものより、出ていく一方だと「掲載する地域を増やすか」「機材をもう一台試すか」を決めるときに手が止まる、というのが正直なところです。判断の手前でブレーキがかからないように、受け取れる場所を作りました。

寄付しないまま使い続けてもらって、まったく問題ありません。そちらのほうが普通の使い方です。何かを制限するつもりはないし、寄付した人に見せる特別なものもありません。

Use · 02

何に使うか

作っているものによって、かかっているものが違います。まとめて受け取って、必要なところから使います。

  • スタディスポットMAP

    共有データベースと地図 API の利用料。掲載を栃木県の外へ広げるほど、地図の読み込み回数とデータ量がそのまま増えます。いま増やしているのは長崎です。

  • 東大理三 数学マップ

    サーバー代はほとんどかかっていません。足りないのは時間のほうで、統合解説はまだ 138 ノード中 6 つです。残りを書く時間に充てます。

  • GADGET LOG

    レビューは、実機を買うか借りるかして、使ってから書いています。次に試す機材の購入費とレンタル代に充てます。試せる数が、そのまま記事の数になります。

  • FocusRoom（開発中）

    勉強に集中するための iOS アプリを作っています。まだ配布していません。開発者登録の費用と、部屋の状態を同期するためのデータベースの利用料がかかります。

  • このサイト自体

    GitHub Pages で動いているので、費用はかかっていません。ここは寄付がなくても消えません。

まだ手をつけていない案も、作ったもののページに置いてあります。何を先に作るか迷っているので、そこへの意見はいつでも歓迎です。

Amount · 03

金額の決め方

決済画面は「応援100円ぶん」を何個ぶん、という形になっています。数量がそのまま金額です。

1¥100
10¥1,000
100¥10,000

上限は 10,000 円にしてあります。一度きりの支払いで、継続課金にはなりません。

Notes · 04

先に書いておくこと

  • 対価としてお渡しするものはありません。お礼に何かが届いたり、機能が解放されたりはしません。
  • 継続課金ではありません。次の月から自動で引き落とされる、ということは起きません。
  • 決済は Stripe が処理します。カード番号がこちらに渡ることはありません。
  • 領収書は、決済後に Stripe から届くメールがそのまま使えます。
  • 金額を間違えた、送るつもりがなかった、という場合は下のフォームかメールで連絡してください。返金の相談に応じます。
